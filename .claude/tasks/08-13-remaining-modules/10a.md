# ФАЗА 10A: Game Action Recording

Асинхронная запись действий.

## Ключевые компоненты

- **GameActionService** — BullMQ async processor

## Задачи

1. recordAction():
   - Добавить job в очередь
   - Не блокирует основную логику

2. Processor:
   - Записать в PostgreSQL
   - Retry с exponential backoff
   - Dead letter queue

## Интеграция

В GameStateService.saveState():
```typescript
await this.prisma.gameState.create({...}); // sync
await this.gameActionService.recordAction(gameId, action); // async
await this.gameSubscriptionService.publishGameUpdate(gameId, state);
```

## Edge Cases

- Queue недоступен → DLQ
- PostgreSQL недоступен → retry
- Дубликат → upsert по sequenceNumber
- Job застрял → remove after 1 hour

## BullMQ Config

```typescript
removeOnComplete: { age: 3600 }  // 1 hour
removeOnFail: { age: 86400 }     // 24 hours
attempts: 3
backoff: { type: 'exponential', delay: 1000 }
```

✅ GameActionService
