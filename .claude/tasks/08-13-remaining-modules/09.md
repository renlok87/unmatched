# ФАЗА 9: Presence Module

Presence — онлайн статус игроков.

## Ключевые компоненты

- **PresenceService** — Redis TTL + PubSub

## Задачи

1. PresenceService:
   - `updatePresence(userId, status, gameId)`
   - `getPresence(userId)`
   - `getOnlineUserIds()`

2. Heartbeat mutation:
   - Клиент вызывает каждые 30 сек
   - Обновить lastSeenAt

3. PresenceUpdated subscription:
   - Pub/Sub для cross-instance
   - Filter по userIds

## Redis Structure

```
presence:{userId} → HASH (status, currentGameId, lastSeenAt) TTL 5min
presence:online → ZSET (score = lastSeenAt)
```

## Интеграция

- joinGame → status='ingame'
- leaveGame → status='online'
- Disconnect → TTL auto cleanup

## Edge Cases

- Redis недоступен → логировать, продолжить
- Presence истёк → удалить из online
- Pub/Sub failure → local state

## Результат

✅ PresenceService
✅ Heartbeat mutation
✅ PresenceUpdated subscription
