# ФАЗА 10B: Replay Service

Сжатые реплеи для просмотра игр.

## Ключевые компоненты

- **ReplayService** — build + save + get
- **ReplayCompressorService** — gzip compression

## Задачи

1. buildReplay():
   - Собрать actions из БД
   - Компактный формат (короткие ключи)
   - Метаданные (duration, turns, winner)

2. saveReplay():
   - Сжать через gzip
   - Сохранить в PostgreSQL BYTEA
   - TTL 30 дней (избранные → навсегда)

3. getReplay():
   - Расжать gzip
   - Вернуть ReplayData

## Compact Format

```json
{
  "v": 1,
  "g": "gameId",
  "p": [
    [1, "ATTACK", {"a": "fid1", "t": "fid2"}],
    [2, "DEFENSE", {"c": "cid"}]
  ]
}
```

## Prisma Schema

```prisma
model GameReplay {
  id       String  @id @default(cuid())
  gameId  String  @unique
  data     Bytes   @db.ByteA  // сжато
  duration Int
  turnCount Int
  expiresAt DateTime?
}
```

## TTL Cleanup

Cron каждую ночь → удалить истёкшие (не избранные).

## Edge Cases

- Game не существует → NotFoundException
- Compression failed → сохранить несжатым
- Decompression failed → BadRequestException
