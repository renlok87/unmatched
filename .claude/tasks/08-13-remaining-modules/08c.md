# ФАЗА 8C: Match Confirmation

Двухфазное подтверждение матча.

## Ключевые компоненты

- **MatchConfirmationService** — Redis + BullMQ timeout

## Задачи

1. Двухфазное подтверждение:
   - Создать confirmation (TTL 35 сек)
   - Запланировать timeout job (30 сек)
   - Ожидать accept от обоих

2. Penalty система:
   - Decline → -25 ELO
   - 3 decline за час → temp ban 30 мин
   - Timeout → penalty не принявшим

## Flow

```
Scheduler находит пару
  → Создать PENDING игру
  → createConfirmation()
  → Отправить matchFound subscription
  → Игроки acceptMatch()
  → Оба приняли → startGame
  → Timeout/decline → penalty + cleanup
```

## Edge Cases

- Confirmation истёк → NotFoundException
- Двойной accept → alreadyAccepted
- Server restart → TTL auto cleanup

## Результат

✅ MatchConfirmationService
✅ Two-phase confirmation
✅ Penalty system
✅ Temp ban
