# ФАЗА 8E: Matchmaking Edge Cases

Систематический разбор edge cases.

## Категории

### Queue
- Игрок умирает → TTL cleanup
- Redis restart → Recovery из PostgreSQL
- Дубликаты → zadd перезаписывает

### Scheduler
- Lock не получен → пропустить
- Нечётное количество → один остаётся
- Clock drift → TTL independent

### Confirmation
- Timeout → penalty не принявшим
- Server restart → TTL auto cleanup
- Двойной accept → корректно обработать

### Penalty
- 3 decline за час → temp ban 30 мин
- ELO < 0 → установить в 0
- Temp ban истёк → автоматически снять

### Multi-instance
- Два scheduler → distributed lock
- Confirmation на instance A → Redis shared
- Lock not released → TTL auto-release
