# ФАЗА 11B: Stats Aggregator

ELO расчет и обновление статистики.

## StatsAggregatorService

```typescript
async updateEloRatings(gameId, winnerId, loserId) {
  const [winner, loser] = await Promise.all([
    this.getUserStats(winnerId),
    this.getUserStats(loserId),
  ]);
  
  // ELO formula
  const expectedWinner = 1 / (1 + 10^((loser.elo - winner.elo) / 400));
  const expectedLoser = 1 / (1 + 10^((winner.elo - loser.elo) / 400));
  
  const K = 32;
  const newWinnerElo = Math.round(winner.elo + K * (1 - expectedWinner));
  const newLoserElo = Math.round(loser.elo + K * (0 - expectedLoser));
  
  // Update PostgreSQL
  await prisma.$transaction([
    prisma.userStats.update({
      where: { userId: winnerId },
      data: { currentElo: newWinnerElo, gamesWon: { increment: 1 } }
    }),
    prisma.userStats.update({
      where: { userId: loserId },
      data: { currentElo: newLoserElo, gamesLost: { increment: 1 } }
    }),
  ]);
  
  // Update Redis
  await Promise.all([
    leaderboard.updatePlayerStats(winnerId, newWinnerElo),
    leaderboard.updatePlayerStats(loserId, newLoserElo),
  ]);
}

async applyQueuePenalty(userId, penalty) {
  const stats = await this.getUserStats(userId);
  const newElo = Math.max(0, stats.currentElo + penalty);
  
  await prisma.userStats.update({
    where: { userId },
    data: { currentElo: newElo },
  });
  
  await leaderboard.updatePlayerStats(userId, newElo);
}
```

## Edge Cases

- Stats не существует → создать с default
- ELO < 0 → установить в 0
- Transaction failed → retry
- Redis update failed → логировать, PG имеет приоритет
