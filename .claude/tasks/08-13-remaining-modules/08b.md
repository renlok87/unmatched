# ФАЗА 8B: Matchmaking Scheduler

Scheduler — фоновый процесс поиска матчей.

## Ключевые компоненты

- **MatchmakingSchedulerService** — BullMQ repeating job + distributed lock

## Задачи

1. Реализовать scheduler:
   - Repeating job каждые 5 сек
   - Distributed lock для multi-instance
   - Expanding search window

2. Matching logic:
   - Найти пары с близким ELO
   - Создать PENDING игры

## Expanding Window

```
0-30 сек → ±100 ELO
30-60 сек → ±200 ELO
60-120 сек → ±400 ELO
120+ сек → ±∞
```

## Edge Cases

- Lock не получен → пропустить
- Нечётное количество → один остаётся
- Multi-instance → distributed lock

## Результат

✅ Scheduler реализован
✅ BullMQ repeating job
✅ Distributed lock
