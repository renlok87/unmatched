# ФАЗА 10C: Audit Service

Security audit logging.

## Ключевые компоненты

- **AuditService** — async запись через BullMQ

## Типы событий

### Auth
- USER_REGISTERED, USER_LOGIN, USER_LOGOUT
- LOGIN_FAILED, PASSWORD_CHANGED

### Game
- GAME_CREATED, GAME_ABORTED, GAME_COMPLETED
- PLAYER_KICKED

### Admin
- ADMIN_USER_BANNED, ADMIN_CONTENT_UPDATED

### Security
- SUSPICIOUS_ACTIVITY, RATE_LIMIT_EXCEEDED
- UNAUTHORIZED_ACCESS

## AuditService

```typescript
await auditService.logEvent({
  type: 'USER_LOGIN',
  userId: user.id,
  ipAddress: req.ip,
  userAgent: req.headers['user-agent'],
  metadata: {},
});
```

## GraphQL

```graphql
type AuditLog {
  id: ID!
  type: String!
  userId: ID
  ipAddress: String
  metadata: JSON!
  timestamp: DateTime!
}

extend type Query {
  auditLogs(userId: ID!, startDate: DateTime, endDate: DateTime): [AuditLog!]!
  suspiciousActivity(timeWindow: Int!): [SuspiciousActivity!]! @Admin
}
```

## Интеграция

- AuthService → login/logout
- GameService → created/aborted
- AdminGuard → все действия

## Edge Cases

- Queue недоступен → логировать
- PostgreSQL недоступен → DLQ
- Metadata > 1MB → truncate
