# ФАЗА 11C: Leaderboard API

GraphQL API для лидерборда.

## Queries

```graphql
extend type Query {
  getLeaderboard(
    heroId: ID
    timeFrame: String = "all"  # all, weekly
    page: Int = 0
    pageSize: Int = 50
  ): LeaderboardResponse!
  
  getPlayerRank(userId: ID!, heroId: ID): LeaderboardRank!
}
```

## LeaderboardResolver

```typescript
@Resolver()
export class LeaderboardResolver {
  constructor(
    private leaderboard: LeaderboardService,
    private stats: StatsService,
  ) {}
  
  @Query(() => LeaderboardResponse)
  async getLeaderboard(
    @Args('options') options: LeaderboardOptions,
  ): Promise<LeaderboardResponse> {
    return this.leaderboard.getLeaderboard(options);
  }
  
  @Query(() => LeaderboardRank)
  async getPlayerRank(
    @Args('userId') userId: string,
    @Args('heroId', { nullable: true }) heroId?: string,
  ): Promise<LeaderboardRank> {
    return this.leaderboard.getPlayerRank(userId, heroId);
  }
}
```

## DTO

```typescript
export class LeaderboardOptions {
  heroId?: string;
  timeFrame?: string = 'all';
  page?: number = 0;
  pageSize?: number = 50;
}
```

## Edge Cases

- Hero-specific leaderboard → требует Redis
- Page < 0 или pageSize > 100 → validation error
- Пустой leaderboard → вернуть { entries: [], totalCount: 0 }
