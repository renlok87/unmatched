# ФАЗА 8D: Matchmaking API

GraphQL API для matchmaking.

## Мутации

- `joinQueue(criteria)` — войти в очередь
- `leaveQueue(mode)` — выйти
- `acceptMatch(gameId)` — принять
- `declineMatch(gameId)` — отклонить
- `queueStatus(mode)` — статус

## Подписки

- `matchFound(userId)` — матч найден
- `matchTimeout(gameId)` — timeout/decline

## Edge Cases

- Temp ban → ForbiddenException
- Рейтинг не найден → 1200 default
- Не в confirmation → ForbiddenException
