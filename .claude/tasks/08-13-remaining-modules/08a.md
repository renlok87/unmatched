# ФАЗА 8A: Matchmaking Queue Manager

QueueManager — фундамент матчмейкинга.

## Ключевые компоненты

- **QueueManagerService** — Redis ZSets + PostgreSQL persistence
- **QueueSyncService** — Recovery после Redis restart

## Задачи

1. Реализовать QueueManagerService с методами:
   - `addToQueue()` — O(log N)
   - `removeFromQueue()`
   - `findMatch()` — expanding window
   - `getQueueSize()`, `getUserPosition()`

2. Реализовать QueueSyncService:
   - `syncFromPostgreSQL()` — при startup
   - `cleanupExpiredEntries()` — cron каждые 10 мин

## Edge Cases

- Игрок уже в очереди → upsert
- Redis недоступен → fallback на PostgreSQL
- TTL истёк → auto cleanup
- Zombie entries → удалить

## Результат

✅ QueueManagerService реализован
✅ Persistence Redis + PostgreSQL
✅ Recovery mechanism
