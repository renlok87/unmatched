# ФАЗА 11A: Leaderboard Service

Leaderboard на Redis Sorted Sets.

## Redis Structure

```
leaderboard:overall → ZSET (score = elo, member = userId)
leaderboard:hero:{heroId} → ZSET
leaderboard:weekly → ZSET

leaderboard:meta:{userId} → HASH {
  username, avatarUrl, gamesWon, gamesPlayed
} TTL 3600 (1 час)
```

## LeaderboardService

```typescript
async getLeaderboard(options) {
  const key = this.getLeaderboardKey(heroId, timeFrame);
  const entries = await redis.zrevrange(key, start, end, 'WITHSCORES');
  
  for (i = 0; i < entries.length; i += 2) {
    const meta = await this.getUserMetadata(entries[i]);
    result.push({ rank, userId, elo, ...meta });
  }
  
  return { entries, totalCount, page, pageSize };
}

async updatePlayerStats(userId, stats) {
  const pipe = redis.multi();
  pipe.zadd('leaderboard:overall', stats.currentElo, userId);
  pipe.zadd('leaderboard:weekly', stats.weeklyElo, userId);
  pipe.hset(`leaderboard:meta:${userId}`, {...});
  pipe.exec();
}
```

## Weekly Reset

Cron каждый понедельник в 00:00 → `DEL leaderboard:weekly`

## Edge Cases

- Redis недоступен → fallback на PostgreSQL
- Metadata истёк → загрузить из БД
- Пустой leaderboard → пустой массив

✅ LeaderboardService
