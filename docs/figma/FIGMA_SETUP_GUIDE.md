# 🎨 Настройка Figma для Unmatched Design System

## 📋 Подготовка к работе

### Шаг 1: Включение MCP сервера в Figma

1. **Откройте Figma Desktop App**
   - Убедитесь, что у вас последняя версия Figma
   - Скачайте с [figma.com](https://www.figma.com/download) если нужно

2. **Включите Dev Mode MCP Server**
   ```
   Figma Menu (верхний левый угол)
   → Preferences
   → Advanced (или Dev Mode)
   → Галочка "Enable Dev Mode MCP Server"
   ```

3. **Перезапустите Claude Code**
   - Закройте и откройте Claude Code снова
   - MCP сервер должен появиться в списке доступных серверов

---

### Шаг 2: Создание файла в Figma

1. Откройте Figma
2. Создайте новый файл: `File → New` или `Ctrl+N`
3. Назовите файл: **"Unmatched Design System"**

---

### Шаг 3: Импорт Design System

Выберите один из способов:

#### Способ А: Автоматический (когда MCP сервер подключён)
Используйте команду в Claude Code для создания компонентов

#### Способ Б: Ручной (текущий вариант)
Следуйте инструкциям ниже для создания компонентов вручную

## 🎨 Создание Design System в Figma (Пошагово)

### Часть 1: Local Styles (Цвета)

1. **Создайте страницу "Colors"**
   - Нажмите `+` в нижней панели страниц
   - Назовите её "Colors"

2. **Создайте цветовые swatches**

   Для каждого цвета:
   - Создайте прямоугольник (`Rectangle Tool` или `R`)
   - Размер: 200 × 200 px
   - Установите цвет (Fill)
   - Нажмите `+` в панели右侧 Design → Local Styles → Create new style
   - Назовите стиль по схеме: `Colors/Primary/NAME`

   **Основные цвета:**
   ```
   Rectangle 200×200px → Fill: #FFD700
   Style name: Colors/Primary/Yellow

   Rectangle 200×200px → Fill: #6B4C9A
   Style name: Colors/Primary/Purple

   Rectangle 200×200px → Fill: #DC143C
   Style name: Colors/Primary/Red

   Rectangle 200×200px → Fill: #1E3A8A
   Style name: Colors/Primary/Blue
   ```

   **Нейтральные цвета:**
   ```
   #000000 → Colors/Neutral/Black
   #1F1F1F → Colors/Neutral/Dark Gray
   #808080 → Colors/Neutral/Gray
   #D3D3D3 → Colors/Neutral/Light Gray
   #FFFFFF → Colors/Neutral/White
   ```

   **Семантические цвета:**
   ```
   #FF6B35 → Colors/Semantic/Energy
   #4ECDC4 → Colors/Semantic/Speed
   #95E1D3 → Colors/Semantic/Defense
   #A8DADC → Colors/Semantic/Magic
   ```

3. **Организуйте swatches в сетку**
   - Выровняйте их в 4 колонки
   - Добавьте текстовые подписи под каждым

---

### Часть 2: Local Styles (Типографика)

1. **Создайте страницу "Typography"**
   - Новая страница: "Typography"

2. **Создайте текстовые стили**

   Для каждого размера:
   - Создайте текстовый слой (`Text Tool` или `T`)
   - Введите текст-пример
   - Настройте размер и вес шрифта
   - Нажмите `+` в Design → Local Styles → Create new style
   - Назовите: `Text/SIZE/WEIGHT`

   **Заголовки:**
   ```
   "UNMATCHED" → 40px, Bold (900)
   Style name: Text/3XL/Black

   "ODA NOBUNAGA" → 32px, Bold (700)
   Style name: Text/2XL/Bold

   "ПЕРЕЛОМНЫЙ МОМЕНТ" → 24px, Bold (700)
   Style name: Text/XL/Bold
   ```

   **Основной текст:**
   ```
   "Описание эффекта карты..." → 14px, Regular (400)
   Style name: Text/Base/Regular

   "MS.MARVEL | x3" → 12px, Regular (400)
   Style name: Text/SM/Regular

   "ФРАКЦИЯ" → 10px, Regular (400)
   Style name: Text/XS/Regular
   ```

---

### Часть 3: Компоненты карточек

1. **Создайте страницу "Components"**

2. **Шаблон игровой карты (Action Card)**

   ```
   Шаг 1: Создайте frame
   - Размер: 300 × 420 px
   - Название: "Card/Action"

   Шаг 2: Верхняя зона (иллюстрация)
   - Прямоугольник: 300 × 252 px (60% высоты)
   - Fill: Линейный градиент (#FFD700 → #FFED4E)
   - Создайте компонент: "Card/Action/Top"

   Шаг 3: Иконка фракции
   - Круг: 40 × 40 px
   - Fill: #6B4C9A
   - Центрируйте в круге иконку (звезда или символ)
   - Создайте компонент: "Icon/Faction/Star"

   Шаг 4: Значение карты
   - Круг: 30 × 30 px
   - Fill: #1F1F1F
   - Текст по центру: цифра белым цветом
   - Создайте компонент: "Icon/Value/Circle"

   Шаг 5: Нижняя зона (описание)
   - Прямоугольник: 300 × 168 px (40% высоты)
   - Fill: #1F1F1F
   - Добавьте заголовок (текстовый слой)
   - Добавьте описание (текстовый слой)
   - Создайте компонент: "Card/Action/Bottom"

   Шаг 6: Соберите карту
   - Сгруппируйте все элементы
   - Создайте главный компонент: "Card/Action"
   ```

3. **Шаблон карточки героя (Hero Card)**

   ```
   Шаг 1: Создайте frame
   - Размер: 300 × 420 px
   - Название: "Card/Hero"

   Шаг 2: Верхняя зона (15%)
   - Высота: 63 px
   - Fill: Транспарентный с rgba(0,0,0,0.05)
   - Логотип "UNMATCHED" слева
   - Имя героя справа (вертикальный текст)

   Шаг 3: Центральная зона (60%)
   - Высота: 252 px
   - Эмблема: круг 120 × 120 px
   - Фон: бежево-коричневый градиент
   - Добавьте декоративные элементы (пламя)

   Шаг 4: Нижняя зона (25%)
   - Высота: 105 px
   - Имя героя (крупный текст)
   - Роль/класс (мелкий текст)

   Шаг 5: Соберите карту
   - Сгруппируйте все элементы
   - Создайте главный компонент: "Card/Hero"
   ```

### Часть 4: Иконки и символы

1. **Создайте страницу "Icons"**

2. **Создайте библиотеку иконок**

   Для каждой иконки:
   - Создайте frame: 40 × 40 px или 24 × 24 px
   - Добавьте emoji или нарисуйте иконку
   - Создайте компонент: `Icon/NAME`

   ```

   - Icon/Attack/Sword (⚔️)
   - Icon/Defense/Shield (🛡️)

   - Icon/Fire (🔥)
   - Icon/Speed (💨)
   - Icon/Magic (✨)
   - Icon/Health (❤️)
   ```

## 🔧 Полезные советы

### Совет 1: Используйте Variants
Для создания вариантов карточек:
```
1. Создайте компонент
2. Нажмите "Add variants" в панели右侧
3. Создайте свойства:
   - Type: Action | Defense | Special
   - Faction: Marvel | Witcher | Historical
4. Комбинируйте варианты
```

### Совет 2: Создайте Grid System
```
1. Нажмите "Layout Grid" в панели右侧
2. Добавьте сетку:
   - Columns: 12
   - Width: 20 px
   - Gutter: 8 px
   - Margin: 16 px
3. Примените к основным frame
```

### Совет 3: Используйте Auto Layout
```
1. Выделите элементы карточки
2. Нажмите Shift+A (Auto Layout)
3. Настройте:
   - Direction: Vertical
   - Gap: 0 (для зон карточки)
   - Padding: 16 px
```

### Совет 4: Создайте Component Properties
```
1. Выделите компонент
2. В панели右侧 найдите "Component properties"
3. Добавьте свойства:
   - Instance swap (для иконок)
   - Text (для названий)
   - Boolean (для опциональных элементов)
```

## 📤 Экспорт для использования

### Настройки экспорта

1. **Для печати (карточки)**
   ```
   Format: PDF
   Scale: 3x (300 DPI)
   Size: 900 × 1260 px (300 × 420 mm)
   ```

2. **Для цифрового использования**
   ```
   Format: PNG
   Scale: 2x (Retina)
   Size: 600 × 840 px
   ```

3. **Для веба (аватары)**
   ```
   Format: SVG или PNG
   Scale: 1x
   Size: 150 × 150 px
   ```

### Создание Export Presets

```
1. Выделите компонент
2. В разделе "Export" нажмите "+"
3. Создайте пресеты:
   - Print: PDF @ 3x
   - Digital: PNG @ 2x
   - Web: SVG @ 1x
4. Примените ко всем компонентам
```
