📋 Инструкция по импорту в Figma

  1. Откройте Figma Desktop App или браузер
  2. Создайте новый файл: File → New
  3. Назовите файл: "Unmatched Design System"
  4. Создайте страницы:
    • "01. Colors & Styles"
    • "02. Card Templates"
    • "03. Heroes"
  5. Импортируйте изображения из папки figma-generated/cards
  6. Создайте компоненты на основе шаблонов
