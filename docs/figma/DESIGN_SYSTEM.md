# 🎨 Unmatched Card Game - Design System Specification

> Полная спецификация Design System для создания карточной игры на основе ассетов Unmatched
>
> **Дата создания:** 31 января 2026
> **Источник:** 88 героев из scraped-data
> **Формат карточек:** Вертикальный (стандартный для карточных игр)

---

## 📐 1. Grid System & Размеры

### 1.1 Размеры карточек

| Тип элемента | Размер (px) | Соотношение сторон | Примечание |
|--------------|-------------|--------------------|------------|
| **Игровая карта** | 300 × 420 | 1:1.4 | Стандартный вертикальный формат |
| **Карточка героя** | 300 × 420 | 1:1.4 | Такой же формат, как у игровых карт |
| **Аватар героя** | 150 × 150 | 1:1 | Квадратный формат для UI |
| **Миниатюра** | 100 × 100 | 1:1 | Для иконок и превью |

### 1.2 Зоны карточки (вертикальное деление)

```
┌─────────────────────┐
│   ЗОНА 1: Верхняя   │  15% высоты (≈63px)
│   Иллюстрация       │
├─────────────────────┤
│   ЗОНА 2: Средняя   │  10% высоты (≈42px)
│   Заголовок         │
├─────────────────────┤
│   ЗОНА 3: Нижняя    │  75% высоты (≈315px)
│   Описание + инфо   │
└─────────────────────┘
```

### 1.3 Отступы (Spacing)

| Тип отступа | Значение (px) | Применение |
|------------|---------------|------------|
| `spacing-xs` | 4 | Мелкие элементы внутри блоков |
| `spacing-sm` | 8 | Между мелкими элементами |
| `spacing-md` | 16 | Стандартный отступ между секциями |
| `spacing-lg` | 24 | Крупные блоки |
| `spacing-xl` | 32 | Внешние отступы карточки |

## ✏️ 3. Типографика

### 3.1 Шрифтовая семья

| Категория | Шрифт | Начертание | Применение |
|-----------|-------|------------|------------|
| **Заголовки** | `Impact` / `Arial Black` | Bold (700+) | Названия карт, героев |
| **Подзаголовки** | `Arial` / `Helvetica` | Bold (700) | Секции, типы карт |
| **Основной текст** | `Arial` / `Roboto` | Regular (400) | Описание эффектов |
| **Мелкий текст** | `Arial` / `Helvetica` | Regular (400) | Метаданные, фракции |

### 3.2 Размеры шрифтов (Font Sizes)

| Размер | px | rem | Применение |
|--------|----|-----|------------|
| `text-xs` | 10 | 0.625 | Мелкие метки, фракции |
| `text-sm` | 12 | 0.75 | Второстепенная информация |
| `text-base` | 14 | 0.875 | Основной текст описаний |
| `text-md` | 16 | 1.0 | Подзаголовки |
| `text-lg` | 18 | 1.125 | Крупные подзаголовки |
| `text-xl` | 24 | 1.5 | Заголовки карточек |
| `text-2xl` | 32 | 2.0 | Имена героев |
| `text-3xl` | 40 | 2.5 | Акцентные заголовки |

### 3.3 Веса шрифтов (Font Weights)

| Вес | Значение | Применение |
|-----|----------|------------|
| `font-light` | 300 | Второстепенный текст |
| `font-regular` | 400 | Основной текст |
| `font-medium` | 500 | Подзаголовки |
| `font-bold` | 700 | Заголовки, акценты |
| `font-black` | 900 | Крупные заголовки |

### 3.4 Высота линии (Line Height)

| Тип текста | Значение | Применение |
|-----------|----------|------------|
| `leading-tight` | 1.2 | Заголовки |
| `leading-normal` | 1.5 | Основной текст |
| `leading-relaxed` | 1.75 | Длинные описания |

## 🧩 4. Компоненты

### 4.1 Шаблон игровой карты (Action Card)

```
┌──────────────────────────────────────┐
│  ┌────┐                              │
│  │ ⚔️ │  ИЛЛЮСТРАЦИЯ (75% ширины)    │ ← Зона 1: Верхняя
│  └────┘                              │
├──────────────────────────────────────┤
│  ПЕРЕЛОМНЫЙ МОМЕНТ                   │ ← Зона 2: Заголовок
├──────────────────────────────────────┤
│                                      │
│  ВО ВРЕМЯ БОЯ: Если МИСС МАРВЕЛ      │
│  начала ход на другой ячейке,        │ ← Зона 3: Описание
│  значение этой карты равно 5.        │
│                                      │
│              [2]           MS.MARVEL │
│                           x3        │
└──────────────────────────────────────┘
```

**Элементы:**
- **Иконка фракции** (верхний левый угол) — 40×40px
- **Стоимость карты** (рядом с иконкой) — цифра в круге, 30px диаметр
- **Иллюстрация** (верхняя зона) — занимает 60% высоты
- **Название карты** (средняя зона) — заголовок, `text-xl`, bold
- **Описание эффекта** (нижняя зона) — основной текст, `text-base`
- **Стоимость/Тип** (правый нижний угол) — иконка с цифрой, 40×40px
- **Фракция** (правый нижний угол) — мелкий текст, `text-sm`

### 4.2 Шаблон карточки героя (Hero Card)

```
┌──────────────────────────────────────┐
│  UNMATCHED        織田信長           │ ← Зона 1: Логотип + имя
├──────────────────────────────────────┤
│          ┌─────────┐                 │
│          │  ГЕРБ   │                 │ ← Зона 2: Герб/Символ
│          │  ⚔️     │                 │
│          └─────────┘                 │
├──────────────────────────────────────┤
│       ODA NOBUNAGA  HONOR GUARD      │ ← Зона 3: Имя + роль
└──────────────────────────────────────┘
```

**Элементы:**
- **Логотип Unmatched** (верхний левый) — 80×30px
- **Имя героя на родном языке** (верхний правый) — вертикальная надпись
- **Герб/Символ** (центр) — 100×100px
- **Имя героя** (нижний левый) — `text-2xl`, bold
- **Роль/класс** (нижний правый) — `text-lg`, secondary color

### 4.3 Иконки и символы

| Иконка | Описание | Размер | Применение |

| `icon-faction-star` | Звезда фракции | 40×40px | Идентификация фракции |
| `icon-value-circle` | Круг со значением | 30×30px | Стоимость/сила карты |
| `icon-sword` | Меч/атака | 24×24px | Боевые карты |

## 📐 5. Радиусы и границы

### 5.1 Радиусы скругления (Border Radius)

| Размер | px | Применение |
|--------|---|------------|
| `radius-none` | 0 | Прямоугольные карточки |
| `radius-sm` | 4 | Мелкие элементы, иконки |
| `radius-md` | 8 | Кнопки, небольшие блоки |

| `radius-xl` | 16 | Карточки (если скруглённые) |
| `radius-full` | 50% | Круглые иконки, символы |

### 5.2 Границы (Borders)

| Тип | Толщина (px) | Цвет | Применение |
|-----|-------------|------|------------|
| `border-none` | 0 | — | Без границ |
| `border-thin` | 1 | `neutral-gray` | Разделители |
| `border-medium` | 2 | `primary-color` | Акцентные рамки |
| `border-thick` | 4 | `accent-color` | Выделенные элементы |

## 🌈 6. Эффекты и стили

### 6.1 Тени (Shadows)

| Тип | CSS | Применение |
|-----|-----|------------|
| `shadow-none` | `none` | Без тени |
| `shadow-sm` | `0 1px 2px rgba(0,0,0,0.05)` | Мелкие элементы |
| `shadow-md` | `0 4px 6px rgba(0,0,0,0.1)` | Стандартные карточки |
| `shadow-lg` | `0 10px 15px rgba(0,0,0,0.15)` |Raised элементы |
| `shadow-xl` | `0 20px 25px rgba(0,0,0,0.2)` | Модальные окна |

### 6.2 Эффекты движения (Motion Effects)

Для динамических иллюстраций (как на аватарах боксёров):
- **Размытие** (blur): `2px` для фоновых элементов
- **Линии движения**: диагональные штрихи, `stroke-width: 2px`
- **Дублирование**: 2-3 копии героя с прозрачностью `0.3-0.5`

## 🔧 9. Рекомендации по реализации в Figma

### 9.1 Структура файла

```
📁 Unmatched Design System
├── 📁 01. Colors & Styles
│   ├── 🎨 Color Palette
│   ├── ✏️ Typography
│   └── 📐 Grid & Spacing

└── 📁 04. Assets
    ├── 🖼️ Illustrations
    ├── 📝 Text Content
    └── 🎭 Hero Avatars
```

### 9.2 Шаги создания

1. **Создайте локальные стили**
   - Цвета (Local Styles → Colors)
   - Шрифты (Local Styles → Text)
   - Эффекты (Local Styles → Effects)

2. **Создайте компоненты**
   - Шаблон карты (Component)
   - Иконки фракций (Components)
   - Символы значений (Components)

3. **Импортируйте ассеты**
   - Загрузите все изображения из `scraped-data/images`
   - Организуйте по героям и типам

4. **Создайте примеры**
   - Соберите 3-5 карточек разных героев
   - Проверьте консистентность дизайна

## 📦 10. Экспорт и использование

### 10.1 Форматы экспорта

| Элемент | Форматы | DPI/Разрешение |
|---------|---------|----------------|
| Карточки для печати | PDF, PNG (300 DPI) | 300×420 mm |
| Аватары для UI | PNG, SVG (72 DPI) | 150×150 px |
| Иконки | SVG (вектор) | 24×24, 40×40 px |

### 10.2 Нейминг компонентов

Используйте префиксы для организации:
- `C/` — Components (например, `C/Card/Action`)
- `I/` — Icons (например, `I/Faction/Star`)
- `H/` — Heroes (например, `H/OdaNobunaga`)
- `S/` — Styles (например, `S/Color/Primary`)
