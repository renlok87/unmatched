# 🎨 Как создать плагин в Figma

## Пошаговая инструкция

### Шаг 1: Откройте Figma

Запустите **Figma Desktop App** или откройте https://www.figma.com

---

### Шаг 2: Создайте новый плагин

1. Нажмите в меню: **Figma** → **Plugins** → **Development**
2. Выберите **"New plugin..."**
3. Введите имя плагина: **Unmatched Design System**
4. Нажмите **"Save as"** и сохраните в любую папку

---

### Шаг 3: Выберите тип плагина

При создании выберите:
- ✅ **"Figma Design"** (для создания дизайна)

---

### Шаг 4: Замените код плагина

1. После создания откроется редактор кода
2. **Удалите весь код** в файле `main.ts`
3. **Скопируйте код** из файла `UnmatchedDesignSystem.ts`
4. **Вставьте** в редактор плагина

---

### Шаг 5: Запустите плагин

1. В Figma создайте **новый файл** (Ctrl+N)
2. Нажмите: **Plugins** → **Development** → **Unmatched Design System**
3. Готово! 🎉

## ❓ Проблемы?

**Плагин не запускается:**
- Убедитесь, что выбрали "Figma Design" при создании
- Проверьте, что скопировали весь код

**Нет папки figma-export:**
- Запустите: `python figma_exporter.py` для создания файлов

**Код не копируется:**
- Откройте файл в VS Code
- Выделите весь код (Ctrl+A)
- Скопируйте (Ctrl+C)
- Вставьте в плагин (Ctrl+V)
