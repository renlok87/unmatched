# Art Tuner: внесённые сохранения

Сюда `tools/art/art_tuner_fold.py` переносит блоки `S08ArtTuner.overrides.json`, которые он внёс в
`unreal/Unmatched/Config/ArtBoards/S08ArtBoardProfiles.json`: `<время UTC>-<доска>.overrides.json` — какие значения
выбрал пользователь в панели (путь, новое значение, старое) и когда они попали в профиль. Файлы не редактируются.
См. [tools/art/ART-TUNER.md](../../../tools/art/ART-TUNER.md).
