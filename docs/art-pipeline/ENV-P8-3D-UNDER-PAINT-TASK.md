| # | Симптом в кадре | Корень (с указанием на код/данные) | Что меняем в P8 |

## 1. Цель и критерии приёмки (измеримые)

Сцена Sarpedon по умолчанию: вокруг настоящего поля карты стоит **3D-остров**, повторяющий силуэты и цвета концепта
`sarpedon-v2`, освещённый **только** светом движка; поверх — анимированные детали.

Гейты (все обязательны; измеряются на эталоне рендера, виды `Fitx1.45`, `K1`, `K1x0.65`, `K2x1.6` центр и на Медузе):

| # | Критерий | Как измерить | Порог |
|---|---|---|---|
| G1 | Освещение едино: без света движка окружение тёмное | Бенч-кадр с `-ArtPreviewLightsOff` (новый флаг: ключ, точки и skylight в 0) | средняя яркость окружения < 12 % от освещённого кадра (у P7c плита светит сама: ~100 %) |
| G2 | Тени между слоями | ROI под передним краем рамы и под фигурой Медузы на K2x1.6: яркость в тени / рядом | ≤ 0,75; щели под рамой нет (нет полосы < 8 яркости шириной > 2 px вдоль пяты рамы) |
| G3 | Силуэты и параллакс | Виды K2x1.6 центр/Медуза: смещение ориентиров борта/руин/частокола между K1 и K2 совпадает с 3D-ожиданием (не C0-проекцией): `anisoP99` растяжения текселей ≤ 1,3; `smearShare_aniso>2` = 0 | по `proto_views.py`-метрикам на новых мешах |
| G4 | Соответствие концепту на виде C0 | `Fitx1.45` vs `sarpedon-v2` вне поля карты: SSIM по кварт-разрешению ≥ 0,55 (P7c: 0,63 к плите ×2, 0,48 к концепту при unlit); ΔE76 крупных пятен (вода, песок, лес, борт) медиана ≤ 6 | иначе — подгонка света/альбедо, не «поверх» |
| G5 | Читаемость карты | `zone_separation.py`, `measure.py` | map Y 106,6 ± 5; min adjacent zone ΔE76 ≥ 23,2 (в пике мерцания); warm share ≥ 0,12; ring ΔL* ≥ 30 |
| G6 | Детали в масштабе рисунка | площадь свечения стекла фонарей на C0 ≥ 80 % нарисованной (P7c 40–45 %); знамя висит вертикально, длина ≥ 90 % нарисованной (325 uu) | по кропам C0 |
| G7 | Движение | live-прогон 15 с, доля изменившихся пикселей по ROI: листва ≥ 3 %, море ≥ 5 %, водопад ≥ 10 %, костры ≥ 10 %, знамя ≥ 5 %; свет брaзиера модулирует скалу (ROI у жаровни: std яркости по времени ≥ 1,5) | `live-diff` как в P7c |
| G8 | Производительность | packaged `render_bench.py`, 3 повтора | Sarpedon K1 ≤ 3,5 мс GPU (P5c 2,62; P7c 2,08), K2x1.6 ≤ 3,8; треугольников окружения ≤ 450k инстансных; Cobble ±0,05 |
| G9 | Регрессии | Marmoreal default = P5c (|diff| ≤ 0,4, px>24 ≤ 0,02 %); Cobble бит-в-бит; вариант `p5c` жив; `-EnvLayoutVariant=user` не тронут; тесты UE все, pytest все | как в P7c |
| G10 | Чистота | концепт и производные вне git (ENV-U3/U7); NoAI не в кадрах ИИ; свет ключа не изменён; `render-reference.json` не изменён | ревью |

**Критерий провала и откат.** Если после одного полного прохода P8 (включая одну итерацию подгонки) не выполнены
G1–G4 или G8, либо пользователь при просмотре говорит «не помогло», Sarpedon возвращается к обычной 3D-сцене:
в `S08ArtBoardProfiles.json` блок `conceptPaste` → `"default": "off"` (вариант `p5c` становится видом по умолчанию),
P8-ассеты остаются доступны по флагу `-ConceptPaste`. Это одна строка профиля плюс перегенерация кадров.

## 2. Архитектура решения

```
A. Настоящее (без изменений): карта, рама frame-002, фигуры, HUD, подсветка ходов
B. 3D-остров (НОВОЕ, lit):          C. Дальний план:
   B1 рельеф острова + обрывы          C1 море: SM_Env_S_SeaRing + M_EnvSea graph 2 (lit, волны) — возвращаем из P5c
   B2 корабль: борт, фальшборт, палуба C2 небо/облака: цилиндр с плитой sea-sky (unlit) + дрейф UV
   B3 руины форта + арка               D. Свет: ключ (−55,30,0) + moon-pool + 5 точек (2 костра, 3 фонаря) = 6
   B4 частокол + канаты                E. Детали/анимация: фонари, костры, пушки, знамя, листва, водопад, прибой,
   B5 лес: деревья/кусты (Fab)             светлячки, искры, дым
   B6 скалы/валуны по кромке
   B7 бухта: песок, сваи, лодка, коряги
   B8 бочки, ящики, канаты
```

**Принцип текстурирования.** Для каждого меша слоя B альбедо берётся проекцией из камеры C0 плиты **без света**
(см. §4.1), запекается в UV-атлас меша (Blender). Грани, невидимые из C0, получают CC0-текстуру того же материала
(Rock058 / Planks023A / Moss002 / Ground055S — уже в проекте, `ground-params.json`) с подгонкой цвета под соседнее
альбедо. Нормали — от геометрии (низкополигональной, с фасками) плюс мягкая детальная нормаль из яркости альбедо
(height-from-luma, сила ≤ 0,3). Шероховатость 0,85–0,95, металл 0. AO запекается Cycles (как у задней стены
Marmoreal: `backwall_build.py`).

**Принцип света.** Плита de-lit не содержит теней и пятен от фонарей. Свет движка: ключ (не трогаем), skylight,
moon-pool, 5 точек по позициям `design.json 5_elements` (fire-fort, fire-brazier, lantern-left, lantern-deck-n,
lantern-deck-se), все точки без теней (бюджет), крупные массы острова `castShadow=true` под ключом. Lumen GI
включён для острова (`bAffectDynamicIndirectLighting=true`) — это и даёт «связность» с фигурами; контролируется
гейтом G5.

**Принцип геометрии.** Низкополигональные меши с читаемыми силуэтами, ≤ 40k треугольников на крупный модуль,
≤ 12k на проп, фаски 1–2 uu на рёбрах (мягкие блики под ключом), без Nanite, без коллизий. Пивоты и контракт
UM_FBX_v1 как у lane K (`k_blender.MeshBuilder`).

## 5. Риски и как их гасим

| # | Риск | Мера |
|---|---|---|
| R1 | De-lit через imagegen оставит часть теней/пятен | Два прохода: «flat lighting» + локальная проверка: разница между delit и clean в зонах фонарей ≥ 20 уровней; при остатках — второй проход только по зонам (inpaint) |
| R2 | Smuggler's Cove фотореалистичен и тяжёл | Децимация до ≤ 40k, альбедо только из плиты (фотореал-текстуры пака не используются), roughness 0,9; если не читается — путь B2-запасной (`SM_Env_Hull`) |
| R3 | Высота моря: P5c кольцо на z −172, обрывы концепта до −300 | Остров строится до −300, кольцо опускаем до −300 (параметр `ground.sea.loc`), водопад удлиняем (`dropUU`) — один параметр в раскладке |
| R4 | Lumen GI от яркого песка/огня «сдвинет» яркость карты | Гейт G5 после каждой итерации; при сдвиге > 3 — `bAffectDynamicIndirectLighting=false` для плато, оставить на обрывах |
| R5 | Тени ключа от острова/деревьев лягут на клетки | `layout_check` правило 7 (тень ключа не на круге) распространить на новые меши; деревья ближе 60 uu к раме — `castShadow=false` |
| R6 | Невидимые из C0 грани (тыл корабля, низ обрывов) выглядят иначе | Fallback CC0 с подгонкой цвета + проверка кропов K2 на швы; при заметном шве — imagegen-доплита для этих граней (в рамках разрешения) |
| R7 | Производительность: тени от крупных масс + Lumen | Гейт G8; при превышении — тени только у острова и корабля, деревья без теней; `r.Lumen` без изменений |
| R8 | Fab-паки не скачаются (Launcher/логин) | Для каждого элемента есть запасной источник в §3 (кит Tripo + Blender) |
| R9 | Стиль «фотореалистичных» паков выбьется | Альбедо везде из плиты; геометрия паков — только форма |
