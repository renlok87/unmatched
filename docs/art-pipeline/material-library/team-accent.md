# TeamAccent — маска акцентов цвета команды (все герои)

Дата: 2026-09-29. Статус: **предложено** (раскладка и правила); по героям — «измерено» в Blender, в UE не проверено.

Решение пользователя (AskUserQuestion 2026-09-29, выбран вариант «Акценты + кольцо (Recommended)»): герой остаётся в
цветах концепта; цвет команды — на кольце/подставке и на **акцентах**: кайма, пояс/кушак, подкладка, лента.
Читаемость команды держит кольцо + форма подставки (5b-R). TeamAccent — это маска этих акцентов на атласе фигуры.

## 1. Раскладка (общая для всех героев)

| Что | Значение |
|---|---|
| Файл | `<run>/textures/2k/T_<Hero>_<Iter>LD_TeamAccent.png` (рантайм 2K, коммитится), 4K-мастер локально; у героев с плоской раскладкой прогона (Merlin, Arthur) — `<run>/textures/T_<Hero>_<Iter>LD_TeamAccent_2K.png` (+ `_4K` локально) |
| Формат | 8 бит, один канал (PNG `L`), **линейный**: UE `TC_Grayscale`, sRGB выкл., мипы обычные (маска фильтруется) |
| Значение | 0 — цвет концепта, 1 — полный краситель команды; мягкий край 3 × 3 тексела 4K |
| UV | UV0 атласа, тот же, что у BC/N/ORM/MatID |
| Гаттер | значение ближайшего покрытого тексела (как у остальных карт) |
| Классы | ненулевые значения только на классах с `teamDyeAllowed` (ткань, кожа снаряжения, перья); металлы, камень, дерево — всегда 0 (правило 5c-A: металл не красится); кожа персонажа и `horn_claw` (диэлектрики — части тела, `teamDyeAllowed` = false; `horn_claw` — не металл, metallic 0) — тоже всегда 0 |
| Площадь | 5–12 % площади фигуры (по 3D-площади, не по текселям), читается с K2 5× |

Формула красителя — та же, что у `M_UM_Figure_v2` сейчас (`um_v2_core.hlsl`):
`dyed = lerp(BC · Team, Team · Y(BC) · TeamDyeGain, TeamDye)`, `BC = lerp(BC, dyed, TeamAccent · teamDyeAllowed(класс))`.
Рекомендуемые параметры MI: `TeamDye 1`, `TeamDyeGain` — по герою (записан в отчёте ld-maps героя): его выбирают так,
чтобы медиана окрашенного альбедо акцента была ≈ 0,8 × TeamColor, а 95-й перцентиль ≤ 0,9 (альбедо в пределах 0,02–0,9).

**Подключение в UE (следующий этап).** Мастер v2 уже умножает `TeamMaskTexture.R` на `teamDyeAllowed` класса, поэтому
отдельного входа не нужно: в MI v2 героя `TeamMaskTexture = T_<Hero>_…LD_TeamAccent`. Палитра — активная
`c11_value_split_proposal` из `art/um-materials/um-masters.json`: P1 `#E8C06A`, P2 `#5A7F9F`.

**Прежний TeamMask (W4-B) — deprecated.** Он красил всю одежду (у Harpy — все тёмные маховые, 14–16 % фигуры), что
противоречит решению «акценты». Файл `T_<Hero>_…_TeamMask.png` в прогонах look-dev остаётся побайтной копией предыдущей
итерации только для совместимости с MI v1; новые MI его не используют.

## 2. Герои

### Harpy (ASSET-HARPY-001, H3 look-dev v2)

Прогон: `art/pipeline-candidates/ASSET-HARPY-001/20260929-h3-lookdev/`, профиль `build-profiles/harpy-h3-lookdev.json`,
отчёт [harpy-lookdev-v2.md](../harpy-lookdev-v2.md). Одежды нет, поэтому акцент — «лента» на браслете и кайма маховых:

| Акцент | Правило (стадия `ld_maps`, `h2_bake_harpy/lookdev_maps.py`) | Площадь фигуры |
|---|---|---|
| **Кончики маховых** по контуру крыла | тёмные маховые (маска W4-B H3: v ≤ 0,22) × расстояние до фронтального (XZ) силуэта фигуры ≤ 2,5 см в исходном кадре = **1,6 см** в игровом масштабе, мягкий край 4 мм; только части крыльев 0/1/3/7 | 5,94 % |
| **Вставка-шнур браслета** | центральная половина высоты браслета (`tripo_part_13`, z 0,1507–0,1662 м исходного кадра); класс `leather_smooth` (тёмная кожа, окрашиваемая), золотые ободки — `gold_antique` и не красятся | 0,24 % |
| **Итого** | | **6,19 %** |

- Перья остаются в цветах концепта: вне акцента BC = H3.
- Тон шнура без красителя — тёмная кожа (медиана Y = медиане акцента крыла), поэтому один `TeamDyeGain` даёт шнуру и
  кайме крыла одинаковый цвет команды. `TeamDyeGain` Harpy = **40** (медиана Y акцента 0,020, p95 0,027).
- Видимость на K2 5× (свет Cobble, азимут 0): краситель меняет 14,7 % (P1) / 14,2 % (P2) пикселей тела; азимут 40 —
  6 504 / 11 067 пикселей. Кадры: `20260929-h3-lookdev/preview/ld_sheet_k2_cobble.jpg`, `ld_sheet_talons_cobble.jpg`.
- Прежний TeamMask (все тёмные маховые, 15,9 % фигуры) — побайтная копия H3, deprecated.
- Когти (`horn_claw`) и золотые ободки не красятся. Когти — диэлектрик (кератин, ORM.B = 0; до исправления 2026-09-29
  ORM.B когтей ошибочно был 1 из-за слота `brass`, см. harpy-lookdev-v2.md §9 — на TeamAccent это не влияло).

### King Arthur (ASSET-KING-ARTHUR-001, H2.2 look-dev v2)

Прогон: `art/pipeline-candidates/ASSET-KING-ARTHUR-001/20260929-h2-lookdev/`, профиль
`build-profiles/king-arthur-h2-lookdev.json`, отчёт [king-arthur-lookdev-v2.md](../king-arthur-lookdev-v2.md). Файл
маски: `textures/T_KingArthur_H2LD_TeamAccent_2K.png` (L8, линейный); та же маска лежит в
`T_KingArthur_H2LD_TeamMaskRGBA_2K.png` канал B (R — прежний TeamMask, G — полоса подставки, A — EdgeMask).

Плащ и табард остаются **красными**, золотая вышивка и каймы не красятся (класс `silk`, `teamDyeAllowed` = 0). Цвет
команды получают узкая внутренняя полоса ткани вдоль золотых кайм **плаща** и пояс. Табард (передняя панель, главный цвет
героя) акцента **не несёт** (ред. 2, 2026-09-29):

| Акцент | Правило (стадия `ld_maps`, `h2_bake_arthur/lookdev_maps.py`) | Площадь фигуры |
|---|---|---|
| **Внутренняя полоса кайм плаща** (`tripo_part_0`) | красная ткань (вес зоны `cloth` × вес красного цвета, мягкие) в пределах **14 мм** (игровой масштаб; 22,8 мм в кадре Tripo) 3D-расстояния от тексела золотой каймы. Кайма — 8-связная компонента вышивки ≥ 2000 текселей 4K (подол и края плаща: 10 компонент, 45 тыс. текселей; мелкие мотивы не считаются). Нормаль тексела каймы должна смотреть так же (скалярное произведение ≥ 0,3): изнанка ткани не считается. Край мягкий, smoothstep 2 мм | 4,70 % |
| **Пояс** | зона `belt` — кожаный пояс торса (класс `leather_worn`); львиная пряжка и заклёпки — золото-металл, остаются вне маски | 0,76 % |
| Табард (`tripo_part_5`) | **не красится**: его красное поле между каймами на груди всего ~25–30 мм, нижняя панель с узлом — сама крупная компонента вышивки. Ред. 1 (полоса 10 мм и на табарде) перекрашивала 60–70 % его красного — дефект ревью | 0 |
| **Итого** | мягкий край — нормированный гаусс σ 1 тексел 4K (≈ 3 × 3), затем умножение на вес красимых зон: на металле, коже лица, волосах, камне, вышивке и воротниковой подкладке маска = 0 (проверено по ядрам зон, 8 бит) | **5,53 %** |

- Проверки «главный цвет не красится» — **по частям**, не в среднем по всей ткани (среднее в ред. 1 скрыло табард):
  доля текселей ядра красной ткани с акцентом ≥ 0,5 — плащ 9,1 %, табард 0 % (порог ≤ 20 % на часть); в кадре — доля
  красного на пикселях табарда (ID-кадр `tabard`) с P1 / P2 ≥ 0,8 × без красителя: 1,00 (ред. 1: 0,29–0,76).
  Для других героев правило то же: у каждой крупной детали главного цвета — своя проверка.
- Экран K2 (свет ≈ Cobble с якорем W4-A 131): доля акцента от пикселей фигуры без подставки — 2,8 % спереди (5×, азимут
  0; пояс и края плаща), 1,3 % на азимуте −40, 15,9 % сзади (5×: вертикальные каймы и подол плаща), 1,5–2,7 % на 1,6×.
  Спереди команду держат кольцо/форма подставки 5b-R, акцент — подтверждение.
- Контраст (CIELAB, K2 5× и 1,6×): акцент против соседней красной ткани ΔE 33,6–46,4, P1 против P2 ΔE 37,7–46,9.
- `TeamDyeGain` Arthur = **12** (по правилу выше: медиана Y акцента 0,040, p95 0,091; ограничило условие p95 ≤ 0,9 —
  медиана окрашенного альбедо ≈ 0,48 × TeamColor; ред. 1 — 11,5). С прежним значением 5,5 акцент P1 на тёмно-красной
  ткани читался хаки-оливковым. Записано в `reports/ld-tone-report.json` → `team_dye_gain` и в `reports/ld-lut.json` →
  `mi_parameters`.
- Прежний TeamMask (плащ, табард, подкладка ворота — вся красная ткань) — побайтная копия канала R H2.2 (2K сверено),
  deprecated.
- Кадры: `20260929-h2-lookdev/preview/ld_k2_5x_cobble.jpg`, `ld_k2_1p6_cobble.jpg`, `ld_closeups.jpg`,
  `ld_id_masks.jpg` (зоны, акцент, маска табарда), атлас маски — `ld_teamaccent_1K.png`.
