# Ростер по наборам: план 3D-моделей героев (2026-10-21)

Решение пользователя 2026-10-21, дословно: «Хорошо, использую Opus High вместо Z-код для приемщика. Вот, и продолжай без
меня, делай все сам. Касательно сетов тоже и 3D модели героев.» Это слово пользователя на пачку больше пилотной
(SKILL.md §1, §11): модели героев идут набор за набором скиллом `3d-model-pipeline`, без вопросов пользователю.
Стоп остаётся только по деньгам и паролям (§5 класс 1).

## Порядок

Принципы порядка:
- сначала дособрать противостояния, у которых один герой уже есть;
- затем наборы, где только гуманоиды;
- фигуры, которым нужен новый контракт рига (не-гуманоиды, §3), — в конце, после решения «rig-contract/3».

Помощники, сделанные этим скиллом, идут вместе со своим героем. В пачке не больше 3–4 фигур одновременно: одна вкладка
Tripo, не больше двух прогонов Blender, один редактор UE на героя (§11.2). Порядок внутри волны выбирает оркестратор.

## Правила для всех волн

- **Приёмщики.** Первый — «Opus xhigh». Второй, «другим профилем» (полоса 8,0–8,4), — «Opus high» (решение
  пользователя выше; AGENTS.md «AI tools and side models»). Z-Code баллов не ставит.
- **Изображения.**
  - Gemini — по SKILL.md §0.
  - Gemini не рисует реальных людей (отказ на Bruce Lee). Для героев-людей (Bruce Lee, Muhammad Ali, Houdini,
    Tesla, Shakespeare, Oda, Tomoe и т.п.) путь подбирает оркестратор: Tripo Image, SYNTX, другие разрешённые
    сервисы. Каждый вывод — строкой F в NOTES.
- **Итог фигуры.** Игровая фигура H2LD в игре на обеих досках (этап 7b) и витринная хайполи по AGENTS.md «Hero showcase
  high-poly». Слепое ревью «было/стало» делают два независимых Opus.
- **Играбельность.** В ростер комнаты (`S08FlowGameModeUmRoom.cpp`) герой попадает, только когда:
  - готовы фигура и витрина;
  - на бэкенде есть его способности (`ABILITY_CONFIGS` или обработчик);
  - пройден плейтест-партия на обеих досках.
- **Упаковка.** Одна упаковка на волну, после 7b всех фигур волны. Затем повторная проверка на пакете, как в ночь на
  21.10 (`docs/game-design/evidence/PLAYTEST-2026-10-21-night/README.md`).
- **Рабочий стол.** Computer Use (Gemini, Tripo в Chrome) — только одна сессия за раз. Отказ пользователя в окне
  разрешения — стоп до его ответа.
