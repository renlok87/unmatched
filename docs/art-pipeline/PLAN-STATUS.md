## Коротко: что сделано иначе, чем планировалось

- **Medusa ушла с v3.1 на H2.** v3 получила решение «доработать v3.1»; v3.1a прошла пороги Blender (T1.2), но UE-проверка T4.1 не выполнялась. Вместо неё сделан проход качества героев: paintover-концепты Codex → Tripo «по частям» (ультра 2M) → bake high→low → H2.1 → H2LD на мастере `M_UM_Figure_v2.1`. В игре до флага 5c-B0 по-прежнему Medusa v2 (`/Game/ArtPreview/Medusa`).
- **Герои начаты до GD-058, и дважды.** План этапа 3 (T7.1) запрещал героев без решения пользователя, журнал кредитов (`tripo.stage3Plan.heroesHarpy`) числил их «ждут решения пользователя». Фактически серия v1 (HEROES-V1, коммиты `de252a25` и `6c994bd0`) начата 2026-09-28 в 14:32 по разрешению пользователя 2026-09-28 «можно на полную использовать лимиты для триппо и синтакс» (`limitNote` журнала): Tripo H3.1 → Blender UM_FBX_v1 → UE через CLI, 610 кредитов. 2026-09-29 по делегированию «делай все без меня» её заменил проход H2/H3, и Arthur, Merlin и Harpy доведены до «технически импортировано» (H2LD/H3LD → look-dev C); v1 помечена `superseded`. В бэклоге ART-006…008 переведены в `in_progress`, зависимость от GD-058 оставлена: приёмка всё равно после gate.
- **Клипы — через rig v2 и H2Anim.** Контракт рига v1 заменён v2 (`UM_HUMANOID_17_v2`, лицо +X). 16 клипов авторены ретаргетом в headless Blender по видео-референсам SYNTX/Kling, а не через сервис video-to-motion; Tripo-авториг отклонён. В S08 проигрывания анимаций не было вовсе — это новая задача ART-013.
- **TeamColor — «акценты + кольцо».** W4-B и look-dev A красили ткань целиком; по решению пользователя краска идёт только по маске TeamAccent (мастер v2.1, look-dev C), команды различаются ещё и кольцом 5b-R (палитра C-11 золото / серебро-синий). `MI_Medusa_P1/P2` (пастельная ткань, решение D-2 волны 5b-R) этому противоречат — ART-015.
- **Рендер DX12/SM6 + Lumen, эталон High.** Решение пользователя 2026-09-28; все прежние редакторные кадры без отпечатка RENDER для приёмки не годятся.
- **Карты — арт-фикстуры** Sherwood Forest 8×5 и T. Rex Paddock 7×5 (вариант (а) плана), не правила.
- **Доски Medusa × King Arthur — оригинальные карты.** Поправка D-03 (решение пользователя 2026-09-30, ENV-U0…U3): Marmoreal и Sarpedon на общем каменном подносе, игра по графу пространств, 3D-окружение по периметру; Cobble — регрессионная доска. Трек ENV-MAPS P0–P6 закрыт 2026-10-01 (раздел ниже); художественная приёмка — GD-058, решение пользователя. **ENV-U15 (2026-10-01):** Marmoreal принят словом пользователя (акт не оформлен); Sarpedon не принят → вклейка концепта (P7), настоящий 3D-остров под de-lit живописью (P8, режим `lit3d` по умолчанию), правки сцены (P9) — раздел «Sarpedon после ENV-U15».
- **Подсветка героев — акцент, а не основной свет.** P9 добавил на всех досках key + rim на Lighting Channel 1; ревью «сильно пересвечены» → P9b: ключ со стороны луны, подставки не освещаются, прирост фигуры +13–28 % вместо +88–152 %.

Анимация значков сделана данными (контракт `icon-motion.json`), а не ассетами UMG: один контракт играют эталон Python и UE.
