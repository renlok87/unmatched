## Почему

- Выбор мышью уже в коде: `ClickCapsule` (QueryOnly, `ECC_Visibility`) строится актором бойца (`S08FighterActor.cpp:91–97, 219–246`); клетки — невидимые инстансы с QueryOnly (`S08BoardActor.cpp:51–64`); клики — `GetHitResultUnderCursor(ECC_Visibility)`. Арт-меши и декор — NoCollision.
- Legacy-импорт SK игнорирует `UCP_` внутри skeletal FBX (измерено S05, AD-OPEN-44); пайплайн для static сам вызывает `remove_collisions` (legacy по умолчанию генерирует коллизию), SK импортируются без PhysicsAsset. Требование 04 и карточек ART-006..011 делать `UCX_`/`UCP_` в Blender — лишняя работа, которую импорт не использует.
- Размер капсулы берётся из **таблицы габаритов** (строки карточек 04: Ø36×60, Ø26×48, Ø36×62, Ø28×54 uu), а не из bounds меша: меч, посох и крылья раздувают bounds, а клип Lunge может выйти за них (G21 критика).
- ART-001 прошёл с `UCX_`/`UCP_`-мешем — это история проверочного набора, её строки остаются как есть.
