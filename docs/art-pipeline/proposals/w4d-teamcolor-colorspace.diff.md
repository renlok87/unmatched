## Суть

- **AD-CNF-58 закрыт решением пользователя: вариант (b).** Цвет команды — на подставке и кольце (С-11) и на одежде фигуры по маске `TeamMask` (плащ, накидка, ткань; не кожа, не лицо, не оружие). Полный multiply всей фигуры (текущая Medusa T4/ArtPreview) — нет. Q-304 (сами цвета #E8C06A / #9FC2D8) остаётся открытым.
- Параметризация (меморандум §1 п.4, дефолт оркестратора): мастер `M_UM_Figure` и `M_UM_BaseMarker`, Custom Primitive Data 0–3 — TeamColor, 4 — InstanceIndex, 5–8 — FxFlash, 9–10 — Rim, 11 — Fade; команда задаётся во время игры из данных бойца, не выбором MI по пути.
- Каждому герою нужна `TeamMask` (выход стадии atlas; у Arthur маска HSV уже строится, у Merlin/Harpy/Medusa — нет), ≈ 0,5–1 дня на ассет (оценка меморандума).
- **AD-OPEN-39 закрыт дефолтом:** палитра хранится hex sRGB; в параметры MI, CPD, профиля света и токенов HUD цвет попадает только через `FLinearColor::FromSRGBColor` (для hex — `FColor::FromHex`), прямое `hex/255` в `FLinearColor` запрещено; скрипты мастера/MI/профиля и валидаторы это проверяют. Проверочная таблица: `python tools/s08/hud_contract/hud_contract.py linear`.
- **Пример в 17 AD-OPEN-39 сохраняется как есть.** Он сравнивает `#3D7BDB`/255 = 0,24 / 0,48 / 0,86 со значением, которое S05 реально записал в `MI_S05_ZoneBlue`, — (0,18, 0,36, 0,70) (`tools/s05/s05_import_scene.py:417`; то же измерение — строки 492, 628, 1818 в 17, ИЗМЕРЕНО). Предложение только добавляет справку: по кривой sRGB `#3D7BDB` даёт linear 0,047 / 0,198 / 0,708 (`hud_contract.hex_to_linear`, юнит-тест); ни hex/255, ни значение MI из S05 с ним не совпадают.
