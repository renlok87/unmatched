| лицо в кадре экспорта смотрит в +X (UE) | нормаль лица (0.685, 0.032, −0.081), 1 374 полигона |

Повторный прогон `ld_maps` + `ld_fbx` в другой каталог дал **те же байты** у всех 18 файлов `textures/` и `export/`
(`reports/determinism-report.json`).

**UV1.** Для каждого острова UV0: `UV1 = (UV0 − центр bbox острова) × s`, где `s = √(площадь 3D / площадь UV0)`
(метры на единицу UV). Поворота и зеркала нет, поэтому касательный базис UV1 совпадает с UV0 (мастер v2 всё равно
строит свой по производным). Метров на единицу UV: тело 1.068, лук 0.712, подставка 2.374.

## 3. Классы (MatID)

Классы строятся по маскам H2.1 и сразу переназначаются на пресеты библиотеки. Используются маски `part_ids`,
`metal_mask` и вес ткани (TeamMask.R W4-B), HSV запечённого BC и 3D-ворота карты положений. Правила идут по порядку
(`classes.rules` профиля):

| Класс (индекс) | Доля атласа | Зоны |
|---|---|---|
| `linen` (10) + TeamColor | 38.7 % | платье и накидка (часть 0, вес ткани ≥ 0.5) |
| `gold_antique` (4) | 18.0 % | маска металла H2.1: диадема, серьги, наручи, пояс, кайма, поножи, накладки лука, обоймы колчана |
| `skin` (13) | 13.2 % | руки, бёдра, кулак; по цвету (v ≥ 0.45, s ≤ 0.36, тон 10–45°) лицо, шея, грудь, пальцы ног, кисть на луке |
| `legacy_bake` (0) | 9.2 % | змеи, волосы, глаза, губы (классов «чешуя» и «волосы» в v1 нет) |
| `stone_base` (14) | 7.6 % | подставка |
| `leather_smooth` (7) | 6.6 % | ремень колчана, кожа пояса (часть 0 вне ткани и металла), тело колчана, подошвы |
| `wood` (15) | 5.0 % | лук вне золота (тёмные филёнки, тетива), стрелы над колчаном (полуплоскость H2.1, обратная сторона) |
| `leather_worn` (8) | 1.8 % | **ремни сандалий**: металл частей 4/5 ниже z 0.104 м и частей 14–16 |

- Мелкие компоненты (< 48 текселей 4K) получают класс соседей, кроме золота: тонкие линии каймы настоящие.
- Гаттер: метка ближайшего соседа на 16 px (4K).
- 2K — мажоритарный выбор в блоке 2 × 2. Декодирование `floor(v / 16)` совпадает с метками на каждом текселе.
- Ремни сандалий в H2.1 были золотом. В концепте это коричневая кожа, поэтому BC и roughness взяты из запечённого
  Tripo до прохода металла (128 531 текселей 4K), metallic 0. Золотые заклёпки на ремнях потеряны (остаток §6).
- `ORM.B` сделан бинарным по классу: 255 у золота, 0 у диэлектриков. В H2.1 у дерева лука и колчана под размытой
  маской металла было до 176/255.
- **TeamMask.R** обнулён вне класса ткани. Проверка `team_mask_only_on_cloth_classes`: максимум вне ткани = 0.

## 4. Тона классов по концепту (замер)

**Как мерили** (`ld_preview` + `ld_measure`):

- Кадры: орто-виды front/side/back, выставленные как концепты (prompts.md), студийный свет H2.1, Cycles, AgX.
- Зоны: проход ID классов (эмиссия MatID, Closest, 1 сэмпл). Модель и концепт совпадают не пиксель в пиксель (лук,
  подставка), поэтому для пикселей концепта берётся маска класса (дилатация или эрозия) **и** цветовые ворота материала
  (`measure.concept_gates`). Ворота откалиброваны по точкам концепта: пояс h29 s0.54, ремень h21 s0.56,
  бедро h30 s0.20 v0.74, платье h9 s0.20 v0.14, подставка h12 s0.14 v0.27.
- Медианы считаются по трём видам вместе.
- Экспозиция: у концепта свой свет. Коэффициент k = Y(концепт) / Y(кадр) взят по платью, k = 0.838 (§5, решение LDD-4).

**Как подгоняли.** Множитель класса (линейный, по каналам) = (концепт / k) / кадр H2LD. Сделано 2–3 итерации,
множители записаны в профиль (`grade.gains`: iter1, iter2, iter3). Сборка детерминирована и не зависит от кадров.

У тёмных классов медиана не опускается ниже 1.2 × пола яркости пресета, то есть 0.024. Низ яркости сжимается «носком»
`f(Y) = lo + Y²/(4·lo)` при Y < 2·lo: вариация полостей сохраняется, а не срезается на пол. Змеи (класс 0) грейдятся по
воротам оттенка 38–110°, так что губы, брови и волосы того же класса не темнеют.

Итог: медианы sRGB. Y/k — яркость относительно концепта после экспозиции (1.0 = как в концепте).

- **Кожа персонажа.** Стала тёплой слоновой костью: оттенок +3.8°, насыщенность 0.144 → 0.190. Альбедо — медиана
  линейного BC (0.445, 0.319, 0.231) → (0.645, 0.413, 0.238).
- **Золото.** Стало античным: темнее на треть, желтее. F0 героя в LUT — (0.863, 0.451, 0.198), Y 0.52 ≥ 0.45, вместо
  табличного (1.0, 0.766, 0.336).
- **Змеи.** Из светлого шалфея стали тёмной оливой, как в концепте.
- **Платье.** Альбедо почти не менялось: тон 5° → 10.9°, яркость в норме. «Серое/светлое» платье в UE — это
  specular 0.5 на тёмном альбедо. v2 даёт ему Cloth: specular 0.4 × (1 − 0.7), sheen в цвет ткани (приближение в
  Blender, `st_lookdev.lut_material`). В кадре H2.1 → H2LD яркость платья упала с 1.24 до 1.00.
- **Камень, дерево, ремни.** Упираются в физический пол альбедо (Y 0.02, правило ALBEDO) и остаются светлее концепта
  в 1.2–1.6 раза. Остаток — это свет концепта (подставка в тени), а не альбедо (решение LDD-5).

## 5. LUT героя

`T_UM_MatLUT_Medusa.dds` — пресеты v1 плюс переопределения `T_UM_MatLUT_Medusa.overrides.json`:

- `bc` — медиана BC класса после подгонки. Для диэлектриков это справка (режим bake-clamped читает текстуру), для
  золота — F0 героя.
- `ymedClassHero` (строка 8) — медиана яркости BC в классе. Золото 0.522, кожа 0.449, лён 0.033, камень 0.027, кожа
  ремней 0.029, дерево 0.027.

Остальные строки — пресеты как есть: Cloth у льна (0.7, specular 0.4, sheen 0.2/0.3/0.5), износ, tilesPerMeter
(512-тайлы ÷ 2). Blender прочитал ту же LUT (EXR, записанный из DDS) без расхождений: `max_abs_diff 0.0`.

## 6. Маска рёбер

`Edge` — выпуклость рельефа из запечённой нормали high-poly:

- кривизна = div(n.xy) / (метров на тексель острова), соседи через границу острова не считаются;
- отображение smoothstep(150, 600) 1/м, то есть радиус 6.7 мм → 0, 1.7 мм → 1;
- 9.4 % атласа ≥ 0.5; среднее у золота 0.22, у камня 0.01.

Рёбра формы low-poly в нормали не записаны — это ограничение.

## 7. Остатки и что проверить в UE

- В UE ничего не импортировано. Сравнение с концептом сделано в Blender: студийный свет, Principled как приближение v2,
  без тайлов деталей. Замер под светом доски на High/DX12/Lumen — задача UE-волны. Эталон — концепт.
- Камень, дерево и ремни светлее концепта в 1.2–1.6 раза: мешает пол альбедо 0.02. Если в UE подставка всё ещё
  светлая, крутить свет, cavityDarken и roughness камня в LUT, а не альбедо ниже пола.
- Золотые заклёпки ремней сандалий стали кожей. Вернуть их можно отдельным правилом по яркости в зоне ремней.
- Змеи, волосы, глаза, губы — `legacy_bake`: у змей нет класса «чешуя», у волос — класса «волосы» (v1.1).
- Формат LUT у Merlin (LD-merlin-blender) — EXR 16 × 8, Ymed в строке 7.R. У Medusa — формат мастера v2
  (`build_ue_inputs.py`, DDS 16 × 16, Ymed в строке 8). Это нужно свести к одному формату (решение LDD-6).
