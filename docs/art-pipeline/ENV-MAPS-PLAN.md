## 1. Что строим

Для пары Medusa (+3 Harpy) × King Arthur (+Merlin) — две доски:

```
ночной фон/туман ─ 3D-окружение по периметру (тема карты, стиль концепта)
                   ┌───────────────────────────────────────┐
                   │ оригинал карты 1337×866, плоско        │ ← подсветка клеток по кругам
                   │ (круги, линии, ромбы стартов, арт)     │   из данных топологии
                   └───────────────────────────────────────┘
                   каменная подложка SM_TableBase (одна на обе карты)
```

- Игра идёт по графу оригинала: Marmoreal 31 клетка / 42 связи, Sarpedon 38 / 61; старты 1 и 2.
- Окружение — только по периметру (ENV-U1), тема из иллюстрации карты (ENV-U2):
  Marmoreal — ночной сад мраморного дворца (аркада, балюстрады, лампы, цветущие деревья);
  Sarpedon — ночная бухта (лес с частоколом и валунами, берег/река, борт пиратского корабля с
  пушками, бочками, фонарями).
- Изображения карт и производные текстуры — вне git (ENV-U3), в git — скрипты, sha256, числа.

## 2. Решения оркестратора (в рамках ENV-U0…U3; пользователь может переиграть)

## 3. Треки и оценка

Часы — инженерные/агентские, диапазон. «MVP» — обе карты играбельны по графу, оригинал на
подносе, окружение по периметру уровня MVP, живые прогоны и кадры для приёмки.

| Трек | Содержание | MVP, ч | Полный, ч |
| --- | --- | --- | --- |

## 4. Порядок и календарь

Параллельно идёт основная сессия (до ~00:30): до ~21:00 UE-редакторы закрыты, тяжёлого GPU нет.

| Фаза | Когда | Что | Выход / гейт |
| --- | --- | --- | --- |
| **P0** | сейчас → 21:00 | D; B (unit-тесты; postgres-спеки — когда поднят Docker); S-подготовка в Python (BC 4K, SDF/ID/маска); E0 концепты; Tripo только после выбора концепта | Фикстуры топологии в git; бэкенд ходит по графу; текстуры готовы; концепты у пользователя |
| **P1** | после 21:00 **и** после гейта ENV-O7 | U, R, S (UE-часть), T1; первые K1-кадры обеих карт на заглушке подноса; perf-гейт | Кадры K1 → пользователю (не блокирует); замер GPU |
| **P2** | следующая сессия | E (MVP) по картам: Sarpedon → Marmoreal; T2 | Кадры K1–K3 по картам, статусы ассетов |
| **P3** | после P2 | Живые packaged-прогоны, K1–K3, финальная приёмка GD-058 с пользователем; P1/P2 окружения | Вердикт; «художественно принято» — только словом пользователя |

Ориентир по календарю при оркестрации workflow-агентами: MVP — 3–4 рабочих сессии, полный — 5–7.
Это прогноз, не замер.

## 5. Риски

| Риск | Мера |
| --- | --- |
| Размытость 1337×866 при зуме 1,6× | Векторный игровой слой поверх; AI-апскейл — по кадрам K3 и с разрешения |
| Ночной грейд портит различимость зон (Marmoreal blue/violet ΔE 14 под луной) | Маска игрового слоя: подъём unlit 35–50 %; тёплые пятна света не центрировать на мультизонах; проверка «без цвета» |
| Манхэттен остаётся где-то в движке/клиенте | Одна функция соседства + guard-тест + регресс Cobble бит-в-бит |
| Конфликт с незакоммиченной 5c-B2 | Гейт ENV-O7; до него — только бэкенд, Python, 2D |
| GPU: доска ×1,7 площади + окружение + Lumen | Perf-гейт до производства периметра, бюджеты на карту |
| Материалы: лимит CC0 почти выбран (22/≈25 наборов, 434/500 МБ) | Нужны доски, трава/мох, песок, вода, листва, кора, мощение — расширение лимита или imagegen/процедурные (вопрос пользователю) |
| Изображения вне git → другой checkout без текстур | Скрипт импорта + проверка sha256 в сборке |
