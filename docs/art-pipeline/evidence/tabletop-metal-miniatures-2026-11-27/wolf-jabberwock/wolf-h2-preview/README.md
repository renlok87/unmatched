# Волк и Бармаглот H2 на обеих досках

Волк собран из новой геометрии Tripo на утверждённом 18-костном риге. При повторном чтении Unreal Engine 5.9 подтвердил 43 928 треугольников, сатиновое серебро, командные ободки и 60 ключей контрольного движения. На обоих кадрах Волк использует синий P2, Бармаглот — золотой P1. Волк занимает 80% диаметра клетки. После локальной правки четырёх подошв все 237 отсчётов прошли проверку опор. Максимальное смещение закреплённой лапы — 0,000775 единицы Unreal. Максимальный радиус модели — 33,59977 при пределе 33,6. Корень остался на месте, финальная поза вернулась к исходной.
