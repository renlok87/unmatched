# Калибровка Z-Code как второго приёмщика — итог (2026-10-20)

Задача (сессия-оркестратор, по делегированию пользователя 2026-10-20): прогнать Z-Code на уже принятом листе или
карточке King Arthur / Medusa и сравнить с баллами Opus; при расхождении больше 1 балла или если GLM не справится с
кадрами — вторым приёмщиком пачки ставить Opus `second-acceptor`.

Исполнитель: приложение Z-Code (Computer Use / Windows-MCP), проект `unmached`, модель **GLM-5.3-Flash** (в ответе
модель назвала себя `account:zai-individual-coding-plan/GLM-5.3-Flash`), режим «Ask before changes». Кадры модель
открывала сама инструментом Read из папки `in/` (вложений в поле ввода не понадобилось); `IMAGES_SEEN: yes`.

| Прогон | Эталон | Z-Code GLM-5.3-Flash | Расхождение |
|---|---|---|---|
| C1 — слепое сравнение витрин King Arthur / Medusa, раунд `blind-s2/r3` (X = очищенный исходник Tripo, Y = H2LD) | Opus max (`docs/game-design/select-screens/blind-s2/r3-REVIEW.md`): X 7 / 7 / 5 / 6,5 / 7 (сред. 6,5), Y 6 / 5,5 / 7,5 / 4,5 / 6 (сред. 5,9), **WINNER X**; Astra в паре раундов того же сравнения — тоже исходник | X 7 / 7 / 6 / 8 / 7 (сред. 7,0), Y 8 / 8 / 8 / 7 / 8 (сред. 7,8), **WINNER Y, clear** | победитель противоположный; по Y +1,9 балла в среднем; дефекты X (8) Z-Code ставит выше Opus (6,5), а «лишний стержень за плечом» находит у Y |
| C2 — повтор принятого листа 1c Ancient Leshen по рубрике concept-sheet §11 | Opus `card-2.json` S 2 / C 1,5 / Q 1,5 / P 1,5 = **8,1**; Sol `card.json` 1,5 / 1,5 / 2 / 1,5 = **8,1** | S 2 / C 2 / Q 2 / P 2 = **10,0** (`card-zcode.json`) | **+1,9 балла** к обоим эталонам; ни одного замечания, хотя оба эталона снимали C и P |

Ещё: `card-zcode.json` — невалидный JSON (лишняя `}` в конце; `json.loads` → «Extra data»), строгой схемы Z-Code не
держит — карточку пришлось бы чинить руками, а скилл запрещает править карточку приёмщика.

**Вывод.** Калибровка не пройдена: расхождение больше 1 балла (C2: 10,0 против 8,1) и противоположный победитель в
слепом сравнении (C1). GLM-5.3-Flash кадры видит и описывает предметно, но оценивает мягко (всё «2» на листе, где два
независимых приёмщика нашли расхождения видов и палитры). По правилу задачи второй приёмщик мини-пачки — **Opus
`second-acceptor`** (свежий контекст; `finish_second.py` ставит `--same-profile-ok`). Z-Code остаётся побочной моделью
для текста (ревью промптов, второе мнение) и для описания кадров без балла.

Время: C1 ≈ 6 мин (≈ 5 мин «Thought»), C2 ≈ 6 мин; каждая запись файла ждёт подтверждения «Allow» в окне Z-Code
(режим «Ask before changes»).
