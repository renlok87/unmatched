## Что сделать

Этап 2 скилла (`.agents/skills/3d-model-pipeline/SKILL.md` §6 «Этап 2», `references/tripo3d-stages.md` §1, §5.1,
§5.4, §5.5, §6, §7, §9; HANDBOOK §3.2 п.3).

- Входы — принятые виды 1c: `art/imagegen/concept-<content-key>-codex/<content-key>-{front,side,back}.png`. До клика —
  sha256 входов против всех `<ASSET_ID>/source-specs/*.json`; `generation-request init` с
  `--primary-source tripo-pending`, затем `prepare-generation --dry-run`.
- Слоты: FRONT = front, слот `SIDE_VIEW` из заявки = side (по умолчанию LEFT), BACK = back, второй боковой пуст (§5.5).
- Операции на одной задаче: «HD модель» из нескольких видов, H3.1, приватность вкл., «по частям» Баланс, ультра-сетка
  2M, треугольники, без текстуры (60) → текстура 8K, «Удалить освещение» **вкл.** (сбрасывается при каждой загрузке
  формы — проверить крупно перед кликом) (30) → PBR (5). Страница текстуры — `/workspace/texture/<uuid>`, не
  `/texture-edit/` (Волшебная кисть).
- Перед каждой операцией: `python tools/art/visual/ledger.py check --service Tripo --next-cost <цена с кнопки>
  --balance <баланс>` (код 0). После — баланс из шапки и строка журнала сразу (через `post_h2.py` или `ledger.py add
  --task <VISUAL_CARD_ID>`).
