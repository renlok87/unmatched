## Находки процесса (Claude in Chrome)

- Выгрузка из диалога «Экспорт» срабатывает **только от клика по координатам**; клик по ref или из JS даёт запрос
  `export-lite` без файла, а неудачная попытка без жеста включает блок «нескольких загрузок» вкладки. Координаты
  считать заново по свежему снимку: окно меняет размер (1400 ↔ 1435 по ширине кадра).
- Загрузка приходит в Downloads через 2–60 с; уход со страницы раньше её отменяет — ждать файл, потом переходить.
- Закрытие первой вкладки группы (созданной `createIfEmpty`) распускает группу, остальные вкладки выпадают из неё и
  становятся недоступны агенту: закрывать вкладки в обратном порядке, первую — последней. В этом прогоне две вкладки
  Studio остались вне группы (открыты страницы `704977ba` и `77db66fe`) — их можно закрыть руками.
- Форма HD модели после эксперимента — как была: HD Model, по частям, Balanced, 8K выкл., Private, H3.1. Умная сетка
  возвращена к Quad / одна цена 5 000 / 4 генерации / P2.0; её приватность Studio сама держит «Sharing Only».
