### 2.2. Документ `docs/unreal/contracts/hud/HUD-AND-ICONS.md`

Язык — русский, кодировка UTF-8, переводы строк LF. Разделы документа:

1. **Архитектура HUD:** гибрид UMG, слои, панели и экраны, состояния, ввод, токены, тексты RU/EN, доступность,
   бюджет.
2. **Решение по наработкам** — по §1 этого задания.
3. **Реестр всех значков**, одна строка на значок:
   - id и назначение;
   - состояние V-xx или экран;
   - форма, цвет и токен, шрифт, размеры;
   - источник и где используется;
   - проверка в градациях серого и контраст;
   - решение: оставить / перерисовать / заменить;
   - статус.
4. **Трассировка** к MS-R / MS-AT (`docs/game-design/move-selection/06-test-and-acceptance.md`) и к задачам
   бэклога.
5. **Задачи и пробелы:**
   - векторная перерисовка глифов замка, часов, метки и цепи (сейчас это Segoe UI Symbol);
   - проверка при 720p (MS-R-30);
   - долг HUD.

**Требование пользователя.** Макеты и значки строятся только на реальных данных: карты, герои и карты колод из
бэкенда и админки (админка `http://localhost:5480`, бэкенд `:3000`). ImageGen-сцены с выдуманными досками и
фигурками недопустимы: пользователь их уже отклонил.

### 2.3. Адверсариальное ревью

Ревью запускается через Workflow с агентами `agent(prompt, { model: 'fable', effort: 'xhigh' })`. Три линзы:
- **(а)** документ против кода, данных и токенов;
- **(б)** несостыковки и граничные случаи: масштаб интерфейса 75–150 %, 720p, серый режим, конфликт с цветами
  зон и команд, локализация;
- **(в)** соответствие языку реальных карт и арт-дирекшну (`docs/game-design/03-art-direction.md`, решения от
  2026-09-28 и 2026-09-29), включая обоснованность решений «оставить / перерисовать / заменить».

Порядок работы:
1. Ревьюеры только находят замечания.
2. Каждое замечание проверить и исправить документ.
3. Записать журнал ревью `docs/unreal/contracts/hud/HUD-AND-ICONS-review-log.md` в виде таблицы:
   замечание → исправлено / отклонено с причиной.
4. Одна итерация ревью и одна итерация исправлений.

### 2.4. Доработка в ImageGen внутри Codex

Шаг выполняется, только если после ревью нет блокеров. Это доработка изображений, не кода. Путь: приложение
«ChatGPT» → вкладка Codex → проект unmached, через computer use; приложение уже разрешено.

1. Написать бриф `docs/unreal/contracts/hud/IMAGEGEN-BRIEF-icons.md`, только по значкам с решением
   «перерисовать».
   - Для каждого значка: что исправить и точный промпт.
   - Фон прозрачный или ровный, стиль — единые плоские иконки как на картах.
   - Референсы:
     - лист MS-C-09;
     - исходные PNG значков из `card_icons.py`;
     - реальные RU-карты из `scraped-data/images/decks/` (сопоставление — в
       `art/imagegen/mvp-v1/reused-cardart.json`).
   - Критерии приёмки:
     - значок читается при 24–32 px;
     - значки различаются в градациях серого;
     - палитра и формы — как в v2;
     - на значке нет букв, кроме цифр.
   - Выход: `art/imagegen/hud-icons-v2/<id>.png`, папка `prompts/`, `manifest.json`.
2. Отправить задачу в новый чат Codex с условиями:
   - писать файлы по абсолютному пути в основной checkout;
   - без пробелов в начале имён файлов (в прошлый раз была такая ошибка);
   - без git-операций.
3. Пока сессия идёт, проверять готовые файлы по критериям. Не прошедшие вернуть Codex с конкретными правками.
4. В конце собрать лист сравнения «было (v2 `card_icons.py` / mvp-v1) → стало».

  основной БД, затем выполнить `node tools/db/sync-dev-stands.cjs sync --apply`.
