## 2. Принципы (из методички «Мультики кодом» и STYLE-v3 §7)

1. **Один источник правды.** Всё движение описано данными: контракт `icon-motion.json` (дорожки и ключи). По нему
   рисует эталон Python и играет UE — одни и те же числа, проверка паритета тестом.
2. **Всё — функция времени t.** Поза значка = f(анимация, t). Случайности нет, повторный прогон даёт тот же кадр до
   пикселя. Часы инъецируемые: тест и съёмка задают t.
3. **Раскадровка до кода.** Для каждого значка таблица «состояние / событие → что двигается / мс / кривая / удар /
   reduced motion».
4. **Один удар на цикл.** Время удара — константа (на неё позже вешается звук, ±40 мс).
5. **Первый кадр не пустой, последний — постер.** Конец появления = мастер; в покое значок неподвижен.
6. **Самопроверка по листам кадров**, потом один агент-критик (один проход ревью — решение пользователя).
7. **Чего не берём из методички:** «на двойках», кипящие линии, штриховка. Это рисованный мультфильм, а HUD — 60 fps
   и читаемость 16–24 px (UI-ACC-005).
8. **Reduced motion** — у каждой анимации своя ветка: только прозрачность ≤ 100 мс или статичный кадр; циклы стоят.
   Исключение — спиннер: индикатор прогресса, ступени по 250 мс без промежуточных кадров (записано в контракте и
   тесте `test_reduced_motion_is_opacity_only_and_short`).
9. **Бюджет:** HUD ≤ 0,5 мс GT; ≤ 3 одновременно циклящих значка (STYLE §7); только RenderTransform и прозрачность
   слоёв и подмена кадра текстуры. Без материалов, если без них можно.

## 5. Решения, принятые сразу

- **Контракт в `docs/`, копия в `Config/`.** UE читает `Config/S08IconMotion.json` (попадает в pak). Копию делает
  скрипт, pytest сверяет хэш. Ловушка упаковки (новый `Config/**.json` → перегенерация makefile, AGENTS.md) учтена.
- **Новый класс виджета, без WBP.** Нативный `UUserWidget` с деревом из кода, как `US08ArtIconWidget`. Редакторский
  ассет не нужен, значит нет и ручной работы в редакторе.
- **Песок часов — подмена кадра текстуры** (8 кадров уровня песка из Python), а не материал. Дёшево, совпадает с
  эталоном до пикселя. Переворот — поворот слоя глифа.
- **Reduced motion — минимальный флаг сейчас** (`-S08ReducedMotion`, CVar `s08.ReducedMotion`). Настройку в меню
  (`US08UserSettings`) делает MS-T-16; флаг станет её источником.
- **Slate-HUD партии не трогаю.** Анимированные значки живут в UMG-слое, который не пересобирается каждое событие.
- **Цифры** («+N», порядок, HP) рисует игра текстом; «тап» при смене числа анимирует значок, а не цифру.

## 6. Риски

| Риск | Что делаю |
|---|---|
| Масштаб > 1 размывает текстуру точного размера без мипов | **принят**: перелёт 1,04 / 1,25 длится ≤ 100 мс, эталон делает то же; проверено кадрами галереи 32 и 64 px (средняя \|Δ\| 0,81 / 0,45). Шаг текстуры вверх не делался |
| Расхождение Python ↔ UE (кривые, pivot, порядок трансформаций) | эталонные позы из Python в JSON, автотест сравнивает с точностью 1e-3 |
| Стоимость 23 тикающих виджетов | тик только у активных анимаций; в покое тик выключен; замер в галерее |
| Пересборка редактора при чужой сессии в UE | редактор и клиенты сейчас не запущены; worktree других сессий не трогаю |
| Нет реальных состояний V-xx в игре | галерея показывает каждую анимацию; API для MS-T описан; проверка в живой игре — только жетон цели |
