# Сообщение для другой LLM

Прикрепи `GDD-BRIEF-FOR-LLM-RU.md` и отправь текст ниже. Документацию из `docs/backend-api/` прикладывай отдельно только если у этой LLM её ещё нет. Для локального агента достаточно доступа к проекту.

---

Я хочу сделать игровое приложение на Unreal Engine, а модели подготовить в Blender. У меня уже есть веб-проект игры, сервер игровой логики и веб-админка. Документация бэкенда уже подготовлена; не нужно составлять её заново.

Используй приложенный `GDD-BRIEF-FOR-LLM-RU.md` как задание. Помоги мне получить заполненный дизайн-пакет для агента, который затем реализует игру: GDD, спецификацию экранов и ввода, художественное направление, индивидуальные задания на модели Blender, таблицы ассетов и эффектов, этапы первой версии и критерии приёмки.

Возьми на себя рутинную работу: извлечение фактов из имеющихся материалов, заполнение таблиц, описание всех состояний интерфейса, поиск противоречий и связывание требований с задачами. От меня нужны решения о желаемой игре, стиле и приоритетах. Не проси меня вручную переписывать API или каталог контента.

Начни с 5–7 вопросов, которые определяют первую версию. Для сложных вопросов предложи 2–3 понятных варианта и объясни последствия. По мере моих ответов заполняй документы; не останавливайся на выдаче пустого шаблона.

Отделяй подтверждённые факты, мои решения, свои предложения и открытые вопросы. Не считай весь каталог контента полностью рабочим только по наличию записей в базе. Не объявляй старые планы Unreal реализованными функциями. При расхождении желаемого поведения с сервером предложи решение и отдельную задачу.

Итог должен позволить разработчику и художнику одинаково понять, что создавать, как проверять результат и что входит в первую законченную версию.
