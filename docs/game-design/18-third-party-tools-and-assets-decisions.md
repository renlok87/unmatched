# 18. Решения по сторонним инструментам и ассетам

Дата: 2026-09-27. Утверждено автором проекта по итогам независимого ревью:
[шорт-лист](../research/2026-09-27-ue-assets-shortlist.md) и
[отчёт ревью](../research/2026-09-27-ue-assets-review.md) (23 замечания, 23
исправлено). Документ фиксирует решения и stage gates по спринтам из
[13](13-sprint-plan.md)/[14](14-sprint-backlog.csv). Он **не** объявляет
покупки, скачивания или интеграции выполненными, кроме явно описанного
smoke-теста встроенного MCP; оценки и состав задач 13/14 не меняет.
