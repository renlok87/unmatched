Written by Claude on 2026-10-06 from the review of CX-16 (first run of `CP-07.codex.md`). The full task is
`docs/game-design/visual/06-tasks/prompts/CP-07.codex.md`. Read it fully first: its package contract, inputs, frame,
sizes, forbidden list and acceptance all apply here unchanged.

## What exists

`art/imagegen/portrait-crop-v1-codex/` is your package (status «предложено», not accepted yet) and
`scraped-data/derived/portrait-crop-v1-codex/` holds the review composites. The review accepts as they are: the
recommended crops in `portrait-crops.json` (B for all four; do NOT change the numbers), the edge masks and underlays in
`vector/`, the badge geometry, the fallback monograms, the loser view, the eye landmarks, the ring-sampling analysis,
the source-hash machinery and the manifest. Keep `_tools/build_portraits.py` and `_tools/verify_portraits.py` as the
single source: edit the scripts, rebuild, do not hand-edit images or JSON.

## Fix exactly this

1. **`verification.json` in the format of 07 §1.2.** Keep every existing key, and add these top-level keys:
   - `exports`: one entry per PNG in `vector/` and `comparison/`: `file`, `size`, `mode` (RGBA), `margin_px`,
     `touches_edge`. The edge masks and underlays are inscribed in their canvas, so `touches_edge` is true by design:
     say so in a `note` on those entries.
   - `palette`: for every PNG in `vector/`, the share of opaque pixels (alpha >= 250) whose colour lies farther than
     ΔE76 3 from the tokens of the card (#061623, #F9EBDB at 0.45 over its neighbours, #111317, #F2EDE4); antialiased
     edge pixels (alpha < 250) are not counted. Expected 0 for every file.
   - `gray`: every colour final and review sheet has its `-gray` partner (list missing ones; expected none); the
     state pairs differ in gray: winner vs loser at 120 su (mean luma difference), badge digits 1 / 2 / 3 (shape
     difference), fallback monogram vs underlay (contrast ratio).
   - `sizes`: every size and scale named in the deliverable exists (`vector/portrait-edge-{32,40,64,80,120,160}-{x1,x2}`,
     composites per character / variant / size / x1, x1.5, x2), each drawn from geometry, none downscaled from the
     320 px master.
   - `acceptance`: one object per line of the card acceptance (the six clauses of the task's `Acceptance:` line), each
     `{passed, measured, expected, note}`, evaluated on the **recommended** crops of `portrait-crops.json` (that is
     what the game uses). The diagnostic variants A and C stay in `limitations` as review-only notes and do not fail
     acceptance. Set `full_acceptance` from this list.
2. **Magnification at 2160p / 150 % (scale x3).** The card expects the list of displays above 1.6x to include the
   2160p 150 % case (expected: Medusa 160 su). Add scale x3 to `magnification-limits.json` and to `verification.json`
   as computed rows only (display px = su x 3, source crop px from `portrait-crops.json`), for the recommended crops of
   all four characters and all six sizes; mark every row above 1.6x. Do not render x3 composites.
3. **Status labels on the working sheets.** On `comparison-working-x1/x1.5/x2.png` and their `-gray` partners in
   `scraped-data/derived/portrait-crop-v1-codex/`, the C tiles of `king-arthur-merlin` and `medusa-harpies` say «ok»
   although C is rejected for the baked ring. Label every tile with both flags, as the master sheet does: ring status
   (`REJECT ring` for sidekick C, `! ring filter` where it applies) and magnification (`! >1.6x` or `ok`).
4. **Overlay sheets.** On `comparison/overlay-working-x1/x1.5/x2.png` (and `-gray`) the captions «Harpy N / 32 su»
   touch the bottom of their cream tiles; leave at least 6 px between tile and caption.
5. **README.md.** Update the sections on limits and checks to the new `acceptance` list, add the x3 rows (which
   recommended displays exceed 1.6x at 2160p / 150 %), keep the status «предложено». Then run
   `verify_portraits.py --finalize` so `manifest-sha256.json` covers every file again, and the read-only
   `verify_portraits.py` must pass.

Nothing else changes: no new variants, no new crops, no generation, no files outside the two package folders, no git,
nothing under `unreal/`.
