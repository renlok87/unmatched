# Задания Codex и SYNTX (`06-tasks/prompts/`)

Здесь лежат заполненные задания генерации — по одному файлу на карточку `06-tasks/*.csv` (ВР-PR09, ВР-PL07):

| Файл | Для чего | Шаблон |
|---|---|---|
| `<id>.codex.md` | задание пакета Codex: приложение ChatGPT или `codex.exe exec` («Прочитай <файл> и выполни задачу») | `T-CODEX-*` |
| `<id>.syntx.txt` | задание вызова SYNTX: настройки и текст промпта | `T-SYNTX-*` |

Файлы **генерирует** `tools/art/visual/prompt_build.py`, руками их не правят: правка — в строке карточки или в
[07-prompt-templates.md](../../07-prompt-templates.md), затем пересборка.

```text
python tools/art/visual/prompt_build.py HB-07
```

## Что внутри файла

1. **Шапка** (происхождение, Codex её не выполняет): id, дата, шаблон, `set` (папка пакета
   `art/imagegen/<set>-codex/`), приоритет, зависимости, таблица и статус карточки, sha256 колонки `prompt`,
   какие блоки раскрыты и sha256 файла 07.
2. **Входы** — каждый существующий путь из колонки `references` с sha256 (папка — дайджест дерева); отсутствующие
   пути помечены `missing`. Отдельно — пути, названные в тексте задания; если карточка записала префикс sha256, он
   сверяется (`match` / `MISMATCH`).
3. **Предупреждения** — статус карточки не «готово к работе», упоминания «Unmatched» / «Digital Edition» (ВР-PR07:
   допустимы только как запрет), отсутствующие входы, расхождения sha256.
4. **Task** — текст колонки `prompt` без тега шаблона и без вступления для Claude (всё до «Task <id>»). Блоки
   `[[B-STYLE]]`, `[[B-PALETTE-CORE]]`, `[[B-FORBID]]`, `[[B-PACKAGE]]` раскрыты дословно из 07 §0.3 и §1.1 (скрипт
   читает их из markdown), `{{set}}` подставлен из колонки `deliverable`.

Скрипт падает (код 2) на неизвестном id, на карточке без тега `[T-…]`, на неизвестном блоке, на `set`, который не
выводится из `deliverable` или противоречит тексту карточки, и на любом оставшемся `{{…}}`.

## Порядок (05 §1.2)

1. `prompt_build.py <id>` → файл здесь.
2. Claude читает файл целиком: нет названий «Unmatched», «Digital Edition», художников (ВР-PR07); hex только из 02 §2;
   входы — только наши файлы (ВР-PR08).
3. Коммит в основной копии только этого пути до запуска:
   `git add -- docs/game-design/visual/06-tasks/prompts/<id>.codex.md`, затем
   `git commit --no-verify -m "docs(visual): <id> Codex task" -- docs/game-design/visual/06-tasks/prompts/<id>.codex.md`.
4. В папку пакета Codex Claude ничего не пишет: дословные промпты туда копирует сам Codex (`prompts/` пакета).
