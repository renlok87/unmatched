## 1. Принципы

1. **Один язык для HUD, значков, карт и VFX.** Основа — плоская печать в подаче DE (решение пользователя
   2026-10-03 для значков, ВР-01 для панелей) и токены «языка карт»: `card.navy`, `card.cream`, цвета типов. Три тона
   на элемент, хайрлайн-кромка, жирный плоский глиф. Без градиентов, бликов, фасок, бронзы, пергамента.
2. **Фигуры и поле — арт, интерфейс — печать.** Фигуры — полуреалистичные статуэтки (ВР-08), поле — живописная
   карта, задник — живопись концепта. Интерфейс и VFX поверх них плоские. Плоское не пытается выглядеть объёмным.
3. **Читаемость первой.** Каждый элемент отвечает на вопрос игрока: «чей ход», «что можно выбрать», «кто кого бьёт»,
   «сколько урона». Если элемент ничего не сообщает, его нет. Декор не перекрывает фигуры, клетки цели и достижимые
   клетки (правило D-10 W5b-R: пересечение HUD-панелей с ними = 0 px²).
4. **Не только цвет.** Каждое состояние несёт форму или глиф. Цвет — третий канал (MS-D-13, И-8). В сером всё
   различимо. Таблица — §11.4.
5. **Красный — только знак.** `state.error` — знак X или «!» и поражение (ВР-21). Красный игры `card.type.attack` —
   диск атаки и кромка полных сердец. Красной заливки фигуры по умолчанию нет (ВР-20).
6. **Принятый арт по умолчанию, флаг только откатывает** (AGENTS.md). Новое включается после приёмки, старое
   остаётся флагом `-S08…Legacy`. Флагов «посмотреть новое» нет. Клиент пишет вид в трассу `ARTLOOK`.
7. **Только реальные данные.** Герои, HP, карты, аватары, доски — из бэкенда, админки и скрапа. Макеты с игровыми
   данными собираются на этих данных, ImageGen для них не используется (решение 2026-10-03). Значения, которых
   нет, пишутся «уточнить: <где>».
8. **DE — только идеи и тайминги** (пользователь, 2026-10-05). Берём структуру, порядок, тайминги, приёмы. Не берём

## 3. Типографика

### 3.1 Шрифт

- **Roboto Bold Condensed** — шрифт HUD, чисел и заголовков (HI-07, по делегированию 2026-10-03, технически
  импортировано). Источник — `Engine/Content/Slate/Fonts/Roboto-BoldCondensed.ttf` UE 5.8, Apache 2.0, кириллица
  U+0400–045F полная, «», №, —, −, × есть. Лицензия — `unreal/Unmatched/Licenses/THIRD_PARTY_NOTICES.txt`.
- **Roboto Regular / Bold** движка — длинный текст: строки эффектов, причины `why.*`, лента, настройки.
- Других шрифтов нет. Bahnschrift — только на старых макетах. Фолбэк — системный, с записью в лог (02-ux-ui-spec).
- Новых вызовов `FCoreStyle::GetDefaultFontStyle` нет (HUD-RULES П3). Шрифт берётся из стиля.
- Цифры в текстуры не запекаются (И-7): цифры на значках, жетонах, бейджах — runtime-текст `font.card`.

### 3.2 Единицы и масштаб

- Размеры в документах — su (slate units). При 1920×1080 и масштабе 100 % 1 su = 1 px.
- Кривая DPI проекта (ВР-62): 720 → 0,75, 1080 → 1,0, 1440 → 1,333, 2160 → 2,0 по короткой стороне окна.
  Настраивается в `DefaultEngine.ini`, секция `UserInterfaceSettings`; у движка сейчас 720 → 0,666.
- Масштаб UI игрока (UI-ACC-001) — `ApplicationScale` 0,75–1,5 поверх DPI. При короткой стороне < 1080 ползунок
  не опускается ниже 1,0 (ВР-62).

### 3.4 Цифры, RU/EN, строки

- Цифры — табличные там, где меняются (HP, счётчики колоды, таймер): ширина не прыгает.

## 4. Формы и материал панелей

### 4.1 Панели

- Тело — `panel.bg` (`card.navy`), прозрачность 0,92 в партии. Модали и экраны — 1,0 поверх `panel.veil`.
- Кромка — хайрлайн `panel.edge` 1 su внутри края (ВР-64). Тень — нет. Двойной рамки нет.
- Радиусы (ВР-64): `radius.s` 4 su — кнопки, чипы, капсулы; `radius.m` 6 su — панели; `radius.l` 8 su — модали, рамка
  карты. Таблетки (полный радиус) — только капсулы чисел и тег.
- Отступы — `space.s` 12, `space.m` 16, `space.l` 24 su; внутри панели 12–16 su (`panel.padding`).
- Размытие фона (Background Blur) и Retainer Box — нет (HUD-RULES П2).

## 9. VFX и постановка

### 9.1 Стиль (ВР-19)

- «Печатный»: плоские формы с жёсткой кромкой, 2–3 тона только из токенов `fx.*`, коротко (≤ 600 мс), без дыма, бликов,
  линз, свечения с градиентом, хроматической аберрации.
- Эффект живёт на фигуре и клетке. Камера неподвижна, тряски нет (D-10, UI-ACC-005).
- Форма — первый канал: звезда = удар, «+» и точки вверх = лечение, обод = защита, вихрь = взгляд Medusa, дуга =
  удар меча Arthur, шевроны = направление атаки.
- VFX никогда не единственный носитель информации: урон — ещё «−N» и HP в HUD, смерть — ещё сердце павшего.
- Свет в VFX не ставим (ВР-73). Тёплые фонари — свет окружения, не эффектов.
- Niagara — CPU, `bDeterminism` + `RandomSeed`, прогрев при загрузке матча, пул `AutoRelease` (CUE-DISPATCHER §3).
- Текстуры — свои: процедурные или флипбуки из Codex / SYNTX по карточке `vfx.csv` (ВР-26).

## 11. Доступность и масштаб

### 11.1 Масштаб и окно

- Масштаб UI 75–150 % (UI-ACC-001) — `ApplicationScale`. При 720p — от 100 % (ВР-62).
- Обязательная проверка каждого блока: 1920×1080 и 1280×720, масштаб 100 % и 150 % (HUD-RULES П6, ACC-020). Обязательный
  выбор не перекрывается (`PLATE overlapReachable=`).
- Поле и мировые значки масштаб UI не меняет. Бейджи L6 — по правилу clamp (§5.3).
- Минимальное окно — 1280×720. Ниже — без гарантий.

### 11.2 Reduced motion

- Источник — `-S08ReducedMotion`, CVar `s08.ReducedMotion`, сохранённая настройка (DE-025).
- Движение UI — только прозрачность ≤ 100 мс (`reduced.max_ms`). Циклы значков стоят на постере, спиннер — ступени
  250 мс.
- Перемещение фигур — прыжок; частиц VFX нет; кольцо хода статично; пульс жетона цели выключен.
- Тряски нет нигде, а не только при reduced motion.

## 13. Приёмка

### 13.1 Что такое визуальная единица

### 13.2 Лист приёмки

Папка `docs/game-design/evidence/VISUAL/<id>/` (ВР-60). Состав:
1. **Мастер и рабочие размеры.** Значки — 1024 и 24 / 32 / 48 px ×4 nearest; скины — ×1 и ×2; карты и портреты —

### 13.4 Режимы и очередь

- **Лёгкий режим** (AGENTS.md «Iteration speed»): правки параметров (цвет, opacity, свет, профиль доски, раскладка);
  ≤ 3 итерации; кадры до / после затронутых видов; только затронутые гейты; без отдельного ревью; без
  `render_bench.py`, если не добавлены свет, меши, материалы или FX. Итерации — live tune в одном клиенте.
- **Полный режим**: новые системы (UMG-блоки, Niagara, ассеты окружения, генератор токенов); все гейты, один проход
  ревью, бенч цены.
- Одна упаковка на изменение; финальные кадры — свежий `-Bench`.
- Очередь (ВР-03): P0 отладка из вида игрока → P1 HUD партии на UMG → P2 карта в руке, рубашка, инспектор → P3 ENV-U16
  Marmoreal → P4 VFX боя → P5 экраны → P6 поворот фигур и правки героев → P7 хвосты Sarpedon.
