## 3. Рабочее место

1. **Worktree:** `git worktree add -b feat/visual-z1-figures C:/tmp/wt-zcode-figures fix/admin-panel`, из основной копии.
   Если путь или ветка уже есть — проверь, что они твои и чистые.
2. **`node_modules`** — junction на основную копию, как сделано в `C:/tmp/wt-visual`.
3. **Игнорируемые папки `unreal/Unmatched`** (`Content`, `Binaries`, `Intermediate`, `Plugins`, `Build`) скопируй из
   основной копии **в** worktree. Команда `robocopy` без `/MIR` и `/PURGE`, с исключением файлов, которые уже есть в
   worktree. Обратно не копируй никогда.
4. **Сборка редактора** (читай хвост лога: `Build.bat` возвращает 0 и при ошибке компиляции):
   `node tools/s08/build-editor.cjs UnmatchedEditor Win64 Development -Project=C:/tmp/wt-zcode-figures/unreal/Unmatched/Unmatched.uproject -WaitMutex -NoXGE -MaxParallelActions=4`
5. **Тесты:** `node tools/s08/run-ue-tests.cjs <фильтр> <лог>`. Сначала посмотри CLI скрипта. Плюс pytest для
   затронутых `tools/` (например, `tools/s08/cue_contract`).
6. **Упаковка — одна на всё задание, в конце:** `powershell -NoProfile -File tools/s08/package-client.ps1`. Учти ловушку
   AGENTS.md про новые `Config/**.json`.
7. **Кадры:**
   - бенч — packaged `-Bench` с видами K1, K2×1,6, K2×2,5, поза задаётся `-BenchMovePose`, `-BenchClipPose`;
   - живой бой — `tools/s09/run-combat-demo.ps1 -ArtPreviewBoardId <доска> -PlayerView`;
   - смотри шаги и параметры в самих скриптах и в `tools/art/render/LIVE-TUNE.md`.

**Коммит** — после каждой карточки, только её пути:
`git -C C:/tmp/wt-zcode-figures commit --no-verify -m "feat(anim): AN-xx …" -- <пути>`.
