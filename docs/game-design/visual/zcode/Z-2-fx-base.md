## 0. Уроки Z-1 — обязательно

Ревью Z-1 нашло, что README обещали больше, чем показывали кадры: фигуры стояли спиной к камере, цифры гарпий не
рисовались вовсе, а в README стояло «художественно принято». Поэтому в Z-2:

- **Ты не ставишь «художественно принято».** Твой статус для всего — «технически импортировано». Художественную
  приёмку делает визуальный чат после своего ревью.
- **Каждое число и каждое «работает» в README — со ссылкой** на файл лога, трассу или кадр (путь). Нет файла — нет
  утверждения. Числа — замеренные, не вычисленные на бумаге.
- **Каждый кадр смотри глазами** в кропе ×4 nearest вокруг каждого эффекта и каждой из шести фигур, в цвете и в
  сером. Эффект должен быть ВИДЕН на кадре. Если не виден — это баг, а не «слишком быстро».
- **Ловушки движка, уже найденные в этом проекте:**
  - `UTextRenderComponent` не рисует шрифты, созданные во время выполнения; нужен офлайн-ассет шрифта;
  - `PlayerCameraManager::GetCameraLocation()` на спавне отдаёт старый вид; камера доски — view target
    `BoardCamera` (хелпер на `AS08BoardActor`, см. `S08BoardActor` после Z-1);
  - `Build.bat` возвращает 0 и при ошибке компиляции: читай хвост лога;
  - вызовы локализации только для редактора в тестах — под `WITH_EDITOR`, иначе игровая цель не собирается (C2039);
  - новый `Config/**.json` попадает в pak только после `touch` `Unmatched.Build.cs` и сборки игры;
  - ассет, который грузится через `LoadObject` без жёсткой ссылки, нужно добавить в `DirectoriesToAlwaysCook`;
  - таймеры с фиксированным шагом зависят от FPS; анимацию веди от тика кадра или от часов CUE.
