   реестр всех визуальных ассетов. Перед фазой 2 задать пользователю вопросы §8.
3. **Производство (фаза 3).** Работа итерациями по циклу §5:

## 5. Рабочий цикл с Codex и SYNTX

### 5.1 Как сложился (образец — DE-012)
1. Claude пишет файл промпта: входы, задача, папка вывода, запреты (не трогать `unreal/`, без git).
   - Образец вне репозитория: `C:/tmp/de-live/2026-10-04/codex-de012-prompt.md`.
   - Шаблон: [CODEX-2D-PACKAGE-PROMPT.md](../../art-pipeline/CODEX-2D-PACKAGE-PROMPT.md).
2. Чат Codex открывает пользователь, или Claude по его слову: приложение ChatGPT, Ctrl+N, короткое сообщение со
   ссылкой на файл промпта. Запасной путь — `codex.exe exec` из пакета приложения. npm-версия `codex` падает.
3. Codex пишет только в свою папку `art/imagegen/<набор>-codex/` и не коммитит. Содержимое папки:
   - `prompts/`;
   - `generation-records.json`;
   - сырые `concepts/`;
   - векторную доработку в `_tools/`;
   - листы `comparison/` в 1024 и 16/24/32 px, в цвете и в сером;
   - `verification.json`, `manifest-sha256.json`;
   - README с рекомендацией.
4. Claude проверяет `git diff` против рамок задачи, коммитит перечислением путей с `--no-verify` и выносит лист A/B
   на арт-приёмку. Решение с дословной цитатой и датой записывается в `01-decisions.md` или в реестр этого чата.
5. Импорт в UE — скриптом `tools/art/*_import.py` (по образцу `icons_v3_import.py`). Принятое включается по
   умолчанию, рядом флаг отката.
6. Кадр: live tune для итераций, свежий packaged `-Bench` для приёмки. Перед отчётом Claude открывает PNG сам.

### 5.2 Роли сервисов
- **Codex:** концепты, 2D, значки, макеты на реальных данных, векторная доработка, листы сравнения.
- **SYNTX:** картинки (стиль, живопись, плиты задника, апскейл), видео-референсы анимаций и VFX (Kling, Veo и др.).
  Нет 3D и mocap.
- **3D, риг, UV:** Tripo Studio. Blender — чистка, проверка, экспорт. UE MCP — сцена и проверки.
- **Mocap:** сервиса нет. Кандидаты — в VIDEO-TO-MOTION.md. Покупку и аккаунт решает пользователь.
- **Значки:** финальные файлы — вектор движка v3 с точными токенами. ImageGen и диффузия дают только эскизы и
  глиф-маски: hex и толщину штриха они не держат.

### 5.3 SYNTX и п. 9.3 оферты
- Оферта SYNTX, п. 9.3: автоматизированный доступ и эмуляция действий пользователя запрещены без письменного
  разрешения ([RESEARCH-2026-10-05.md](../de-footage/task/runs/RESEARCH-2026-10-05.md)).
- **Агент не автоматизирует SYNTX:** ни через MCP, ни через Chrome.
  - Генерирует пользователь вручную по промпту, который готовит Claude.
  - Либо по прямому подтверждению пользователя на каждую генерацию.
- Права на результат: пп. 9.1, 9.4, 3.3 оферты. Условия провайдера модели (Kling, Veo, Flux и др.) оферта не
  отменяет. Проверять на официальном сайте модели и записывать ссылку и дату.
- Кредиты и подписки не покупать. Каждую трату записывать в `credits-ledger.json`.

### 5.4 Правила качества
- **Поштучный осмотр.** Каждый ассет смотреть в полном размере и в рабочих размерах (16/24/32 px для значков, 720p
  и 1080p для HUD), в цвете и в сером, рядом с кадром DE для сравнения структуры. Метрик мало. Пользователь о
  значках v2: «нарисованы криво», «топорно», «ты не провел полноценного ревью».
- **Макеты UI только на реальных данных:** карты, топология, герои и аватары из бэкенда и админки, оригинальный
  арт карт. Пользователь: «Используй реальные карты и изображения героев из бэкэнда… Не нужно делать хуйню».
  ImageGen не используется для макетов с игровыми данными.
- **Готовый арт по умолчанию, флаги только откатывают** («Accepted art is the default; flags only roll it back»).
  Не прятать принятый арт за флагом ревью.
- **Смотреть кадр перед отчётом** («Look before you report»): доска настоящая, задник верный для карты, все шесть
  фигур v2.
- Только реальные доски Marmoreal и Sarpedon original.
- **Режимы работы** (AGENTS.md «Iteration speed»):
  - лёгкий: до 3 итераций, только затронутые гейты;
  - полный: для новых систем;
  - одна упаковка на изменение;
  - цену рендера мерить `render_bench.py`.
- Ревью — один проход в конце.
- Не дёргать пользователя по мелочам. Спрашивать только блокеры (деньги, пароли, капча) и арт-приёмку.
