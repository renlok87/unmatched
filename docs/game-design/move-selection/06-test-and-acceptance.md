# 06. Тесты и приёмка

Дата: 2026-10-03. Статус: ПРЕДЛОЖЕНИЕ, v2 (после адверсариального ревью — [09](09-review-log.md)). Тесты MS-AT-xx
проверяют требования MS-R-01..74 ([03](03-ux-spec.md), [04](04-technical-design.md)) и граничные случаи MS-E-xx
([02](02-rules-and-edge-cases.md)). Матрица трассировки — §7.

Как запускать:
- backend — jest (спеки рядом с кодом, как `backend/src/game-engine/services/s03-turn.spec.ts`);
- UE Automation — `node tools/s08/run-ue-tests.cjs <фильтр> <абсолютный путь лога>` (фильтр — подстрока имени для
  `Automation RunTests`, `run-ue-tests.cjs:2, 18`); префиксы новых тестов: `Unmatched.S08.MoveParity.`,
  `Unmatched.S09.MoveSel.`, `Unmatched.S08.MoveHL.`, `Unmatched.S08.MoveAnim.`; существующие тесты черновика
  называются `Unmatched.S09.CMD <описание>` (после `CMD` — пробел, 9 тестов), фильтр — `Unmatched.S09.CMD`;
- контракты — `tools/s08/cue_contract/cue_contract.py`, `tools/s08/hud_contract/hud_contract.py`;
- кадры — упакованный Development, `-Bench -BenchFixture=<gameState> -BenchMoveDraft=<сцена>`, фингерпринт `RENDER` по
  `docs/art-pipeline/render-reference.json`; стоимость — `tools/art/render/render_bench.py` (новый вариант MS-T-08);
  подбор — live tune.

Пороги регистрируются **до** съёмки (D-6) в `docs/game-design/evidence/MOVE-SEL/ms-thresholds.json` (создаётся в
MS-T-13) — в том числе таблица ΔE цвета подложки к зонам каждой доски (03 §4.2b).
