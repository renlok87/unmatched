## 2. Что важно из внутренних исследований

### 2.1. Сервер (R1, перепроверено)

1. Манёвр — две мутации. `beginManeuver` списывает действие, добирает карту и открывает `metadata.pendingManeuver`
   (`backend/src/game-engine/services/game-action-executor.service.ts:1644-1668`). `maneuver` принимает `moves[]` и
   `boostCardId` (`:1693-1844`). Начатый манёвр нельзя отменить; минимальное завершение — `moves: []`.
2. `maneuver` уже принимает **несколько бойцов одним вызовом** и проверяет их **последовательно**, каждый на состоянии
   после предыдущего (`:1723-1779`). Буст прибавляется каждому бойцу (`backend/src/game-engine/validators/game-rules.validator.ts:317-344`).
   Весь манёвр даёт один `+1` к seq (`game-action-executor.service.ts:1781-1784`).
3. Пустой путь бойца отклоняется кодом `EMPTY_PATH` (`game-rules.validator.ts:333-335`). «Не двигать бойца» кодируется
   отсутствием записи в `moves[]`.
4. Правила пути GD-015 едины для валидатора, бота и эффектов: союзник проходим, живой враг блокирует, конец свободен от
   любого живого бойца, побеждённые не мешают (`backend/src/game-engine/movement/traversal.ts:19-69`).
5. Смежность — одна функция `isAdjacent` (`backend/src/game-engine/engine/board-topology.ts:191-201`). На графовой
   карте соседи — только `links`; соседняя по решётке клетка без связи не смежна (Marmoreal — 14 таких пар, Sarpedon —
   5; `backend/prisma/fixtures/boards/{marmoreal,sarpedon}.topology.json`, поле `summary`).
6. Сервер не отдаёт ни достижимых клеток, ни пути. Соперник видит только итоговые позиции: `input` мутации в журнале
   виден только автору (`backend/src/games/game-state.service.ts:1124-1131`), а для MOVE-эффектов путь не существует
   вообще.
7. Ошибки валидатора несут `code`, но в GraphQL уходит только текст: исполнитель возвращает `error` без кода
   (`game-action-executor.service.ts:1752-1756`), резолвер бросает `BadRequestException(result.error)`
   (`backend/src/games/resolvers/game-actions.resolver.ts:134-138`).
8. Бот двигает только героя, не бустит, идёт строго ближе к ближайшему врагу (`ai-decision.service.ts:49-58, 422-459`).

### 2.2. Клиент UE (R2, R4, перепроверено)

1. Логика черновика есть и покрыта тестами: `FS09CommandUi` (`S09ManeuverUi.h:31-44, 238-259`), правила в
   `FS08BoardModel` (`S08BoardModel.h:139, 194-221`). Сетка и граф обслуживаются одной функцией `Neighbours`.
2. Игрок не строит путь и не видит его: `BuildManeuverPath` вызывается только в `ConfirmManeuver`
   (`S09ManeuverUi.cpp:640-642`). Нет hover по клеткам, нет призрака, нет маркеров намеченных ходов.
3. Дефекты по коду (подтверждены перечитыванием 2026-10-03):
   - B-01: цель «своя клетка» превращается в ход с пустым путём (`S09ManeuverUi.cpp:637-639`), сервер ответит
     `EMPTY_PATH` и отвергнет весь манёвр;
   - B-02/F8: смена буста не пересчитывает подсветку и не перепроверяет нарисованные ходы (`:562-580`);
   - F2/B-08: каждая цель проверяется против исходного снапшота (`:533-541`), а сервер — последовательно; клиент
     запрещает законный план «A уходит, B встаёт на место A»;
   - B-06/F3: `immobilized` не проверяется; эффекты бойца декодируются (`S08BoardModel.cpp:537-552`), но не читаются;
   - F4: `Movement` берётся как есть (0 при отсутствии поля — `S08BoardModel.h:88`), сервер подставляет 2;
   - F10: «живой» на клиенте — `Health > 0 && X >= 0` (`S08BoardModel.h:94`), на сервере — `health > 0 && !isDefeated`;
   - B-09/F5: «быстрый ход» TASK-022 — два клика без подтверждения тратят действие (`S08FlowGameMode.cpp:1211-1260`).
4. Фигурка телепортируется (`S08FighterActor.cpp:226`). Cue `FighterMoved` несёт только from/to
   (`S08FlowController.h:49-57`) и пишется лишь в трассу.
5. Подсветка спавнит актор с MID на каждую достижимую клетку при каждом выборе (`S08BoardActor.cpp:1750-1800`).
6. Свободные клавиши (по `S08FlowGameMode.cpp:1772-1900` и `S08FlowGameModeArtView.cpp`): заняты M, E, A, N, R, G, X,
   D, I, L (только на терминальном экране — `S08FlowGameMode.cpp:1794-1795`), Enter, Esc, 1–9, Space, F10, Shift+F10,
   стрелки (только при открытом просмотре сброса), колесо, ЛКМ/ПКМ. Tab, H, P, F1 заняты только в Art View. Свободны в
   игре: Tab, Backspace, Delete, B, T, H, W, Ctrl+стрелки, Ctrl+Z (W не используется нигде: `grep EKeys::W` по
   `unreal/Unmatched/Source` — 0).
   `Config/DefaultInput.ini` содержит только оси движка; привязок действий нет.

### 2.3. Внешние референсы (R3)

Опорные выводы:
- **Undo до границы скрытой информации** (BGA Undo policy, Into the Breach, Fire Emblem, Unmatched DE «do over»).
  Для нас граница — добор в `beginManeuver`; всё после него до коммита — локальный черновик.
- **Двухъярусная дальность** (XCOM 2: синяя — одно действие, жёлтая — рывок). Для нас: база и «с бустом».
- **Превью пути по наведению с последствиями** (XCOM 2, BG3, HoMM Cursor Shadow). Для нас главные последствия —
  зоны пространства и кто сможет атаковать.
- **Подтверждение только для необратимого** (BGA Studio Guidelines, lichess `submitMove`).
- **Не только цвет, ввод без drag и удержаний, срабатывание на отпускании** (XAG 103/107, Game Accessibility Guidelines).
- **Короткие анимации с настройкой скорости и пропуском** (BGA 0,5–0,8 с; lichess NONE/FAST/NORMAL/SLOW; критика
  долгих анимаций Unmatched DE в BoardGameQuest).
- **Ход соперника постфактум** (chess.com Highlight Move, lichess `highlight`, Action Log перезапуска Unmatched).

### 2.4. Технические паттерны (R4)

- Шаг стоит 1, доски крошечные (31/38 пространств, сетка ≤ 20×20): нужен BFS по слоям; A* и кэш путей не нужны.
- Оптимистичного перемещения не делать: дискретная команда раз в несколько секунд, добор уже скрыт и зафиксирован,
  реакции чужих героев клиент не моделирует (R4 §4.1).
- UE: ISM с per-instance custom data вместо актора на клетку; путь — по R4 `USplineMeshComponent`, в плане заменён на
  ISM прямых сегментов (связи и шаги сетки — прямые отрезки; один draw call на весь путь, 04 §6.1); призрак — dithered
  fade через Custom Primitive Data (индекс `Fade` зарезервирован в `docs/unreal/contracts/cue-dispatcher/CUE-DISPATCHER.md`).
- Подсказки — одна серверная функция оценки для бота и игрока, только публичные данные.

### 2.5. Библиотеки (R5, документ 07)

Готового модуля подбора хода под серверную авторитетность нет. Всё делается встроенными средствами UE 5.8. Все
проверенные сэмплы Epic и большинство дешёвых UI/FX-паков помечены NoAI. Кандидаты на спайк без NoAI: Magic Circle
Creator, Simple Path Tracer, Glow Path, Card & Board Game SFX (07 §3).
