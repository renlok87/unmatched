## 1. Сценарий в двух словах

1. Свой ход, есть действие. Игрок кликает своего бойца — видит, куда тот может дойти (база и с бустом).
2. Кликает пространство — появляется чип «Начать манёвр: добор 1 карты». Enter — сервер добирает карту.
3. Черновик открыт: цель уже стоит, путь виден, у цели призрак фигурки. Игрок наводит курсор на другие
   пространства — линия пути перестраивается. Выбирает буст картой руки — подложки сразу расширяются.
4. Выбирает других бойцов, ставит им цели; номера показывают порядок. Ошибка подсвечена и объяснена.
5. Enter — «Отправлено…». Сервер применил — фигурки едут по своим путям, соперник видит то же самое.

Предвыбор хранится до открытия черновика (переносится в него) или до выхода в MS-S-01/MS-S-00; переживает MS-S-10.

черновик сохраняется (MS-E-91).

## 3. Ввод

### 3.1. Мышь

Клетка под курсором определяется пересечением луча мыши (`DeprojectMousePositionToWorld`) с плоскостью поля и
`WorldToCell` (04 §6.2), а не попаданием в актор. Попадание в актор фигурки используется только для выбора бойца.

| Ввод | Где | Действие | Состояния |
|---|---|---|---|
| ЛКМ (на отпускании) по своему бойцу | доска | выбрать бойца — кроме случая MS-R-71 (клетка под курсором входит в V-01/V-02 выбранного бойца) | MS-S-01, 02, 06, 07 |
| ЛКМ по своему бойцу в строке панели | HUD | выбрать бойца (всегда, без исключений MS-R-71) | MS-S-06, 07 |
| ЛКМ по чужому бойцу | доска | плашка бойца; в черновике тост `why.fighter.not.yours` | любые |
| ЛКМ по достижимому пространству (V-01) | доска | MS-S-02: предвыбор; MS-S-07: цель выбранного бойца (CUE-003), даже если на пространстве стоит фигурка, которая по черновику уходит (MS-E-85) | MS-S-02, 03, 07 |
| ЛКМ по пространству яруса буста (V-02) без карты или с недостаточной картой | доска | MS-S-02: предвыбор со статусом «нужен буст +k»; MS-S-07: цель со статусом NeedBoost, открывается панель буста (MS-S-08) | MS-S-02, 07 |
| ЛКМ по той же цели повторно | доска | без действия (MS-E-83) | MS-S-03, 07 |
| ЛКМ по недостижимому | доска | CUE-004 + причина (`why.cell.unreachable`, `why.cell.no.path`, `why.cell.enemy`, `why.cell.ally`); цель не меняется | MS-S-02, 03, 07 |
| ЛКМ по клетке выбранного бойца | доска | снять его ход (если есть) | MS-S-07 |
| ЛКМ по чипу «Начать манёвр» | доска | начать манёвр | MS-S-03 |
| ЛКМ по карте руки | HUD | в черновике — буст вкл/выкл; вне — осмотр (как сейчас) | MS-S-06..08 |
| ПКМ по карте руки | HUD | всегда инспектор карты (UI-INP-004), черновик не меняется | любые |
| ПКМ по доске | доска | шаг назад, как Esc, но черновик никогда не сбрасывает (только снимает выбор бойца, закрывает панель буста, отменяет предвыбор) | MS-S-02, 03, 06, 07, 08 |
| Наведение на пространство | доска | превью пути, бейдж шагов, глиф шага, значки последствий (CUE-001, ≤ 1/150 мс звук) | MS-S-02, 03, 07, 12 |
| Колесо | доска | зум (D-10, без изменений); анимацию не пропускает | любые |

Правило клика (MS-D-17): нажатие запоминает пространство под курсором; действие выполняется на отпускании, если под
курсором то же пространство. Иначе — ничего. Удержаний нет нигде. Потеря фокуса окна или уход курсора за пределы
вьюпорта между нажатием и отпусканием сбрасывают сохранённое нажатие и очищают hover (MS-E-104); отпускание над HUD не
действует на доску.

### 4.2a. Каналы и приоритеты (MS-R-72)

Одно пространство может нести несколько состояний. Подложка рисуется четырьмя независимыми каналами; внутри канала
показывается одно состояние с наибольшим приоритетом:

| Канал | Состояния по убыванию приоритета |
|---|---|
| кольцо | Conflict (V-09) > NeedBoost (V-04b) = Destination (V-04) > Sent (V-10) > EnemyBlock (V-07) > AllyPass (V-06) > ReachBase (V-01) > ReachBoost (V-02) > PendingMove/Place (V-11/V-12) |
| контур | Threat (V-16) > LastTo (V-15) > LastFrom (V-14) |
| центр | точка шага (V-03, V-15) — одна на пространство, сколько бы путей через него ни шло |
| глиф | Invalid X (V-08, 350 мс) > «!» (V-09) > бейдж порядка > номер шага > звезда подсказки (V-13) |

Бейджи у одного пространства — на фиксированных якорях: сверху — чип «+N»/«+k»; снизу — бейдж порядка; справа — до
трёх значков зон (при большем числе — два значка и «+1»); слева — «отсюда можно атаковать: N»; справа сверху —
звезда подсказки; слева сверху — «глаз + число». Совпадающие сегменты путей разных бойцов (одна и та же связь)
смещаются поперёк на `widthUU × (k − (m − 1)/2)`, где m — число путей на связи, k — порядок хода (0..m−1).

- Превью строится по наведению на пространство из подложек V-01/V-02 выбранного бойца: канонический путь (MS-D-05),
