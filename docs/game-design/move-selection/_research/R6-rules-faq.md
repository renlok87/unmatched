## 2. Сверка по пунктам

| Пункт | Официальный ответ | Источник | Следствие для сервера и клиента |
|---|---|---|---|
| **MS-Q-01** (R1-Q01). «Move [боец] N spaces» без «up to»: ровно N или 0..N? | **«официального ответа нет»**. Рулбуки задают «не больше значения движения» только для манёвра (S1 стр. 9, S2 стр. 8). Где нужна точная дистанция, карта пишет это явно: Bullseye «Master Strategist» — «Move Bullseye exactly 4 spaces». По архиву (S7, Discord RG `…/725016882393907241/959831189403893810`, неофициально) «exactly» значит: выбрать пустое пространство ровно в 4 шагах без повторного входа в пространства; нет такого — не двигаться; движение прервано — остановиться. Для простого «Move N» нет ни правила, ни ответа RG. | S1, S2 — официально (косвенно); S7 — неофициально | Консервативное правило 02 RL-14: как сервер, то есть «до N», 0 разрешён (`backend/src/game-engine/effects/effect-text-parser.ts:503-512`, `backend/src/game-engine/services/game-action-executor.service.ts:638-642`). R1-D05 остаётся P2, MVP не затронут. На MS-T-19, MS-T-20, MS-D-19, MS-D-20 не влияет. В скрейпе без «up to» только Dr. Jill Trent («Move Jill Trent 1 space», вариант выбора) и Bruce Lee (с «you may»). Наблюдение: Bullseye «exactly 4» по регэкспу `:503` тоже попадает в «до 4», это расходится с S7. Вне MVP; прогоном не проверено. |
| **MS-Q-02** (R1-Q02). Буст манёвра без движения (сброс ради цикла колоды) | **«официального ответа нет»**. Официальный текст: буст при манёвре необязателен: сбросить 1 карту и прибавить её BOOST к значению движения (S1 стр. 9–10, S3 стр. 10). Шаг движения необязателен, двигать бойца на 0 разрешено: «You are allowed to move a fighter zero spaces» (S1 стр. 9). Прямого запрета нет, явного разрешения тоже. В S2 стр. 8 буст выбирают до начала движения. В S7 и S8 записи нет. | S1, S2, S3 — официально (вопрос не покрыт) | Консервативное правило 02 MS-E-09: разрешено, как сервер (`moves: []` + `boostCardId`, карта уходит в сброс), кнопка «Подтвердить: сбросить карту без движения». MS-T-11 можно доводить с этим поведением. Порядок из S2 атомарный коммит MS-D-06 не нарушает: буст и ходы применяются одной мутацией. Требование MS-T-20 (`BOOST_NO_VALUE` и при `moves: []`, MS-E-81) остаётся. |
| **MS-Q-03 / O-7**. Карту без напечатанного BOOST нельзя использовать для буста | **Официально, но косвенно.** Соавтор игры объяснил, что у карт Voyage (Sinbad) нет BOOST именно затем, чтобы их нельзя было сбросить бустом ради постоянного эффекта: «Voyage cards have no boost value» (S6). Прямого «нельзя» в рулбуках нет; правило буста прибавляет BOOST сброшенной карты (S1). Неофициально и явно — «нет»: S7 (ссылается на тред S6), S8 (спор `172c0a4a-…`), RU-файл `:117-118`, `:234-236`. | S6 — официально; S7, S8 — неофициально | Подтверждает MS-D-20: клиент не предлагает `null`, причина `why.boost.no.value`. **Разблокирует MS-T-20**: `BOOST_NO_VALUE` в исполнителе до цикла ходов, в том числе при `moves: []` (MS-E-81, MS-AT-07). Карта с `boostValue: 0` остаётся допустимой (MS-E-08): S6 говорит только об отсутствии значения. Что у Loki «Trick» напечатан именно 0, не проверено (R1-Q03). |
| **O-14а**. «Move» соблюдает правила движения, «Place» — нет | **Официально: да.** S2 стр. 8: при «place» бойца не двигают по правилам, а ставят в новое пространство, причём только в пустое. Сказанное в S5 про «move» дословно: «If the card says 'move', you have to use the rules of movement». Там же сказано, что сквозь врагов идти нельзя, а на ловушке Muldoon нужно остановиться. Если эффект двигает бойца соперника, действуют те же правила с точки зрения соперника (S1 стр. 9). RU-файл `:15-16` (неофициально) говорит то же. | S1, S2, S5 — официально | RL-13 и RL-09 подтверждены; сервер совпадает (`game-action-executor.service.ts:638-679`), изменений нет. Выражение «new space» в S2 не решает R1-D06/RL-15 («any other space») и не говорит, можно ли при PLACE «in any space» остаться на месте (RU `:112`, неофициально — можно). Оставить как сервер. |
| **O-14б**. «Up to X» включает 0 | **Официально: да.** Игрок написал, что «up to 2» включает 0 и что для последующего эффекта такой боец считается переместившимся (Dracula «Ravening Seduction»). Jacobson ответил: «That's correct.» (S4). Для манёвра — S1 стр. 9. RU-файл `:17` (неофициально) говорит то же. | S1, S4 — официально | RL-13 и MS-E-58 подтверждены; сервер совпадает: остаться на месте законно (`:638-642`), автозавершение MOVE — нулевой шаг (`:872-875`). Для будущих эффектов «после перемещения»: ход на 0 шагов тоже считается перемещением. MS-T-19 и MS-T-20 это не касается. |
| **O-14в**. «Moving through» — войти в пространство и выйти из него | **«официального ответа нет»** (только S7, Discord RG `…/725016882393907241/1315748792875880538`, неофициально). | S7 — неофициально | Консервативное правило 02 RL-05: сквозь своих бойцов проходить можно, сквозь врагов нельзя, конечное пространство должно быть свободным. Совпадает с `backend/src/game-engine/movement/traversal.ts:19-69`, изменений нет. |
| **O-15**. «Cannot leave their space» останавливает манёвр, MOVE и PLACE, но не снятие побеждённого бойца | **Официально — частично.** В примере хода S3 (стр. 14–15) карта She-Hulk «Nerve Cluster Strike» запрещает Spider-Man покидать пространство. Из-за этого не срабатывает свой PLACE-эффект Spider-Man от «Thwip!»: «Spidey is stuck where he is». Что запрет действует на манёвр и MOVE, следует из самого текста: покинуть пространство нельзя. Исключение для снятия бойца с 0 здоровья есть только в S7 (Discord RG `…/953776992258490368/971142766241415168`, к T-Rex «Terrifying Roar») — неофициально. | S3 — официально (PLACE); S7 — неофициально (снятие) | **Разблокирует MS-T-19**: сервер отвечает `FIGHTER_IMMOBILIZED` на MOVE- и PLACE-эффекты (MS-R-63, MS-AT-05) независимо от того, чей эффект двигает бойца. В S3 эффект собственный, а запрет наложил соперник. **Оговорка:** отклонять только перемещение в другое пространство. Нулевой исход (остаться) должен оставаться законным, иначе обязательный PLACE на обездвиженном зависнет, как R1-D07. Снятие побеждённого с поля не трогать; сервер его сейчас не ограничивает. Добавить такой случай в MS-AT-05. **MS-D-19**: после MS-T-19 клиент гасит обездвиженного бойца и в эффектах, а пометку «правило уточняется» (MS-E-63) убирает. |
| **O-16**. Нет допустимого пространства для PLACE или MOVE — эта часть эффекта пропускается | **«официального ответа нет».** В рулбуках есть только правило расстановки (S2 стр. 4: если в зоне нет места, сайдкика ставят в любое пространство) — к эффектам во время игры оно не относится. Ещё S2 стр. 8: PLACE — только в пустое пространство. Неофициально — пропустить эту часть: S7 (Discord RG `…/725016882393907241/775748494605942884`), S8 (спор `7f3dab72-…`), RU-файл `:18`, `:114-115` (перевод S7). | S2 — официально (вопрос не покрыт); S7, S8 — неофициально | Консервативное правило 02 RL-16 / MS-E-61: клиент показывает «Нет свободного пространства. Ожидание сервера», трасса `MS-REJECT place.no.space`. Исправление сервера (R1-D07) — вне MVP. Если его делать, то «пропустить часть» — единственный исход без зависания, и он совпадает с неофициальным ответом. Связано с оговоркой к MS-T-19. |

## 3. Итог для MS-Q-01..03

- **MS-Q-01** — официального ответа нет. Действует RL-14 «как сервер»: «Move N» = до N, 0 разрешён. R1-D05 остаётся
  P2, MS-T-19 этого ответа не ждёт. Точная дистанция встречается на картах только со словом «exactly» (Bullseye); её
  обработка в парсере — отдельное расхождение вне MVP.
- **MS-Q-02** — официального ответа нет. Официальный текст буст без движения не запрещает (буст необязателен, 0
  шагов разрешено). MS-E-09 остаётся: разрешено, как сервер. Панель MS-T-11 можно доводить.
- **MS-Q-03**:
  - O-7 — официально, но косвенно (S6), а явное «нет» есть только в неофициальном архиве. MS-T-20 разблокирована,
    MS-D-20 подтверждено.
  - O-15 — официально для PLACE (S3); для манёвра и MOVE следует из текста запрета. Исключение для снятия
    побеждённого бойца — неофициально. MS-T-19 разблокирована при условии, что нулевой исход остаётся законным.
  - O-16 — официального ответа нет. MS-E-61 остаётся как есть.
- Пометки «фан» в 02 (RL-07, RL-10, RL-13, RL-16) можно заменить ссылками на S-коды этого файла. Это отдельная правка,
  в рамки MS-T-01 она не входит.
