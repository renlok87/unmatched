## ENV-U0. Схема доски (чат 2026-09-30, ~16:00)

Дословно: «у нас есть единая каменная подложка, модель которой ты уже создал. На нее накладывается
оригинал карты из сорсов, то есть такие круглые тайлы, с направлениями движения. Да? Раскрашенные.
И, соответственно, по этим картам нам нужно создать эти окружения.»

Следствия:
- Слои: каменная подложка `SM_TableBase` (одна на обе карты) → оригинальная карта → 3D-окружение.
- Игра идёт по топологии оригинальной карты (граф клеток со связями и стартами), а не по сетке.
- **Заменяет** прежнюю трактовку «своя интерпретация, без арта оригинальных карт; изображения
  только sha256, не кукать» (черновики разведки `C:/tmp/env0-handoff/`, решение D-03 «Cobble City»
  для этого набора). Cobble City остаётся технической регрессионной доской.
- Концепт пользователя `art/imagegen/env-v1/reference/user-diorama-concept-2026-09-30.webp`
  нарисован на квадратной сетке: переносится стиль, не раскладка.

### ENV-U1. Вся иллюстрация + 3D-окружение по периметру

- Оригинал кладётся на поднос целиком, плоской «картой»: круги, линии связей, ромбы стартов и
  фоновая иллюстрация как есть. Разрешение источника 1337×866 → апскейл ×2–4 (метод — замером).
- Подсветка (выбор, достижимость, путь) рисуется поверх по кругам клеток из данных топологии;
  собственные плиты клеток и метки зон S08 на этих картах не нужны (зоны нарисованы в оригинале).
- 3D-окружение ставится **только по периметру карты** и продолжает её тему за край.
  Низкие 3D-акценты внутри карты (гибрид) — не в объёме; возможны позже отдельным решением.

### ENV-U2. Тема — из иллюстрации карты, стиль — из концепта

- Marmoreal → мраморный дворец-сад: стены/балюстрады, арки и лестницы, сад, цветущие деревья.
- Sarpedon → лес с частоколом и валунами, берег, река, пиратский корабль (палуба, пушки, бочки).
- Стиль концепта: ночь, луна (холодный ключевой свет + свечение фона; неба в кадре K1 нет),
  тёплые фонари на столбах, скальный поднос, направление B · Painted Miniature, «мрачноватая
  атмосферная диорама».

### ENV-U3. Оригинальные изображения — вне git

  другой checkout получает их запуском импорта.
