Материал панелей — плоская печать в языке значков v3: тёмная navy-основа, cream-текст, хайрлайн-кромка. Камня, пергамента и металла нет. |

| ВР-03 | §8 п3 | Очередь производства: **P0** убрать отладку из вида игрока; **P1** HUD партии на UMG (портреты с аватарами, рука с картами, бой, колода, PENDING, TOP, CONN, LOG, баннер, тосты); **P2** карта в руке, рубашка, инспектор; **P3** ENV-U16 Marmoreal (нарисованный задник); **P4** VFX боя по CUE; **P5** экраны меню, ROOM, пауза, настройки, переподключение, загрузка, результат, ABORTED; **P6** поворот фигур и правки героев; **P7** хвосты Sarpedon P10. |
| ВР-04 | §8 п4 | Лимит трат до 2026-10-28: SYNTX ≤ 300 токенов (баланс 2026-10-05 — 478), Tripo ≤ 3000 кредитов. Codex — по подписке, учёт по пакетам. Покупок нет. Каждая трата — в журнал до и после. |
| ВР-05 | §13 п13 | Сборка — только личная и локальная (LAN), как для паков Fab. Перед генерацией в SYNTX записывать модель и ссылку на условия провайдера с датой. Коммерческих прав не заявляем. |
| ВР-06 | §8 п6 | Поворот фигур (ART-012). В покое фигура стоит вполоборота к камере (≤ 45° от оси камеры), с наклоном к ближайшему врагу. При атаке разворачивается к цели (120 мс до выпада), после — возврат за 150 мс. Спиной к камере не стоит никогда. Черновик `wip/art012-facing-2026-10-04` не берём, делаем заново. |
| ВР-07 | §8 п7, §13 п6, п28 | Постоянных именных плашек над фигурами нет. Имя — в плашке при наведении или выделении. Плашка бойца по умолчанию выключена на настоящих досках: HP есть в теге и портрете. Гарпиям — номер 1–3 цифрой на подставке и в теге (без букв). |
| ВР-08 | §13 п11 | Канон вида героев — «коллекционная статуэтка» hero-quality-v1, как у фигур v2. Направление B Painted Miniature (ART-002) заменено. |
| ВР-09 | §13 п12 | Мазок кисти и брызги туши DE не используем нигде, не только кляксу «COMBAT!». Правило 9 STYLE-v3 отменяется. |

## 3. VFX и постановка

| ВР | Вопрос | Решение |
|---|---|---|
| ВР-19 | §8 п8 | Стиль VFX «печатный»: плоские формы с жёсткой кромкой, 2–3 тона из токенов, коротко (≤ 600 мс), без дыма, бликов и линз. Эффект живёт на фигуре и клетке, камера неподвижна (D-10). |
| ВР-20 | §13 п35 | Удар: белая вспышка 70 мс, затем тёплый всплеск-звезда `#FFB45C` у точки контакта и кремовый обод 300 мс. Красная заливка всей фигуры уходит из вида по умолчанию, откат — `-S08HitTintLegacy`. |
| ВР-21 | §13 п36 | Канал формы обязателен: урон — звезда-всплеск и «−N», лечение — «+N» и поднимающиеся точки. Цвет никогда не единственный носитель. Красный зарезервирован за X «нет защиты» и поражением. |
| ВР-22 | §8 п8 | CUE-014 Medusa — вихрь на модели без луча, вспышка сердца цели. Arthur — короткая золотая дуга у меча. Строка «луч от Head» в контракте заменяется. |
| ВР-23 | §13 п41 | CUE-009 защита — кремовый импульс обода фигуры 300 мс плюс слот в HUD. CUE-006 (свечение карты) и CUE-012 (лечение) входят в MVP. |
| ВР-24 | §13 п37 | CUE-016: грейд сцены 500 мс — тёплый при победе, холодный с −20 % насыщенности при поражении, виньетка 0,25. CUE-017: −30 % насыщенности сцены плюс значок CONN. |
| ВР-25 | §13 п38 | Бюджет VFX: ΔGPU ≤ 1 мс на худшем наборе, мерить `render_bench.py` на текущем ПК (RTX 4090), D-07 — отдельно позже. Не больше 3 одновременных боевых систем. У каждой системы `UNiagaraEffectType` с бюджетом. |
| ВР-26 | §13 п39 | Боевые VFX — свои Niagara на своих текстурах (процедурные, флипбуки из Codex/SYNTX). SoftTofu (CC BY 4.0) — с атрибуцией. Fab Standard — только локально. NoAI-паки не трогаем. |
