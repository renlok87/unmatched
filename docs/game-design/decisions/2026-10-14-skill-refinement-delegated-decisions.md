| № | Решение | Почему | Находки |
|---|---|---|---|
| ДС-1 | Этап 6 — только headless-авторинг клипов и валидаторы. Приёмка клипов — шаг 7a.2 после импорта (skeleton → import → measure → frames → приёмка). «4 клипа `pass`» — выход 7a; вход 7.0 — модель `pass` и 4 клипа авторены с PASS валидаторов. | Приёмке клипа нужен импорт (G-MANIFEST, UE-кадры), импорт требовал принятых клипов — круг; пилот уже шёл так. | RA-01, F43 |
| ДС-2 | Два класса стопа. «Вопрос пользователю»: деньги, лимиты, покупки; лицензия и IP; решения вне делегирования; необратимое (удаление данных, история git). «Разбор оркестратором»: FAIL стадии или инструмента — фикс или опция инструмента, запись F, при выборе — файл решения; FAIL при тюнинге профиля — итерация (не больше 3), не стоп. | Пилот закрыл ≥ 6 таких FAIL сам; буквальный стоп на каждом противоречит делегированию. | RA-02 |
| ДС-3 | Агентский редактор UE: скрытый (`-RenderOffScreen -unattended -nosplash -ModelContextProtocolPort=8123`, без Live Coding, `UE_CONSOLE_DROP`), PID-файл, опознание по командной строке. Гейт «редактор пользователя» — только для интерактивного запуска. 7a — строго один герой за раз; редактор пачки поднимает и закрывает оркестратор, шаги — под `ue_lock`. | Пользователь UE сам не открывает (2026-10-14); второй агент 7a потерял бы чужой редактор на :8123. | RA-07, RC-05 |
| ДС-4 | `um_masters build` в импорте заменяется проверкой только для чтения; известный дрейф UM-MASTERS до пилота — не стоп; пересборка мастеров — только при смене графа и с коммитом. | Шаг давал ложный стоп по дрейфу, бывшему до прогона. | RA-16, F91 |
| ДС-5 | Расширенные пробы рига блокируют сборку только у `profile_version ≥ 2` (новые герои); у Medusa и пилота (v1) — WARN в отчёте. Закоммиченные профили не меняются. | Повтор принятых прогонов (Leshen без ног) не должен падать. | RB-08 |
| ДС-6 | Источник движения клипов по умолчанию — паттерн библиотеки героя с тем же классом оружия; видеорефы SYNTX — только для нестандартного движения с причиной в карточке. | Визуального потолка SYNTX хватает примерно на одного героя; пилот шёл на паттернах. | RA-18, RC-02, F44 |
| ДС-7 | Полный повтор детерминизма — один раз на фигуру, на прогоне, который идёт в UE; доработка r<N+1> — `--reuse-from` с повтором только пересчитанных стадий. | 7 полных повторов пилота по 12–19 мин и 2,5 ГБ. | RC-07, RC-08 |
| ДС-8 | Кадры приёмки модели для приёмщика — 1200 px, JPEG q92; листы и бенч-PNG в git не идут (рабочий каталог). | Переподключения WebSocket у Sol; вес репозитория. | RC-22, RA-13, F97 |
