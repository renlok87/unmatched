# Только настоящие доски — решение 2026-10-04

## Происхождение

Первый живой прогон вехи M1 шёл на доске по умолчанию — синтетической Cobble City 5×6. Демо-скрипт при этом проверял
пустую сетку 20×20. Узнав об этом, пользователь написал дословно:
**«Давай оставим только доски, которые осуществлены на реальных досках из игры.»**

Как применять решение, решает оркестратор: действуют делегирования «сам реши все вопросы» (2026-10-03) и «делай все без
меня» (2026-09-29). Если пользователь решит иначе, прав он.

## Решения

| № | Решение |
|---|---|
| НД-1 | Доска по умолчанию для новой игры — Marmoreal · original map. Раньше бралась самая старая строка `Board`. Неизвестный `boardId` при создании игры — ошибка. |
| НД-2 | Пустая сетка 20×20 больше не подставляется. Если доски нет или её клетки негодны, старт игры завершается явной ошибкой. |
| НД-3 | Три синтетические строки удаляются из основной БД. Перед удалением строки выгружаются в резервную копию. Сиды их больше не создают, стенды клонируются заново (`tools/db/sync-dev-stands.cjs`). Старые партии на этих досках остаются историей: внешнего ключа у `Game.boardId` нет, начать такую партию нельзя. |
| НД-4 | Демо, приёмка и инструменты по умолчанию берут Marmoreal · original map, вторая карта — Sarpedon. Из демо и проверок убираются: шлюзы `BOARD 20x20`, детектор серой сетки (`check-board-shot.ps1`) и ветки Cobble. |
| НД-5 | UE: из `S08ArtBoardProfiles.json` удаляются профили синтетических досок и их пробный свет. Код поверхности Cobble 5×6 удаляется. `-Bench` по умолчанию идёт на Marmoreal. |
| НД-6 | Прогоны на Cobble 5×6 и сетке 20×20 доказательством больше не считаются. Старые доказательства остаются в истории как есть. |

## Что сознательно не трогается сейчас

- **29 досок каталога** (импорт настоящих карт с картинками). Их клетки — сетки 12×8, приблизительные копии настоящих
  карт. Ими пользуются веб-лобби, админка, веб-клиент Phaser и подбор соперника (matchmaking): им пользуется только веб, и он
  берёт самую старую доску каталога. Веб-клиент не умеет рисовать оригинальные карты. Если
  убрать каталог, у веба не останется досок. Вопрос к пользователю: выводить ли каталог, когда веб научится рисовать
  настоящие карты.
- **Тестовые данные, а не доски игры:**
  - решётки правил движения — эталонные фикстуры 5×6 и 20×20 из `gen-move-fixtures`;
  - снимок состояния сервера `docs/game-design/evidence/S08/fixtures/04-game-state-query-host.json` с доской 20×20,
    на нём стоят тесты декодера и HUD.

  Переснять снимок на Marmoreal — отдельная задача.
- **Исторические скрипты и доказательства** прошлых задач (`tools/tripo-pipeline/**`, `tools/art/t5cb*`, `art004_*`,
  `art005*` и т. п.).
- Слово «cobble» как **материал мостовой** (`T_cobblestone_*`, пункт qa010 `K2.cobble_borders`) и `cobble-fog` —
  настоящий набор «Cobble & Fog». Эти значения к доске Cobble City не относятся.
