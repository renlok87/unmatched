# 08 — Звук экранов и модалей: хуки для визуального трека

Дата: 2026-10-06 (AU-S6). Для кого: исполнитель экранов визуального трека.

- Карточки экранов: [06-tasks/screens.csv](../visual/06-tasks/screens.csv), SC-01…SC-43.
- Звуки: [03-sound-registry.csv](03-sound-registry.csv). Все ассеты уже лежат в `/Game/Audio`.

У экранов, которых ещё нет, звуки стоят в банке со статусом `in-bank`, см. [07 §9](07-production-log.md).
Экрану не нужно ничего импортировать. Он вызывает функцию игрового режима, и звук играет через ту же систему, что и
в партии: шины, громкости, трасса `SFX bank=…`.

## Как экран играет звук

Публичные функции `AS08FlowGameMode`. Это `UFUNCTION(BlueprintCallable)`: их можно вызывать из C++ и из WBP.

| Функция | Что делает |
|---|---|
| `PlayScreenSound(FName BankId)` | Звук банка на шине UI; для `STG-*` — на шине музыки. Неизвестный id — строка `AUDIO-SCREEN unknown` в трассе, тишина |
| `SetAudioPaused(bool)` | Экран паузы открыт/закрыт: музыка тише на 10 дБ, пока открыт |
| `PlayHeroSelectSting(FString HeroName)` | Подтверждение героя в комнате: `STG-SELECT-<ГЕРОЙ>` по имени героя, если он есть в банке |

Сами по себе уже звучат, экран их не вызывает:
- музыка меню с конца BOOT (LOGIN, LOBBY) и тихий слой в ROOM;
- вход: `UI-LOGIN-OK` / `UI-LOGIN-ERR` по стадиям потока;
- звуки комнаты: создание, вход и выход игрока, готовность;
- старт партии: `UI-ROOM-COUNT-GO` у гостя (у хоста — экран отсчёта);
- потеря и возврат связи: CUE-017 и CUE-018 с приглушением музыки на 6 дБ;
- результат: стинг героя и исхода, реплики;
- инспектор карты: открытие и смена карты, пока экран ведёт `bInspecting` и `InspectedCard`.

## Карточки SC → звуки

| Карточка | Момент | Банк | Сейчас |
|---|---|---|---|
| SC-01 база экранов | любая кнопка экрана: нажатие / «назад, отмена» / наведение | `UI-BTN-CLICK` / `UI-BTN-BACK` / `UI-BTN-HOVER` | в банке; лучше в базовой кнопке `UUmScreenBase` |
| SC-01 база модалей | модаль открылась / закрылась | `UI-PANEL-OPEN` / `UI-PANEL-CLOSE` | звучит для колод и сброса; модали вызывают сами |
| SC-03 BOOT | появился логотип | `UI-BOOT-LOGO` | в банке |
| SC-03 BOOT | конец BOOT (переход в LOGIN / LOBBY) | музыка меню (полная) | звучит сама с выхода из стадии Boot (AU-S6, ответ визуального чата) |
| SC-04 BOOT ошибка | сервер недоступен | `UI-NET-LOST` | вызвать на показе ошибки |
| SC-05 модаль «Вернуться в партию» | открыта / согласие | `UI-PANEL-OPEN` / `UI-CONFIRM` | вызвать |
| SC-06, SC-07 LOGIN | ввод, переключатель RU/EN | `UI-BTN-CLICK`, `UI-TOGGLE` | итог входа звучит сам |
| SC-08…SC-13 LOBBY | создать, войти по коду, обновить список | `UI-BTN-CLICK`; ошибка кода или списка — `UI-REJECT` | создание и вход звучат сами |
| SC-14 ROOM выбор героя | наведение / выбор / подтверждение | `UI-SELECT` / `PlayHeroSelectSting(имя)` | стинги Артура и Медузы в банке |
| SC-16, SC-23 колода | открыть / закрыть | `UI-PANEL-OPEN` / `UI-PANEL-CLOSE` | вызвать |
| SC-17 ROOM | готовность, старт, выход | — | звучат сами по ответам комнаты |
| SC-18 отсчёт (только хост) | каждая цифра 3-2-1 / конец отсчёта | `PlayScreenSound(UI-ROOM-COUNT)` / `PlayScreenSound(UI-ROOM-COUNT-GO)` | цифры в банке; «старт» экрана гасит автоматический «старт» при переходе в партию на 8 с — у гостя (без отсчёта) он звучит сам |
| SC-19, SC-20 загрузка | ошибка подключения | `UI-NET-LOST` | вызвать |
| SC-21…SC-23 INSPECT | открыть, листать | `CRD-INSPECT-OPEN` / `CRD-INSPECT-PAGE` | звучат сами, если экран ведёт `bInspecting` / `InspectedCard`; иначе вызвать |
| SC-24 PAUSE | открыта / закрыта | `SetAudioPaused(true/false)` + `UI-PANEL-OPEN` / `UI-PANEL-CLOSE` | вызвать |
| SC-24 PAUSE | подтверждение выхода из партии | `UI-PAUSE-EXIT` | в банке |
| SC-25 настройки звука | ползунок — каждые 10 % / переключатель | `UI-SLIDER-TICK` / `UI-TOGGLE` | в банке; громкости применяются сами через `US08UserSettings` |
| SC-26…SC-30 настройки | переключатели, ползунки | `UI-TOGGLE` / `UI-SLIDER-TICK` | в банке |
| SC-31…SC-33 RECONNECT | потеря, возврат связи | CUE-017 / CUE-018 | звучат сами (связь пропала дольше 1,5 с) |
| SC-34, SC-35 GAMEOVER | экран результата | стинг героя и исхода, реплика | звучат сами (CUE-016) |
| SC-36, SC-37 | «Посмотреть доску», «Сыграть ещё» | `UI-PANEL-CLOSE`, `UI-CONFIRM` | вызвать |
| SC-38 ABORTED | партия прервана | `STG-ABORTED` | звучит сам |
| SC-41 подсказки | тост подсказки | `UI-TOAST` | в банке; только подсказки и сообщения сервера, не отладочный текст |

Правило частоты: звук экрана играет в кадре его визуального отклика, один раз на действие. Повторная перерисовка
экрана звук не повторяет. Наведение — только при смене элемента под курсором.
