# 05 — План производства и интеграции звука

Дата: 2026-10-05. Фаза 3 аудио-чата ([00-AUDIO-BRIEF.md](00-AUDIO-BRIEF.md) §1 п. 3). Что делать — [02-audio-design.md](02-audio-design.md)
и [03-sound-registry.csv](03-sound-registry.csv); тексты — [04-vo-script.md](04-vo-script.md); **готовые карточки
задач** — [06-task-cards.csv](06-task-cards.csv) (47 карточек, у каждой: инструмент, настройки, вход, промпт,
исключения, число дублей, оценка токенов, результат, обработка, цель громкости, приёмка).

## 0. Коротко

- **Источник всего генерируемого — SYNTX** (решение пользователя 2026-10-05): музыка и стинги — Suno V6 (cover по
  нашим нотам, generate), голоса — ElevenLabs v3. SFX и окружение — CC0-библиотеки и собственный синтез, потому что
  генератора SFX в SYNTX нет.
- **Агент генерирует сам по готовой карточке**, без подтверждения на каждую генерацию; каждую трату пишет в журнал.
  Покупки за деньги и пополнение токенов — пользователь. Выбор на слух и приёмка — пользователь (G-ART).
- **Пять этапов:** AU-S1 подготовка → AU-S2 музыка и голоса → AU-S3 SFX и окружение → AU-S4 интеграция в UE → AU-S5
  микс и приёмка. Оценка — 15–17 рабочих дней агента плюс сессии прослушивания.
- **Токены SYNTX:** ≈ 380–570 на весь MVP (музыка 150–320, голоса 230–250). Баланс 478 — нужно пополнение
  ~300 до озвучки (§5).
- **Нужно от пользователя:** 8 решений §7, первое — утвердить тексты реплик и начать AU-S1.

| Резерв SFX (если CC0 не хватит) | Fab Card & Board Game SFX ($29.99) или ElevenLabs SFX v2 через stiva.ai | только по решению и покупке пользователя | Fab Standard License / по условиям модели |
| Разделение на стемы | Demucs (Meta, MIT), локально | `htdemucs`, 4 стема, CPU | инструмент, на права не влияет |

**Учёт.**
- Каждая генерация записывается в `docs/art-pipeline/evidence/s3-baseline-2026-09-28/credits-ledger.json`, ключ
  `syntx`: время, операция, модель, Δ, баланс до и после, карточка. Этот журнал показывает админка (Art Hub,
  раздел кредитов).
- Каждый исходник лежит вне git: `C:/tmp/audio-src/<набор>/` + `manifest.json` по схеме
  `unmatched.audio-source-manifest/1`, как у `syntx-suno-2026-10-05`: URL, sha256, длина, LUFS, лицензия, карточка,
  промпт, `voice_id` и настройки.
- В git попадают: манифесты (копия в `art/audio-candidates/<набор>/`), импортированные ассеты UE, атрибуции в
  `unreal/Unmatched/Licenses/THIRD_PARTY_NOTICES.txt` (Kenney по желанию автора, Incompetech, если возьмём).

**Формат.** SYNTX отдаёт Suno в MP3 ~185–192 kbps. Если WAV недоступен, MP3 декодируется один раз в WAV
48 кГц / 24 бит и дальше обрабатывается без потерь; в UE — 16 бит. Двойного кодирования в MP3 нет.

## 2. Конвейеры

### 2.1 Музыка (AUC-M01…M06)
1. **Мотивы** (AUC-M01): агент пишет MIDI трёх мотивов по 02 §2.7, по 2 варианта, и рендерит их простым тембром.
   Пользователь выбирает на слух.
2. **Скетчи** (AUC-M02): MIDI на 24–32 такта для меню и двух карт — мелодия, аккорды, бас, ударные. Последний такт
   ведёт в первый. Пользователь слушает скетчи.
3. **Генерация** (AUC-M03…M05): загрузка скетча в SYNTX (`upload-files`), Suno V6 **cover** с промптом карточки и
   исключениями. 1 генерация = 2 варианта; при браке (вокал, другой темп) ещё 1–2.
4. **Стемы и петли** (AUC-M06): Demucs → L2 = ударные + бас, L1 = остальное; окно петли кратно такту; «завёрнутый»
   хвост; проверка шва и нуль-тест L1 + L2 против полного трека.
5. Нормализация (L1 + L2 −23 LUFS-I), WAV 48/16, импорт, MetaSound темы.
6. Прослушивание: петля три круга подряд + переход L1 → L1 + L2.

### 2.2 Стинги (AUC-S01…S13)
Suno V6 cover по мотиву → `sting_cut.py` вырезает 2–3 с вокруг каденции, хвост до 4 с, fade-out 300–600 мс →
нормализация (−18 LUFS-I) → прослушивание. Стинг лимита руки — синтез арфы.

### 2.3 Голоса (AUC-V01…V10)
1. Тексты 04 утверждает пользователь (решение Р-1).
2. Кастинг: 3–4 кандидата готовых голосов на бойца × 3 пробные строки; нормализация для честного сравнения;
   пользователь выбирает (Р-3). `voice_id` и настройки — в манифест.
3. Пакетная генерация: строка = запрос, 3 дубля; `vo_process.py` отбирает дубль по длине, клиппингу и тишине;
   обработка: ФВЧ 80 Гц, де-эссер, компрессия, нормализация −19 LUFS-I, TP ≤ −3 dBTP.
4. Гарпии: проба v3 (AUC-V04); при неудаче — обработанные CC0-записи хищных птиц.
5. Строки субтитров RU/EN из 04 → таблица UE (AUC-V10).
6. Финальный набор слушает пользователь; брак переделывается точечно.

### 2.4 SFX (AUC-X01…X08)
1. Скачивание паков (Р-6) и индекс: длина, LUFS, спектральный центроид, имя.
2. На каждую единицу реестра — 2–3 кандидата: файл пака как есть или слои (удар = тело + металл + хвост).
3. Обработка: обрезка, fade 5 мс, EQ, нормализация по группе 02 §5.3.
4. Синтез UI-тонов и магических слоёв (AUC-X03) — без скачивания.
5. Прослушивание кандидатов пользователем по категориям; выбор → `status=chosen` в реестре.

### 2.5 Окружение (AUC-A01, A02)
Постель 60–120 с с завёрнутым хвостом + точки; MetaSound с таймерами и панорамой из JSON карты. Sarpedon — сразу;
Marmoreal — постель сразу, точки привязываются к элементам нарисованного задника после ENV-U16.

### 2.6 Прослушивание
Для каждой сессии G-ART агент собирает локальную страницу `C:/tmp/audio-review/<сессия>/index.html`: плеер на
каждый кандидат, громкость выровнена, кнопки выбора; итог выбора — JSON, который пользователь отдаёт в чат одной
вставкой. Сессии: (1) мотивы и скетчи, (2) голоса-кастинг, (3) музыка и стинги, (4) реплики, (5) UI и карты,
(6) бой и смерть, (7) эффекты и окружение, (8) итоговый микс в игре.

## 6. Риски

| Риск | Что делаем |
|---|---|
| Права Suno через агрегатор (опись §6) | риск принят пользователем; манифест хранит источник каждой единицы, замена на другой источник — без правки кода |
| Suno добавляет вокал или хор | исключения в промпте; проверка на слух; при браке — повтор генерации |
| Cover уходит от скетча (темп, длина) | скетч с ударными и басом; допуск ±2 BPM; при провале — generate по тому же промпту + ручной поиск петли |
| Мотив «плывёт» между стингами | все стинги героя — cover одного файла мотива |
| Артефакты Demucs в L1 без баса | слушать L1 отдельно; запасной путь — L2 из CC0-перкуссии по сетке тактов |
| Готовый голос ElevenLabs недоступен в SYNTX | кастинг начинается с проверки; замена похожим |
| Крики гарпий из TTS неубедительны | фолбэк — CC0-записи хищных птиц |
| Нет задника Marmoreal (ENV-U16) | постель сейчас, точки — после задника |
| Перегрузка звуком | лимиты одновременности, бюджет реплик, ducking; замер LUFS записи партии |
| Скорость «Нет» и каскады | звуки идут за моментами картинки; гейт AU2 ±17 мс |
