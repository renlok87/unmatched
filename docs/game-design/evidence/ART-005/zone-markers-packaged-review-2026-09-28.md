# ART-005 · проверка формы игровых зон в packaged K1

**Решение 2026-09-28:** принять как **рабочий кандидат для двух зон Cobble City** геометрическое различие, не зависящее от цвета. Blue получает сплошную кромку клетки и ромб; red — три разделённых штриха кромки и два вертикальных штриха внутри клетки. Это не утверждение финальной палитры или полного QA-010/GD-058.

Основа — живой `boardState` Cobble 5×6 (30 клеток: 15 blue, 15 red). Логика и кликабельные поверхности не менялись; новые штрихи — только `NoCollision`-декор в существующем opt-in `-ArtPreview`. После перехода red к трём отдельным мешам каждый счётчик игрового состояния ведётся **по клеткам**, а не по инстансам: трасса у обоих клиентов содержит `zones=30 blue=15 red=15 blueMarks=15 redMarks=45`.

Доказательства: [кадр хозяина с HUD](live-zonemarks-run/run-20260928-060532/phase2-board-host-1920x1080.png), [кадр второго игрока](live-zonemarks-run/run-20260928-060532/phase2-board-joiner-1920x1080.png), [серый диагностический кадр](zone-markers-grayscale-qa-2026-09-28.png), [трассы и хеши](live-zonemarks-run/run-20260928-060532/manifest.json). Серый кадр получен из кадра хозяина простой конвертацией Pillow `ImageOps.grayscale` без изменения геометрии. На нём в K1 ромбы и пары штрихов различаются визуально; red-кромка читается как прерывистая, blue — как непрерывная.

Проверки: `Unmatched Win64 Development` собран успешно; BuildCookRun с `-skipbuild` завершился успешно. Два packaged-клиента сняли 1920×1080 кадры с HUD; пиксельная проверка освещённого поля и областей HUD прошла, оба получили `seq=1`; второй прошёл тестовый WS reconnect. Созданная прогоном партия была завершена со статусом `ABORTED`. Код PowerShell разобран без ошибок, `git diff --check` чистый. Эти проверки подтверждают воспроизводимость кандидата, не зрительную различимость для каждого игрока.

**Открыто:** материалы зон на кадрах выглядят приглушёнными и требуют отдельной цветовой/световой настройки в выбранном B · Painted Miniature. Нет проверки deuteranopia, независимого зрителя, мультизонной клетки, выделения фигуры, K2/K3, 1280×720/UI 150 %, разных световых секций Sherwood Forest и T. Rex Paddock и замера FPS/GPU. Полный [QA-010](../../10-acceptance-tests.md) и GD-058 не приняты. Текущая серверная карта не содержит мультизон; их нельзя имитировать в арте как факт игрового состояния.
