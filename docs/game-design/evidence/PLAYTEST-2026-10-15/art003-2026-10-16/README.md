# ART-003 — силуэты фигур без цвета (2026-10-16)

Кадр `render_bench.py` Sarpedon K1 (пакет `02d00b90`, 1920×1080, эталон рендера), вырезки шести фигур ×3: верхний ряд
цветной, нижний — в оттенках серого (`01-sarpedon-color-vs-gray.jpg`). Обзорные кадры обеих карт с тем же набором —
`../gd045-prelim-2026-10-16/`.

| Критерий | Наблюдение |
|---|---|
| Все типы различимы без цвета | Гарпия — раскрытые крылья и высокий гребень; Медуза — лук, сидящая поза; Мерлин — посох и длинная мантия; Артур — меч и плащ с широкими плечами. В сером силуэты не путаются |
| 3 гарпии имеют маркеры | цифры 1 / 2 / 3 на подставке, читаются и в сером (ВР-07) |
| Своё / чужое без цвета | подставка: свои — круглая табличка, чужие — шестиугольник; кольцо выбора — сегментированное |
| Сценические размеры единообразны | герои одной высоты в кадре; гарпии ниже героев, но с размахом крыльев того же масштаба; подставки одного диаметра |

Это проверка по делегированию (кадр из игры, не макет). Авторский просмотр пользователя по карточке остаётся.
