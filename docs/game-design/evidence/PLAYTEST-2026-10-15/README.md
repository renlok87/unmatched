## Не проверено / открыто

- Окно «Партия идёт» (BOOT, возврат в живую партию) писало имена героев с сервера по-английски («Medusa», «King
  Arthur») — исправлено 2026-10-16, имена на языке интерфейса (`18-resume-ru-names.jpg`).
- Курсор «недоступно» над окном «Партия идёт» был артефактом devexec, не игры: Slate пересчитывает форму курсора по
  WM_SETCURSOR от ОС (реальная мышь — каждое движение) или при смене захвата мыши; фальш-курсор devexec сообщений ОС не
  получает, форма оставалась с клика по «Войти». `move` теперь вызывает `FSlateApplication::QueryCursor` — проверено:
  рука над «Войти», стрелка мимо.
- Залипшая кнопка карты после схемы не воспроизвелась вручную (руки из 2 и 3 карт); поставлена страховка, первопричина
  не найдена.
- ~~Баннер «Вас атакуют…» 1–2 с держится во время собственной атаки (прогон 4, B2, низкая)~~ — исправлено 2026-10-16:
  пока доигрывается показ прошлого боя, окно защиты ещё закрыто, и статус говорит «Соперник атакует»
  (`bDefenseDeferred`, тест `S09OpponentViewTests`).
- Английский на экране: названия досок «Marmoreal · original map», ник бота «AI Bot», латинское «HP» — по решениям
  ВР-VS5-SC37-01 и строкам контракта; не трогали.
- Окно защиты на 720p / 4:3: «Без защиты» стоит над панелью защиты (раскладка класса S по ВР-VS2-HB29-11), не под ней.
