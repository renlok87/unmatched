# GD-053 — деградация и отсутствие контента (2026-10-15)

- **Нет ассета → понятный placeholder:** герой без арта (Buffy) — портрет-монограмма «B» в комнате и панели
  (`room-unsupported-hero.jpg`), серые фигуры-примитивы на поле, карты — рамка с текстом без иллюстрации; в трассе
  `PORTRAIT fallback id=buffy reason=no-registry-entry`, `CARD-ART fallback key=buffy:… reason=no-registry-entry`
  (missing-report).
- **Неизвестная механика → блок совместимости (новое, `455de43e`):** в каталоге 584 карты 84 героев несут эффекты
  `UNSUPPORTED`. Комната UMG предлагает только ростер MVP; если второе место выбрало героя вне ростера (другой клиент,
  админка), «Начать партию» заблокирована с причиной «Герой соперника пока не поддерживается в этой версии»
  (`why.room.hero.unsupported`) — живьём: хост Медуза, гость Buffy (кадр).
- **Fallback не заменяет отсутствующий эффект:** сервер не подменяет `UNSUPPORTED` молча — эффект уходит в
  `manualEffects` с предупреждением и метрикой `unsupported-effect` (`card-effect-executor.service.ts`).
- **Повреждённый ответ:** обрезанный / битый HTTP-ответ мутации → «исход неизвестен», без повтора, авторитетный
  запрос (UE `Unmatched.S10` 50/50, `adversarial-review-2026-09-27.md`); живые обрывы — `fault-2026-10-15/`.
- **Смена версии:** клиент проверяет хеш токенов темы (`UMHUDTHEME … sha`) и штамп сборки (`package-client.ps1`
  STAMP). **Проверка протокола (2026-10-16):** сервер отвечает публичным `serverInfo { protocol }`
  (`backend/src/health/protocol.ts`), клиент сравнивает с `S08ClientProtocol` (`S08/S08Protocol.h`) на этапе BOOT
  «Загрузка досок» и при расхождении останавливается с баннером «Сервер другой версии» и «Повторить» вместо ошибок
  контракта позже. Старый сервер без запроса (HTTP 400 `Cannot query field "serverInfo"`) считается протоколом 0.
  Одинаковость двух чисел держит `tools/s08/test_protocol_version.py`. Живьём через подменяющий прокси: протокол 99 →
  баннер (`10-version-mismatch.jpg`, трасса `SERVER protocol=99 client=1 MISMATCH`), старый сервер →
  `SERVER protocol=0` и тот же баннер (`11-version-old-server.jpg`), «Повторить» после возврата правильного сервера →
  дальше по BOOT (`12-version-retry-ok.jpg`). UE `Unmatched.S08` 395/395.
