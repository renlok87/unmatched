# GD-047 — UI и доступность: 1280×720, UI 150 %, инспектор (2026-10-15)

Dev-клиент, VS_AI Медуза против Артура, `s08.Settings uiScale=150` (вернул 100 после прогона), окно 1280×720 и 1920×1080.

| Критерий | Итог | Кадр |
|---|---|---|
| 1280×720 и UI 150 % не скрывают обязательный выбор | PASS: панель «Мимолётный взгляд» класса S видна, «Подтвердить» неактивна до цели, статус «Выберите цель на поле»; щелчок мимо цели — тост «Щёлкните подсвеченного бойца на поле» (`6991b6cc`) | `01`, `02` |
| Цвет дублируется формой | PASS: свои P1 — круглые таблички с золотом, чужие P2 — шестиугольник; цели — сегментированное белое кольцо; выбор клетки — кольцо клетки; недоступные карты — серые + тултип причины | `01`, папка `choices-2026-10-15` |
| Инспектор не мешает смене фазы | PASS после фикса: окно защиты, выбор или сброс, открывшиеся под инспектором, закрывают его один раз (`INSPECT close why=choice`, `6991b6cc`); до фикса способность Медузы и окно защиты оставались под ним | `03`, `04` |

Закрыто 2026-10-16 (косметика UI 150 % на 1080p): торцы мраморного картуша и рамок v2 на 150 % были в 1,33 раза
шире расчётных, длинная строка статуса заходила на торцы (`05`). Причина: Slate рисует поля 9-slice у Box-кисти в
пикселях самой текстуры (`ElementBatcher` `AddBoxElements`: `ResourceProxy->ActualSize` через обратное преобразование
раскладки), а не по `ImageSize`. x2-текстура при 1,5 px/su давала поля ×1,33. Порог x2-скинов поднят с 1,5 до 2,0 px/su
(`SkinX2MinPxPerSu`, как у рамок карт): на 150 % и ниже — x1, x2 только с 4K / UI 200 %, где он ложится 1 : 1.
Кадр после фикса — `06-1080p-150-fixed.jpg`: тёмная полоса картуша нормальной ширины, текст внутри. HUD-тесты 126/126.

## Таблички гарпий на узком экране и при UI 150 % (2026-10-16)

Прогон по разрешениям на финальном коде нашёл: в колонке гарпий Marmoreal табличка гарпии 1 закрывала саму фигуру на
1440×1080 (класс S) и при UI 150 % (`07`, `09`). Причина: табличка шире пустой полосы над фигурой; гарпия зажата между
гарпией 3 и Медузой, правило привязки «центр таблички ближе к своей фигуре» отбрасывало места слева и справа, и
оставался запасной вариант `inset` поверх фигуры. Исправлено в `S08ArtHud`: табличка привязана и тогда, когда она
вплотную к своей фигуре и до чужих дальше на 0,4 её высоты (у гарпий — без запаса: на табличке та же цифра 1–3, что на
подставке); `inset` штрафуется перекрытием своей фигуры. То же правило — в гейте `tools/art/t53_readability.py`.
После: `08` (1440), `10` (150 %), `11` (720p), `12` (2560×1080) — фигуры открыты, таблички рядом. Тест
`Unmatched.S08.ArtHudUmg.TagColumn`; UE `Unmatched.S08` 396/396 (`Pause.Tree` — известная гонка движка, прошла при
повторе), t53 pytest 21/21.
