## Галерея в игре

Режим `-S08IconGallery` в редакторском клиенте `-game` (UE 5.8, DX12), 1920×1080. На панели HUD все 23 значка, каждый
играет свой сценарий из контракта. Часы замораживаются в моменты 0, 40, 100, 180, 300, 500, 700, 900, 1100, 1300, 1600
и 2000 мс, в каждый момент снимается кадр с UI (`TakeEvidenceShot`).

```bash
UnrealEditor.exe unreal/Unmatched/Unmatched.uproject /Game/S08/S08Arena -game -windowed -ResX=1920 -ResY=1080 -S08IconGallery -S08IconGallerySize=64 -S08IconGalleryShots=<dir> -S08IconGalleryTimes=0,40,100,180,300,500,700,900,1100,1300,1600,2000
```

Прогоны:
- `reduced`: плюс `-S08ReducedMotion`;
- `normal-32`: `-S08IconGallerySize=32`;
- замер стоимости: `-S08IconGalleryPerfFrames=1200`, с подписями и без (`-S08IconGalleryNoLabels`).

| Что | Где |
|---|---|
| Кадры: обычное движение, 64 px / reduced, 64 px / обычное движение, 32 px | `normal/`, `reduced/`, `normal-32/` (по 12) |
| UE против эталона Python | `<серия>/compare.png`: «UE \| эталон \| \|Δ\|×4» по значку и моменту |
| Метрики сравнения | `<серия>/compare.json` |
| Трасса прогонов, в том числе строки `perf` | `gallery-trace.txt` |
| Автотесты UE | `automation-2026-10-03.txt` |

Сравнение делает скрипт `art/imagegen/hud-icons-v3/_tools/compare_ue_gallery.py`. Значок вырезается из кадра UE.
Эталон строится `motion.compose()` в момент `t mod (сценарий + 400 мс)`.

## Совпадение с эталоном

| Серия | Пар «значок × момент» | Средняя \|Δ\|, 0..255 | Худший p99 |
|---|---|---|---|
| обычное движение, 64 px | 276 | **0,447** | 89 (`state-threat`, 1300 мс) |
| reduced motion, 64 px | 276 | **0,021** | 27 (`loader-spinner`) |
| обычное движение, 32 px | 276 | **0,812** | 105 (`state-immobilized`, 180 мс) |

Максимумы — тонкие контуры при дробном масштабе: билинейная выборка UE против PIL. Сдвигов и пропущенных слоёв нет.

**Детерминизм.** Два отдельных прогона дали 24 кадра из 24, совпадающих до пикселя (`normal` и `reduced`). Первый
прогон — `gallery-ue4`, сборка до кэширования трансформов; второй — `gallery-ue5`, после.

**Масштаб больше 1.** Появление (1,04) и жетон цели (1,25) растягивают текстуру точного размера без мипов. На 32 px
это видно только как мягкий край в первые 100 мс появления, эталон делает то же самое. Шаг размера текстуры вверх, о
котором говорил план, не делался — принятый риск, см. план §6.

## Стоимость

Замер A/B в одном процессе. Блоки по 100 кадров чередуются: галерея скрыта (Collapsed) или показана, все 23 значка
анимируются непрерывно. Первые 5 кадров после каждого переключения не считаются. Итого 570 кадров на каждый режим.

| Прогон | `EvaluateAt` 23 значков, мс: среднее / p95 | Кадр игрового потока: показана − скрыта, мс: медиана / p95 |
|---|---|---|
| с подписями и панелями | 0,053 / 0,070 | +0,225 / +0,088 |
| без подписей (`-S08IconGalleryNoLabels`) | 0,053 / 0,065 | +0,243 / +0,422 |
| до кэширования трансформов (`gallery-ue4`) | 0,083 / 0,138 | +0,362 / +0,806 |

Выводы:
- Слой из 23 одновременно анимирующихся значков стоит **≈ 0,23–0,24 мс в медиане**. Это Slate (тик, раскладка,
  отрисовка) плюс вычислитель.
- Разность p95 зашумлена (0,09–0,42 мс): это два разных набора кадров, а не одно и то же.
- Бюджет HUD П8 (≤ 0,5 мс GT p95) для галереи-худшего случая на грани. В реальном HUD одновременно движутся единицы
  значков, а в покое виджет ничего не пересчитывает и не трогает Slate. Это подтверждено кэшированием: −0,12 мс в
  медиане.
- Всё измерено в редакторской сборке. В упакованной Development не мерилось.

## Что не проверено

- **Жетон цели в живом бою.** Он включается флагом `-S08IconMotion`. Пробник `-S09HudProbe` создаёт виджет (в трассе
  есть строка `HUD art widget icon … source=icon-motion-v3`), но без начатой партии на сервере жетон не показывается.
  Нужен упакованный клиент и двухклиентное демо: `tools/s08/run-phase2-demo.ps1 … -ArtPreviewIconProbe -ClientExtraArgs
  "-S08IconMotion"`. Рамка qa010 `icon` берётся из геометрии виджета без масштаба анимации (1,25 → 1,05).
- **Звук на удары** (`beat_ms`) — следующий шаг.
- **Состояния подбора хода V-02..V-16** ещё не реализованы (MS-T). API для них: `US08AnimatedIconWidget::SetIcon`,
  `PlayAnim`, `SetTeamTint`, `SetReducedMotion`, `GetAnimator().IsCycling()`.
