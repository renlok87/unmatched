# S02 — проверенный серверный бой

Дата: 2026-09-18. GD-006…GD-009 выполнены в пределах серверного S02.
Исходный commit: `c8957e4a1aa0baada079ccdb2b84545b19dca1e9` (S01).
Точный состав проверенного кода и результаты: [verification.json](verification.json).
Эталон: [S01 rules-oracle](../S01/rules-oracle.md), R-08…R-13; отмена объявленного BOOST — R-16.

Это **in-process gameplay harness** с реальными GameActionExecutor, CardEffectExecutor,
CombatResolver, DeckManagement, GameRulesValidator и HeroAbilityRegistry. Только метрики
заменены инертным объектом. Карты и состояния заданы явно; случайной раздачи нет.
HTTP/WS-клиенты и UE не запускались, БД не менялась, чужие процессы не останавливались.
Это не проверка всех 27 карт, полной партии или сетевого MVP.

## Воспроизведение

Нужны зависимости из `backend/package-lock.json` и Node/npm. На этой машине worktree
использовал junction `backend/node_modules` на установленные зависимости исходного
checkout; сборка и тесты исполнялись **из этого worktree**, не из живого backend/dist.
На другой машине установить зависимости обычным способом. Credentials не нужны.

```powershell
./tools/s02/run_harness.ps1
cd backend
npm test -- --runInBand game-engine game-state.service.spec.ts
npm run build
cd ..
python docs/game-design/_validation/validate_package.py
node tools/s01/verify_capture.mjs
node tools/s01/verify_cleanup.mjs
python tools/s01/verify_artifacts.py --ue-artifact-root C:/Users/ren/.codex/worktrees/2b4f/unmached
```

Последняя команда проверяет сохранённый пакет S01 по SHA256 и старые smoke-маркеры;
это не новый запуск UE. Без `--ue-artifact-root` она ищет пакет в текущем checkout.
Обновлена только совместимость проверяющего скрипта с последующими done-спринтами
и расположением уже собранного артефакта.

Регрессии ответного урона, terminal-check, defender-first, продолжений выбора и
Feint/boost сначала воспроизводились красными тестами. Итог: **624/624 теста,
20/20 suites**, `tsc --noEmit` + Nest build; документальные проверки отдельно.
Изменены старые ожидания, требовавшие ответного урона/отложенного GAME_OVER, и
противоречивые fixtures с живым героем у якобы мёртвого игрока.
