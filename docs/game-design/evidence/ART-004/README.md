## Исходный preflight и выбор режима

В открытой [Tripo Studio](https://studio.tripo3d.ai/ru/workspace/generate) проверен вход **multi-view**: слоты «Спереди», «Слева», «Справа», «Обратная сторона». Иконка с несколькими изображениями открывает **Batch to 3D до 30 файлов** — это другой режим для нескольких моделей, его не использовать для одного персонажа. [Документация Tripo H3.1](https://developers.tripo3d.ai/en/docs/generation-multiview-to-model/standard) допускает front + дополнительные виды, минимум два изображения; [официальное руководство](https://www.tripo3d.ai/blog/multi-view-to-3d) рекомендует согласованные front/side/back. Веб-интерфейс и API могут иметь разные цены/параметры, поэтому окончательную стоимость фиксировать по кнопке Studio после загрузки.

Исходный план **одного** пробного запуска: H3.1, multi-view, «Геометрия и текстура», фронт/лево/спина, правый слот пустой. 8K-текстура и «генерация по частям» не нужны для первой проверки; 2K-карты и рабочая топология готовятся отдельно. До загрузки был установлен «Приватный»: при первом осмотре форма показывала «Только для обмена». Лимит 20 MB на каждый файл соблюдён. Баланс перед запуском — 25 200 кредитов; после загрузки форма показала 55, списано 55. Подробности — в [отчёте](tripo-pilot-20260927/README.md).

## Художественный и технический бриф для оценки результата

Medusa — стилизованная мрачная миниатюра, лучник. Нужны семь узнаваемых змеиных голов в верхнем силуэте, бронзовый венец, серая кожа, тёмная накидка, лук в левой руке, колчан за плечом и нейтральная круглая подставка. Изображения служат **референсами**, а не пиксельной разметкой UV или утверждённой палитрой сцены. Избегать дополнительных конечностей, дублированного оружия, слитых змей, нарисованной вместо геометрии тетивы и фотореалистичного микрошумa. Сцена S05 содержит полезный технический риг/клипы, но [её K2](../S05/art-references/frames/frame-K2-closeup.png) показывает геометрически иную условную Medusa; внешний вид S05 не принимать за этот концепт.

При просмотре генерации последовательно проверить все четыре стороны, крупный план головы/семи змей, обе кисти, положение лука относительно тела, колчан и непрерывность плаща. Если хотя бы один из этих признаков не выдержан — сохранить результат как пробу, а не продвигать в ретопологию. Сам Tripo-меш, даже удачный визуально, не является `ASSET-MEDUSA-001`: нужны ретопология, UV0, проверенные BC/N/ORM, настраиваемый TeamColor, опора/поворот/коллизия, сокеты `Weapon` и `Head`, риг и четыре клипа по [карточке 04 §3.1](../../04-blender-production.md) и [анимационному брифу 18](../../18-animation-production-brief.md). Предлагаемые до GD-058 ориентиры: высота 50–55 uu, база Ø30×6 uu, 15–25k tris и 2K-текстуры; **не принимать их как утверждённые бюджеты**. S05-скелет и клипы можно использовать только после проверки совместимой топологии и ретаргета, не автоматически.

Кандидата нужно проверить на Cobble City с [ART-005 покрытием и зонами](../ART-005/README.md), затем сравнить с [листами A/B/C по Sherwood Forest и T. Rex Paddock](../ART-002/README.md#привязка-следующего-цветового-прохода-к-готовым-картам) и проверить в UE на **двух реальных картах с различным цветовым рисунком**. Листы ART-002 служат только пробой языка света. Красный/синий цвет игровой зоны не равен художественному освещению: материалы Medusa должны сохранять читаемость лица, лука и команды в холодных и тёплых секциях без перенастройки её текстур под каждое поле. Финальная приёмка — K1/K2/K3 с HUD и отдельный packaged-замер по GD-058/ACC-022; пока открыта.
