Именованные слоты надёжнее позиционного API-порядка front/left/back/right. Интерфейс Studio располагает right перед back. Batch to 3D — другой режим.

## Bridge, Remesh и Smart UV

Панель Studio уже показывает Blender Bridge подключённым, переключатель включён, UI-версия `v1.0.3`. В системе открыт пользовательский Blender. Передача в него не выполнена, чтобы не добавить объект в чужую открытую сцену. Исходный экспорт сохраняется отдельно для проверки.

[DCC Bridge](https://www.tripo3d.ai/integrations/blender): Blender ≥4.1, Windows/macOS, Chrome/Edge; тарифы Pro/Max/Team. Официальная страница на момент проверки называет Bridge 1.0.32 — это не доказательство установленной версии. [Руководство](https://www.tripo3d.ai/blog/tripo-dcc-bridge-for-blender) указывает экспорт с pivot снизу по центру, максимальными текстурами, без pack_uv и vertex colors. Bridge ускоряет передачу, но не проверяет контракт импорта UE. API-аддон Blender — другой продукт с отдельными API-кредитами.

[Smart UV](https://www.tripo3d.ai/blog/smart-uv): до 80k треугольников / 40k квадов; первые две модели бесплатны, затем Pro/Max/Team — 20 кредитов. Для плотного исходника сначала нужен Remesh. Проверять швы лица, змей, кистей; пересечения островов, плотность, padding и перенос текстуры. Стоимость операции в аккаунте нужно проверять по форме перед запуском.

На самом исходнике [Studio показывает](smart-uv-limit.png) существующую UV-развёртку с заполнением **60.9%**, но кнопка Smart UV отключена из-за 1.88 млн треугольников. [Форма Remesh](remesh-options.png) предлагает P1.0, quad, 10k полигонов за **40 Studio-кредитов**; этот вариант может попасть в предварительные 15–25k tris после триангуляции, но не обещает сохранность тонких змей и тетивы. Пробу Remesh/Smart UV в этом запуске не заказывали: сначала зафиксировали исходник и выявили ручные проблемы силуэта/разделения.

## Решение по следующим персонажам

Можно параллельно заказать **только пробные 3D-черновики**, по одному H3.1 multi-view на персонажа, за текущие **55 Studio-кредитов каждый** (ориентир 165 суммарно; цену перепроверить в форме перед каждым запуском), с Private, без 8K/parts. Точные слоты: Arthur `front+left+back` v5, Merlin `front+right+back` v3, Harpy `front+left+back` v5 из `art/imagegen/mvp-v1/generation-inputs.json`. Противоположные боковые виды v7/v5/v5 остаются спорными кандидатами и **не загружаются**. Каждый GLB хранить с task ID и исходными SHA, без замены Medusa/S05. Параллельная генерация этих черновиков независима; их Blender/UE-доводку планировать последовательно после просмотра всех ракурсов. Если три проверенных вида конкретного героя дают противоречивые кисти/оружие/крылья, не ретраить автоматически, сначала исправить исходные виды или моделировать детали вручную.

## Приёмка, которая остаётся обязательной

Ретопология с деформационными петлями; UV0 без нежелательных перекрытий; BC/N/ORM и TeamColor; разделение тела/оружия/базы; масштаб и опорный pivot; сокеты Weapon/Head; веса, четыре клипа без root motion; импорт UE и K1/K2/K3 с HUD; две реальные карты с разной палитрой; packaged-проверка. Предварительные 15–25k tris/2K и 50–55 uu не превращаются в утверждённые бюджеты от факта генерации.
