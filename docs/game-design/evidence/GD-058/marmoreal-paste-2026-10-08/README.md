# GD-058 · дополнение к финальному акту: Marmoreal с нарисованным задником (EN-17, 2026-10-08)

**Принято по делегированию (без личного просмотра пользователя), лёгкий режим (ВР-59), 2026-10-08.** Это дополнение
к [финальному акту 2026-10-03](../final-2026-10-03/README.md); прошлые акты не правились. Статусы реестра этим актом
не повышаются. Машина — ПК разработки (RTX 4090 / i9-13900F), **не D-07**.

## Почему пересъёмка

Правило §1.2 акта: изменение строки таблицы требует пересъёмки K1 и K2 обеих карт. Изменилась строка «Свет и рендер» и
вид доски Marmoreal:
- профили `S08ArtBoardProfiles.json` rev 23 (EN-13, `8ea9c6c9`): нарисованный задник Marmoreal по умолчанию
  (ENV-U16, решение пользователя 2026-10-04 «Нарисованный задник»), 3D P5c — откат `-NoConceptPaste`;
- свет героев Marmoreal P9c (AN-36 / EN-14, `7ca326ad`): ключ 5,5 лк `#FFF0E0`, контр 2,75 лк `#C8D8FF`, блик 1,0;
- ветер вклейки `ampPx` 0,4 (ВР-VS5-47, `b68e21b4`; в `-Bench` заморожен).

Решение по делегированию ВР-EN.13: объём — K1 / K2 обеих карт и ACC-022 Marmoreal в лёгком режиме; полный раунд —
в конце фазы 3.
