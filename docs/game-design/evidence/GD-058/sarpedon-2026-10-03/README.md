## Известные ограничения (VERDICT §5–6 и P10)

- **В-3** (пушки / SSIM корабля) не выполнен:
  - SSIM полигона корабля 0,442 < 0,45;
  - cannon-1 тёмная;
  - стволы смотрят по нормали борта, а не влево, как на рисунке: поворот выдавливает колёса лафета сквозь борт.
- **В-5** (знамя +20 %, lantern-left) и **В-6 / И-3** (гладкие паковые камни у западного и северного края рамы) не
  делались. Это самый заметный стык стилей на K2.
- **Водопад:**
  - теперь тёмная полупрозрачная вуаль с рваным верхом, а не белые струи между тёмными скалами, как в концепте;
  - прямые боковые стенки выреза острова не менялись.
- **Огонь** на K1 по-прежнему читается «точечным пятном», жаровня — красно-оранжевым комком. **G7** — свет жаровни
  (std) не исправлен.
- **G2** (тень под передним краем рамы и под Медузой) — слабость ночного ключа, одинакова с P5c. **G4-SSIM** 0,49 < 0,55:
  SSIM для пары «живопись ↔ движок» — слабая мера. **D1** подсветки героев открыт. **G6**: lantern-left 0,69 < 0,8.
- Панель и доработка смотрели статичные кадры `-Bench` и короткий live. Живую партию на Sarpedon после P10 не
  запускали.
- Стоимость измерена на RTX 4090, не на целевом D-07: ACC-022 с пометкой «не D-07», как в РД-4. Контактные тени P9b
  теперь вошли в замер: K1 2,60 мс со светом героев.
- Концепт sarpedon-v2 — imagegen-правка кадра игры. «Идентичность» ему измерялась SSIM / ΔE по C0.
- Решение по делегированию, без личного просмотра пользователя.
