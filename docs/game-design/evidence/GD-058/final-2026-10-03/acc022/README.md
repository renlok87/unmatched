# ACC-022 на ПК разработки (не D-07): оригинальные карты, 60 FPS, 1080p — 2026-10-03

Основание: РД-4 в [2026-10-03-delegated-decisions.md](../../../../decisions/2026-10-03-delegated-decisions.md) — целевого
ПК класса D-07 нет, принимается замер ПК разработки с пометкой «не D-07».

**Пометка на каждом числе: dev-PC (RTX 4090, i9-13900F), не D-07; на машине работала параллельная сессия пользователя
(загрузка GPU без клиента перед замером — 44 %, `gpu-idle-before.txt`).**

## Как мерили

- Упакованный клиент Development, штамп `8f524d8b` (вид Sarpedon P10, жетон v3 по умолчанию, `Licenses/` в стейдже).
- `python tools/art/render/render_bench.py run --variant dx12-lumen-high-v2-fps60 --repeats 1 --views K1+K2x1.6+K2x2.5
  --warmup 30 --settle 8 --measure 65 --bench-fixture …/S08Bench<Map>.json`: один клиент, 1920×1080, DX12 SM6, Lumen,
  High, герои v2, свет героев, `t.MaxFPS 60` (как у клиента по умолчанию), окно замера 65 с на вид.
- Кадры несут отпечаток `RENDER`, все шесть — на эталоне (`referenceCheck` в `bench-run.json`).

## Что это значит

- На ПК разработки цель ACC-022 «1080p / 60 FPS» на обеих оригинальных картах выполнена с запасом: кадр GPU ~2,5 мс
  при бюджете 16,7 мс.
- **Это не замер D-07.** Бюджет целевого класса этими числами не подтверждён; GPU-кадр 2,5 мс на RTX 4090 не
  переносится на слабые видеокарты линейно (Lumen, render thread 4–5 мс).
- Двухклиентный режим (два клиента по 30 FPS) этим прогоном не мерился; см. акты P6 и промежуточный GD-058.
