# GD-058 · финальная приёмка по делегированию: герои v2, HUD и доски-карты Marmoreal и Sarpedon (2026-10-03)

**Что это.** Финальный акт раннего визуального gate GD-058. Он собирает три решения:
- промежуточную приёмку героев, HUD и читаемости на Cobble и фикстурах — [акт 2026-09-30](../interim-2026-09-30/gd058-interim-2026-09-30.md);
- решение самого пользователя по Marmoreal — [акт Marmoreal](../marmoreal-2026-10-01/README.md);
- приёмку Sarpedon по делегированию — [акт Sarpedon](../sarpedon-2026-10-03/README.md).

Затем акт закрывает по пунктам перечни §4, §8 и §9 промежуточного акта.

**Кто решает.** Одна приёмочная панель (агент) по делегированию пользователя, **без личного просмотра
пользователя**. Порядок — РД-4 в [журнале решений 2026-10-03](../../../decisions/2026-10-03-delegated-decisions.md):
«После РД-2 и РД-3 — финал по делегированию. ACC-022 на целевом классе D-07 измерить нечем: принимается замер ПК
разработки с пометкой «не D-07»». РД-2 (акт Marmoreal, `b1d1a353`) и РД-3 (акт Sarpedon, `80e52060`) выполнены.

**Полномочие.** Пользователь, дословно:
- 2026-09-29: «делай все без меня»;
- 2026-10-03: «сам реши все вопросы».

**Правила честной пометки** (как у промежуточной приёмки и РД):
- решение записывается как «принято по делегированию (без личного просмотра пользователя)»;
- статус художественной приёмки пользователем по делегированию не ставится, статусы реестра этим актом не повышаются;
- FAIL остаются FAIL;
- если пользователь посмотрит сам и решит иначе, прав он.

## 1. Что решено

**Вердикт: принято по делегированию (без личного просмотра пользователя), 2026-10-03.** Условие вердикта (§5.1)
выполнено: p95 кадра 16,67 мс на всех шести видах обеих карт.

Условие. Числа ACC-022 на ПК разработки («не D-07») должны дать p95 кадра ≤ 16,7 мс на каждом снятом виде обеих
карт. Если хотя бы один вид это не выполнит, вердикт этого акта меняется на «не принято по делегированию», а
ACC-022 записывается как FAIL даже на ПК разработки.

### 1.1 Что принято по делегированию

Эталон перед серией:
- **Фигуры.** Шесть бойцов набора D-03 — Medusa H2LD и 3 × Harpy H3LD против King Arthur H2LD и Merlin H2LD — на
  мастере `M_UM_Figure_v2.1` с клипами H2Anim.
- **Доски.** Две оригинальные карты:
  - Marmoreal — в виде P5c/P6, который пользователь принял сам (ENV-U15), плюс свет героев P9b;
  - Sarpedon — в виде lit3d + P9b + P10, принятом по делегированию.
- **HUD.** Плашка, теги, кольца и дуги прицела; жетон цели v3 — по [акту ART-011](../../ART-011/hud-icons-v3-2026-10-03/README.md).
- **Регрессия.** Cobble City 5×6 и фикстуры Sherwood 8×5 / T. Rex 7×5 остаются регрессионными досками
  читаемости, как в промежуточном акте.

Сборка карт: packaged со штампом `8f524d8b` (в нём и `f5d6d740` — жетон v3, и `7509eacb` — раннер T4.3). После
штампа `unreal/` не менялся. Сборка Cobble: `f8accb3d…` (2026-09-30).

### 1.4 Что этим вердиктом не покрыто

Эти пункты остаются FAIL или открытыми; подробности — §4.
- **Целевой ПК.** ACC-022 и perf-gate на целевом ПК D-07 — **остаются открытыми**. Норматив 15 прямо говорит: «Если
  указанного ПК нет, performance-gate остаётся открытым». Условие GD-058 «6 копий фигурки и участок проверены на
  целевом ПК» не выполнено.
- **Нормативы QA-009 / QA-010 / GD-030:**
  - коллизия мышью и реальный ввод (T4.3);
  - независимый зритель-человек;
  - номера гарпий H1 / H2 / H3.
- **FAIL:**
  - лицо Medusa на K2 1,6×;
  - тёмные перья Harpy;
  - гейты света героев на Marmoreal и Cobble;
  - В-3, G4-SSIM, G6 и G2 Sarpedon.
- **K3 в текущем виде по умолчанию** — живого боя после P6 нет.
- **HUD-долг:** отладочный текст, плашка поверх Medusa на K1, теги на шве, разметка зон.
- **Художественная приёмка пользователем** — её нет, кроме решения самого пользователя по доске Marmoreal.
