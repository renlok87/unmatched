# GD-058 · повторная самостоятельная арт-приёмка, 2026-09-28

**Решение: GD-058 не принят; ART-004 и ART-005 не закрыты.** Пользователь делегировал художественное решение и приёмку, поэтому это итог проверки имеющихся результатов, а не просьба об утверждении. Выбранный язык **B · Painted Miniature** сохраняется. Доказательства показывают рабочий технический путь Blender → Unreal, живой packaged K1 с HUD/`boardState` и [сравнение игрового K2](../ART-004/live-k2-zoom-comparison-2026-09-28.md), а также улучшенные камень, дерево и углы Cobble City. [Акт однослотовой правки лица](../ART-004/face-winding-lighting-self-acceptance-2026-09-28.md) устранил отсечение; [следующая двухслотовая проба](../ART-004/face-section-evaluation-2026-09-28.md) сделала лицо цельнее при прежнем PBR-материале, но оставила открытым художественный контраст. Полного K1–K3 с итоговыми ассетами и измеренного packaged-результата на D-07 по-прежнему нет.

Акт [2026-09-27](acceptance-review-2026-09-27.md) остаётся историческим: его строка «генерации Medusa нет» больше не описывает текущий состав поставки. Для текущего вердикта использовать таблицу ниже. Статус задач в [бэклоге](../../14-sprint-backlog.csv) не изменён этим актом.

## Следующий приёмочный проход

1. По [акту v2](../ART-004/neck-winding-evaluation-2026-09-28.md) довести шейдинг лица Medusa в уже работающем игровом K2 с подставкой, змеиным силуэтом, кистями и луком; проверить нормали/тангенты и остаточный контраст. Пробный перенос общего света оценивать отдельно с доской, другими фигурками и GPU; не переносить персональный источник света без проверки. Анимации остаются вне работы до согласованного видео-пайплайна.
2. Довести общую Cobble-сцену: заменить технические подписи и плоские debug-заменители, подтвердить клик/команду/статус с HUD, решить полезный диапазон зума по живому сравнению 1,6×/5× и снять K3 из той же сцены. K3 может быть честно помеченной постановкой визуального события, если исполнены условия кадра.
3. Повторить QA-009/010 на этой поставке и packaged D-07 на целевом классе ПК. После этого заново вынести решение о GD-058. **Шесть копий одной принятой Medusa для раннего gate допускаются** [строкой GD-058](../../14-sprint-backlog.csv); производство Arthur/Merlin/Harpy и других полей не требуется для закрытия этого gate и не должно подменять его.
