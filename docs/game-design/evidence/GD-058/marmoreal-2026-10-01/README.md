вопросы», РД-2 в [2026-10-03-delegated-decisions.md](../../../decisions/2026-10-03-delegated-decisions.md). Акт фиксирует

## Реестр

Статусы записей реестра этим актом **не повышаются**:
- `ASSET-ENV-M-BACKWALL-001` (стена Marmoreal) — дочерняя запись `ASSET-ENV-KIT-001`;
- кит окружения, поднос и рама — общие с Sarpedon, а Sarpedon не принят.

Правило реестра: «дочерняя запись не может быть выше родителя». Ссылка на акт записана в `nextStep` и `blocker` этих
записей. Повышение — когда будет принят Sarpedon или Marmoreal-часть кита выделится в свою запись.
