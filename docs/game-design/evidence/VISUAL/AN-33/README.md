## Приёмка по пунктам

- D6 зоны кожи меньше P9b: P9b под вклейкой (p9c/metrics/p9b-paste.json) — 10,06; итог 10,2–10,5 — **не выполнено**
  строго (в пределах шума сессии; против текущей базы P9c 10,6–11,1 — лучше). Записано, не скрыто.
- Порядок зон по L как у эталона — PASS (1,00). D3 ≤ 0,5 % — PASS (0 %).
- Face ROI p50 Marmoreal ≥ 0,9 × Sarpedon: 156 / 144 = **1,08 — PASS** (база была 0,98).
- В сером черты лица различимы на K2×2,5 — **не выполнено, и материалом не решается**: в позе покоя ВР-06 (вполоборота к
  камере, голова к врагу) камера K2 видит волосы и затылок, лица в кадре нет ни на одной карте
  ([лист K2×2,5](medusa-K2x2p5-marm-base-final-sarp-base-block.jpg)). Кандидат — поза головы / поворот покоя (AN-23…25),
  не этот рычаг.
- Остальные фигуры не изменились: вне рамки Medusa итог − база = 0,46 / 0,44 / 0,44 средн., > 24: 0,034 / 0,015 / 0,020 %
  (K1 / K2×1,6 / K2×2,5) — столько же, сколько повтор базы (0,46 / 0,44 / 0,43; 0,033 / 0,019 / 0,018 %).
- G-LOOK: Marmoreal original, `backdrop=paste(default)`, Sarpedon `lit3d(default)`, шесть фигур v2
  (кадры K1 — [AN-31/vs8-look-*](../AN-31/)). Кадры открыты в цвете и сером.
