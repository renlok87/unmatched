# AN-31 — лист приёмки

Лист собран `tools/art/visual/sheet.py` 2026-10-07 по 02-visual-design.md §13.2.

**Решение:** художественно принято, по делегированию (2026-10-06, ВР-07 и ВР-72)
**Дата решения:** 2026-10-06
**Ревью:** ZCode (Z-1), один проход, арт и рамки задачи вместе (02 §13.3)
**Флаг отката:** `-S08BaseDigitLegacy` (S08ArtLook.h, трасса ARTLOOK `baseDigit=on|legacy`)

## Что сделано (карта AN-31)

Диск card.navy + цифра card.cream (runtime-текст UTextRenderComponent поверх диска-меша, не UDecalComponent;
ВР-AN08 размеры от границ подставки: диск ⌀0,5 верхней грани, цифра 0,6⌀, центр на 0,7 радиуса к камере),
у трёх гарпий v2, компоненты на акторе (не вращаются с фигурой), пересчёт места в ApplyFighter/EndMove,
скрытие в растворении и Place-переносе. Шрифт — офлайн FontFace `F_UM_RobotoBoldCondensed` (Roboto Bold
Condensed из движка, Apache 2.0) + transient UFont в C++ (UE5.8 не даёт офлайн-импорта композитного шрифта —
ВР-Z1-03, см. Z-1 README). Трейс `ARTPREVIEW basedigit fighter=.. n=.. discUU=11.0 capUU=6.6`.

## Что проверено (packaged `-Bench`, stamp `f8903fb9`, обе карты)

- Трейсы: `basedigit fighter=f-0-sk0 n=1`, `f-0-sk1 n=2`, `f-0-sk2 n=3` на обеих картах — цифры совпадают
  с тегом (последняя цифра Label, та же функция, что AudioKeyOf).
- K1 (обе карты): диск виден, замер по сетке (кроп 4× с линейкой 10 px): Marmoreal ≈ 8–9 px, Sarpedon
  ≈ 8–10 px — критерий «диск ≥ 8 px» выполнен.
- K2×1,6 в фокусе на каждой гарпии (`-BenchMovePose=140 -BenchMovePoseFighter=f-0-sk0|1|2`; Sarpedon sk0 —
  без свободного двухрёберного пути, сфокусирован `-BenchClipPose=Idle@12 -BenchClipPoseFighter=f-0-sk0`):
  диск 61–102 px, высота цифры ≈ 0,6·диск ≈ 36–61 px — критерий «цифра ≥ 9 px, читается» выполнен; порядок
  1/2/3 сверен с трейсами по кропам (стек трёх фокусов Marmoreal).
- Диск у кромки к камере, не на когтях и не на кольце команды (глаза, кропы обеих карт); в середине хода диск
  едет с фигурой (фокус-кадры сняты на t=140 мс хода).
- Цвета: диск card.navy, цифра card.cream (контраст пары ≈ 15,6 : 1 по карточке); в сером различим (ряды
  листа).

### Живой бой (обе карты, те же прогоны что AN-24)

`basedigit` 3 строки в трейсах обеих карт; на результатных кадрах демо диски на подставках гарпий видны,
после ходов на месте; при растворении скрыт (погибший Артур — не гарпия; скрытие проверено юнит-тестом
UpdateBaseDigit → смерть/Place).
