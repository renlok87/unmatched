## Решения по делегированию

- **ВР-VS5-18.** P9c = ключ `#FFF0E0` 5,5 лк, контр `#C8D8FF` 2,75 лк, блик контра 1,0. «Не ярче P9b» понимается как
  (а) люксы ключа и контра не выше P9b, (б) средняя яркость тела на K1 не выше P9b в тех же кадрах под вклейкой. Цвет
  контра и его блик — вне явного списка строк карточки, но в её цели (кромка D4 при меньших люксах); тесты
  `HeroLight.Shipped` и `test_hero_light.py` допускают блик контра 0,6…1,0 и любой холодный контр.
- **ВР-VS5-19.** Методика замера: каждый прогон (`off`, маски, `on`, `idle`) — первый кадр свежей live-сессии (`start` с
  `--profiles` для масок и idle). Перезагрузка с файлом override сдвигает фазу анимации фигур (два кластера поз:
  до 1,7 % пикселей > 24) и ломает маски и D5; idle снимается всеми тремя видами (часы `-Bench` зависят от номера вида).
  Маска фигуры `maskfig` — с `litPedestal: true` (у P9b подставка всегда была в канале 1; иначе маска подставки пуста).
  Четвёртый прогон после трёх итераций — не подбор, а пересчёт итога i2 к пределу «не ярче P9b» (люксы ×0,79).

## Остатки

- D1 FAIL (0,93–0,97) — ни один параметр карточки его не поднял; кандидат — материал (AN-33, AN-34), которые карточка
  ставит после этого света.
- Свежий packaged `-Bench` K1 / K2×1,6 / K2×2,5 и H5 (≤ +0,25 мс) — EN-15.
