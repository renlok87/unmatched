# FX-35 — CUE-017 обесцвечивание при разрыве связи

**Статус: технически импортировано (VS-6 F4, `1ddec221`, ветка `feat/visual-vs6`, не влито).** Кадры — editor `-Bench`
с замороженным весом; живой обрыв стендом S10 на двух клиентах — шаг Frames (бэкенд стенда в шаге F4 не поднимался).
Приёмка — по делегированию.

## Что сделано

- Третий набор `S08CuePostProcess`: насыщенность сцены в кадр события, вес 1 сразу; держится до CUE-018 (FX-36).
- Событие — **ребро значка CONN (HB-14) в `lost`**: поток партии не готов после того, как был готов в этой партии
  (`FS08NetWatch`, те же входы, что `UmConnection::Resolve`; тест `CuePostProcess.NetWatch` сверяет оба). Начало
  партии (первая подписка) — `syncing`, не разрыв. Звук CUE-017 по-прежнему через 1,5 с (AU-S6), кадр — сразу.
- Повторный разрыв, пока связь не вернулась, — duplicate (D5): `FX desat duplicate t=…`, состояние не меняется. Разрыв
  во время возврата цвета — снова полный вес.
- С грейдом поражения CUE-016 — × 0,8 × 0,64. Reduced motion — то же (движения нет). `-S08FxLegacy` — нет.
- Не затемняет и не размывает: меняется только ColorSaturation (яркость кадра 0,1327 → 0,1340). HUD (UMG) не тронут.
- Трасса: `FX desat on t=<ms> sat=0.64 grade=<none|victory|defeat>`. Бенч: `-BenchFx=desat,<w>`.

## Решения (по делегированию)

- **ВР-VS6-43.** Строка таблицы «desaturation 0.3» мерится на кадре (HSV S −30 %, приёмка карточки). ColorSaturation
  движка действует до тоновой кривой, которая возвращает часть цветности: 0,7 дало −25,2 %, поэтому в движок идёт
  **0,64** (−30,6 % / −30,1 %). cue-table CUE-017 исправлена.
- **ВР-VS6-42.** Разрыв для кадра — ребро `lost` значка CONN (сразу), не 1,5 с звука: значок и сцена говорят одно.

  — шаг Frames.
- «Пауза skeletal» из 07 в карточку не входит (клиент idle-анимации не останавливает).
