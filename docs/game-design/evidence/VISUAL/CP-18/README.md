# CP-18 — буст: карта рубашкой вверх и чип «+N»

VS-3, шаг U1, 2026-10-07, ветка `feat/visual-vs3`. Карточка — `cards-portraits.csv` CP-18; 02 §6.3, §5.3; 04 §2.6–§2.8
(SD-54, SD-56); QA-005; ВР-CP11. Общее — [README CP-15](../CP-15/README.md). Коммит `67a57467`.

**Статус:** API виджета, тест приватности и лист движения готовы. Кадр C (атака с бустом, оба клиента одного боя) и
трасса защитника без `boostValue` до `state=reveal` — после H9 (COMBAT-EDGE) и рук HB-24, шаг «Кадры». Полёт карты в
слот буста делает владелец.
**Откат:** `-S08SlateHud=hand,combat` (у владельца); `-S08CardArtLegacy` — плашка вместо рубашки.

## Что сделано

- `SetFaceDown(bool, AnimMs = 150)` — переворот в рубашку героя владельца:
  - scaleX 1 → 0 (75 мс), смена лица в кадр ребра, 0 → 1 (75 мс);
  - reduced motion — кроссфейд лица 100 мс (ВР-VS3-10).
- `SetBoostChip(N)`:
  - `state-boost` 24 su (диск card.navy с белым кольцом v3) и «+N» живым текстом (`hud.card.boost`, И-7: цифры не
    запекаются);
  - чип появляется после переворота (150 → 330 мс) по ключам `appear`;
  - `HiddenBoost` — чип без числа (буст соперника, ВР-CP11), `NoBoostChip` — убрать (уход 120 мс);
  - место — по центру верхнего края, 16 su над рамкой (ВР-VS3-09).
- Приватность:
  - буст соперника приходит через `ApplyModel(…, bFaceDown)`: в виджете нет ни имени, ни значения, ни `boostValue`;
  - трасса пишет только `key=back:<hero> lang=back … chip=1`, без числа (ВР-VS3-11).
- UE `Unmatched.S08.Hud.Card.Boost` проверяет:
  - 37,5 мс — ещё лицо, scaleX внутри (0, 1); 75 мс — ребро, рубашка; 150 мс — рубашка;
  - чип 0,15 на 150 мс и 1 на 330 мс, текст «+3» у Noble Sacrifice (BOOST 3 из данных);
  - в трассе нет «+3»; у соперника нет числа и лица;
  - reduced — кроссфейд.
