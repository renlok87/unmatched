## Решения по делегированию (шаг V3)

| № | Решение | Почему |
|---|---|---|
| ВР-VS4-55 | «+N» — число не показанных зон (ключей − 2), а не «+1» | у четырёх зон не показаны две; на настоящих досках ≤ 3 зон — только тест |
| ВР-VS4-56 | L6 20…23 px (K1 на 720p: круг 66–70 px, L6 21 px) — значок 24 px; ниже 20 px — нет | значки зон сейчас — единственный канал L6 у клетки (бейджи MS-T-10 ещё не рисуются); карточка требует ≥ 24 px на 720p; экспорты начинаются с 24 |
| ВР-VS4-57 | Колонна сначала на правом якоре; если задевает фигуру или тег — ближайшее из мест справа от препятствия, выше, ниже (минимум перекрытия, затем расстояния) | `dont`: не закрывать фигуру и тег; на Marmoreal M01 и Sarpedon S25 якорь попадает на фигуру |
| ВР-VS4-58 | Лист `-S08IconGalleryWorld` — см. [HB-45](../HB-45/README.md#решения-по-делегированию-шаг-v3) | |
