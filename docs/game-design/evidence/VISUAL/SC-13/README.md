## Что сделано (`do`)

| Пункт | Где и как |
|---|---|
| Состояние `error` | ошибка ответа `availableGames` или 10 с без ответа (`FUmLobbyPoll::TimedOut`) → `ErrorIcon` `resource-connection-lost` 48 su (красный — только его X), `ErrorText` «Не удалось загрузить список игр» (`screens.lobby.list.error`, `text.primary`), `RetryButton` «Повторить» (обычная, `common.btn.retry`); «Обновить» скрыта (одно действие один раз); главная — «Создать». |
| Повтор | «Повторить» — внеочередной запрос; опрос 15 с продолжается; поздний ответ заменяет ошибку списком. Создание и вход по коду при ошибке работают (колонки не блокируются). |
| Звук | `UI-REJECT` один раз на переход в ошибку, `UI-BTN-CLICK` на «Повторить». |
| Трасса | `LOBBY list state=error reason=timeout waited=<ms>` / `reason=failed`; `SHOT widget id=UI-SCR-LOBBY … state=error`. |
