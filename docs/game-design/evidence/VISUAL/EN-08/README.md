# EN-08 — мерцание фонарей Marmoreal: накладка и точечный свет

**Статус: технически готово, по делегированию (2026-10-07, VS-5 шаг E2, ветка `feat/visual-vs5`).** Вклейка Marmoreal
ещё за флагом `-ConceptPaste` (по умолчанию её включает EN-13). Кадры — live tune editor `-game` (`-ConceptPaste`,
настоящая карта Marmoreal, шесть фигур v2). Приёмочные packaged `-Bench` — EN-15.

## Что сделано

- Профиль `marmoreal-original.conceptPaste` оставлен со значениями E1 (ВР-VS5-01): 5 точек на мировых точках
  `paint-lantern` (`lantern-nw/ne` 80 cd r 480, `lantern-w/e` 75 cd r 460, #FF9A45, мерцание 0,08 @ 4,0 / 4,5 / 5,0 / 5,5 Гц;
  `portal-glow` 65 cd r 380 #FFB066 без мерцания), `hide` += `layoutLights`, 6 слотов `anim.lanterns` (4 со ссылкой
  на свет, 2 бра со своим мерцанием 0,06 @ 6,0 / 6,5 Гц). Бюджет 6 точек вместе с moon-pool, теней нет.
- Подбор (лёгкий режим): ни одна итерация не понадобилась — блик на ближней к фонарю фигуре идёт со стороны фонаря,
  пересвета нет, зоны различимы (таблица). `heightUU` 100 и интенсивности не менялись (ВР-VS5-16).
- В заметку блока профиля добавлена строка ревизии VS-5 E2.

## Решения по делегированию

- **ВР-VS5-16.** Значения света и мерцания остаются из P5c и образца Sarpedon (ВР-EN.14), подбор не нужен. Пункт 2
  меряется с шагом ≈ 0,7 с: снимок live tune занимает ≥ 0,45 с, шаг 100 мс инструментом не снять. Ядро стекла
  клиппируется (sRGB ≈ 250), поэтому меряется пятно свечения. Совпадение фигуры при amp 0,08 тонет в шуме
  idle-анимации, синхронность подтверждена диагностическим прогоном и тестом.

## Остатки

- Пункт 2 по стеклу lantern-w (4,6 %) и lantern-ne (5,8 %) ниже 6 % на выборке из 12 кадров. Амплитуда по карточке
  0,08; поднимать её — решение вне лёгкого режима. Перемерить на packaged-кадрах EN-15.
- ΔGPU ≤ 0,05 мс меряет EN-15 (`render_bench.py`).
