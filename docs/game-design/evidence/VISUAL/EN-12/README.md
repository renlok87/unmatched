# EN-12 — лёгкий туман у подошвы обрыва Marmoreal (канал материала вклейки)

**Статус: технически готово, по делегированию (2026-10-07, VS-5 шаг E2, ветка `feat/visual-vs5`).** Вклейка за флагом
`-ConceptPaste` до EN-13. Кадры — live tune editor `-game`.

## Что сделано

- `conceptPaste.anim.mist` = {opacity **0,22**, panPxPerS [6, 0], noisePx 220, colorSrgb **#2A3A58**}. Канал B
  `MI_ConceptPaste_Anim` (EN-06), без отдельной плоскости (ВР-EN.5); P5c `backdrop.mist` скрыт (`hide backdrop`).
- Подбор, 2 итерации:
  - (1) цвет #0F1523 → #2A3A58 при opacity 0,18: ΔL* 0 → 2,1;
  - (2) opacity 0,18 → 0,22 (верхний предел карточки).
- Маска на экранах: маска EN-04 спроецирована через рельеф листа (`paste_proto.sheet_points` и камера кадра из трассы).
  Туман — самая нижняя полоса под обрывом. На K1 его нет в кадре (маска 0 px), на K1×0,65 — 4,6 % кадра.

## Решения по делегированию

- **ВР-VS5-15.** Цвет дымки — тон нарисованного тумана, поднятый до L* ≈ 25: #2A3A58. Отношение B/R 2,1 — не синее
  нарисованного (2,3). Медиана маски из `lanterns.json` (#0F1523) равна среднему цвету самой маски, и lerp к ней
  ничего не меняет (ΔL* 0,0 на замере). Тест `test_marmoreal_profile_block…` теперь проверяет «светлее медианы, не
  синее, opacity 0,12–0,22».

## Остатки

- В -Bench туман стоит (t = 0) — по карточке. ΔGPU входит в ≤ 0,10 мс анимаций, меряет EN-15.
