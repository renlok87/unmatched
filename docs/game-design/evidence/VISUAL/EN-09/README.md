# EN-09 — падающие лепестки сакуры Marmoreal (Niagara)

**Статус: технически готово, по делегированию (2026-10-07, VS-5 шаг E2, ветка `feat/visual-vs5`).** Вклейка за флагом
`-ConceptPaste` до EN-13. Кадры — live tune editor `-game`.

## Что сделано

- `cp_layout.py` читает новый список `layout.fx` из `marmoreal.paste.json`. Для каждого fx луч C0 через нарисованный
  пиксель бьёт в плоскость `planeZ`, затем `+dz` и `towardC0UU` вдоль того же луча к камере. Якоря нет, сид = CRC id.
  В `validate` новые проверки: сфера спавна плюс снос не доходит до прямоугольника рамы, `reducedMotion off`,
  у светлячков ≥ 80 uu до стекла нарисованных фонарей.
- `marmoreal.concept.layout.json` получил `fx.add`: `petals-sakura-w` (−634,5; −17,5; 236,0) и `petals-sakura-e`
  (634,5; −17,5; 236,0), система `/Game/EnvKit/FX/NS_Env_CherryPetals`, `warmupS` 6, `reducedMotion off`.
- Параметры — через `user` раскладки, ассет системы не пересобирался, поэтому откат P5c не меняется:
  - `SpawnRate` 4, `Lifetime` 6–9 с → ≈ 30 частиц;
  - `Gravity` (∓7, 0, −16) при `Drag` 1: снос наружу 7 uu/с и падение 16 uu/с на предельной скорости;
  - шум 4–8, сфера 50 uu, спрайт 3–5 uu;
  - `Color` (10,8; 3,5; 20,5).
- Подбор, 3 итерации: (1) спавн перенесён на видимую на K1 часть крон; (2) и (3) цвет и размер. Лепесток на кадре
  K2×1,6 — (161, 118, 137), цель #A17290.

## Решения по делегированию

- **ВР-VS5-11.** Центроид маски petal-area (C0 54,6 / 1851,3) лежит за кадром K1. Поэтому спавн стоит на внутренней,
  видимой на K1 части крон: C0 (196,8; 359,9) и (1723,2; 359,9), это тоже внутри маски. Точка сдвинута на 100 uu
  к камере: на плоскости кроны z 160 частицы прятались за листом вклейки.
- **ВР-VS5-12.** Цвет лепестка — сакура кадра из 02 §10.1, #B37F9C × 0,9 = #A17290. Медиана маски из `lanterns.json`
  (#4C335A × 0,9) включает тени листвы, и лепестки читались тёмными точками. Все параметры идут через `user`
  раскладки: ассет `NS_Env_CherryPetals` и лепестки отката P5c прежние.

## Остатки

- Лепестки падают на фоне самих крон и почти сливаются с ними. Метрика видит 17 пятен, но глазом они еле заметны.
  Предложение для EN-15 / ревью: спавн у нижнего края крон, чтобы лепесток выпадал на тёмный фон. Лимит в 3 итерации
  лёгкого режима исчерпан.
- Скорость вращения 30–90 °/с не проверена: в паке её задают `Minimum/Maximum_Rotation_Value`, смысл единиц не
  подтверждён, параметры не менялись. Смерть на z ≤ 0 не настроена отдельно (модуля kill нет). Частицы гаснут по
  времени жизни: за 9 с при 16 uu/с они проходят около 144 uu вниз от z ≈ 236.
- ΔGPU ≤ 0,05 мс меряет EN-15.
