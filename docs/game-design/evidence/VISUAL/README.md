# Листы приёмки визуала (`evidence/VISUAL/`)

Приёмка визуальных единиц фазы 3 — по листам в этой папке и строке реестра
[03-asset-registry.csv](../../visual/03-asset-registry.csv) (ВР-60, 02-visual-design.md §13). Визуальная единица —
карточка `06-tasks/*.csv` или строка реестра: значок, скин, блок HUD, экран, карта-шаблон, портрет, клип, VFX по CUE,
элемент окружения.

## Раскладка

```text
docs/game-design/evidence/VISUAL/
  README.md                этот файл
  <id>/                    лист одной единицы (id карточки, например HB-02)
    README.md              решение, замеры, проверка глазами, флаг отката (шаблон пишет sheet.py)
    sheet-NN-<имя>.png     вход NN: цвет | серый Rec.709 | дейтеранопия; прозрачные — на трёх фонах
    sheet-sizes.png        все входы в рабочих размерах (×4 nearest для ≤ 128 px)
    sheet-manifest.json    входы и выходы с sha256, настройки листа
    <кадры>.png            кадры обеих досок, трассы — то, что лист требует по 02 §13.2
  VS-<N>/README.md         итог спринта: листы карточек, кадры обеих досок, гейты, траты (ВР-PL14)
```

Лист собирает `tools/art/visual/sheet.py`, кадры и трассы кладёт шаг 5 цикла (05 §1.6):

```text
python tools/art/visual/sheet.py HB-02 --inputs <мастер или кадр> ... [--sizes 24,32,48]
```

- Серый — яркость Rec.709 по закодированным sRGB-значениям: Y' = 0,2126 R' + 0,7152 G' + 0,0722 B'.
- Дейтеранопия — модель Machado, Oliveira, Fernandes 2009, тяжесть 1,0, в линейном RGB.
- Прозрачные входы — на `panel.bg` `#061623`, на `card.cream` `#F9EBDB` и на нейтральном сером поля `#808080`
  (02 §13.2 п. 4).
- Размер, которого нет среди файлов, скрипт пересчитывает из мастера и подписывает «resampled»: это превью, а не
  экспорт рабочего размера (И-9). Рабочие размеры на лист подаются готовыми файлами.

## Состав листа (02 §13.2)

1. Мастер и рабочие размеры: значки — 1024 и 24 / 32 / 48 px ×4 nearest; скины — ×1 и ×2; карты и портреты — все показы
   02 §6.2.
2. Цвет, серый, дейтеранопия — для каждого размера.
3. Кадр на обеих настоящих досках — Marmoreal original и Sarpedon original, K1 и K2, packaged `-Bench` с отпечатком
   `RENDER`. Для HUD — ещё 1280×720 и 150 %. Других досок нет (AGENTS.md «Board scenes and heroes»).
4. Контекст: на `panel.bg`, на `card.cream`, на поле.
5. Движение — лист кадров по времени, обычный и reduced.
6. Трассы: `ARTLOOK`, `SHOT widget` (HUD), `CUE fx` (VFX), `concept-paste` (окружение).
7. README: что проверено, замеры (контраст, ΔE, ΔGPU), что не прошло, флаг отката.

Перед отчётом Claude открывает каждый PNG листа сам (Read): доска настоящая, задник верный для карты (Marmoreal —
нарисованный, Sarpedon — lit3d), все шесть фигур v2. Трасс мало.

## Решение и пометка

- Приёмка — **по делегированию** (пользователь 2026-10-06: «Не знаю. Делай сам, меня это не касается. Все решения
  принимай»; ВР-17, ВР-42, ВР-60). Один проход ревью в конце, арт и рамки задачи вместе.
- Принятая единица помечается в README листа и в реестре 03 дословно: **«художественно принято, по делегированию»**,
  с датой и ссылкой на лист. Слово «лично» — только при цитате пользователя с датой.
- Не принятая — «не принято» и причина в разделе «Что не прошло».
- Принятое включается по умолчанию, прежнее — флагом отката (`-S08…Legacy`, `-S08SlateHud`); флаг вписывается в
  `S08ArtLook.h` и трассу `ARTLOOK` и записывается в README листа.
- Листы «наш ассет рядом с кадром DE» сюда не кладутся: только `C:/tmp/visual-review/<set>/` (ВР-60). Сканы карт,
  аватары и иллюстрации карт в лист попадают только на кадрах нашего клиента (ВР-48).
