# SC-18 — ROOM: отсчёт перед стартом

VS-7, шаг S3, 2026-10-08, коммит `323599df`. Карточка — `screens.csv` SC-18; 04 §1.4 (отсчёт), UX §2.4; макет CX-30
`art/imagegen/sc18-room-countdown-codex/` (ВР-VS4-SC18-01 / -02). Общее — [SC-14](../SC-14/README.md).

**Статус:** UE-часть готова, живая проверка editor-build, по делегированию. **Откат:** `-S08SlateHud=room`.

| Пункт | Где и как |
|---|---|
| Состояние | `countdown` в `UUmScreenRoom`: `CountVeil` (`card.navy` 0,8 на весь холст, забирает указатель — ввод закрыт), `CountPanel` (`panel.bg` 1,0 по тексту) > `CountText`: цифра — число `type.display`, затем «Партия начинается…» (`screens.room.countdown`, `type.title`). Reduced motion — только смена цифры (масштаба нет). |
| Хост | ответ `startGame` перевёл стадию в `Started` (сервер не ждёт) → 3-2-1 по 1000 мс → «Партия начинается…» 1000 мс → LOADING. |
| Гость | статус IN_PROGRESS из опроса комнаты → «Партия начинается…» 1000 мс → LOADING. |
| Звук | хост: `PlayScreenSound(UI-ROOM-COUNT)` на каждую цифру, `UI-ROOM-COUNT-GO` в конце; у гостя старт звучит сам. |
| Трасса | `ROOM start seen phase=countdown|starting`, `ROOM countdown n=<3|2|1> t=<мс>`, `ROOM countdown go t=<мс>`, `SHOT widget id=UI-SCR-ROOM … state=countdown … phase=countdown|starting digit=<n>`. |

Проверка: интервалы цифр в трассе `s3a` — 1009 / 1000 / 1000 мс (`s3d` — 1013 / 999 / 1000), в пределах 1000 ± 50. Тест `Room.Model`:
`CountDigit` 0 / 999 / 1000 / 2500 / 3000 мс → 3 / 3 / 2 / 1 / конец; `Room.Tree`: «3», ввод закрыт (нажатие «Выйти» не проходит),
«Партия начинается…». Открыты: countdown-3 и starting 1080p (`s3a`, `s3g`), starting гостя 720p (`s3b2`), countdown-3 класса S (`s3f`).

| № | Решение | Почему |
|---|---|---|
| ВР-VS7-30 | «Партия начинается…» держится 1000 мс (хост — после 3-2-1, гость — сразу), затем LOADING | карточка: гость видит только эту строку; без паузы она не читается |
| ВР-VS7-33 | Отсчёт идёт после ответа `startGame` (триггер карточки); звук не правим: `AudioOnStage` (файл чата звука) играет `UI-ROOM-COUNT-GO` на переходе в `Started`, если экран не сыграл его за 8 с до того, — у хоста «старт» звучит дважды (в начале и в конце отсчёта) | чат звука ждал «старт» экрана до перехода (08: «старт экрана гасит автоматический на 8 с»), карточка ставит отсчёт после ответа; поведение `S08FlowGameModeAudio.cpp` не меняется — открытый пункт для чата звука |

Под отсчётом идёт настоящая партия: на первом снапшоте под вуалью 0,8 появляются доска и фигуры (сервер не ждёт отсчёта).
