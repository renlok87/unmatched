# EN-10 — ветер в нарисованных сакурах Marmoreal (UV-искажение по маске)

**Статус: технически готово, по делегированию (2026-10-07, VS-5 шаг E2, ветка `feat/visual-vs5`).** Вклейка за флагом
`-ConceptPaste` до EN-13. Кадры — live tune editor `-game`.

## Что сделано

- `conceptPaste.anim.wind` = {ampPx **0,5**, hz 0,25, gustHz 0,6, gustAmp 0,35, wavePx 400}. Раньше было ampPx 1,2,
  стартовое значение E1. Канал G материала `MI_ConceptPaste_Anim` (EN-06), C++ и материал не менялись.
- Подбор, 3 итерации лёгкого режима: ampPx 1,2 → 0,8 → 0,5. Метрика G7 по маске sakura: Fitx1,45 = C0, поэтому маска
  EN-04 ложится на кадр напрямую; пары живых кадров через ≈ 1 с.

| ampPx | изменено > 8 уровней в кронах |
|---|---|
| 1,2 | 44,6–46,4 % |
| 0,8 | 31,6–34,5 % |
| **0,5** | **19,8–23,0 %** (без пятен свечения фонарей: 18,1–21,3 %) |

## Решения по делегированию

- **ВР-VS5-14.** ampPx 0,5 — ниже диапазона подбора карточки (0,8…1,6). Плита ×2 (EN-03) детальнее эталона Sarpedon:
  любой сдвиг крон меняет пиксели сильнее, и G7 = 3–20 % достижим только при ≈ 0,5. Пик смещения
  0,5 × 1,35 ≈ 0,7 C0 px: на K2×1,6 крона заметно дышит, на K1 движение едва видно, как и задумано для
  полустатичного задника. Частота и порыв — по карточке.

## Остатки

- G7 на верхней границе (две пары из трёх чуть выше 20 % вместе с лепестками перед кронами). Если EN-15 на
  packaged-кадрах получит > 20 %, взять ampPx 0,45.
