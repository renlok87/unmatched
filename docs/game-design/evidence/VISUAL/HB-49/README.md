### 1. Бюджет П8 — выполнен (ВР-VS5-30)

Причина перерасхода: UMG-HUD каждый кадр заново рисовал, мерил и вносил в сетку попаданий все виджеты экрана GAME.

перерисовывается только изменённое; виджеты с тиком тикают как раньше. Откат — `-S08HudNoCache`; трасса
`HUD-ROOT … cache=1`.

### 3. HB-14 и вспышка «RECONNECTING» в начале партии (ВР-VS5-34, -45)

Причина: в лобби поток «готов» по определению, и `FUmTopStrip` запоминал `wasReady` ещё до партии — первая подписка
партии выглядела обрывом (`lost`), Slate писал «RECONNECTING». Теперь `wasReady` защёлкивается только в идущей партии:
начало партии — `syncing`, обрыв после готовности — `lost`. Кадр `s09-exit-conn-syncing` снимается через 0,1 с
(подписка длится доли секунды). Снят в прогонах `leet2-sarp-720-150` и `ex3-sarp-1080-100`; в editor `-game` значок
связи на этом кадре ещё не нарисован (текстура компилируется — «Подготовка: Текстуры»), STATUS «Синхронизация…» виден;
кадр упаковки — в шаге кадров.
