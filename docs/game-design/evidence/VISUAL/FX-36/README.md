# FX-36 — CUE-018 возврат цвета после восстановления связи

**Статус: технически импортировано (VS-6 F4, `1ddec221`, ветка `feat/visual-vs6`, не влито).** Кадры — editor `-Bench`
с замороженным весом; живой стенд S10 (разрыв посреди боя) — шаг Frames. Приёмка — по делегированию.

## Что сделано

- Возврат: вес набора disconnect 1 → 0 **линейно за 300 мс** внутри показа CUE-018 800 мс (ВР-FX09, ВР-VS5-SC33-02;
  04 §1.9 исправлен с «800 мс»), reduced motion — 100 мс, без «вспышки возврата». Трасса
  `FX desat off t=<ms> ms=<300|100> recovered_seq=<R>`.
- Восстановление = поток снова готов и восстановление состояния не ждёт — тот же кадр, где закрывается RECONNECT
  (SC-33) и выходит тост «Позиции обновлены (пропущено N)».
- **D4 без повтора пропущенного.** Снимок, применённый во время разрыва, — восстановленное состояние: первой строкой
  `HandleApplied` (`S08FxNetOnApplied`) идёт реконнект его seq **до** его CUE:
  - `FS08CueDispatcher::OnReconnect(R)` — `CUE reconnect recovered_seq=R`, активные показы `cut=reconnect`, дальше
    серверные CUE с seq ≤ R — `stale`;
  - постановка боя и взгляда Medusa обрываются (`cut=reconnect`), удержанные HP и падения отпускаются сразу;
  - `US08CueFxSpawnerComponent::CutAllForReconnect(R)` гасит все живые системы (Deactivate, `FX cut reason=reconnect
    recovered_seq=R systems=n`) и хранит R (`IsStaleSeq`); очереди пыли, шевронов, звёзд и лечения сбрасываются
    (`FX reconnect … dropped=…`);
  - показы seq ≤ R не начинаются: постановка боя закрытого во время разрыва боя, взгляд, пыль, шевроны, звезда, обод
    блока, лечение, «−N» — `FX skip what=… seq=… reason=stale`.
  Если за разрыв снимков не было, реконнект идёт в кадр восстановления с R = применённый seq.
- Фикстура `reconnect-no-replay` не менялась: `cue_contract.py run-fixtures` PASS 22 / 0.

## Решения (по делегированию)

- **ВР-VS6-42.** Каждый снимок, применённый во время разрыва, — восстановленное состояние (реконнект его seq до его
  CUE); иначе пропущенные удары успели бы показаться до строки `CUE reconnect` (G3 их бы не поймал).

## Остатки

- Живой стенд S10 (разрыв посреди боя, обе карты): G3 PASS, кадры R0 / R0+300 по часам игры — Frames.
- Фигура, погибшая во время разрыва, проигрывает свою смерть актёром (DeathSettle и растворение — вне FX; CUE-013 при
  этом `stale`, угольки FX-26 идут от растворения). Решать в карточке смерти, не здесь.
