## Что сделано (`do`)

| Пункт | Где и как |
|---|---|
| 1. Переворот — `UUmCardWidget::Flip(bToFace, SpeedMul, &Face)` | край, видевший рубашку, получает лицо того же боя (тот же стабильный id `combat.<key>.attack\|defense`) — и переворачивает карту на месте: атакующая — в кадр раскрытия, защитная — через `DefenseFlipDelayMs(скорость)` = 120 мс × скорость; длительность — CP-20 `RevealFlipMs` 160 мс × скорость (в 130–200); лицо входит в виджет в кадре ребра (CP-20). Своя карта атаки у атакующего уже лицом — не переворачивается. |
| 2. Уход | конец постановки (CUE-011 + конец): трасса `HUD-COMBAT leave seq=<n> key=<k>`; 0–150 мс × скорость гаснут лента, плашка, штамп и пустой слот, карта до 0,5; 150–350 мс карта летит (ease-out) к цели, уменьшаясь до ширины мини-карты 32 su, и гаснет; потом край свёрнут. Цель — своя карта к центру фишки сброса (`FUmHudLayout::DiscardChipCentreSu`, HB-27), карта соперника — к центру PANEL-OPP (ВР-VS3-55). |
| 3. Новое объявление | новый ключ боя в модели (CUE-008) обрывает уход в полёте: старые карты убраны в тот же кадр, до показа новых (R-03). Открытый бой, исчезнувший без постановки (переподключение, отсечка R-03), — края скрыты сразу (ВР-VS3-66). |
| 4. Скорость UI-ACC-013 и reduced motion (04 §3.5) | скорость масштабирует переворот, задержку защитной и уход; «Нет» (0) — всё мгновенно. Reduced — переворот как смена лица прозрачностью 100 мс (CP-20), уход — только прозрачность ≤ 100 мс, без полёта. |
| 5. Трассы | `SHOT widget id=UI-HUD-COMBAT-EDGE … state=reveal face=1 …` в кадре с лицом (до ребра — `face=0`); `HUD-COMBAT leave seq=<n>`; во время ухода `leave=1 visible=0`. |
| 6. Тесты | `Unmatched.S08.Hud.CombatEdge.Flip` (атакующая в t 0, защитная ждёт до t 120, лица к t 200 / t 320, при скорости 0,5 — 60 мс; постановка без открытого боя — без переворота), `.Leave` (кривая 75 мс: лента 0,5, карта 0,75; 350 мс при ×1, 525 при ×1,5, reduced 100; после ухода строки `UI-HUD-COMBAT-EDGE visible=1` нет; новый бой обрывает уход). |
