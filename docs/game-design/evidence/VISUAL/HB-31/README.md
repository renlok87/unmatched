## Что сделано (`do`)

| Пункт | Где и как |
|---|---|
| 1. `TimerText`, `TimerBar` в `UUmHudCombatEdge` (Side=Own, только защитник) | своя строка 28 su ленты: «{n} с» (`hud.combat.timer`, type.tag, табличные цифры Roboto) от 6 su слева; полоса 230×4 (S 150×4) у нижней кромки ленты — дорожка `panel.bg.inset`, заполнение `card.cream` на n / окно (окно = `timeoutAt − startedAt`, 30 с). Лента растёт 28 → 56 su (S 40 → 68), кнопки ниже (HB-29 «Дельта 04»). У атакующего таймера нет (у него «Ждём защиту…» в центре, HB-33). |
| 2. Тик | `FTSTicker` 0,25 с регистрируется, только пока показан таймер (окно защиты своего защитника), и снимается сам вне окна; между тиками — ни одной работы. Секунды меняют текст только при смене целой секунды. |
| 3. Warning (последние 10 с) | с «10 с»: кромка ленты `state.warning` 2 su (`WarnEdge`) и значок v3 `state-warning` 24 su (IC-47, «appear») справа от секунд — форма, не только цвет. Звук `UI-TIMER-WARN` / `UI-TIMER-TICK` — уже по реестру (`S08AudioCues` Beeper, звуковой чат), не меняется. |
| 4. Источник — `combatInfo.timeoutAt` и серверное время снимка | `RefreshUmCombat`: при новом `timeoutAt` осталось = `timeoutAt − metadata.lastActionAt` применённого снимка (серверные часы), дальше счёт по монотонным часам клиента (`FPlatformTime`); без `lastActionAt` — запасной путь локальных часов (`SecondsUntilDeadline`). Трасса `HUD-TIMER anchor left=<s> window=<s> src=server\|local seq=<n>`. |
| 5. Трасса | `HUD-TIMER left=<s> state=normal\|warning\|expired side=own seq=<n>` при смене состояния. |
| 6. Expired | 0 с: «0 с», обе кнопки отказывают `why.deadline.passed` (CUE-004 и причина при нажатии); решает сервер. |
| 7. Тест | `Unmatched.S08.Hud.CombatEdge.Timer`: 11 с — normal «11 с», 10 с — warning «10 с» (кромка и знак видимы), 0 — expired, кнопки недоступны с `why.deadline.passed`; три строки HUD-TIMER; у атакующего таймера нет. |

## Решения по делегированию

| № | Решение | Почему |
|---|---|---|
| ВР-VS3-54 | Якорь дедлайна — `metadata.lastActionAt` снимка: осталось = `timeoutAt − lastActionAt` в момент применения, затем монотонные часы клиента; окно полосы — `timeoutAt − startedAt`; warning — от показанных «10 с» (осталось ≤ 10 с), как в тесте карточки «11 → 10 с — warning» | карточка: «источник — timeoutAt и серверное время снапшота, а не локальные часы»; в снимке нет отдельного поля серверного времени, `lastActionAt` — время последнего действия (атаки), то есть начало окна. Известный предел: клиент, подключившийся посреди окна, видит больше секунд на время своей задержки — дедлайн проверяет сервер |
