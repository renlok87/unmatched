## Дельта VS-6 F4 (2026-10-08, по делегированию ВР-VS6-36)

- **D1 — решение.** Порог карточки «≥ 0,986» — это «не хуже P9b», но число 0,986 мерилось у P9b с 3D-садом. В тех же
  кадрах нарисованного Marmoreal P9b даёт 0,965, P9c — 0,968, то есть P9c не хуже P9b: по смыслу правила карточки D1
  **PASS**. Абсолютный порог AN-36 «≥ 1,0» добавочным светом под ночной экспозицией недостижим (самопроверка
  ENV-HERO-LIGHT.md: ровный +30 % теряет рельеф) — рельеф переходит к материалу фигур (AN-33 / AN-34), не к свету.
  P9c остаётся светом героев под нарисованным задником: он выигрывает у P9b D2 (насыщенность) и держит D6 4/4.
- **Откат.** P9c больше не попадает в откат `-NoConceptPaste`: профиль `marmoreal-night` получил `heroLightNoPaste`
  (P9b, rev 22) — ВР-VS6-34, `docs/game-design/evidence/VISUAL/VS-6-F4/`.
