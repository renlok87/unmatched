## Вывод

- Класс 3 (`feathers_flight`, MatID 56) у SK_Harpy_H3LD меняет только светлую полосу по передней кромке крыла (маска
  разницы i2 − база — тонкая линия), сами тёмные маховые от него почти не меняются; класс 12 ухудшил D6. Ни одна
  итерация не лучше базы вне шума сессии → **блока Harpy в профиле нет** (ВР-VS8-03).
- D6 на Marmoreal: **2 из 3 PASS** (P9b с 3D-садом: 1 из 3). harpy-a падает только на порядке насыщенности тело /
  подставка (C 21,1 против 20,4 при эталоне 12,0 / 22,1) — эту пару рычаг карточки не меняет. **Порог 3/3 не выполнен,
  записан.**
- В сером маховые темнее рыжих кроющих — PASS ([harpy-a](harpy-a-K2x2p5-base-i2-i3.jpg),
  [harpy-b](harpy-b-K2x2p5-base-i2-i3.jpg); строки база / i2 / i3, цвет | серый). Почти серыми, как в эталоне, они не
  становятся: множитель яркости не снимает насыщенность.
- Sarpedon — 4 из 4 PASS (база, блок туда не ставился). Остальные фигуры не менялись.
- G-LOOK — как AN-33 (настоящие доски, вклейка / lit3d, шесть фигур v2).
