## Решения по делегированию (ВР-Z2)

- **01** Реестр несёт пути cue-table; системы боя отсутствуют до FX-13+ → прогрев systems=0, vfx=missing
  (честное состояние таблицы), спавн только существующих ассетов.
- **02** NoDepthTest — свойство материала, не статик-свитч: два мастера-близнеца (Print / Print_Overlay),
  MI выбирает мастер.
- **03** Звезда-флипбук — процедурная заготовка (PIL): художественная звезда — FX-21.
- **04** Канальная раскладка MI (тело = токен эффекта, кромка card.glyph, контур mark.keyline) — карточка
  имена MI без раскладки.
- **05** Бюджет ≤ 40 PS-инструкций недостижим с обязательной кривой M_ConceptPaste: 191 против 334 у пасты.
- **06** Грейд профиля: у Niagara-рендерера нет пер-компонентного override → MI плашек пекут измеренный фит,
  боевые системы получат его юзер-векторами (контракт в шапке спавнера).
- **07** Кук /Game/S08/FX уже покрыт строкой /Game/S08 (DefaultGame.ini:17).
- **08** Модули шума донора нельзя удалить тюном — обнулены (strength 0); системы FX-13+ строить без них.
- **09** Капы MaxSystemInstances живут в SystemScalabilitySettings-массиве (не python-свойства): типы созданы,
  капы выставить не удалось — задокументировано, боевых систем пока нет (не влияет).
- **10** Пипетка FX-02 вне порога (18.3–18.6 против ≤ 6) при код-идентичной кривой пасты и запечённом фите —
  остаток цепочки движка; калибровка по реальным кадрам — за визуальным чатом.
- **11** Вспышка/обод через EyeAdaptationInverse display-unit (как хит-тинт): сырой линейный путь даёт ~0.55
  luma через фиксированную экспозицию; вход fx.flash 0.95 < потолка 1.5.
- **12** Кадры состояний FX-06/17/19 в бенче — статические записи CPD (кривые — юнит-тесты + демо): таймеры
  в бенче не детерминированы, статика повторяема (FX-04 A/B ≤ 0.39).

## Что не сделано и почему

- **Системы боя (звезда, вихрь, дуга, угольки, пыль, шевроны)** — карточки FX-13..FX-32 вне скоупа Z-2
  (поручение: «не делай FX-21 и дальше»); реестр и типы готовы к ним.
- **Пипетка ΔE ≤ 6** — не достигнута (ВР-Z2-10), числа и пути выше.
- **33-мс кадр первого показа** — измерим только когда существуют боевые системы (прогрев инфраструктуры
  готов, плашка прогревается пулом).
- **Капы типов эффектов** — ВР-Z2-09 (не выставлены через python; C++-путь авторинга — за FX-13+, когда
  системы реально конкурируют за лимиты).

### Решения по делегированию (ВР-Z2R)

- **01** Код каналов фигуры живёт в `S08/Fx/S08FigureFxChannels`; в акторе только точки вызова (+32 строки cpp).
- **02** Принять PS-инструкции M_FX_Print (209 / 229 у SDF): бюджет ≤ 40 недостижим с обратной кривой.
- **03** Статичные кадры бенча годятся для состояний каналов; для FX-19 есть живой кадр фазы обода, кадр самой
  вспышки требует хука захвата (остаток).
- **04** Лимиты типов эффекта — сейчас (правка 8), не в FX-13.
- **05** Тест детерминизма: под -nullrhi проверяет ассет и пишет, что частицы не проверены; позиции — в процессе с RHI.
- **06** Звезда плашки — копия шаблона движка DirectionalBurst; строка атрибуции SoftTofu не нужна.
- **07** Плашка: тело отличается от кромки card.glyph на ≥ 20 уровней серого; «тело к кромке ≥ 3 : 1» понимается
  как тело к внешнему контуру mark.keyline (светлые токены FX с белой кромкой 3 : 1 не дают).
- **08** Обод — кромка по 1 − N·V вершинной нормали; интенсивность сужает полосу, цвет всегда полный крем;
  оба канала замещают альбедо.
- **09** Обратная кривая тона — по каналам AP1 (фильмовая кривая движка работает в AP1).
- **10** Приоритет сортировки полупрозрачных FX = 20 (поверх плиток хода).
- **11** Эмиссив вспышки и обода — обратная кривая фита профиля вместо EyeAdaptationInverse; потолок карточки
  «≤ 1,5» относится к значению на экране (fx.flash × 0,82), не к линейному эмиссиву.
- **12** Остаток цепочки движка (расширение гаммы, десатурация) снят измеренной матрицей дисплея по пяти токенам
  плашки (Sarpedon K1); проверено и на Marmoreal.
- **13** Поле вокруг вспышки меряется кольцом 6–20 px от силуэта (без подставки); статичный бенч — худший случай.
