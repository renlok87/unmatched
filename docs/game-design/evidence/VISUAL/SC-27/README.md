| Пункт | Где и как |
|---|---|
| Строка | «Масштаб интерфейса» — ползунок `UiScalePercent` 75–150 % шагом 5, значение «{n} %» и подпись диапазона `settings.interface.scale.range` «{min}–{max} %» (новый ключ; «75–150 %», при короткой стороне окна < 1080 — «100–150 %» и левый край дорожки = 100, ВР-62). |
| Применение | на отпускании ползунка: `ApplySetting uiScale` + `Save` → `UmHudScale` (HB-09) ставит масштаб, класс L / S пересчитывается в том же кадре, модаль перекладывается; поле и мировые значки масштабом UI не меняются (04 §3.6). |
| Трасса | `SETTINGS set uiScale=150 source=pause`, `HUD-SCALE … canvas=1280x720 … ui=150 class=S`, `HUD-LAYOUT class=S canvas=1280x720 scale=1.500 … overlapField=0`. |

Проверка: тест `Pause.Model` — 75..150 шаг 5, при 720p минимум 100 и подпись «100–150 %»; `Pause.Tree` — модаль и кнопки низа внутри
холста на 1920×1080 при 100 / 150 % и 1280×720 при 100 / 150 % (холст 1138×640, класс S), на 150 % звук прокручивается. Вживую:
`s4b` / `s4f` 1080p — 100 → 150 % (холст 1280×720, S, `overlapField=0`) → 75 % (2560×1440, L, `overlapField=0`) → 100 %; `s4c` / `s4g`
720p — 100 → 150 % (1138×640, S) → 100 %. Открыты: game-interface, -ui150, -ui75 (`s4f`), game-interface и game-*-ui150 (`s4g`).
