# SC-26 — Настройки: язык RU / EN (вкладка «Интерфейс», `US08UserSettings::Language`)

VS-7, шаг S4, 2026-10-08, коммит `28ec24d2`. Карточка — `screens.csv` SC-26; 04 §1.8, §6.1, §6.2, §7.2 (набор I); макет CX-32
`art/imagegen/sc26-settings-language-codex/` (ВР-VS5-SC26-01…03). Общее — [SC-24](../SC-24/README.md).

**Статус:** UE-часть готова, живая проверка editor-build, по делегированию. Набор I (все экраны и блоки HUD на EN и в псевдолокали
на обеих досках, packaged) — шаг «Кадры».
**Откат:** `-S08SlateHud=pause`; язык по-прежнему меняют чипы LOGIN и `-culture=`.

| Пункт | Где и как |
|---|---|
| Поле | `US08UserSettings::Language` (UI-ACC-010) `ru` по умолчанию, `s08.Settings language=ru|en`, `DescribeLanguage` (вне `Describe`, его текст закреплён тестами). |
| Строка | «Язык» — чипы «РУССКИЙ» / «ENGLISH» (`settings.interface.language.ru|en`, свои названия в обоих языках); выбор → `UmText::SetUiLanguage` (тексты таблиц пересчитываются в следующем кадре, без перезапуска) + `Save`; трасса `SETTINGS set language=en source=pause`. |
| Запуск | `-S08Lang=ru|en|pseudo` → `-culture=` (скрипты набора I) → сохранённый язык; трасса `SETTINGS language=<l> culture=<c> pseudo=<0|1> source=<flag|culture|saved>` (ВР-VS7-52). Чипы RU / EN на LOGIN тоже сохраняют `Language`. |
| Псевдолокаль | `-S08Lang=pseudo`: культура ru, каждая строка таблиц — «[» + текст + «~» × ⌈0,3·длина⌉ + «]» (`UmText::Pseudo`, ВР-VS7-45); имена героев, карт и досок — данные, не трогаются. |
| EN | тексты — `SourceString` тех же ключей `st-screens.csv` (новых литералов нет). |

Проверка: тест `Pause.Model` — `language=EN` → `en`, `de` и `pseudo` отказ, `ResolveLanguage` по флагу, `Pseudo("Пауза")` = «[Пауза~~]»;
`Pause.Tree` — EN-заголовок «Pause», «Master volume», все ряды всех вкладок помещаются на 1080p 100 / 150 %, 720p 100 / 150 % в RU и EN
и в псевдолокали при 720p 150 %. Вживую: `s4b` / `s4f` — щелчок «ENGLISH» в партии: модаль и HUD перешли на EN без перезапуска,
обратно «РУССКИЙ»; `s4e` — `-S08Lang=en`; `s4d` — псевдолокаль 720p 150 %: ни одна строка не обрезана, колонка вкладок выросла до
≈170 su (модаль 730 su, ВР-VS7-47), подпись «Масштаб интерфейса» встала над ползунком (ВР-VS7-48), чипы скорости анимации ушли на вторую строку. Открыты: game-interface,
-en (`s4f`), lobby-*-en (`s4e`), lobby-*-pseudo-ui150 (`s4d`).

Кадры: полные — `scraped-data/derived/visual-evidence/SC-26/`; в git `interface-en-1080p-100.jpg`, `interface-pseudo-720p-150.jpg`.
