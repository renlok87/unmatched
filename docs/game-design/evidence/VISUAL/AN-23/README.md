Лист собран `tools/art/visual/sheet.py` 2026-10-07 по 02-visual-design.md §13.2 (переснят после ревью Z-1).

**Решение:** художественно принято, по делегированию (2026-10-07, ВР-06; повторная проверка после ревью —
пометка ZCode от 2026-10-06 была снята ВР-Z1R-06)
**Дата решения:** 2026-10-07
**Ревью:** визуальный чат, ревью Z-1 + один проход по кадрам (02 §13.3)
**Флаг отката:** `-S08FacingLegacy` (S08ArtLook.h, трасса ARTLOOK `facing=v1|legacy(-S08FacingLegacy)`)

## Что было не так (ревью 2026-10-07)

Кадры ZCode противоречили README: Harpies 2 на Marmoreal и Harpies 1/3 на Sarpedon стояли спиной, Артур и Мерлин —
к центру доски. Причины (F1–F3): ApplyHeroV2 на каждом снапшоте возвращал мешу угол полуполя, первая команда
считалась без врага (поворот шёл внутри цикла спавна), камера бралась из устаревшего POV camera manager
(`cam=-136/-160` против камеры K1 в (0, 1342, 1917)).

## Что исправлено

- F1: после ApplyHeroV2 v1-угол (или идущий поворот) накладывается заново; первый apply синхронизирует угол
  с показанным полуполем — поворот начинается от того, что видно.
- F2 / ВР-Z1R-04: угол покоя считается вторым проходом SyncFighters, когда все акторы снапшота есть;
  `src=spawn` пишется всегда; спавн без врага — лицом к оси камеры.
- F3 / ВР-Z1R-04: один хелпер камеры `AS08BoardActor::ViewCameraLocation` — view target (BoardCamera).
- F6: поворот идёт от кадрового тика актора (тик включён только на время поворота), не от таймера 60 Гц.
- F7: концы плана хода считаются по самой фигуре (`RestYawFor`: враг у точки прибытия, без мёртвой зоны),
  старт плана — от показанного угла.
