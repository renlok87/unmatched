## Что проверено (карта AN-21, packaged `-Bench`)

Профиль ease ВР-AN05 (трапеция скорости, E = min(80·T/280, T/2)) против линейного легаси — финальный пакет
(stamp `f8903fb9`), 16 прогонов: `-BenchMovePose=40|80|280|520` × Marmoreal original + Sarpedon original ×
K2×1,6 + K2×2,5 × default + `-S08MoveEaseLegacy`, warmup 15 / settle 3 / measure 2, `RENDER reference=1`
(4 строки на прогон).

### Трейсы

- default: `MS-ANIM settings … ease=1 easeMs=80`, ARTLOOK `move=ease80` — все 8 прогонов.
- легаси: `MS-ANIM settings … ease=0 easeMs=80`, ARTLOOK `move=legacy(-S08MoveEaseLegacy)` — все 8 прогонов.
- `BENCH done views=2 elapsed≈32.2` во всех 16.

### Пиксельная сверка ease против легаси (mean |ΔRGB| / пикселей с |Δ|>24)

| карта | 40 мс K2×1,6 | 40 мс K2×2,5 | 80 мс K2×1,6 | 280 мс K2×1,6 | 280 мс K2×2,5 | 520 мс K2×2,5 |
|---|---|---|---|---|---|---|
| Marmoreal | 0.474 / 11342 | 1.010 / 25461 | 0.636 / 11261 | **0.312 / 44** | **0.262 / 160** | 1.338 / 26350 |
| Sarpedon | 0.714 / 10985 | 1.178 / 18465 | 0.538 / 9789 | **0.322 / 2211*** | **0.214 / 370** | 1.314 / 24417 |

\* Sarpedon K1-фон анимирован (водопад/огонь lit3d) — остаточный шум выше; на Marmoreal (полустатичная вклейка)
280 мс практически идентичны (44–160 пикселей).

Выводы: **на 280 мс (вершина) позиции совпадают** — расхождение падает на порядок против 40/520 мс; на
40/80/520 мс разница локализована в области движущейся фигуры (bbox ~150×170 px на K2×1,6) — профиль работает.

### Глазами (Read PNG, пара кропов 40 мс ease|legacy, K2×1,6 Marmoreal)

- ease: фигура едва сошла со стартовой клетки — ≈ 1/24 ребра (карта: «40 мс — 1/24 ребра»).
- легаси: ≈ 1/6–1/7 ребра (карта: «линейно было бы 1/7»).
- Наклон корпуса (lean 10°) в обоих режимах — профиль ease не трогает наклон.

Точность 1/24 против 1/7 также зафиксирована юнит-тестами `Unmatched.S08.MoveAnim.Pose` (s(40)=1/24, s(80)=1/6,
прибытие 560 мс, непрерывность скорости в 80 мс; k=1/200 на одном ребре; легаси — линейно).
