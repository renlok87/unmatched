## Что проверено (карта AN-25 — живой бой, обе карты)

Те же прогоны, что AN-24 (`run-combat-demo.ps1 -JoinerAttack -PlayerView`, обе карты, packaged, 30 FPS).

### src=attack-return

- `FACING fighter=f-0-hero src=attack-return from=118 rest=118 ms=150` — 150 мс, мёртвая зона здесь не
  действует (возврат доводит до угла покоя; from == rest, т.к. цель — ближайший враг и покой совпал).
- `FACING fighter=f-1-hero src=attack-return from=-305 rest=55 ms=150` — полный возврат через 0° (кратчайшая
  дуга).
- Marmoreal: 12 строк src=attack-return; Sarpedon: 10. Все ms=150.
- Возврат стартует по концу LungeAttack (583 мс × play rate): в трейсе `attack-return` идёт сразу после
  `stage=hit/minus/hp` той же seq — в пределах ±42 мс расписания (окно демо-снимков не тикает мс-штампами
  каждого поворота; длительность фиксирована ms=150 в трейсе).

### Через 150 мс |off| ≤ 45

- После каждого возврата следующий снапшот/бой считает покой заново: нарушений |off| > 45 нет ни в одной
  строке FACING (пакетные и живые прогоны).
- Кадр после боя (`s09-combat-result.png`, обе карты): оставшиеся фигуры вполоборота к камере, спиной никто;
  погибший Артур лежит на клетке (DeathSettle), его диск-цифра скрыт (гарпий касался AN-31).

### Глаза (Read PNG)

Результатные кадры обеих карт: поле спокойно, лица/профили видны, задник по карте, шесть v2, маркеров нет.

### Гейты

Демо-гейты зелёные, G-CUE PASS (см. AN-24 — те же трейсы).
