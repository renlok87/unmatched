# DE-023 — портреты хода: кадры редактора (2026-10-05)

Это не живая приёмка. Кадры живой партии двух клиентов (G-LIVE) и лист A/B снимает агент приёмки прогона E
(DE-028). Здесь — проверка вида самого виджета до упаковки.

## `de023-portrait-sheet.png`

Превью портретов поверх галереи значков, редактор `-game`, offscreen, 1920×1080:

```
UnrealEditor.exe unreal\Unmatched\Unmatched.uproject /Game/S08/S08Arena -game -windowed -ResX=1920 -ResY=1080 -ForceRes
  -RenderOffScreen -nosound -S08IconGallery -S08IconGallerySize=64 -S08IconGalleryPortraits [опции строки]
  -S08IconGalleryShots=<dir> -S08IconGalleryTimes=0,120,300,600,1000,2000
```

Из Git Bash — с `MSYS_NO_PATHCONV=1`, иначе `/Game/...` превращается в путь Git.

- Данные портретов — образец превью (Medusa 15/15 — соперник, King Arthur 16/18 — свой ход), а не снапшот сервера.
- Все анимации превью стартуют в 0 мс: начало хода (кольцо), выбор действия (первый слот трекера гаснет), удар по
  сердцу.
- Колонки — моменты 0 / 120 / 300 / 600 / 1000 / 2000 мс.

| Строка | Опции | Что видно |
|---|---|---|
| default | — | вид по умолчанию: кольца нет (глиф DE-012 ждёт арт-приёмки), статус «YOUR TURN», слот гаснет за 150 мс, сердце вздрагивает без ореола |
| ring | `-S08TurnRingIcon=marker-turn-ring` | вспышка обода жёлтый → оранжевый → красный за 1000 мс, затем тлеющий обод 0,35 до конца хода |
| team | `-S08TurnRingIcon=marker-turn-ring-team -S08HeartGlow` | обод цветом команды; ореол сердца на 200–1000 мс |

Кадры просмотрены: портреты в левом нижнем углу; монограмма в круге читается; кольцо обводит диск, не задевая
текст; слоты трекера и сердце — принятые значки v3.
