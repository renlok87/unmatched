## Метод и проверки

1. **Три независимых прохода** по изображению, без доступа друг к другу и к внешним графам:
   A — визуально по регионам (кропы ×2–5); B — алгоритм по пикселям (маска чёрных линий вне
   кругов, геодезический путь между ободами, компоненты связности); C — «от степени»: каждая
   клетка ×3, выходы линий с обода, ребро засчитано только при виде с обоих концов.
   **Итог: 42/42 и 61/61 рёбер и 4/4 старта — единогласно у всех трёх** (`votes.json`).
2. **Внешняя сверка:** граф the-unmatched.club совпал 42/42 и 61/61; CV-старты unbrewed — 4/4 на
   обеих картах.
3. **Машинные проверки** (`checks.json`): симметрия, одна компонента, нет рёбер через третий круг,
   скан «пропущенных» прямых рёбер (лучший не-кандидат покрыт линией на 0,58 / 0,36 против 1,00
   у принятых).
4. **Критик полноты:** 8 случайных рёбер, особые участки и оба набора стартов пересмотрены на
   кропах — всё подтверждено; зоны всех 69 клеток независимо восстановлены по пикселям (Lab,
   36 секторов) — совпали с SVG.

## Правила, важные для реализации (BoL Vol. 1)

- Смежны только клетки, соединённые линией; расстояние роли не играет.
- Клетка с несколькими цветами входит во все свои зоны; ranged-цель — смежная **или** с общей
  зоной; melee — только смежная.
- Движение: через союзников можно, через врагов нельзя, заканчивать на занятой нельзя.
- Партия на двоих: первый игрок ставит героя на старт 1, второй — на старт 2; старты 3–4 — для
  командной игры. Сайдкики — на отдельные клетки в зоне (любой из зон) своего героя.
