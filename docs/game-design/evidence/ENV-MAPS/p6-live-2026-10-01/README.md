### Исправление проверяльщика `tools/s09/xcheck_graph_duel.py`

Позиции бойцов брались только из строк `CUE move`. Боец, который за партию ни разу не сдвинулся (Артур в первой
партии Sarpedon, Мерлин во второй), оставался без позиции, и его атаки или атаки по нему попадали в
`illegalLooking`, а дальние атаки не засчитывались. Теперь для бойца без `CUE move` и без пути `MANEUVER` в журнале
сервера позиция берётся из финального `GameState` (раз он не двигался, это и его старт); список таких бойцов
пишется в `unmovedFromFinalState`. После правки во всех трёх партиях `illegalLooking` = 0; первая партия Sarpedon
по-прежнему не проходит гейт `ranged:f-0-hero` — честно: дальней атаки Медузы в ней не было.
