# ART-011, раунд 2 — повторная приёмка `action-maneuver`, `resource-connection-reconnecting` / `-lost` и документов

Дата: 2026-10-03. Панель одна, приёмка по делегированию (РД-1 в `docs/game-design/decisions/2026-10-03-delegated-decisions.md`,
полномочия «делай все без меня», «сам реши все вопросы»). Это единственный разрешённый повтор, следующего раунда
доработки нет. Проверялся коммит `444c1cc6` против `444c1cc6~1`. Репозиторий не менялся, игра не запускалась.

## Вердикт

**ПРИНЯТЬ (по делегированию).**

Все три обязательные правки первой панели (О-1, О-2, О-3) выполнены по существу. Регрессий у остальных 21 значка нет:
мастера, размеры, слои, листы движения и GIF побайтно те же. Контракт изменён только в двух id.

Одно отклонение записываю честно. Строгая буква О-2(б) («≥ 1 px при 24 px в каждой фазе», alpha > 0) не выполняется
в модели рантайма. Эта модель — билинейный поворот 24-px текстуры, так считают `motion.py` и UE. В 27 из 72 фаз
у бара по диагонали оказывается один пиксель каймы знака с α ≤ 13/255 (≤ 5 %, цвет keyline). На панели это меняет
пиксель на 0,4 уровня яркости, на креме — на ≤ 11. Контакта ореолов глазом нет, при пороге α > 16/255 зазор есть во всех
72 фазах, в векторной модели тоже. Это кайма выборки, а не рисунок, поэтому решение — принять, а формулировку STYLE
уточнить (З-1).

Остальные находки ниже не меняют решения. Они записаны как замечания без доработки и как пункты для личного взгляда
пользователя.

Числовой порог для UE-галереи (её ещё не сняли, GPU занят) дан в разделе «Порог для UE». Арт-вердикт от неё не зависит.
Превышение порога будет дефектом импорта или рантайма (не тот pivot, старый Config, не та текстура), перерисовки
оно не потребует.

## Замечания без доработки

Перерисовки они не требуют. З-1 и З-7 — правки текста, их может внести оркестратор при интеграции.

- **З-1 (текст).** STYLE §4 №20: к «32 и 24 px — 1 пустой px» дописать, что замер векторный. При повороте
  24-px текстуры в рантайме (билинейно) в 27 из 72 фаз у бара появляется один пиксель каймы с α ≤ 13/255. Иначе
  документ снова расходится с фактом — это то, за что первая панель ставила Д-1.
- **З-2.** При 32 px головка — утолщение в 3–4 px, знак читается «кольцом со щелью», а не «↻». В статике (reduced)
  смысл держат кольцо и цвет. Если HI-02 покажет путаницу со спиннером, есть два пути: поднять порог головки до 48 px
  (тогда 32 px — дуга без головки, как 24) или нарисовать головку ≥ 5 u только при 32 px.
- **З-3.** При 16 px знак касается ореола короткого столбика (и у reconnecting, и у lost). На панели не видно,
  на креме ореолы сливаются. Критерий О-2 на 16 px не ставился. Если понадобится — при detail 0 сдвигать знак на 1 px
  влево-вверх.
- **З-4.** На креме при 32 px знак в статике выглядит «◎», в фазах поворота — «@» и мутное пятно при 24 px. Тонкий штрих
  W2 с keyline с двух сторон после билинейного поворота размывается. Основной фон значка связи — тёмная панель HUD,
  там чисто.
- **З-5.** `-lost` при 24 px на пике штампа (×1,08, около 110 мс) кайма X подходит к бару (5 px, α ≤ 72/255). Это
  кратко и на глаз незаметно.
- **З-6.** В сером reconnecting ↔ lost при 24 px — 5,5 (было 9,5): самая слабая пара набора. По форме они различимы,
  в цвете и в движении — сильно. П-4 первой панели остаётся в силе. Серые числа в STYLE §4 (17,1 / 8,5) и §6 (8,5)
  после О-2 не перемерены.
- **З-7 (текст).** Таблица STYLE §10 по-прежнему называет текущими «+2,5 u, (−6, −5), r 3,6». Нужна строка ART-011
  (О-1, О-2) либо пометка «история». `sheets/compare-v2-v3.png` последний раз собирался в `496b38e2` и показывает
  старые v3-отпечатки и стрелку. Пересобрать или пометить.
- **З-8 (пожелание, вне критериев).** При переходе online → reconnecting столбики прыгают на 3,75 u (раньше на 2,5),
  потому что у reconnecting нет `appear_from_online`, как у lost. Можно добавить такой же переход.

## Порог для UE-галереи (`compare_ue_gallery.py`, ещё не снята)

Базовые числа первой панели: 64 px — 0,447 по 276 парам, 32 px — 0,812, reduced — 0,021. По id при 64 px:
maneuver 0,80, reconnecting 0,286, lost 0,100.

Требую:

1. **Normal, 64 px, весь набор: mean\|Δ\| ≤ 0,747** (0,447 + 0,3).
2. **По id при 64 px:** reconnecting ≤ 0,747 и lost ≤ 0,747. У maneuver своя база выше, поэтому для него ≤ 1,10
   (0,80 + 0,3): его текстуры тоже переимпортированы.
3. Кадры вращения reconnecting: p99 ≤ 50 в каждом кадре (база — максимум 16). Старый pivot (10, 11) дал бы орбиту
   знака до ≈ 2,6 u и p99 далеко за 50.
4. 32 px весь набор ≤ 1,112 (0,812 + 0,3); reduced ≤ 0,321 (0,021 + 0,3).
5. В трассе галереи ревизия контракта — `icon-motion-2026-10-03b`.

Если порог превышен, это дефект импорта или рантайма. Его чинят без перерисовки, арт-вердикт остаётся.

## Что пользователю стоит посмотреть лично

Это приёмка по делегированию: пользователь сам не смотрел ни первый раунд, ни этот. При возвращении — 2–3 минуты:

## Честные ограничения этой приёмки

- В движке не проверено: UE-галерея отложена (GPU занят), порог дан выше. Slate / UMG, живой HUD и упакованная
  сборка тоже не смотрелись.
- PNG смотрел через загрузчик изображений. Широкие листы он ужимает до ~2000 px, поэтому малые размеры смотрел
  отдельными кропами ×8–×24 nearest. `reel.mp4`, `reel-reduced.mp4` и `index.html` не открывал.
- Зазор при повороте мерил двумя моделями (билинейный поворот растра — как `motion.compose()` и UE; векторный перерендер).
  Дробные углы между шагами 5° не проверял.
- Серые числа — метрика первой панели (luma на `tag.background`); метрику авторов из STYLE воспроизвести не удалось.
- Кадры DE видел только в кропе первой панели (scratchpad, вне репозитория); новых кадров DE не брал.
- Остальные 21 значок заново глазами не пересматривал: они побайтно те же, что приняла первая панель.
