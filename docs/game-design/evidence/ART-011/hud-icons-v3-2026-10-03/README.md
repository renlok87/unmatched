## Известные ограничения (записаны панелью, доработки не требуют)

- При 24 px в рантайме (билинейный поворот) в 27 из 72 фаз у столбика — один пиксель каймы знака α ≤ 13/255; на
  глаз не видно. Записано в STYLE-v3 §4 № 19–21 (З-1).
- При 32 px головка «↻» читается утолщением, знак — «кольцом со щелью»; смысл держит вращение (З-2).
- В сером reconnecting ↔ lost при 24 px различаются слабее всех пар набора (5,5); в цвете и движении — сильно (З-6).
- При 16 px знак связи касается ореола короткого столбика (З-3); на креме тонкий штрих стрелки мутнеет (З-4).
- Не проверено панелями: живой HUD в бою, упакованная сборка, Slate/UMG-текст поверх значков, звук на удары.
- Ревизия контракта в логе галереи не печатается; галерея читает `Config/S08IconMotion.json` с ревизией
  `icon-motion-2026-10-03b`, а новый pivot подтверждён косвенно — p99 кадров вращения 16 (со старым pivot (10, 11) был бы
  далеко за 50).

## Что следует из решения (РД-1)

Жетон цели v3 с анимацией становится видом по умолчанию после проверки в живом бою (qa010 `icon`); прежний вид —
флагом отката. Статус в [plan-status.json](../../../../art-pipeline/plan-status.json): HUD-ICONS-V3 — «принято по
делегированию», `art_status` остаётся «технически импортировано».
