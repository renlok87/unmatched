## Решение

Правило: «стало» остаётся умолчанием, если ни один ревьюер ни для одного героя не назвал «было» лучше **и** ни у одного «стало» нет
дефекта, которого нет у «было».

- «Было» лучше не назвал никто: ревьюер 1 выбрал «стало» для обоих героев, ревьюер 2 оценил обоих «поровну».
- Дефектов только у «стало» нет ни в одной из четырёх оценок. Все найденные дефекты общие, а лишняя мягкость найдена только у «было».

**Итог: KEEP.** Флаг Nanite остаётся на 49 материалах, полные кластеры (1,79 млн и 1,64 млн треугольников) стали видом витрины по
умолчанию. Откат через robocopy не выполнялся.

## Общие дефекты (не от этой правки, открытые пункты витрины)

Оба ревьюера нашли их и на «было», и на «стало». Правка Nanite их не вносила, и в этом раунде они не исправлялись:

- **Оба героя:** золотая текстура затекает на лицо. У Артура это мазок по правой скуле, глазу и бороде, у Медузы полоса от
  диадемы по профилю (лоб, нос, губы, подбородок).
- **King Arthur:** тёмная полоса по правой кромке клинка; боковина пьедестала плоская кремово-жёлтая, без фактуры и фаски;
  внутренняя сторона плаща и пространство между ног уходят в почти чёрную массу; левая латная перчатка мягкая.
  Тёмное пятно на щеке и светлые точки на верхней кромке пьедестала тоже есть в обоих состояниях.
- **Medusa:** жёлтые вставки на юбке плоские, постеризованные, похожи на кляксы; тетива — толстый коричневый стержень;
  у пьедестала рваный край верхнего диска и зубчатая нижняя кромка боковины; кожа меловая, сероватая; пальцы на рукояти лука мягкие.
