## Решения оркестратора

1. **Где идёт работа.** В основном checkout, ветка `fix/admin-panel`, без worktree. Причины:
   - других сессий нет, пользователь отошёл;
   - в основном checkout лежит 2,7 ГБ игнорируемого Content: задники EnvMaps, EnvKit, паки Fab, v2-фигуры. В свежем worktree этого нет, а без них нельзя проверить «принятый арт по умолчанию»;
   - инкрементальная сборка UE занимает ~10–40 с, тогда как полная в новом worktree — десятки минут.

   Правила AGENTS.md для сессии в основном checkout соблюдаются:
   - коммитить сразу и ничего не оставлять в staged;
   - `git commit --no-verify`;
   - чужие незакоммиченные файлы не трогать: `.claude/settings.local.json`, `docs/game-design/evidence/S06/*.json` и любые неотслеживаемые файлы, созданные не этим прогоном;
   - не делать stash, reset и checkout чужих файлов;
   - не пушить.
2. **Порядок.** Прогоны идут строго друг за другом, задачи внутри прогона — тоже по одной:
   - A: DE-003…008;
   - A′: DE-016, DE-027;
   - A04: DE-010…013;
   - B: DE-014, MS-T-08, DE-015, DE-017;
   - C: DE-018, MS-T-12, DE-019, DE-020;
   - D: MS-T-16, DE-021, MS-T-17, DE-022;
   - E: DE-023…026, DE-028;
   - F: DE-029…031;
   - G: DE-032, DE-033.

   Базовые MS-T-08, 12, 16 и 17 выполняются как сопряжённые с DE (07 §5): без них DE-017, 020, 021 и 022 не собрать.
3. **ENV-U16 в этот прогон не входит.** Это задача окружения: отдельная сессия пользователя, worktree `C:/tmp/wt-envmaps`, финальная арт-приёмка у пользователя. По 07 §6 п. 5 кадры Marmoreal снимаются с `-ConceptPaste`, если такой флаг есть. Если флага нет — с текущим видом и пометкой «ENV-U16 open». Кадры Sarpedon снимаются без оговорок.
4. **Внешние зависимости.**

   | Задача | Зависит от | Решение |
   |---|---|---|
   | DE-029 | GD-040 (planned) | Делается часть без GD-040: путь FINISHED, заголовок по герою-победителю, без автозакрытия, кнопка просмотра доски. ABORTED и повторная комната ждут GD-040 |
   | DE-032 | GD-049 / ART-010 | Делается диспетчер звука CUE с фолбэком без ассетов. Подключение ассетов ждёт DE-013 и покупки/лицензии |
   | DE-033 | GD-050 (плейтест людьми) | Делается только раздел протокола наблюдения |
   | DE-010, DE-011 | ART-012 / ART-013 (in_progress) | Строятся на текущих v2-фигурах и клипах |
5. **Не входит.**
   - DE-009: живые остатки DE делаются только через computer use в основной сессии, агентам игра недоступна.
   - DE-034…037: post-MVP, по плану после приёмки MVP GD-057.
   - DE-038: только по слову пользователя.

   Всё это остаётся `planned` с причиной в CLOSEOUT.
6. **Гейты и упаковка.**
   - Исполнитель задачи собирает UnmatchedEditor, при необходимости игровую цель, гоняет тесты задачи и делает live tune там, где меняются только параметры.
   - Упаковка и живая приёмка G-LIVE — один раз на прогон, отдельным агентом приёмки в конце прогона: Marmoreal и Sarpedon original, кадры просматриваются до отчёта.
   - В каждом прогоне один ревьюер, один проход. Затем при необходимости один проход исправлений.
7. **Журнал.** Каждый прогон ведёт `task/runs/<прогон>-2026-10-04.md`: задачи, коммиты, гейты, решения, отклонения. Итог всех прогонов — в `task/runs/CLOSEOUT-2026-10-04.md`. Статусы задач — в [07-sprint-backlog.csv](../07-sprint-backlog.csv).
