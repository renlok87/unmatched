## DE-023 — W-15 (HUD): кольцо хода, баннер, трекер, сердце

**Итог:** done, коммит e077974a. Основание — 01 F-07, F-12, D-DE-07, D-DE-12, «Резолюция ревью» пп. 6 и 9; 02 SD-08, SD-25, SD-34,
SD-35; 02-ux-ui-spec §4.3 «Ход и действия»; 03 W-15; ICON-MOTION.md «Трекер действий: поведение игры»; строка DE-023
в CSV; хвосты DE-012 (A04) и DE-022 (D). Режим полный; гейты G-ICON и G-UE. G-LIVE — агент приёмки прогона E.

**Что было (HEAD bf382d32).**
- Портретов игроков в HUD не было. Трекер DE-022 — два ряда цветных блоков в Slate-панели справа, которую
  пересоздаёт `RefreshHud`; отметка приходила только со снапшотом сервера.
- Баннера «Ваш ход» не было (CUE-015 не подключён). Кольца хода в HUD не было.
- Сердце `resource-hp-full` в HUD не анимировалось. Записи DE-012 (кольцо, ореол сердца) жили только в галерее.

**Что сделано.**
- **Модели `S09/S09TurnHud.*`** (без мира, тесты `Unmatched.S09.TurnHud.*`):
  - `FS09TurnCue` — смена ключа хода `currentTurnPlayerId#turnCount` даёт событие кольца для обеих сторон. Баннер —
    только на свой ход, 600 мс: появление 100, уход 150, кадр 0 не пустой. При reduced motion — 100 мс статично.
    Первый снапшот (вход, переподключение) — кольцо в покое, без баннера. GAME_OVER — кольцо уходит, баннера нет;
  - `FS09TrackerMarks` — своя отметка в момент выбора: открыт черновик атаки или выбор схемы, либо команда только что
    отправлена. Для отправленной команды (beginManeuver / attack / scheme) защёлка держит отметку до ответа сервера:
    рост потраченных, новый seq, 10 с дедлайна команды или новый ход. Отмена возвращает слот;
  - `FS09HeartWatch` — damage / deplete / heal по показанному HP героя.
- **Портрет `S08/S08TurnPortraitWidget.*`** — постоянный UMG-виджет с деревом из кода, как `US08AnimatedIconWidget`.
  Строится один раз с HUD, `RefreshHud` его не пересоздаёт:
  - круглый диск цвета команды (жетон С-11 по виду команды героя) с монограммой героя, имя, статус «YOUR TURN» /
    «THEIR TURN» / «waiting» — акцент текстом, не только цветом; сердце 24 px + «hp/max»; трекер;
  - трекер — `resource-action-full` 32 px на слот: `spend` (150 мс, hold), `gain`, поза покоя за 1 кадр при смене
    хода; GAIN_ACTION добавляет слот;
  - сердце играет `damage` / `deplete` / `heal`; слой `glow` (кандидат DE-012) скрыт без `-S08HeartGlow`;
  - кольцо — запись контракта из `-S08TurnRingIcon=<id>`: appear (вспышка 1000 мс, затем тлеющий обод 0,35 до конца
    хода), поза покоя при входе посреди хода, leave при смене хода.
- **`US08AnimatedIconWidget`:** `SetLayerHidden` (слой всегда с opacity 0) и `ShowAtRest` (поза покоя сразу, при
  нужде — с отыгранным hold-событием).
- **Игровой режим (`S08FlowGameModeTurnHud.cpp`):**
  - `BuildTurnHudWidgets` — два портрета в левой колонке внизу (соперник над своим, отступ 24) и баннер вверху по
    центру (+132, под слотом метки исхода боя). Только при арт-виде;
  - `FeedTurnHud` — в применении снапшота после `FeedOpponentView`: событие хода, кольца, статусы, защёлка трекера;
  - `TickTurnHud` — каждый кадр: видимость (живой HUD, до экрана результата), имя, HP и сердце из `HudFighters()`,
    трекеры, появление трекера соперника за 150 мс (`FS09ActionTracker`), прозрачность баннера. Постановка боя держит HP
    до «контакт + 80 мс», поэтому сердце вздрагивает вместе с «−N»;
  - `NoteActionChosen` — во всех местах отправки beginManeuver / attack / scheme, ручных и автоклиента S09;
  - Slate-ряды трекера DE-022 не рисуются, когда есть портреты; при `-S08GreyBoard` остаются;
  - трасса: `HUD-TURN config …`, `HUD-TURN seq= turn=own|opp|over initial= ring= flash= banner= reduced=`,
    `HUD-TRACK own=a/b server= local= opp=a/b oppVisible= anim=…`, `HUD-TRACK chosen=…`,

**Решения.**
1. **Кольцо по умолчанию не рисуется.** Поведение F-07 сделано и покрыто тестами: обе стороны, 1000 мс, затем тлеющий
   обод; reduced — статично; вход посреди хода — в покое. Но глиф `marker-turn-ring` — кандидат DE-012 до
   арт-приёмки, а задание прогона и IMPL требуют «кандидаты готовить, по умолчанию не включать». ICON-MOTION.md тоже
   относит подключение к HUD «после приёмки». Кольцо включает опция `-S08TurnRingIcon=<id>`. Id приходит с командной
   строки, в коде клиента его нет, поэтому `test_candidates_are_gallery_only` не ослаблялся. После приёмки достаточно
   одной строки — значения по умолчанию `FS08TurnHudLook::RingIcon`. До неё чей ход, показывают статус портрета и
   баннер.
2. **Слот трекера — `resource-action-full`, а не `action-*`.** 02 §4.3 называл `action-*` spend 0,4, но `action-*` —
   значки типа действия: у пустого слота типа нет, а для трекера соперника снапшот тип не сообщает. В v3 «очко
   действия» — это `resource-action-full` с принятыми `spend` / `gain`; смысл «потрачено = погасло» тот же. 02 и
   ICON-MOTION.md исправлены.
3. **Ореол сердца скрыт**, как требует строка CSV (ревью A04): `damage` играет 1000 мс, слой `glow` на opacity 0. Для
   листа A/B — `-S08HeartGlow`.
4. **Арта портрета героя нет** — вместо него диск цвета команды с монограммой (круг по окну кольца, 21 u из 32). Это
   заглушка до арта портретов, а не арт-решение.
5. **Место — левая колонка внизу**, соперник над своим (02 §4.1: «слева сверху соперник, снизу своя»). Верх левого края
   занят командной панелью S09, поэтому обе панели внизу. На Marmoreal левый нижний угол — задник, а не поле.
6. **Отметка «в момент выбора»** ставится по открытому черновику атаки и по выбору схемы, а для отправленных команд
   держится защёлкой до ответа сервера. Манёвр отмечается при отправке beginManeuver: клавиша M сразу отправляет
   команду, и сервер тратит действие. Отклонённая команда снимает отметку новым seq или через 10 с (дедлайн команды).
7. **Баннер — постоянный Slate-виджет, а не UMG.** Он строится один раз, `RefreshHud` его не трогает, длящихся
   анимаций значков в нём нет. Ввод не блокирует (HitTestInvisible).
8. **Трекер соперника при reduced motion появляется сразу**, как в DE-022 (`FS09ActionTracker::OpponentAlpha`), хотя
   ICON-MOTION.md предлагал opacity за 100 мс. Оставлено поведение DE-022: разница всего 100 мс, а данных DE для
   reduced нет.

**Отклонения.**
- Кадров живой партии нет: упаковка и G-LIVE — у агента приёмки (IMPL п. 6). Вид виджета проверен на превью в галерее.
- Портреты не добавлены в мягкие препятствия раскладки плашки и ярлыков (`ArtHud.CommandPanel/SidePanel/HandPanel`):
  они в углу вне поля. Если вживую плашка ляжет на портрет — добавить.

**Хвосты.**
- **Агенту приёмки (G-LIVE):** на кадрах s09 обеих карт — два портрета слева внизу. У активного игрока статус
  «YOUR TURN» / «THEIR TURN», трекер соперника виден только в его ход. Если попадёт — кадр начала своего хода с
  баннером. Трассы: `HUD-TURN config portraits=1 ring=none heartGlow=0`, `HUD-TURN seq=… turn=own|opp`,
  `HUD-TRACK chosen=…`, в бою `HUD-HEART … anim=damage glow=0`.
- **DE-028 (лист A/B):** кольцо — `-S08TurnRingIcon=marker-turn-ring` и `=marker-turn-ring-team`; ореол сердца —
  `-S08HeartGlow`; вариант трекера DE — галерея. Быстрые кадры без бэкенда — `-S08IconGallery
  -S08IconGalleryPortraits` (команда — в README свидетельств).
- **После арт-приёмки:** выбранное кольцо сделать значением по умолчанию `FS08TurnHudLook::RingIcon`, перенести id из
  `candidates` контракта в принятый набор; если ореол принят — убрать скрытие `glow`.
- **DE-031:** замерить стоимость постоянных UMG-портретов (риск S11e в 07); проверить, что плашка не ложится на
  портрет.
- **Арт:** портреты героев с круглой обрезкой — отдельная арт-задача; пока монограмма.
