## 0. Полномочия

Запросы пользователя дословно (чат, 2026-10-04).

Исходная цель:

> «…будет ли здравая идея чтобы ты нашел инструмент, который анализирует видео, запустил несколько параллельных
> агентов, распланировав время, и изучил этот ролик и выцепил для нас важную информацию для реализации
> последующих этапов.»

Постановка пакета:

> «Да, именно составь пакет документов на основе которых потом попилится задача для workflow.»

Про пробелы в данных:

> «Если данных по каким-то пунктам непонятно, я могу запустить купленную игру, и ты там сам заисследуешь,
> используя компьютеры Use, необходимые механики и»

(сообщение оборвалось на этом месте).

Что из этого следует:
- **Этот пакет — вход для workflow, а не команда на его запуск.** Запуск каждого прогона из
  [05-workflow-plan.md](05-workflow-plan.md) требует отдельной команды пользователя.
- Решения с пометкой «пользователь» в [01-decisions.md](01-decisions.md) ждут его ответа. Остальные решения
  делегированы и имеют значение по умолчанию.
- **Живое исследование DE** ([04-de-live-research.md](04-de-live-research.md)) идёт только в основной сессии:
  - пользователь сам запускает игру и выдаёт доступ computer use;
  - файлы игры не читаем и не распаковываем (EULA);
  - computer use отпускаем сразу после серии действий: оранжевая рамка пользователю мешает.
- Действует постоянное делегирование «делай все без меня»: спрашивать только о блокерах и финальной
  арт-приёмке.

## 4. Границы

**Входит:**
- перенос выводов P1–P2 разбора (README §9) в документы;
- реализация P1: подбор хода MS-T-08/12/16/17, раскадровка боя, кольцо хода и трекер действий, подача смерти;
- закрытие открытых вопросов живым исследованием, если пользователь его запустит.

**Не входит:**
- копирование ассетов, текстов карт и интерфейса DE — берём только идеи;
- доступ к файлам игры, чтение её памяти (Cheat Engine установлен — не использовать), распаковка;
- онлайн-партии DE без отдельного согласия пользователя: в них участвуют другие люди;
- звуковой разбор: отдельная задача, см. R-12 и MS-T-18;
- P3 разбора — лобби, статусы загрузки, история и статистика. Только запись в бэклог (W-20).

**Нормативность.** Разбор DE — довод, а не закон. Где наша спецификация осознанно лучше DE, она остаётся. Это
предвыбор, призраки, лента событий, видимый таймер защиты, быстрый бой. Перенос делается только там, где
[02-spec-deltas.md](02-spec-deltas.md) даёт явное основание.
