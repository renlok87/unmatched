# 06 — Инструкция: живое исследование DE в новом чате

Для пользователя. Порядок:
1. Подготовить компьютер и игру по шагам 1–3.
2. Открыть новый чат и вставить промпт из шага 4.

Дальше исследование ведёт Claude по протоколу [04-de-live-research.md](04-de-live-research.md). После него он сам
принимает пять делегированных решений ([01-decisions.md](01-decisions.md)).

Время: подготовка ~10 мин; сессия 60–90 мин, из них ~55 мин мышь и клавиатура заняты; разбор и решения ещё
~30–60 мин, в это время компьютер свободен.

## 1. После перезагрузки — до запуска игры

1. **Закрыть Unreal проекта:** редактор UnmatchedEditor (в том числе на втором рабочем столе) и упакованные
   клиенты. Они грузят GPU и мешают записи.
2. **Убрать посторонний звук.** Рекордер пишет весь системный звук.
   - Закрыть Яндекс.Музыку и другие плееры.
   - Включить «Не беспокоить» в Windows.
   - Заглушить Telegram, Discord и почту.
3. **Устройство вывода.** Игра должна играть в устройство Windows по умолчанию. Проверка в шаге 5 покажет, какое это
   устройство (сейчас «Headphones (High Definition Audio Device)»).
4. **Игру не запускать от имени администратора.** Иначе computer use не сможет кликать (Windows блокирует ввод в
   повышенные процессы).

## 2. Настройки игры (⚙ в главном меню)

| Раздел | Параметр | Значение | Зачем |
|---|---|---|---|
| VIDEO | Режим окна | **Оконный** или **оконный без рамки** (не эксклюзивный полноэкранный) | запись по окну и computer use; в эксклюзивном режиме бывает чёрный кадр |
| VIDEO | Разрешение | **1920×1080** | как у ролика; удобно мерить |
| VIDEO | Качество | **High**, если держит 60 fps; иначе Medium | |
| VIDEO | VSync или лимит FPS | **вкл / 60** | ровная частота кадров для замеров |
| GAMEPLAY | ANIMATION SPEED | **1x** | эталон; другие скорости Claude включит сам в R-13 |
| GAMEPLAY | DISABLE COMBAT CAMERA | **выкл** (боевая камера включена) | поведение по умолчанию |
| GAMEPLAY | LOWER HAND, DISABLE WARNINGS | **выкл** | по умолчанию; проверяются в R-15 |
| AUDIO | Music | **0** | чистые звуки событий для R-12 |
| AUDIO | SFX / эффекты | **100** | |
| AUDIO | Master | комфортно, не 0 | |
| GENERAL | Язык | **English** | термины совпадают с разбором ролика |

Потом выйти в **главное меню** и оставить окно игры на основном мониторе, на текущем рабочем столе, не свёрнутым.
Онлайн-вход не нужен: исследование идёт только в LOCAL PLAY и TUTORIAL.

## 3. Модель нового чата

В новом чате (вкладка Code, этот репозиторий, ветка `fix/admin-panel`) **до отправки промпта** выбрать в меню
модели:
- модель — **Sonnet 5.5**;
- effort — **low**.

Так быстрее цикл «скриншот → решение → клик». Разбор записи и решения пойдут через workflow с агентами **Opus,
effort high** — разрешение уже стоит в промпте.

Если серия буксует (путается в меню, промахивается), можно поднять effort до medium прямо по ходу.

## 5. Во время сессии

- Когда приложение спросит доступ computer use к окну игры, разрешите.
- Между «серия N: начинаю» и «серия N: закончил» не трогайте мышь и клавиатуру: идёт управление. Между сериями
  компьютер ваш, только не двигайте и не закрывайте окно игры.
- Остановить можно в любой момент: стоп в чате или на оранжевой рамке. Запись остановится по файлу STOP; если чат
  прерван, создайте пустой файл `C:/tmp/de-live/<дата>/session-01/STOP`.
- После серий Claude разбирает запись и пишет документы, игра уже не нужна.

## 6. Если что-то не так

| Симптом | Что делать |
|---|---|
| Проверка: `FAIL DE window` | Игра не запущена или запущена не из Steam. Открыть главное меню и повторить |
| Проверка: `WARN project Unreal processes` | Закрыть редактор и клиенты проекта, повторить |
| Проверка: `FAIL venv` | Выполнить команду из строки FAIL: она пересоздаёт `C:\tmp\de-footage\tools\venv` с `soundcard`, `numpy`, `yt-dlp` |
| Чёрное видео в записи | Переключить игру в оконный режим или оконный без рамки |
| Тишина в `audio.wav` | Игра играет не в устройство по умолчанию: сменить устройство по умолчанию в Windows или вывод в игре |
| Computer use не кликает в игре | Игра запущена от администратора: перезапустить обычным способом |
| Заголовок окна не латиницей | Передать его рекордеру из PowerShell, а не из bash |
