## Волна 2 — P1 в коде

### W-10. Кольца-кандидаты и автовыбор (MS-T-08+)

- **Файлы:**
  - `S08/S08MoveHighlight.*` — создаётся в MS-T-08 по плану `05`;
  - `S09/S09MoveInput.*`, `S09/S09ManeuverUi.*`;
  - тесты в `S09/S09MoveSelectionTests.cpp`.
- **Приёмка:**
  - в MS-S-06 кольца стоят под всеми своими бойцами, которые могут ходить;
  - обездвиженные и мёртвые бойцы колец не получают;
  - если может ходить ровно один боец, сразу наступает MS-S-07;
  - Tab по-прежнему перебирает бойцов;
  - автоперехода к следующему бойцу после назначения хода нет.
- **Свидетельства:** кадры до и после на Marmoreal original (три бойца Медузы; один подвижный — Sarpedon или
  сценарий с обездвиженными).

### W-11. Выбор без целей и подача отложенных выборов (MS-T-12+)

- **Сначала — спайк сервера.** Создаёт ли `backend/src/game-engine/effects` pending-эффект без допустимых целей
  (урон смежному без соседей, MOVE без доступных клеток)? Если создаёт, правило «нет целей → эффект завершается,
  в состоянии остаётся причина» ставится на сервер с jest-тестом. Клиент только объясняет.
- **Файлы:**
  - backend `game-engine/effects` и его spec;
  - `S09/S09HudModel.*` (pending);
  - `S08/S08ArtHud*` (модальный выбор, тост);
  - `S08/S08WhyText.*`;
  - `docs/unreal/contracts/hud/why-reasons.json`;
  - тесты `S09/S09PendingTests.cpp`.
- **Приёмка:**
  - нет ни одного состояния, где игрок ждёт ввода без подсвеченной цели;
  - причина видна;
  - выбор в чужой ход — «объект → цель (до N)»;
  - у модала есть «свернуть»;
  - повторяющийся необязательный триггер — тост, а не модал;
  - обязательный выбор каждый ход — компактный и помнит прошлый вариант.

### W-13. Взгляд соперника и строка статуса (MS-T-17+)

- **Приёмка:**

  - трекер действий соперника обновляется по снапшоту;
  - эффект соперника, который двигает моего бойца, анимируется по следу, с картой-источником и подписью «ваш боец»;
  - строка «что делать сейчас» есть в каждом состоянии хода;
  - камера стоит;
  - MS-AT-26 и MS-AT-30 зелёные.
- **Свидетельства:** прогон двух клиентов на Marmoreal, кадры клиента-соперника.

### W-14. Раскадровка боя (CUE-008…011)

- **Блокеры:** D-DE-01 (длительность) и D-DE-03 (выпад). Без ответа пункт не начинать.
- **Файлы:**
  - `S09/S09HudModel.*` (бой);
  - `S08/S08ArtHud*` (панель боя, три состояния слота защиты);
  - `S08/S08FighterActor.*` — LungeAttack и HitReact; красная заливка — параметром материала;
  - `S08/S08BoardActor.*` — «−N», CUE-011 fallback;
  - диспетчер CUE в `S08/S08FlowController.*`;
  - фикстуры `docs/unreal/contracts/cue-dispatcher/fixtures/`;
  - тесты `S09/S09CombatTests.cpp`, `cue_contract.py run-fixtures`.
- **Приёмка:**
  - порядок «переворот → эффекты → слэм → контакт → HitReact и HP → исход» соблюдается;
  - сумма — по D-DE-01;
  - пропуск кликом сокращает бой до финального состояния ≤ 1 кадр;
  - ничья подписана «защита держит»;
  - трасса `CUE …` проходит `cue_contract.py check-trace`;
  - живой бой на Marmoreal между двумя клиентами.
- **Ассеты:** клипы есть только у Медузы, и то блокауты (бриф 18). У остальных бойцов — материал-фолбэк:
  вздрагивание и заливка без клипа.
