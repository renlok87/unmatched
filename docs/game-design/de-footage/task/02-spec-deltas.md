# 02 — Дельты спецификаций SD-01…SD-40

Как применять (для каждого агента прогона «Синхронизация спецификаций»):
1. **Сверить «Сейчас».** Открыть место и проверить, что текст или значение совпадает с колонкой «Сейчас».
   Если не совпадает (другая сессия уже меняла документ), дельту не применять. Записать её в журнал прогона как
   `stale` с цитатой текущего текста.
2. **Проверить решение.** Если дельта зависит от D-DE с пометкой «пользователь» ([01-decisions.md](01-decisions.md))
   и ответа нет, не применять (`waiting D-DE-xx`). Для делегированных D-DE применить умолчание и пометить в тексте
   документа: «по умолчанию, D-DE-xx».
3. **Сослаться на основание.** Указать строку [../timings.csv](../timings.csv) (`event_type`) или таймкод README в
   колонке «Основание» документа или в скобках. Формулировка: «Данные DE (разбор 2026-10-04)». Ассеты, тексты карт
   и строки интерфейса DE не копировать — только числа и порядок.
4. **Гейт.** Запустить гейт файла из [00-TASK.md §5](00-TASK.md#5-гейты).

Обозначения:
- `07` — `docs/game-design/07-animation-vfx-audio.csv`;
- `cue` — `docs/unreal/contracts/cue-dispatcher/cue-table.json`;
- `03`, `05` — `docs/game-design/move-selection/03-ux-spec.md` и `05-implementation-plan.md`;
- `02` — `docs/game-design/02-ux-ui-spec.md`;
- `18` — `docs/game-design/18-animation-production-brief.md`;
- `IM` — `docs/unreal/contracts/hud/ICON-MOTION.md`;
- `11` — `docs/game-design/11-open-questions-and-risks.md`.
