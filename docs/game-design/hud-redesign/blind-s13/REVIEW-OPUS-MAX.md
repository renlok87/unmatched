# Слепое сравнение, срез 13 — Opus max (2026-10-16)

**A** — HUD «Стол», срез 13 (упакованный клиент). **B** — HUD v2. Порядок кадров снова переставлен; рецензенту не
сообщалось, какой из них новый.

| Критерий | A | B |
|---|---|---|
| Цельность, один материал | 7,5 | 7,0 |
| Премиальная настолка / уровень Arena | 6,5 | 5,0 |
| Без лишних значков | 7,5 | 4,5 |
| Ясность компоновки | 7,0 | 5,5 |
| Читаемость на 1080p | 6,5 | 6,0 |
| Дёшево или премиально | 7,0 | 5,0 |
| **Среднее** | **7,0** | **5,5** |

**Вердикт:** A лучше на 1,5 балла, примерно +27 %. Отрыв дают лишние значки (+3,0), премиальность (+2,0), сходство
с настолкой (+1,5) и компоновка (+1,5). По целостности и читаемости почти паритет.

## Пять главных проблем A

1. **Правый нижний угол: «башня» около 375×325 px.** Левые края блоков разъехались, пустой сброс выглядит чёрной
   дырой, латинские хоткеи M/A/G/E спорят с иконками.
   *Исправление:* одна плита шириной с панель действий; мини-стопки слева от «Действие 1 из 2»; пустой сброс —
   контур карты при 25 % непрозрачности; хоткей — мелкой гравировкой или при наведении.
2. **Плашка соперника: около 340×250 px при минимуме данных.** Рубашки карт и строка внизу повторяют одно и то же.
   *Исправление:* зеркало плашки игрока, рубашки веерной стопкой с бейджем «5», высота не больше 150 px, фаска.
3. **Рука:** упирается в раму доски и уходит за край экрана, правила наклонены. Чип «Рука 5/7» выглядит как синяя
   веб-таблетка.
   *Исправление:* наклон не больше 3°, увеличение ×1,8 при наведении, счётчик руки — гравированной биркой в
   плашке игрока.
4. **Состояние хода разбросано по четырём углам.** «Ход 1» на 250 px, ещё «ВАШ ХОД», «ЖДЁТ», «Действие».
   *Исправление:* ужать «Ход 1», две пипы действий, кант активного игрока, баннер при смене хода.
5. **Плашка игрока:** «1 1/1» читается как «11/1», служебный текст 11–13 px.
   *Исправление:* номер — бейджем внутри жетона, HP помощников не меньше 16 px.

## Что взять из B

- подсказку с вариантами, но только в нестандартных состояниях;
- подписанную структуру хода;
- явное «доступно / недоступно» у кнопок;
- компактные чипы колоды;
- ровную руку;
- HP у фигуры только по контексту;
- свёрнутый журнал.
