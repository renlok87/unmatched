# Слепое сравнение, срез 19 — Opus max (2026-10-16)

**A** — HUD «Стол», срез 19 (упакованный клиент). **B** — HUD v2. Рецензенту не сообщалось, какой кадр новый.

| Критерий | A | B |
|---|---|---|
| Цельность, единый материал | 7,0 | 6,0 |
| Премиальная настолка / MTG Arena | 6,0 | 5,0 |
| Иконочный шум (10 — ничего лишнего) | 7,5 | 4,0 |
| Ясность раскладки | 7,0 | 5,5 |
| Читаемость на 1080p | 7,5 | 6,0 |
| Дёшево ↔ премиально | 6,5 | 5,0 |
| **Среднее** | **6,92** | **5,25** |

**Вердикт:** A лучше на ~1,7 балла и выигрывает по всем шести пунктам.

## Пять главных проблем A

1. **Слабый призыв к действию в доке.**
   *Сейчас:* общая фраза, мелкая стадия, доступные кнопки ничем не выделены.
   *Исправление:* фраза из доступных действий («Действие 1 из 2: манёвр, атака или схема»), пипсы, золотая подсветка
   дока и активных кнопок.
2. **Плоский материал**, металл колец портретов разный.
   *Исправление:* один материал с фаской и тенью, один металл для всех колец; ход показывать свечением.
3. **Портреты** — обесцвеченные кропы.
   *Исправление:* перекадрировать по лицу, вернуть цвет, привести к одному стилю (новый арт).
4. **Жетоны HP** закрывают контуры клеток.
   *Исправление:* размер около 70 %, лента у края подставки, полупрозрачность при полном HP.
5. **Колода и сброс:** пустой сброс читается как незагрузившаяся текстура, подписи спорят с призывом.
   *Исправление:* призрачный силуэт карты, подписи 14–16 px.

## Что взять из B

- формулировку призыва с перечнем вариантов, собранную из доступных действий;
- пипсы стадий хода;
- руку соперника мини-рубашками;
- лавр — только у того, чей ход;
- металлический бортик значков (значки v3 — решает пользователь);
- журнал свёрнутой вкладкой.
