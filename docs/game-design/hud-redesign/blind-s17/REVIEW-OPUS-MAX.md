# Слепое сравнение, срез 17 — Opus max (2026-10-16)

**A** — HUD «Стол», срез 17 (упакованный клиент). **B** — HUD v2. Какой кадр новый, рецензенту не сообщалось.

| Критерий | A | B |
|---|---|---|
| Единство материала | 7,5 | 6,5 |
| Премиальная настолка / MTG Arena | 6,5 | 5,0 |
| Захламлённость значками (10 — ничего лишнего) | 8,0 | 4,0 |
| Компоновка, порядок чтения | 7,0 | 5,5 |
| Читаемость на 1080p | 7,5 | 6,0 |
| Дёшево или премиально | 7,0 | 5,0 |
| **Среднее** | **7,25** | **5,33** |

**Вердикт:** A лучше примерно на 1,9 балла и выигрывает по всем шести критериям, включая читаемость (+1,5).

## Пять главных проблем A

1. **Сигнал «ваш ход, что делать» спрятан в угол.**
   *Исправление:* вкладка по центру над рукой: «Ваш ход · действие 1 из 2 · рука 5/7».
2. **Нижняя полоса не собрана.** Центр руки около x 900, это на 60 px левее оси; верхние кромки блоков на разной высоте.
   *Исправление:* общая сетка, колоду встроить в модуль действий.
3. **Портреты — сырые вырезки арта, оправы разные.**
   *Исправление:* отдельные портретные кадры, одна оправа, ход отмечать свечением.
4. **Плашки HP на поле:** заходят на соседние клетки, цифры около 11 px.
   *Исправление:* «диск здоровья» у края подставки, цифры 15–16 px.
5. **Текст карт в покое нечитаем.**
   *Исправление:* наклон не больше 1,5°, превью ×2 при наведении.

## Что взять из B

- руку ровно по оси;
- крупную подсказку, компактно у руки и с учётом контекста;
- рубашки руки соперника;
- одинаковую оправу портретов;
- явное состояние кнопок (это значки v3 — решает пользователь);
- журнал свёрнутым.
