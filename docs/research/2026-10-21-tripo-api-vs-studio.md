# Tripo3D: API-ключ против подписки Studio (ресёрч 2026-10-21)

Запрос пользователя: «По ресерчу про отличие API ключа трипо и подписочной модели, если они есть.» Workflow tripo-api-vs-studio: три исследователя (оплата, функции и лимиты, лицензия) и проверяющий, источники открыты 2026-10-21. Ничего не покупалось, ключи не вводились.

**Итог: Tripo Studio (подписка) и Tripo API — проверено 2026-10-21**

Коротко: Studio и API — это два разных кошелька. Подписка Max на API не распространяется. Ради пачек без кликов API по функциям подходит, а с юридической стороны это самый чистый путь. Но платить за него придётся отдельно: примерно $1,2–1,5 за героя, около $100–120 за 80 фигур. Это поверх подписки, а её квота сейчас в основном сгорает. Ниже: [пров.] — я сам открыл источник 2026-10-21; [не пров.] — взято у исследователя, сам не перепроверял.

Расчёт на 80 фигур по 125 кредитов:
- Studio: около 10 000 кредитов, это 40% одного месяца Max;
- API: 9 600–12 000 кредитов, то есть $96–120;
- каждая перегенерация H2 в API добавляет около $0,90.

Наш расход: баланс Studio упал с 21 540 (2026-10-13) до 20 030 (2026-10-21), всего 1 510 кредитов за 8 дней [пров.].

## 2. Вывод

Целиком на API переходить не стоит. Подписка уже оплачена, а её квота в основном сгорает, так что API — это новые деньги, а не замена.

API имеет смысл только как отдельный канал для пачек, когда важно не кликать. Его плюсы:
- до 10 генераций одновременно без рабочего стола;
- автоматизация явно разрешена;
- модели приватны по умолчанию.

Цена этого:
- примерно в 2,8 раза дороже за кредит;
- теряем зернистость частей, бесплатные пресеты, картинки и повторы.

Что нужно от пользователя, если решит:
1. Новое решение о тратах. Сейчас в журнале стоит «кредиты, подписки и паки не покупаются (ВР-04)» (`docs/game-design/visual/credits-ledger.json:42`).
2. Свой аккаунт на developers.tripo3d.ai, API-ключ в `TRIPO_API_KEY`. Ключ создаёт и вводит сам пользователь, не в чат и не в репозиторий.
3. Пополнение баланса или пробные кредиты. Для пилота на 1–2 героя хватит $5–10.
4. Строка условий в журнале: `ledger.py terms --service Tripo --model "Tripo API …"`.

Пилот проверит, совпадает ли `generate_parts` с «Баланс» в Studio и совпадает ли 8K-текстура с удалением освещения.

Бесплатную альтернативу тоже стоит проверить: пакетная генерация до 30 в самой Studio Max. Поддерживает ли она multiview по частям, неизвестно.
