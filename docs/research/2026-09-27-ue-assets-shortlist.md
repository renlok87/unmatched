## 1. UMG MCP for Unreal Engine 5.8 — [github.com/winyunq/UnrealMotionGraphicsMCP](https://github.com/winyunq/UnrealMotionGraphicsMCP)

**Что именно ускоряет.** Сборку всего UMG-слоя клиента: экраны BOOT→LOGIN→LOBBY→ROOM (TASK-025, размер L), каркас HUD с рукой/колодой/сбросом (TASK-026, L), UI-семейства и локализация RU/EN (TASK-051, L), инспектор/пауза/настройки (TASK-054, M). UI — самая «ручная» часть бэклога (три задачи L подряд); инструмент позволяет AI-агенту создавать виджеты, менять layout, материалы и UMG-анимации явными tool-calls вместо ручных кликов в редакторе.

**Почему безопасно.** MIT; заявлена именно UE 5.8 + Win64 — точное совпадение с `.uproject` (EngineAssociation 5.8). В проекте уже включён плагин `ModelContextProtocol` (проверено в `unreal/Unmatched/Unmatched.uproject`), т.е. транспорт MCP уже используется командой.

**Сверка с встроенным (ревью 2026-09-27).** В `.uproject` включён и `AllToolsets` — по докам Epic именно он поставляет в UE 5.8 MCP-инструменты редактора (SceneTools/ActorTools/MaterialInstanceTools/ObjectTools). Шаг 0 плана: инвентаризация toolset'ов AllToolsets до внедрения стороннего MCP-сервера; правки материалов по возможности вести встроенным MaterialInstanceTools, UMG MCP брать только за недостающие виджет-специфичные функции (создание UMG-виджетов, layout, UMG-анимации). Источник: dev.epicgames.com/documentation/unreal-engine/unreal-mcp-in-unreal-editor.

**План интеграции.** 1) Поднять MCP-сервер инструмента, подключить к редактору UE 5.8 на неважной ветке; смоук-тест: создать/изменить тестовый виджет. 2) Использовать при реализации WBP-каркасов TASK-025/026: агент генерирует виджеты, разработчик ревьюит и связывает с C++ базовыми классами UmClient. 3) Не отдавать агенту фиксацию иерархии слоёв CommonUI (Game/Menu/Modal/Toast из 02 §1.3) — генерация только внутри неё.

**Стоимость.** $0.

**Риски.** Молодой проект одного автора (204★, push 2026-08-02 — проверено `gh api` в этой сессии); удалённое управление редактором — только на выделенной ветке до доверия; каждый сгенерированный виджет проходит ревью (локализация RU/EN — длинные строки, QA-011).

## 2. UE5Coro — [github.com/landelare/ue5coro](https://github.com/landelare/ue5coro)

**Что именно ускоряет.** Весь асинхронный клиентский код: спайк A «транспорт UE↔сервер» (TASK-011, M/L) — Login → HTTP GraphQL → WS-подписка; ядро синхронизации (TASK-023, M/L) — применение снапшотов по sequenceNumber, gap-догон eventsSince пачками, in-flight гейт мутаций (INT-005); боевой поток атака→защита→резолв (TASK-030) и схемы (TASK-031). Корутины заменяют цепочки колбэков делегатов UE на линейный C++20 — по опыту это дни работы на каждом этапе.

**План интеграции.** 1) Подключить релиз v2.3.2 (только numbered release — между v1/v2 были breaking changes) как плагин в `Plugins/` или модуль в `Source/`. 2) UmNet: обёртки мутаций и подписок как `ue5coro::task` (`co_await` на HTTP/WS-ответах). 3) UmModel: StateStore применяет снапшоты из корутины дедупликации. 4) CUE-очередь (TASK-028): тайминги 07 (feedbackDelay ≤ 200 мс, блок ≤ 1 с) на await-ерах таймеров с отменой (пропуск кликом).

**Стоимость.** $0 (BSD-3-Clause-Clear).

**Риски.** Матрица версий движка не публикуется — первым делом проверить компиляцию под UE 5.8.2 в пустом модуле (час); не собирать через Clang/LLVM (предупреждение автора); зафиксировать версию в VCS.

## 3. GraphQL Client (Pandoa/Pandores) — [fab.com](https://www.fab.com/listings/531b2dce-cac7-42a5-905b-143ef7b64b75)

**Что именно ускоряет.** HTTP-половину интеграции с бэкендом: 11 игровых мутаций (endTurn, maneuver, attack, playDefense, resolveCombat, playScheme, resolvePendingEffect…), auth (login/refresh), контент-queries (contentVersion → AllHeroes → HeroDetails → AllBoards). Это TASK-011 (спайк), TASK-023–026, TASK-030–034 — весь критический путь. Запросы хранятся .graphql-файлами на диске (удобно версионировать и сверять с `docs/backend-api/`), WalkResult экономит ручной JSON-парсинг; JWT Bearer — через SetHeader после логина.

**План интеграции.** 1) Купить, установить как плагин в `Plugins/`, проверить сборку в VS2022 (UE 5.8 заявлена листингом, но агент компиляцию не проверял). 2) В UmNet: сервис-обёртка `UUmGraphQLService` (engine subsystem) — хост из конфига (TASK-060: адрес сервера не в коде), SetHeader Authorization после Login. 3) Файлы запросов в `Content/GraphQL/*.graphql` по операциям из `docs/backend-api/02–05`. 4) Двухфазный парсинг JSON-внутри-строк (INT-002) остаётся своим слоем в UmModel. 5) Fallback: если плагин не соберётся под 5.8 — тонкая собственная обёртка над HTTP-модулем движка (запросы простые POST JSON).

**Стоимость.** $14.99–29.99 (одна Standard-лицензия).

**Риски.** Подписки не поддерживаются вовсе — закрываются пунктом 4 ниже. Закрытый исходник, один автор, без отзывов. ⚠ Два ID листинга Fab: фактчекинг 2026-09-27 подтвердил, что 531b2dce-… рендерится живым листингом «GraphQL Client» (обновлён 2026-07-06), второй ID 2e4c42bb-… напрямую закрыт Cloudflare, но на него ссылаются собственные доки автора — канонический не установлен. Цена и блок версий UE не перепроверены: перед оплатой открыть листинг в браузере, сверить цену/версию UE.

## 4. Подписки graphql-ws: встроенный IWebSocket + CrowdyCPP как паттерн — [доки IWebSocket UE 5.8](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/WebSockets/IWebSocket) + [github.com/CrowdedKingdoms/CrowdyCPP](https://github.com/CrowdedKingdoms/CrowdyCPP)

Готового плагина с graphql-transport-ws не существует (вывод обоих агентов темы, перепроверен независимым поиском при ревью 2026-09-27). Рекомендуемая связка из трёх находок каталога (6.2–6.4): транспорт — встроенный модуль WebSockets движка (бесплатно, задокументирован для 5.8), паттерн протокола — MIT-код CrowdyCPP; платный [BlueprintWebSocket (Pandores)](https://github.com/pandoa/BlueprintWebSocket) — **опция-дубль встроенного модуля** (релевантность понижена до medium по итогам ревью): его автореконнект не знает о протоколе graphql-transport-ws (переподписка с `since` из INT-004 — наш код в любом случае), плюс требует cacert.pem в packaged-сборке; цена не проверена (листинг за Cloudflare).

**Что именно ускоряет.** Подписку `gameStateUpdated(gameId, since)` — единственный источник живых событий партии: спайк A (TASK-011), дедуп HTTP+WS (TASK-023, INT-003), gap-протокол и реконнект-базис (INT-004), полный реконнект-оверлей без повторного расхода карт (TASK-033), VS_AI (ходы бота приходят только подпиской, TASK-032). CrowdyCPP уже реализует ровно наш сценарий: connection_init с авторизацией, bounded-реконнекты, **повтор активных подписок после переподключения** (= переподписка с `since: lastSeq`).

**План интеграции.** 1) Build.cs UmNet: добавить `WebSockets`, `HTTP`, `Json`. 2) `UUmGraphqlWsClient` поверх IWebSocket: state machine connection_init (authorization в payload) → connection_ack → subscribe/next/complete + ping/pong-таймеры. 3) По образцу CrowdyCPP: bounded-реконнект с backoff, после восстановления — повтор активных подписок с `since` (INT-004 п.4), далее eventsSince/full-state по размеру дыры. 4) Тесты на фикстурах TASK-011/012 (дубль seq, gap, устаревшее). 5) Токен в connection_init — заголовки handshake не нужны (ограничение IWebSocket не блокер).

**Стоимость.** $0 (оба компонента); опция Pandores WS — платно (цена уточняется на листинге).

**Риски.** Протокол и таймеры пишем сами (~2–4 дня с образцом); CrowdyCPP — молодой проект (0★, зато push 26.09.2026, проверено `gh api`) под их платформу — берём паттерн, не SDK целиком; в packaged-сборке учесть SSL-сертификаты (для Pandores WS нужен cacert.pem, для встроенного модуля — проверить на спайке).

## 5. UE-BUITween (benui) — [github.com/benui-dev/UE-BUITween](https://github.com/benui-dev/UE-BUITween)

**Что именно ускоряет.** Все плавные движения UMG: полёт карты из колоды в руку и в сброс (CUE-005, TASK-026 «рука», TASK-030 «выпуск карт в сброс»), hover-превью карт, появления панелей/экранов (переходы 200–300 мс, 02 §2), инспектор карт (TASK-054). Иначе каждый эффект — ручной таймлайн/тик; библиотека даёт твины translation/scale/opacity/color с easing из одной строки C++, тикает на паузе (важно для оверлея реконнекта).

**План интеграции.** 1) Скопировать исходники (это одна компактная C++-библиотека, CC0 — можно править свободно) как модуль в `Source/` или ThirdParty; смоук-тест компиляции под 5.8 (база UE4, API рендер-трансформов Slate стабилен — по оценке агента). 2) UmClient: хелпер `UmPlayCardTween(...)` для CUE-005/008-011, вызовы из CueSubsystem (TASK-028) с таймингами 07. 3) Дуги полёта карты (если понадобятся) — поверх твина своим кодом.

**Стоимость.** $0 (CC0-1.0, проверено `gh api`).

**Риски.** Не обновлялась с 2023-08-05 (push подтверждён `gh api`) — если под 5.8 не соберётся, форкнуть и поправить самому (лицензия позволяет); это единственный риск, и он дёшев.

## 6. KayKit — Character Animations — [kaylousberg.itch.io/kaykit-character-animations](https://kaylousberg.itch.io/kaykit-character-animations)

**Что именно ускоряет.** Этапы 4–5: эталонная модель Medusa с клипами Idle/LungeAttack/HitReact/DeathSettle (TASK-041, L), остальные модели и анимации Arthur/Merlin/гарпий (TASK-050, L), CUE-013 (смерть гарпий). 161 анимация ровно по D-11: idle, hit, death, одно-/двуручный мили (Arthur), spellcasting (Merlin), блоки, эмоции — боевой набор миниатюр без обращения к аниматору на этапе прототипа и, возможно, в MVP.

**План интеграции.** 1) Скачать FBX (CC0). 2) Свой риг из Blender-пайплайна (D-06, файл 04) делать сразу в пропорциях, совместимых с ретаргетом; в UE 5.8 — IK Rig/IK Retargeter с KayKit-скелета (Rig_Medium) на риги Medusa/Arthur/Merlin. 3) Привязать клипы к состояниям FighterActor (TASK-021 → этап 3/5): idle-луп, выпад при атаке, вздрагивание при уроне, оседание при смерти (CUE-011/013). 4) Гарпии (нестандартный риг с крыльями) — корпус ретаргетится, крылья анимируются в Blender (прямых анимаций крылатых в находках нет — подтверждено обоими агентами).

**Стоимость.** $0 (достаточно бесплатного тира; SOURCE $14.99 — только если нужны .blend).

**Риски.** Ретаргет на свои риги потребует настройки (день-два на первый риг, дальше конвейером); стиль сверхпростой — для эталона Medusa (TASK-041) клипы, скорее всего, останутся прототипными, финальные делает аниматор по образцу.

## 7. KayKit — Board Game Bits — [kaylousberg.itch.io/board-game-bits](https://kaylousberg.itch.io/board-game-bits)

**Что именно ускоряет.** Прототипы маркеров для серой сцены (TASK-020/021) и fallback-иерархию INT-018: токены/миплы/кубы/пешки CC0 закрывают маркеры урона и счётчики эффектов до готовности Blender-производства. **Стоимость.** $0 (EXTRA $4.99+ опционально).
