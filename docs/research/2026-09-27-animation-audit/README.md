# Аудит анимации — рабочие материалы к брифу 18 (2026-09-27)

Происхождение: dynamic workflow `dwfrun-27214b91-48a9-4c01-b9f6-0863104eea8f`
(15 субагентов, 6 этапов, ~1 ч 10 м; независимый ревью — 1 раунд, blocking-замечаний
нет). Итоговый документ: `docs/game-design/18-animation-production-brief.md`.

Эта папка — снимок промежуточных материалов аудита, из которых собран бриф.
Источник истины — сам бриф; при расхождениях приоритет у брифа. Длительности
клипов и FPS внутри материалов — PROPOSAL (утверждённых значений нет).
Внешние сервисы в прогоне не использовались; ассеты никуда не отправлялись.

## Главные цифры аудита

- Обязательных уникальных skeletal-клипов: **16** (4 клипа D-11 × 4 персонажа).
- Дополнительных optional-клипов: **0**; заменено VFX/материалом/существующими клипами: 10.
- Из 32 событий реестра 28 не требуют skeletal-анимации.
- Модель есть только у Medusa (блокаут, 17 костей, 4 клипа подтверждены в
  packaged-сборке); Harpy/Arthur/Merlin — «planned».
- Общий скелет и retargeting не доказаны — требуется тестовый риг (6 пунктов в §9/§16 брифа).
