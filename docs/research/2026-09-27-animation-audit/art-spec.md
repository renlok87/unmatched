## 1. Требования к ригу

### 1.1 Уровень рига (УТВЕРЖДЕНО)

- **D-11 дословно**: «Анимации фигурок: лёгкий риг (idle, выпад при атаке, вздрагивание при уроне, оседание при смерти), перемещение плавным скольжением» — `00-vision-and-scope.md:105` (реестр решений §8, все D приняты 2026-09-18, `00-vision-and-scope.md:91`).
- Пересказ в 17 §1.1: «Лёгкий риг: idle, выпад при атаке, вздрагивание при уроне, оседание при смерти. Перемещение — плавным скольжением» → следствие: «Набор клипов на фигурку: Idle, LungeAttack, HitReact, DeathSettle (имена — ПРЕДЛОЖЕНИЕ 07). Для перемещения нет скелетного клипа» — `17-art-production-spec.md:177`.
- Все четыре типа фигурок — skeletal: «общее для всех четырёх: skeletal по D-11 (УТВЕРЖДЕНО)» — `17-art-production-spec.md:918`; карточки 04: Medusa `04:108`, Harpy `04:132`, Arthur `04:156`, Merlin `04:180`.

### 1.2 Скелет (всё ПРЕДЛОЖЕНИЕ, черновик 04)

- Состав: `root + hips + spine + head + 2×(arm: upper/lower/hand) + 2×(leg: upper/lower/foot) + weapon` — «~15 костей» — `04:30`. - Влияния на вершину: **≤ 4**, масштаб костей единичный — `04:30`, пересказ `17:877`, `17:1571`.
- Один шаблон скелета на всех персонажей: имена костей из `blender/_shared/rig_template.blend` — `04:30`. **Файла шаблона в репозитории нет**; S05 строит скелет скриптом — `17:892`, `17:1572`, AD-CNF-18/21 (`17:2126`, `17:2155`).

## 3. Требования к экспорту FBX

### 3.2 Один FBX на клип, общий Skeleton (ПРЕДЛОЖЕНИЕ)

- «Skeletal-анимации экспортируются отдельным FBX-клипом на действие (Idle/LungeAttack/HitReact/DeathSettle) с тем же скелетом — импорт в UE как Animation Sequences на общий Skeleton. Альтернатива "один FBX со всеми действиями" — проверить… выбран раздельный вариант как заведомо предсказуемый (ПРЕДЛОЖЕНИЕ)» — `04:52`; пересказ `17:891`, `17:1576`.
- S05 (ИЗМЕРЕНО, не пресет): `bake_anim=True`, `bake_anim_use_nla_strips=False`, `bake_anim_use_all_actions=False`, `bake_anim_force_startend_keying=True`, `FBX_SCALE_UNITS`, `mesh_smooth_type='FACE'` — `blender/S05/build_medusa.py:129-135` (цит. `17:1582`). - Add Leaf Bones: в 04 не задано — ОТКРЫТО (`17:1581`); S01/S05: `add_leaf_bones=False` — ИЗМЕРЕНО.

### 3.3 Единицы и масштаб

- Blender: Metric, Unit Scale 1.0, 1 unit = 1 м; клетка 1.0 м = 100 uu; «не выставлять ручной Scale при импорте — если потребовался, это дефект» — `04:20` (ПРЕДЛОЖЕНИЕ, зафиксировать после проверки кубом).
- Три конкурирующих рецепта (04 FBX Units Scale / S01 `FBX_SCALE_NONE` / S05 ×100 в данные + `FBX_SCALE_UNITS` + патч UnitScaleFactor=1.0) — блокирующее противоречие AD-CNF-01 (`17:1922-1933`), рецепт зависит от выбора импортёра (legacy vs Interchange) — AD-OPEN-03 (`17:2705-2714`).

### 3.4 Оси и ориентация

- Blender Z-up, «лицом вперёд» = −Y; экспорт Forward −Y / Up Z; ожидание: «персонаж… в UE смотрит вдоль +X» — `04:21` (ПРЕДЛОЖЕНИЕ). QA-009: root-движение 100 uu, «без разворота» — НОРМАТИВ; направление +X — взято из предложения 04 (AD-OPEN-04, `17:2722`).
- Факт S05 (ИЗМЕРЕНО): legacy FBX даёт −Y_bl → +Y_ue; Medusa «faces +Y in UE»; root motion пробы (0, 100, 0); гейт стрелки +X проходит только из-за поворота меша на +90° по Z перед экспортом — `17:1516`, AD-CNF-02 (`17:1935-1944`).
- Где ключуется root motion: на объекте арматуры (legacy-импортёр делает его костью 0; извлечение root motion читает только кость 0; анимация pose-кости `root` дала delta = 0) — ИЗМЕРЕНО `blender/S05/build_medusa.py:363-368` (цит. `17:1329`).
