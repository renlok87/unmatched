# Матрица «событие → механизм подачи» (anim-audit-18)

Субагент «аналитик событий и механизмов», 2026-09-27. Ветка `fix/admin-panel`.
Вход: `events-registry.md`, `acceptance.md`, `art-spec.md`, `characters.md` (все прочитаны полностью) + первичная сверка источников (см. §6).

Словарь механизмов (строго, из задачи): `SKELETAL_CLIP` / `ACTOR_TRANSFORM` / `MATERIAL_ANIMATION` / `NIAGARA_VFX` / `UI_ANIMATION` / `CAMERA_OR_POSTPROCESS` / `AUDIO_ONLY` / `NO_ANIMATION_REQUIRED`.

Колонки таблицы: Skeletal = SKELETAL_CLIP, Transform = ACTOR_TRANSFORM, VFX = NIAGARA_VFX (частицы), UI = UI_ANIMATION, Audio = AUDIO_ONLY. Механизмы `MATERIAL_ANIMATION`, `CAMERA_OR_POSTPROCESS`, `NO_ANIMATION_REQUIRED` колонок не имеют — указаны в Примечании; полная строка «Механизмы: …» перечисляет весь набор однозначно. ✓ = задействован, — = не задействован.

Происхождение: УТВ = УТВЕРЖДЕНО (D-11 — 00-vision-and-scope.md:105, проверено напрямую), PROPOSAL = предложения 01/02/04/05/07, АВТОР = рекомендация этого этапа. Обозначение `07:N` = строка CSV 07-animation-vfx-audio.csv (CUE-001=07:2 … CUE-018=07:19; весь файл прочитан в этой сессии).

## 6. Идемпотентность и риски дубля (общие для всех механизмов)

- Единственный санкционированный механизм подавления дубля — клиентский seq-guard: `< local` → игнор, `== local` → merge (16:17-21, проверено напрямую); «Сервер дедупликацию не обещает» (16:74-77, проверено напрямую). Ни один механизм подачи (SKELETAL_CLIP, NIAGARA_VFX, MATERIAL_ANIMATION, UI_ANIMATION) не защищён от двойного запуска сам по себе — при прямом вызове из подписчика без seq-guard дубль HTTP+WS даст двойной клип/VFX/цифру. Прямое требование: «−N» и HitReact ровно один раз (QA-007, 10:87-97 по acceptance.md:19-20).
- Named-события (attackInitiated/combatResolved/…) — «вспомогательные CUE (анимации/звук)», в окне барьера теряются без восстановления; полнота — только по gameStateUpdated (16:89-96, проверено напрямую). Все механизмы, повешенные на named-события (в т.ч. skeletal CUE-008/011), обязаны терпеть потерю триггера — игра продолжается без них.
- Локальные события ввода (CUE-001…004) дублей доставки не имеют — риск не применяется.
- Reconnect: только финальное состояние + один тик CUE-018 (07:19; QA-108); механизмы, пытающиеся «достроить» пропущенное (любой replay skeletal/VFX), нарушают ACC-012.
