## 5. UX-состояния (не события, но требуют визуальных состояний)

- FSM ввода S0–S6/S6E: ничего не выбрано → боец → карта → цель → подтверждение → in-flight → подтверждено/ошибка (02:808, 02:815–829).
- UI-CARD-FRAME: normal / hover / selected / disabled / focus (02:897); hover карты — увеличение ~120% + подъём 24 px за 150 мс, не перекрывает цели (P1) (02:687–688, UI-INP-001 02:788).
- UI-BUTTON: normal / hover / pressed / disabled / focus / selected — «все 6 обязательны» (02:900); disabled сохраняет читаемость текста причины (P2) (02:900).
- UI-CURSOR: обычный / указатель (интерактив) / недоступно / занято (in-flight мутация) (02:901).
- Неиграбельные карты руки: приглушены + тултип-причина (`why.not.your.turn`, `why.no.actions`, `why.defense.only.in.combat`, `why.banner.mismatch`, `why.syncing`, `why.wait.defender`, `why.immobilized`, `why.not.in.range`) (02:691).
- Подсветки поля: кольцо выбранной фигурки; достижимость — контур + заливка 20% + глиф «шаг»; цели — рамка-прицел + глиф «меч»; PLACE — пунктир + глиф «метка»; занятые — крест-штрих + причина (02:704–710).
- Панели/UI-PANEL: normal / акцент «ваш ход» / ошибка (02:899); индикатор связи ● зелёный / ◐ жёлтый (in-flight или gap) / ● красный (02:751).
- HP-бар: плавная анимация ≤400 мс + «−N» (02:698); смерть помощника — затемнение плашки + слот «погиб» (02:698, PROPOSAL).
- Таймер защиты 30 с: цвет+пульс последние 10 с, тихий тик последние 5 с (02:721, 02:860).
- Отмена выбора: Esc/ПКМ по шагам S3→S2→S1→S0 (02:792, 02:805); кольцо выбора гаснет за 150 мс (07:3).
