# Art Tuner — ползунки света и просмотр доски без сервера

Окно игры с доской, шестью фигурами, живыми огнями и эффектами — без бэкенда. Справа панель с ползунками: двигаешь —
сцена меняется сразу. «Сохранить» записывает твои значения в файл, ИИ-агенты вносят их в основной профиль.

Статус: **технически импортировано / измерено** (2026-10-03). «Художественно принято» решаешь только ты.
План и решения: [docs/art-pipeline/ART-TUNER-PLAN.md](../../docs/art-pipeline/ART-TUNER-PLAN.md).
Только для личного и локального использования.

## Как открыть

1. Двойной клик по `tools/s08/Unmatched-ArtTuner.cmd` — откроется Sarpedon.
   Другая карта: `Unmatched-ArtTuner.cmd marmoreal` или `Unmatched-ArtTuner.cmd cobble`.
2. **F10** — панель тюнера, **F1** — справка по клавишам.
3. Двигай ползунки или впиши число в поле и нажми Enter.
4. **Ctrl+S** (или кнопка «Сохранить») — значения записаны. При следующем запуске они вернутся сами.
5. Скажи агенту «внеси значения тюнера» — он перенесёт их в профиль (см. ниже).

Лаунчер запускает собранный клиент `unreal/Unmatched/Saved/StagedBuilds/Windows/Unmatched.exe`. Если его нет — сначала
упаковка (`powershell -File tools\s08\package-client.ps1`). Без упаковки, из редактора (после пересборки UnmatchedEditor):

```
"C:\Program Files\Epic Games\UE_5.8\Engine\Binaries\Win64\UnrealEditor.exe" C:\Users\ren\WebstormProjects\unmached\unmached\unreal\Unmatched\Unmatched.uproject /Game/S08/S08Arena?game=/Script/Unmatched.S08FlowGameMode -game -ArtView=sarpedon -ArtTuner -ArtTunerFile=C:\Users\ren\WebstormProjects\unmached\unmached\unreal\Unmatched\Config\ArtBoards\S08ArtTuner.overrides.json -ArtPreview -ArtPreviewDiorama -ArtPreviewHeroesV2 -windowed -ResX=1920 -ResY=1080
```

## Клавиши

| Клавиша | Что делает |
|---|---|
| колесо | приблизить / отдалить |
| Пробел | общий вид (сбрасывает поворот и сдвиг) |
| правая кнопка + движение | повернуть камеру; короткий щелчок — снять выбор героя |
| средняя кнопка + движение | сдвинуть камеру |
| левая кнопка по фигуре | выбрать героя |
| 1–5 | виды K1 / K1x0.65 / K2x1.6 / K2x2.5 / Fitx1.45 (как в замерах) |
| Tab / Shift+Tab | следующий / предыдущий герой — так видно подсветку «активного» |
| H | подсветка героев вкл/выкл (только на экране, в файл не пишется) |
| P | пауза: эффекты, ветер, мерцание огней, дыхание подсветки |
| F1 | справка |
| F10 | панель Art Tuner (в обычной игре с сервером — Shift+F10) |
| Ctrl+S | сохранить |
| Alt+Enter / F11 | полный экран |

Пока курсор над панелью или ты печатаешь в поле, игра клавиши и колесо не получает.

## Панель

- Группы сворачиваются: подсветка героев (ключ, контур, общее и состояния), свет сцены (луна, небо, экспозиция), точечные
  огни профиля, туман, тон карты, огни сцены lit3d, материалы сцены (яркость острова, корабля, рамы и т. д., ветер листвы),
  сцена (уровень моря, высота водопада).
- В каждой строке: подпись, ползунок, поле для точного числа, единица (лк, кд, uu, °, Гц, ×, EV). Наведи на подпись —
  увидишь диапазон и путь в профиле.
- **●** — значение отличается от профиля, **×** справа — вернуть это одно значение.
- «сбросить» у группы — вся группа к профилю. «Отменить всё» — все значения к профилю. Файл меняется только по «Сохранить».
- Группа **«Сцена (пересборка)»** пересобирает сцену целиком (фигуры начинают анимацию заново) — это короткое «моргание».
  Всё остальное меняется сразу на месте.
- Пометка **«! скрыт на этой карте»** (туман на Sarpedon): карта сама прячет этот слой, ползунки сцену не меняют.
- Внизу — сколько раз применено, время последнего применения и ошибки (например, «конус внутр. больше внешнего» — такое
  значение не применяется, сцена остаётся прежней).
- Диапазоны ползунков — те же проверки, что игра делает при запуске. В поле можно вписать и больше края ползунка, если
  это допускает проверка.

Не на панели (правила проекта): поворот луны (ключ сцены −55, 30, 0), добавление и удаление огней, их положение.

## Что и куда сохраняется

- Файл: `unreal/Unmatched/Config/ArtBoards/S08ArtTuner.overrides.json`. Он **не в git** — это твой черновик.
- В файле только изменённые значения: путь в профиле, новое значение и старое («was»). Для каждой карты свой блок, так что
  сохранение Sarpedon не трогает сохранённое для Marmoreal.
- При запуске с этим файлом значения накладываются на профиль. Запись, которую уже нельзя применить (профиль изменился),
  пропускается с предупреждением внизу панели — игра не падает.

## Как ИИ подхватывает значения

Агент запускает:

```
python tools/art/art_tuner_fold.py --dry-run     # показать, что изменится
python tools/art/art_tuner_fold.py               # внести, revision профиля + 1
```

- Инструмент правит **текст** профиля: меняются только сами значения, форматирование, порядок ключей и длинные строки
  досок остаются как были. Новые необязательные ключи (например, блок `materialOverrides` с яркостью острова) вставляются
  в стиле своего объекта.
- Если с момента сохранения профиль поменяли (сессия ENV-MAPS), значение не вносится: инструмент покажет «было / стало» и
  остановится. `--force` берёт твоё значение.
- После внесения сохранённый блок уходит в `docs/art-pipeline/art-tuner-saves/` (в git — видно, что и когда ты выбрал),
  а файл черновика очищается.

## Что требует перезапуска или новой упаковки

- **Перезапуск окна:** правка реестра строк `Config/ArtTuner/S08ArtTunerParams.json` (подписи, диапазоны, новые строки).
- **Новая упаковка:** изменения C++, профиля, раскладок, материалов или ассетов, сделанные агентами. Собранный клиент
  читает свои копии профиля и раскладок, поэтому свежие правки других сессий видны только после упаковки.
- Кадры с изменёнными значениями помечены `profilesSource=tuner` и не считаются эталонными — приёмка только по свежему
  `-Bench` без тюнера.

## Для агентов: то же из кода

Те же действия, что у ползунков, через live tune (`tools/art/render/LIVE-TUNE.md`):

```
python tools/art/render/live_tune.py start --map sarpedon --art-view --tuner-file <файл>   # окно вне экрана
python tools/art/render/live_tune.py tune --set heroKey.key.lux=9.5 --set "conceptLights.intensity#1=120"
python tools/art/render/live_tune.py tuner-state            # строки, значения, изменения
python tools/art/render/live_tune.py tuner-panel open       # кадр «с панелью»
python tools/art/render/live_tune.py art-view --view K2x1.6 --yaw -60 --pitch 40 --select f-0-hero
python tools/art/render/live_tune.py shot --views K1 --out <папка> --clock free
python tools/art/render/live_tune.py tuner-save
python tools/art/render/live_tune.py stop
```

Строку можно назвать по id (`heroKey.key.lux`, `materials.Island.gain`, `conceptLights.intensity#1`) или по пути в профиле.
Все id видны в `tuner-state`.
