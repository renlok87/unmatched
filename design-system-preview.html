🎨 Unmatched Design System

Визуальный справочник для создания карточной игры

📋 О проекте

Этот Design System создан на основе анализа 88 героев из игры Unmatched. Он содержит все необходимые компоненты для разработки дизайна вашей карточной игры: цветовую палитру, типографику, шаблоны карточек и компоненты.

🚀 Следующие шаги

  1. Включите MCP сервер в Figma (Preferences → Enable Dev Mode MCP Server)
  2. Создайте новый файл в Figma с названием "Unmatched Design System"
  3. Начните с создания Local Styles (цвета и шрифты)
  4. Создайте компоненты для шаблонов карточек
  5. Импортируйте ассеты из папки scraped-data/images
  6. Соберите 3-5 примеров карточек для тестирования
