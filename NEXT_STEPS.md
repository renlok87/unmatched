## 🎯 Три пути развития

### Путь 1: Работа в Figma (Рекомендуется для дизайнеров)

**Задача:** Создать визуальные карточки в Figma

**Шаги:**
```
1. Откройте Figma Desktop App
2. Включите: Figma → Preferences → Enable Dev Mode MCP Server
3. Создайте файл: "Unmatched Design System"
4. Откройте FIGMA_SETUP_GUIDE.md и следуйте инструкциям
5. Создайте Local Styles (цвета, шрифты)
6. Создайте компоненты (шаблоны карточек)
7. Импортируйте ассеты из scraped-data/images
8. Создайте 3-5 примеров карточек
```

**Результат:** Готовые дизайны карточек для печати или цифровой игры

---

### Путь 2: Разработка цифровой игры (Для разработчиков)

**Задача:** Интегрировать Design System в существующий проект

**Шаги:**
```
1. Создайте CSS переменные на основе DESIGN_SYSTEM.md
2. Создайте React компоненты карточек
3. Интегрируйте данные героев в Zustand store
4. Добавьте новые герои в игру
5. Реализуйте отрисовку карточек по Design System
```

**Пример кода:**
```css
/* src/styles/design-system.css */
:root {
  --color-primary-yellow: #FFD700;
  --color-primary-purple: #6B4C9A;
  --color-primary-red: #DC143C;
  --color-primary-blue: #1E3A8A;

  --color-neutral-black: #000000;
  --color-neutral-dark-gray: #1F1F1F;
  --color-neutral-gray: #808080;
  --color-neutral-white: #FFFFFF;

  --text-3xl: 40px;
  --text-2xl: 32px;
  --text-xl: 24px;
  --text-base: 14px;
  --text-sm: 12px;
  --text-xs: 10px;

  --spacing-xs: 4px;
  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 24px;
  --spacing-xl: 32px;

  --card-width: 300px;
  --card-height: 420px;
}
```

```tsx
// src/components/cards/ActionCard.tsx
import styles from './ActionCard.module.css';

interface ActionCardProps {
  title: string;
  description: string;
  value?: number;
  faction?: string;
  illustration?: string;
}

export function ActionCard({
  title,
  description,
  value,
  faction,
  illustration
}: ActionCardProps) {
  return (
    <div className={styles.card}>
      <div className={styles.cardTop}>
        {faction && (
          <div className={styles.factionBadge}>
            <FactionIcon type={faction} />
          </div>
        )}
        {value && (
          <div className={styles.cardValue}>{value}</div>
        )}
        {illustration && (
          <img src={illustration} alt={title} className={styles.illustration} />
        )}
      </div>
      <div className={styles.cardBottom}>
        <h3 className={styles.title}>{title}</h3>
        <p className={styles.description}>{description}</p>
        <div className={styles.meta}>
          <div className={styles.cost}>2</div>
          <div className={styles.faction}>{faction}</div>
        </div>
      </div>
    </div>
  );
}
```

**Результат:** Цифровая версия игры с красивым дизайном

### Путь 3: Печать карточек (Для настольной игры)

**Задача:** Напечатать собственные карточки

**Шаги:**
```
1. Создайте дизайн в Figma (путь 1)
2. Экспортируйте карточки в PDF @ 300 DPI
3. Отправьте в типографию или распечатайте дома
4. Разрежьте по контуру и используйте в игре
```

**Требования к печати:**
- Формат: PDF
- DPI: 300 (печать)
- Размер: 300 × 420 мм (или пропорционально)
- Цветовая модель: CMYK
- Bleed: 2-3 мм со всех сторон

**Результат:** Физические карточки для настольной игры

## 💡 Полезные советы

### Совет 1: Начните с простого
Не пытайтесь сразу сделать всё идеально. Начните с 3 героев, создайте базовые шаблоны, затем масштабируйте.

### Совет 2: Используйте автоматизацию
Скрипт `figma-automation-script.js` может создать базовую структуру автоматически. Используйте его для ускорения работы.

### Совет 3: Создайте систему
Не делайте каждую карточку с нуля. Создайте компоненты с Variants и Component Properties для гибкости.

### Совет 4: Тестируйте постоянно
После каждого этапа тестируйте дизайн. Проверяйте читаемость, контраст, консистентность.

### Совет 5: Документируйте
Добавляйте комментарии в Figma, создавайте guide для использования компонентов. Это поможет в будущем.
