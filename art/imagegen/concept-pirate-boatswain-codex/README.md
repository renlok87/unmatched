# Боцман-пират — дизайн фронта, этап 1a

Дата: 2026-10-13. Ассет: ASSET-PIRATE-BOATSWAIN-001.
Статус: **предложено**.

Созданы два оригинальных фронтальных концепта коллекционной окрашенной миниатюры через встроенный image_gen. Единственный визуальный вход — medusa-quality-reference.png, только как эталон качества исполнения. Палитра взята из неизменённого palette.json. Карточка ассета и другие изображения не читались как входы.

Выбран **design-front g2**: `design/pirate-boatswain-front.png` — побайтная копия `concepts/pirate-boatswain-design-front-g2.png`. Причина выбора: сохранены четыре якоря идентичности, правильная рука с оружием и нейтральная поза; по сравнению с g1 исправлен вид подставки — верх скрыт, передние грани горизонтальны. Все шесть пунктов CHECKLIST при визуальном осмотре выполнены.

Использовано **2 из 2** разрешённых генераций. CORE в обеих попытках одинаковый; в g2 добавлена одна строка CORRECTION про строгий вид подставки с ребра. Первый вариант сохранён без изменений: скрипт дал 13 PASS, но визуально провален пункт CHECKLIST о камере и подставке — была видна её верхняя поверхность.

Финальный скрипт на g2: **код 0, 12 PASS, 1 WARN, 0 FAIL**. WARN `view.single_component`: алгоритм выделил дополнительные компоненты маски (крупнейшая 2,107 % кадра). Изображение осмотрено: это одна фигура на одной подставке; WARN разрешён заданием. Отдельные отчёты каждого кандидата сохранены в `checks/design-front-g1/` и `checks/design-front-g2/`; финальный — `design/checks-report.json`.

Отклонение от CORE: подставка g2 заметно шире заданного ориентира — около **0,75 роста фигуры вместо около 0,55**. Оценка сделана по силуэту, не является замером 3D-модели. Это отдельно записано в verification.json. Круглое сечение подставки нельзя доказать по единственному строгому фронтальному виду. Коррекция скрыла верхнюю поверхность, но не обеспечила требуемую пропорцию диаметра; при выборе приоритет отдан пункту CHECKLIST о камере. Новых генераций не выполнялось.

Малые решения: для фронтального вида side_view записан как null; контрастные белые полосы рубашки, тёмная кожа и сталь считаются нейтральными материалами. Межвидовое совпадение не оценивалось: в этапе 1a создан только фронт. Между g1 и g2 генератор изменил усы/бороду, ворот рубашки, ремни, верёвку, носки и детали обуви; эти изменения перечислены в prompts.md.

Все PNG сохранены без ретуши, изменения размера, кадрирования, перекраски и перекодирования. Обе копии image_gen оставлены по исходным путям, записанным в generation-records.json. SHA-256 входов совпали до и после работы; ранее существовавший palette.json сохранён. Текстовые файлы написаны Python в UTF-8 без BOM. Команды git, Unreal, Tripo и SYNTX не запускались. Установка openskills через npx недоступна из-за отсутствия пакета в локальном кэше; инструкции навыка прочитаны непосредственно из локального SKILL.md без установки.

Пакет готов к рассмотрению приёмщиком; художественная приёмка не выполнялась.
