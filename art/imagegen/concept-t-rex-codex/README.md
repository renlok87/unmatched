# ASSET-T-REX-001 — концепт 1a

Дата: 2026-10-13. Статус: **предложено**.

Сделан один фронтальный дизайн коллекционной расписанной миниатюры T. rex. Использованы только указанный эталон качества Medusa и palette.json; эталон был единственным изображением во всех вызовах image_gen. Выполнено 2 из 2 разрешённых генераций, размер каждой — 1086 × 1448 (точно 3:4).

Выбрана **design-front g2**, файл `design/t-rex-front.png`: подставка показана с ребра, лапы отделены от корпуса просветами, фон ровнее. По сравнению с g1 также улучшились верхнее поле и центрирование. Исходные кандидаты сохранены в `concepts/`, копии инструмента оставлены на месте. Все копирования побайтные, обработки пикселей не было.

g1 не прошёл визуальные пункты о подставке с ребра, просветах у лап и ровном фоне. Скрипт дал код 0: 12 PASS, 1 WARN (`view.frame_top`: верх 3,660% вместо 4%). WARN не был причиной повторной генерации. Для g2 CORE сохранён дословно, добавлены ровно три строки CORRECTION только по визуально не пройденным пунктам.

Проверка кандидата g2 и финальная проверка выбранного файла: код 0, 13 PASS, 0 WARN, 0 FAIL. Все шесть пунктов визуального CHECKLIST отмечены в verification.json. `limit_reached` пуст: не пройденных пунктов CHECKLIST у выбранного вида нет.

Отклонения от CORE сохранены в verification.json: подставка шире заданной (около 0,71 высоты фигуры вместо примерно 0,55), центр x48,158% вместо x50%, низ y93,715% вместо y93%. Круглую форму дисков в плане нельзя надёжно подтвердить по фронту с ребра. Есть слабый шум фона и небольшие натуральные цветовые детали глаз и пасти; точное попиксельное совпадение с палитрой не заявляется. Межвидовая согласованность не оценивается: на 1a только один вид.

Малые решения: при конфликте «striding» и явно заданной нейтральной позы приоритет отдан двум опирающимся стопам; хвост выведен вправо в изображении для читаемости якоря. `side_view=null`: боковой вид на этом этапе отсутствует. Художественную приёмку проводит следующий исполнитель.

SHA-256 обоих входов совпадает с заданием до и после работы. Существовавший palette.json сохранён. Все управляемые записи — внутри пакета; разрешённые оригиналы image_gen — вне пакета по путям generation-records.json. Git, Unreal, Tripo, SYNTX, загрузки и фоновые сервисы не использовались.
