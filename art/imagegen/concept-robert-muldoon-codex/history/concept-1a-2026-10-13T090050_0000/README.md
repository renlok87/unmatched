# Robert Muldoon — концепт 1a

Статус: **предложено**.

Создан один фронтальный дизайн коллекционной окрашенной миниатюры для ASSET-ROBERT-MULDOON-001. Инструмент — встроенный image_gen; единственный вход изображения — эталон качества Medusa. Палитра взята из неизменённого palette.json. CORE в обоих вызовах сохранён дословно; во втором добавлена одна строка CORRECTION.

## Выбор

Для вида design-front выбрана **g2**: design/robert-muldoon-front.png — побайтовая копия concepts/robert-muldoon-design-front-g2.png. Использовано 2 из 2 разрешённых генераций, по одному изображению на вызов; размер каждого результата 1086 × 1448, аспект 3:4. PNG не ретушировались, не обрезались, не масштабировались и не пересохранялись. Обе исходные копии image_gen оставлены на месте; пути и SHA-256 записаны в generation-records.json.

В g2 выполнены все шесть визуальных пунктов CHECKLIST: один персонаж, фронтальный ракурс, подставка строго с ребра, полный кадр, оружие в собственной правой руке (слева для зрителя), оба зазора между руками и корпусом, все якоря идентичности и основная палитра. Верх маски 4,834%, низ 92,887%, центр подставки x50,0%.

## Проверки и то, что не получилось

- g1: скрипт завершился с кодом 0 (12 PASS, 1 WARN, 0 FAIL). WARN view.frame_top: верх маски 2,210%. Это предупреждение само по себе не стало причиной повтора. Визуально нарушен пункт CHECKLIST о подставке: видна верхняя плоскость и изогнуты передние грани. Поэтому g1 не выбрана.
- g2: скрипт кандидата и финальный прогон завершились с кодом 0 (12 PASS, 1 WARN, 0 FAIL). Допустимый WARN view.single_component: сегментация нашла дополнительную крупную область площадью 2,282% кадра. На самом изображении видны только одна фигура и одна подставка; второй персонаж отсутствует. Вероятная причина — разделение тёмных областей подставки маской, это интерпретация, а не отдельная проверка.
- Открытых нарушений CHECKLIST выбранного дизайна нет; limit_reached пуст. Другие виды не создавались: согласованность front/side/back на этапе 1a не проверяется. Круглую форму подставки нельзя доказать единственной проекцией строго с ребра; это ограничение фронтального дизайна.

## Небольшие решения

Сохранены оба кандидата и отдельные отчёты их проверок. g2 выбрана по выполнению ракурса подставки и верхнего поля. Незначительные тёплые металлические детали патронов оценены как часть сдержанной земляной гаммы. Из-за нейтральной фронтальной проекции два круглых яруса подставки изображены горизонтальными полосами; для этого не менялся CORE, исправлен только его невыполненный пункт. Между генерациями модель самостоятельно изменила детали лица, шляпы, патронов, оружия и складок; ручного редактирования не было.

Пакет подготовлен для проверки приёмщиком; художественная приёмка не выполнялась. SHA-256 обоих входов до/после совпадают. palette.json сохранён без изменений. Все файлы, записанные исполнителем, находятся внутри этого пакета; исключение, предусмотренное заданием, — собственные копии инструмента image_gen. Команд git не выполнялось. Запущенные команды завершились; фоновых процессов этой задачи нет.
