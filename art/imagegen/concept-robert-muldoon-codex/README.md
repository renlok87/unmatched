# Robert Muldoon — концепт 1a, доработка fix1

Статус: **предложено**.

В корректирующем запуске 2026-10-13 создан один фронтальный дизайн для ASSET-ROBERT-MULDOON-001. Встроенный image_gen получил только исходный эталон качества Medusa. Отклонённый дизайн не передавался как изображение; палитра и эталон остались неизменны. В каждом вызове сохранён дословный CORE и обязательная коррекция S из задания: чисто выбритое длинное угловатое лицо Роберта Малдуна в исполнении Боба Пека.

## Выбор

Для **design-front выбрана g4**. `design/robert-muldoon-front.png` — побайтовая копия `concepts/robert-muldoon-design-front-g4.png`. Использовано **2 из 2** разрешённых генераций этого запуска, g3 и g4; вместе с исходным запуском в пакете 4 генерации. Каждая генерация дала одно изображение 1086 × 1448, аспект 3:4. Размер в вызовах не задавался, ручной обработки PNG не было. Исходные копии инструмента оставлены на месте; оба пути, хеши и размеры каждой генерации записаны в журнале.

В g4 лицо без усов, длинное и угловатое, с выраженными скулами; визуально выполнена коррекция S. Сохранены фронтальная нейтральная стойка, оружие в собственной правой руке (слева для зрителя), широкополая шляпа, одежда сафари цвета хаки и пояс с патронами. Верхняя плоскость подставки скрыта, передние грани обоих ярусов горизонтальны. Все шесть пунктов CHECKLIST отмечены с наблюдениями в verification.json. Степень портретного сходства окончательно оценивает приёмщик.

## Проверки и неудачи

- g3: код 0, 12 PASS / 1 WARN / 0 FAIL. WARN `view.frame_top`: верх маски 2,486%, предупреждение разрешено и не было причиной повтора. Визуально нарушен пункт CHECKLIST о проекции подставки: виден верх и передние грани изогнуты. Поэтому g3 не выбрана.
- g4: кандидат и финальный прогон — код 0, 13 PASS / 0 WARN / 0 FAIL. Открытых нарушений CHECKLIST нет, `limit_reached` пуст.
- Для g4 верх маски 5,110%, низ 94,475%, центр подставки x50,092%. Низ отличается от запрошенного y93%; это записанное отклонение CORE, без обрезки и без нарушения CHECKLIST. Побайтовая копия не корректировалась.
- В исходном запуске g1 не прошла визуальный пункт о подставке; g2 была выбрана исполнителем. Коррекция усатого обобщённого лица прежнего дизайна назначена в текущем задании. Старые README, verification.json и финальный отчёт сохранены побайтно в `art/imagegen/concept-robert-muldoon-codex/history/concept-1a-2026-10-13T090050_0000/`; сырые g1/g2 и их кандидатские отчёты не менялись.

## Небольшие решения и ограничения

В g4 после обязательной коррекции S добавлена только одна строка CORRECTION для проваленного пункта о подставке; CORE и обязательная строка S не менялись. Предупреждение о верхнем поле g3 не исправлялось отдельным запросом. Инструмент сам изменил форму шляпы, детали оружия, хват, патроны и складки одежды между g3 и g4; это новые генерации, без ретуши.

В строго фронтальной проекции два круглых яруса подставки читаются горизонтальными полосами. Их круглую форму и точный диаметр около 0,55 роста невозможно подтвердить единственным видом; подставка визуально шире ориентировочного отношения. Другие виды не создавались, согласованность front/side/back пока не проверяется. Сходство лица оценено визуально по заданию без дополнительного портретного референса. Небольшие латунные детали патронов оценены как часть сдержанной гаммы.

Записи и точные промпты дополнены, нумерация продолжена после g2. Прежний выбор g2 сохранён в историческом verification.json, текущий выбор в журнале — только g4; путь прежнего финального отчёта переведён на его историческую копию. Все новые отчёты кандидатов находятся в своих папках. Все файлы исполнителя записаны внутри пакета; предусмотренные заданием собственные копии image_gen вне пакета оставлены на месте. Команды git не выполнялись; Unreal, Tripo, SYNTX и загрузки не использовались. Команды и проверки завершились, фоновых процессов этой задачи нет.

Пакет подготовлен для проверки Claude; художественная приёмка не выполнялась.
