# Шреддер — дизайн front, этап 1a

Статус: **предложено**.

Созданы две генерации одного фронтального концепта. Единственный графический вход — референс мастерства Медузы; палитра прочитана из palette.json. Обе исходные генерации сохранены без обработки в concepts/, оригиналы image_gen оставлены на месте.

Выбран **design-front g2**, копия — design/shredder-front.png (1086 × 1448). Подставка показана с ребра, без видимой верхней плоскости; все четыре якоря идентичности и палитра читаются. Поэтому g2 предпочтительнее g1 для следующего этапа.

У g1 видна узкая верхняя плоскость подставки. В CORRECTION также вошло выравнивание визуально воспринимаемого фона. У g2 фон проверен глазами и контрольными пробами: почти однородный нейтральный тёмно-серый, со слабой пиксельной фактурой.

Проверки кандидатов лежат в checks/design-front-g1/ и checks/design-front-g2/. Итоговый отчёт — design/checks-report.json. Все три запуска дали код 0, без FAIL. У выбранного g2 остаются допустимые WARN: view.frame_top — верх маски 2.21% при желаемых ≥4%; view.single_component — вторичная компонента маски 1.71%. Низ маски — 94.613% вместо заданных 93%; центр подставки — 50%. Отклонения перечислены в verification.json.

Все шесть пунктов визуального CHECKLIST для g2 отмечены passed. Использовано 2 из 2 разрешённых генераций; limit_reached пуст, поскольку проваленных пунктов CHECKLIST у выбранного кандидата нет. Окончательное художественное решение принимает приёмщик.

Малые решения: g2 выбран за более точную геометрию фронтальной подставки; side_view записан как null для фронта; WARN не использованы как основание ретрая; новых видов в этом запуске не создавалось.

Журнал — generation-records.json; точные промпты — prompts.md и prompts/concept-prompts.json. SHA-256 входов проверены до и после работы; palette.json сохранён побайтно. manifest-sha256.json включает все файлы пакета, кроме самого манифеста.
