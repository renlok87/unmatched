## Библиотека и воспроизведение

[_tools/screen_mockup_base.py](_tools/screen_mockup_base.py) — детерминированная библиотека без записи на диск, сетевых и движковых вызовов. Следующие SC-пакеты копируют её без изменений. `Theme(tokens_path, bold_font, regular_font, spinner_path, skins_folder)` принимает пять явных путей. `Viewport.preset(resolution, scale)` задаёт холст; `Canvas` содержит `veil`, `panel`, `button`, `chip`, `key_chip`, `checkbox`, `text_field`, `progress`, `spinner`, `grid`, `text`, `finish`. `draw_screen(shown=False)` и `draw_base_modal(open=False)` сохраняют фон без изменений.

Все прямоугольники заданы в su. Набор `vector/x1` выбирается при итоговом px/su ≤1,0, `vector/x2` — выше. Прозрачное защитное поле PNG лежит вне content rect; скины ресемплируются Lanczos. Поля срезов читаются из `slice-margins.json`; углы равномерно масштабируются, кромки растягиваются только вдоль своей длины, центр — по двум осям. Фокусные PNG HB-08 являются кольцами: библиотека подставляет normal и исходный outset 4 su (зазор 2, толщина 2). Флажок всегда 24×24 su, только равномерный масштаб, без растяжения. Selected-чип использует `Btn_Selected` из того же набора: teal-печать и светлая кромка, без добавленной галочки. Цвета текста состояний читаются из `runtime-style.json` и токенов.

|---|---:|---|---|---|
| 1920×1080 / 100 % | 1,0 | 1920×1080 | L / 24 su | x1 |
| 1920×1080 / 150 % | 1,5 | 1280×720 | S / 16 su | x2 |

Второй шаг обновляет manifest после изменения README или записи осмотра, не меняя PNG. Сборка сверяет входы с `fix1-before.json`, сохраняет точные текстовые копии в derived и не перезаписывает исходный `source-hashes-before.json`. `source_audit.py` повторно не запускался; архивная копия генератора v3 побайтово сохранена и не исполняется. Четырёхкратное внутреннее разрешение сохраняет дробный кегль 10,5 px; финалы рисуются для своих размеров, не уменьшаются из одного мастера.

## Измерения и оставшееся непрохождение

Все цифры, текстовые bounding boxes, маски, пары состояний и каждый критерий — в [verification.json](verification.json); геометрия su и px — в [layout-geometry.json](layout-geometry.json). Независимый `verify_package.py` проверяет хеши, инвентарь, Rec.709, строки, состояния hidden/closed, запрет primary-selected, обязательную причину disabled, детерминизм и сохранение угла 9-slice при изменении ширины. Проверка целостности проходит; **общая приёмка false из-за контраста границы модали**, статус «предложено».

Контраст `text.primary` / непрозрачный `panel.bg` — **15,70:1**, проходит 13:1. `text.secondary` / navy — **8,70:1**; selected glyph/teal — **4,75:1**; главная normal — **10,91:1**, hover — **11,29:1**, pressed — **8,43:1**. Все активные пары ≥4,5:1. Сырые disabled: обычная **8,84:1**, главная **6,60:1** на фактически отрисованном теле; они помечены `exempt_inactive: true`, как и кромки inactive. Их значения не используются для ложного FAIL.

Минимальный текст — 14 su: **10,5 px** при 720p/100 %, **15,75 px** при 720p/150 %. Спиннер 48 su, флажки 24 su, прогресс 480×8 su. Спиннер сохранён из v3; контраст основной непрозрачной печати — **17,24:1** (переходные пиксели сглаживания и тёмная наружная keyline не являются цветом глифа). Обводка печати прогресса glyph/teal — **4,75:1**. Нового замка disabled нет.

Вуаль и тела не изменены ради порога. Для каждого прямого пикселя границы `boundary = max(edge_vs_backdrop, body_vs_backdrop)`. Углы исключены; растровая дробная толщина сохранена. Ниже min / p05 / медиана и доля ≥3:1; **требуется доля 100 %**:
