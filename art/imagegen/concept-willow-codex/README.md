Выбран **design-front g4**: `design/willow-front.png` — побайтовая копия `concepts/willow-design-front-g4.png` (1086 × 1448, аспект 3:4). Молодое лицо, современный вязаный кардиган с вышивкой и длинная богемная юбка заменяют впечатление нарядной фэнтезийной мантии. Видны длинные красные волосы, многослойный зелёный кардиган, фиолетовая юбка и голубое заклинание в поднятой пустой руке; между руками и корпусом есть просветы. Верх подставки скрыт, передние кромки горизонтальны. Все шесть пунктов визуального CHECKLIST пройдены.

В этом прогоне использованы **2 из 2** разрешённых генераций: g3 и g4. Всего в журнале четыре design-front генерации. Один вызов image_gen — одно изображение, единственный визуальный вход — исходный QUALITY_REFERENCE Medusa. CORE не менялся; обе принятые строки коррекции S/P присутствуют в каждом вызове. g4 добавляет только третью строку для ракурса подставки. Отклонённые дизайны не использовались как референсы.

**Что не прошло:** у g3 виден узкий верх подставки, поэтому провален пункт строгой фронтальной ортопроекции. Скрипт g3 дал код 0: 12 PASS / 1 WARN / 0 FAIL. WARN верхнего поля (3,315%) не был причиной повтора. g3 сохранён без изменений вместе со своим отчётом.

**Технический итог:** g4 и финальный запуск на выбранном файле — код 0, 13 PASS / 0 WARN / 0 FAIL. Отчёты кандидатов: `checks/design-front-g3/checks-report.json`, `checks/design-front-g4/checks-report.json`. Финальный отчёт: `design/checks-report.json`. Прежние сырые g1–g2 и их отчёты не изменены. Предыдущий финальный отчёт дополнительно сохранён побайтово в `checks/design-front-g2/selected-final-checks-report.json`; история проверок остаётся в verification.json.

**Ограничения:** низ подставки g4 — y95,235% вместо заданных y93%; центр x49,862% вместо ровно x50%. Верх y5,525% удовлетворяет минимуму 4%. Фон визуально простой тёмно-серый, но содержит мелкую фактуру и небольшую пиксельную вариацию. Целевые HEX присутствуют в промпте; естественная роспись и свет дают тёплые блики волос и местами оливковый оттенок кардигана. Точное пиксельное совпадение со свотчами не заявляется. Все ограничения открыто записаны в verification.json. Непройденных пунктов CHECKLIST у выбранного файла нет, поэтому limit_reached пуст. Художественную приёмку и оценку коррекций S/P выполняет приёмщик.

Малые решения: выбран g4 за исправленный ракурс и чистый отчёт при сохранённых якорях. Приглушённые цветочные узоры относятся к богемной повседневной одежде; нейтральные обувь и украшения не создают отдельного сильного цвета. Свечение у обеих пустых кистей не считается оружием или удерживаемым предметом. Различия лица, длины волос, вязки, складок и свечения между генерациями — вариативность image_gen. Межвидовая согласованность не оценивается: задача включает только один front этапа 1a.

Все изображения скопированы без ретуши, ресайза, обрезки, перекраски и перекодирования; оригиналы image_gen оставлены на месте и зарегистрированы абсолютными путями. Входные SHA-256 совпадают до и после работы. Журналы и точные промпты дополнены, ранние записи сохранены. Все явные записи выполнены внутри пакета; автосохранения image_gen вне него предусмотрены заданием. Git, Unreal, Tripo, SYNTX и загрузки не выполнялись. Текст записан Python в UTF-8 без BOM; manifest-sha256.json сформирован последним. Фоновые процессы этой задачи не оставлены.

# ASSET-WILLOW-001 — фронтальный дизайн Willow, этап 1a

Статус: **предложено**. Дата: 2026-10-13.

Выполнены две генерации встроенным `image_gen.imagegen`, по одному изображению на вызов. Единственный визуальный вход — эталон качества Medusa; палитра использована как текстовая спецификация. Другие ассеты и изображения не использовались.

Выбран **design-front g2**: `design/willow-front.png` — побайтовая копия `concepts/willow-design-front-g2.png` (1086 × 1448, точный аспект 3:4). У второго кандидата скрыт верх подставки и горизонтальны её передние кромки. Сохранены все четыре якоря образа и зазоры между руками и корпусом. По визуальному CHECKLIST выбранный файл проходит все шесть пунктов.

g1 сохранён в `concepts/`. Его скрипт завершился кодом 0, но визуально не прошёл пункт строгой фронтальной ортопроекции: виден верх подставки. Поэтому второй вызов содержал неизменённый CORE и одну строку CORRECTION только для этого пункта. WARN верхнего поля не стал причиной повтора.

Автопроверки: g1 — 12 PASS / 1 WARN / 0 FAIL; g2 и финальный выбранный файл — 11 PASS / 2 WARN / 0 FAIL. Все три запуска завершились кодом 0. Отдельные отчёты кандидатов — `checks/design-front-g1/checks-report.json` и `checks/design-front-g2/checks-report.json`; финальный отчёт — `design/checks-report.json`.

Точные координаты CORE не получены: верх маски g2 y = 3.315% вместо ≥4% (допустимый WARN `view.frame_top`), низ подставки y = 96.133% вместо 93%; центр x = 50%. Допустимый WARN `view.single_component` выделяет дополнительную компоненту 1.907% кадра; глазами второй фигуры или подставки нет. Фон выглядит ровным, но содержит мелкую фактуру и небольшую пиксельную вариацию: абсолютно одноцветное поле не получено. Ограничения записаны в `verification.json`.

Малые решения: выбран g2 за исправление ракурса, несмотря на дополнительный WARN сегментации. Приглушённые нейтральные оттенки обуви, украшений и вышивки допустимы и не конкурируют с основной палитрой. Пиксельный размер выбрал инструмент. Изменения лица, орнаментов, украшений, складок юбки и рисунка свечения между g1 и g2 — вариативность новой генерации, не ручная правка. Все изображения сохранены без ретуши, ресайза, обрезки, перекраски или перекодирования.

Лимит этой задачи — две генерации, использованы обе. У выбранного файла нет непройденных пунктов CHECKLIST, поэтому `limit_reached` пуст. Исходные копии инструмента оставлены на месте; абсолютные пути и SHA-256 записаны в `generation-records.json`. Референс и исходная `palette.json` неизменны.

Все явные записи исполнителя находятся внутри пакета. Git, загрузки, Tripo, SYNTX и доступ к Unreal не выполнялись. Собственное автоматическое сохранение двух оригиналов инструментом image_gen вне пакета предусмотрено заданием и отражено в журнале. Текстовые файлы записаны Python в UTF-8 без BOM. `manifest-sha256.json` записан последним.

Художественную приёмку выполняет принимающий агент; здесь сохранён предложенный дизайн и его технические проверки.
