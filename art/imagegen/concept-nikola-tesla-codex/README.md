# Nikola Tesla — концепт 1a

Дата: 2026-10-13. Статус: **предложено**.

Создан один фронтальный дизайн расписанной коллекционной миниатюры через встроенный image_gen. Использованы только референс качества Medusa и заданная палитра; единственный вход изображения — референс Medusa. CORE передан дословно. Выполнены две генерации из разрешённых двух.

Для вида design-front выбрана **g2**, файл `design/nikola-tesla-front.png`. По сравнению с g1 подставка показана строго с ребра: её верхняя поверхность скрыта. Катушка с синими дугами находится в собственной правой руке, слева для зрителя; пробор, усы и длинное пальто видны. Все шесть пунктов CHECKLIST выбранного файла отмечены как выполненные в verification.json.

Обе кандидатные проверки и финальная проверка выбранного файла: код **0**, 13 PASS, 0 WARN, 0 FAIL. У g1 визуально не выполнен пункт строгого фронтального вида подставки: виден её верх. При первичном осмотре также возникло подозрение на градиент фона, поэтому в CORRECTION включено его выравнивание. Последующие замеры свободных участков показали малые вариации: примерно RGB 47–51 у g1 и 41–44 у g2; существенный градиент ими не подтверждён. Финальная оценка фона g2 — выполнено. В verification.json сохранено это уточнение. Лимит генераций исчерпан, невыполненных пунктов выбранного файла нет.

Малые решения: выбран g2 за исправленный силуэт подставки и более объёмные читаемые дуги; side_view = null, поскольку выполнен только дизайн анфас этапа 1a. Межвидовая согласованность не оценивалась. Точные HEX по каждой освещённой поверхности не гарантируются изображением; основные цвета оценены визуально.

Оба исходных PNG сохранены в `concepts/` без изменения байтов. Рабочий и выбранный файл в `design/` — побайтная копия g2. Ретушь, масштабирование, обрезка, перекраска и перекодирование не выполнялись. Оригиналы инструмента оставлены на месте; абсолютные пути записаны в generation-records.json. Входные хеши не изменились. Записи пакета используют пути от корня репозитория с прямыми слешами.

Все записи исполнителя находятся в этом пакете; автоматическое сохранение image_gen вне пакета — предусмотренное заданием исключение. Git, Unreal, Tripo, SYNTX и загрузки не использовались. Художественное принятие остаётся за приёмщиком.
