# ASSET-WAYWARD-SISTER-2-001 — концепт 1a

Статус: **предложено**.

Создан фронтальный дизайн миниатюры второй своенравной сестры. Использованы только эталон качества Medusa и исходная palette.json. Выполнены две генерации image_gen.imagegen; CORE дословный, у g2 добавлен только CORRECTION из трёх строк.

Выбран **design-front g2**: `design/wayward-sister-2-front.png`, 1086×1448, аспект 3:4. У g2 подставка видна с ребра, без верхней поверхности, фон ровный, под обеими руками видны зазоры. Хват собственной левой кистью справа в кадре. Читаются длинный нос, рваные серо-зелёные одежды, травы на верёвочном поясе и заданная палитра.

Что не вышло: вместо палочки (wand) в обеих генерациях нарисован длинный посох. Пункт CHECKLIST об идентификационных якорях помечен false; лимит **2/2** исчерпан, несоответствие записано в verification.json.limit_reached. Решение принимает приёмщик.

Все три прогона скрипта: код 0, 12 PASS, 1 WARN, 0 FAIL. Каждый кандидат проверен в собственном checks/design-front-g<N>; выбранный файл — в design/checks-report.json. Автоматический PASS не означает выполнения всего визуального CHECKLIST.

У g2 верх маски y=3.108% вместо >=4%: допустимый WARN view.frame_top. Низ подставки y=96.271% вместо целевого y=93%. Верхнее поле не стало причиной повторной генерации. Изображения не ретушировались, не обрезались, не масштабировались и не пересохранялись.

Небольшие решения: оставлены капюшон, косы и костяные подвески генератора; фиолетовые цветы и кристаллы поддерживают акцент. g2 выбран за исправленные подставку, фон и зазоры рук. Длинный посох отмечен как несоответствие, а не принят как замена wand.

Сырые g1 и g2 сохранены в concepts/ без перезаписи, выбранный дизайн — побайтовая копия g2. Оригиналы инструмента оставлены на месте, абсолютные пути записаны в generation-records.json. Входные SHA-256 совпали до и после; palette.json не изменён. Файлы пакета записаны Python в UTF-8 без BOM. Собственных записей вне пакета нет; исходные изображения image_gen создаёт сам инструмент по явному исключению задания. Git, Unreal, Tripo и SYNTX не использовались. Создан только один вид; художественная приёмка остаётся следующему этапу.
