# Blackbeard — концепт 1a

Дата: 2026-10-13. Статус: **предложено**.

Создан один фронтальный дизайн коллекционной расписанной миниатюры капитана Чёрная Борода. Единственный вход изображения — эталон качества Medusa; использованы заданные CORE и палитра. Входная палитра сохранена без изменений.

Выбран **design-front g1**: `design/blackbeard-front.png`. Использована 1 из 2 разрешённых генераций. Все шесть пунктов визуального CHECKLIST пройдены: сабля справа у фигуры (слева у зрителя), косы с алыми лентами, треуголка, перевязь с пистолетами, отдельные от корпуса руки, подставка с ребра. Детализация соответствует назначению расписанной коллекционной миниатюры.

Проверка кандидата и финальная проверка: код 0, PASS 12 / WARN 1 / FAIL 0. Единственное невыполненное числовое требование — верхнее поле: 2,693% вместо минимум 4% (`view.frame_top`). Кадр не обрезан. По заданию этот WARN не является причиной ретрая, поэтому второй вызов не использован. Проваленных пунктов CHECKLIST нет; `limit_reached` пуст. Решение о приёмке остаётся за приёмщиком.

Малые решения: три пистолета на диагональной перевязи; три крупные косы бороды с лентами; латунные пуговицы и гарда, приглушённая кожа. Оценка палитры визуальная с учётом света и ручной росписи; точное совпадение HEX всех пикселей не заявляется. Параметры камеры генератора недоступны, поэтому строгий фронт и отсутствие перспективного разворота оценены по самому изображению.

Оригинал image_gen оставлен на месте; `concepts/blackbeard-design-front-g1.png` и выбранный дизайн являются побайтными копиями. Их SHA-256: `05d18b22077fb04a8da587d5637bb0917c37d8042ac495aeca282caeed2d3197`. Размер выбран инструментом: 1086×1448, аспект 3:4. Правок пикселей нет.

SHA-256 входов до и после, все проверки и ограничения записаны в `source-hashes-before.json` и `verification.json`. Точные промпты и ссылки на входы — в `prompts.md`, `prompts/concept-prompts.json` и `generation-records.json`. Манифест охватывает каждый файл пакета, кроме самого себя.
