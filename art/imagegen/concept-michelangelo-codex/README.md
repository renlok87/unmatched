# Michelangelo — дизайн-front, этап 1a

Дата: 2026-10-13. Карточка: ASSET-MICHELANGELO-001. Статус: **предложено**.

Созданы два самостоятельных фронтальных концепта одной коллекционной миниатюры через встроенный image_gen. Единственный визуальный вход — эталон мастерства Medusa. palette.json — текстовая палитра. CORE передан дословно в обоих вызовах; во втором после CORE добавлены две строки CORRECTION по визуально проваленным пунктам g1. Один вызов дал одну картинку и один вид; размер не передавался.

Выбран **design-front g2**, его побайтовая копия — `design/michelangelo-front.png`. Он лучше g1 выполняет требования к подставке и фону: верхняя поверхность подставки скрыта, её границы горизонтальны, фон ровнее. Все идентификационные признаки видны. Оба PNG имеют размер 1086×1448, аспект 3:4.

g1 сохранён в `concepts/michelangelo-design-front-g1.png`: скрипт дал exit 0 (13 PASS, 0 WARN, 0 FAIL), но глазами обнаружены видимая верхняя поверхность подставки и перепад тона фона. g2 и его финальный прогон: exit 0, 12 PASS, 1 WARN, 0 FAIL. WARN `view.single_component` сообщает о фрагментах маски; визуально в PNG одна фигура с двумя нунчаками и одной двухъярусной подставкой. По контракту WARN не требует повторной генерации.

Не выполнен CHECKLIST «No weapon or held object»: в руках нунчаки. Неизменяемый CORE и соседний пункт CHECKLIST одновременно требуют нунчаки в каждой руке. Убрать их — нарушить SUBJECT и IDENTITY ANCHORS. Лимит использован: **2 из 2 генераций**. Невыполненный пункт записан в `verification.json` → `limit_reached`; решение остаётся за приёмщиком.

Также подставка шире CORE: диаметр относительно высоты фигуры без подставки примерно 0.747 (≈0,75), задано около 0,55. Оценка вычислена по маске; алгоритмическая оценка верха подставки приблизительна. Этот размер не входит в отдельный автоматический гейт и обязательный CHECKLIST, но отклонение записано в `verification.json` → `core_deviations`. Изображение не правилось.

Мелкие решения: `view=design-front`, `side_view=null`; mode — generate, поскольку эталон используется только для мастерства. Светлая грудная пластина, пояс и приглушённая пряжка — оттенки коричневого без дополнительного насыщенного цвета. Боковой и задний виды этапом 1a не предусмотрены; согласованность с ними пока не проверена. Изменения между кандидатами перечислены в `prompts.md`.

Оригиналы image_gen оставлены на месте, абсолютные пути записаны в `generation-records.json` → `original_path`. Кандидаты и выбранный PNG не ретушированы, не масштабированы, не обрезаны, не перекрашены и не перекодированы. Копии проверены по байтам и SHA-256. Входы и существовавшая palette.json сохранены. Ручные записи ограничены пакетом; внешние оригиналы image_gen прямо разрешены контрактом. Git, Unreal, Tripo, SYNTX и загрузки не запускались.

Финальный отчёт — `design/checks-report.json`; отчёты кандидатов — `checks/design-front-g1/checks-report.json` и `checks/design-front-g2/checks-report.json`. Это предложение этапа 1a; внешняя приёмка данным запуском не выполнялась.
