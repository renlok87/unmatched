# MS-T-00 v2 — макеты подбора хода на реальных данных

Дата: 2026-10-03. Статус: **предложение для арт-приёмки** (MS-Q-04). Заменяет ImageGen-концепты v1.

## Почему v2

Концепты v1 сгенерировал ImageGen в Codex. Модель придумала свои доски, фигурки, портреты и пути, которые идут не
по связям. Пользователь их отклонил: «Используй реальные карты и изображения героев из бэкэнда. Они у нас уже есть
в админке». Файлы v1 остались локально в `art/imagegen/move-selection-v1/` и в git не попадают (там `.gitignore`).

v2 собирается скриптом, генерации нет. Все данные реальные:

| Что | Источник |
|---|---|
| арт карт Marmoreal, Sarpedon | `scraped-data/images/maps/{marmoreal,sarpedon}.png` — тот же арт, по которому построена топология бэкенда |
| пространства, связи, зоны, старты | `backend/prisma/fixtures/boards/{marmoreal,sarpedon}.topology.json` |
| достижимость и путь | алгоритм 04 §3.1: FIFO BFS, враги блокируют, союзники проходимы, канонический путь по `K = spaceId` |
| герои | `Hero.avatarUrl`/миниатюры из БД бэкенда (как в админке): Medusa — аватар `bI206lUtJUQru-FOD8A74`, миниатюра `UiSptDItsyT0i3wGg7lsQ`; King Arthur — `dgwIAej9v-Omrn0sSVs5i`, `q2P9K10o3vHFETym77rtX` |
| сайдкики | `Hero.sidekicks[].avatarUrl` из БД (то, что показывает админка): Harpies `G42WIKYZ1cmwACVwMggzM`, Merlin `4Rl9Oq9N82zhatbTShnXn`. Скачаны 2026-10-03 в `scraped-data/images/heroes/sidekicks/` (по 128 px) |
| движение | Medusa 3, Harpies 3, King Arthur 2, Merlin 2 (`docs/game-design/evidence/S01/content-*.json`) |
| рука | реальные RU-карты Medusa (`art/imagegen/mvp-v1/reused-cardart.json` → `imageUrlRu`); BOOST по `catalog-medusa.json`. Рука та же, что в живом кадре K1: Snipe, Gaze of Stone ×2, Clutching Claws, Hiss and Slither |
| геометрия, цвета, тексты | 03 §4.1–4.5, §8.2, §9 (полосы в uu, вырез ±15° под ромб лидера, кромка `#111317`, строки RU) |

Картинки являются производными от отсканированного арта карт и героев. Поэтому по правилу ENV-U3 они лежат в
игнорируемой папке `scraped-data/derived/move-selection/`. В git идут только скрипт, этот README и `manifest.json`
(в нём sha256 всех выходов и входов).

Сборка (около 30 с):

```bash
python tools/art/move_selection/build_mockups.py
```

## Итерация 2: значки в языке карт

Значки v1 были эмодзи-глифами системного шрифта. По запросу пользователя («во вторую итерацию полностью переработать
значки в рамках нашей игры … сейчас у тебя есть доступ к тому, как выглядят карты») набор v2 строится из элементов
реальных карт: `tools/art/move_selection/card_icons.py`.

| Элемент карты | Цвет / шрифт (сняты с RU-карт Medusa) | Где используется |
|---|---|---|
| круг BOOST (белый диск, толстый тёмно-синий обод, жирная цифра) | обод `#061623`, крем `#F9EBDB` | чип «+N» яруса буста и NeedBoost |
| лента героя слева (цветной блок сверху, синяя лента, вырез снизу) | `#061623`; верх — экранный цвет команды | бейдж порядка хода; красная лента с «!» — конфликт |
| блок типа карты (плоский цвет, белый глиф) | атака `#DC2F33`, защита `#2976AE`, универсальная `#6B4E8F`, хитрость `#FDBE72` | замок, сквозь, часы, подсказка, цепь; MOVE/PLACE — блок с молнией хитрости или меткой на фиолетовом pending `#8A56C6` |
| заголовок (узкий жирный капс на синем) | Bahnschrift Bold Condensed | бейдж шагов «3/3», текст причины, заголовок панели, кнопки |
| звезда атаки | белая на синем, не красная | «отсюда можно атаковать: N»; красный остаётся только у отказа и «!» (03 §4.2) |

Открыто для следующей итерации. Глифы замка, часов, метки и цепи пока берутся из Segoe UI Symbol. Их стоит
перерисовать вектором в толщине линий карточных иконок и проверить при 720p (MS-R-30).

## Наблюдения для арт-приёмки (MS-Q-04)

- **Цвет подложки на картах.** Золото `#FFC857` на светлом мраморе Marmoreal видно, но на жёлтых и бежевых зонах и
  на песке Sarpedon сливается: ярус буста читается в основном по пунктиру. Бирюза `#4CD2DC` уверенно читается на
  всех зонах обеих карт. На серо-голубых зонах она ближе по тону, но её отделяет тёмная кромка. Это визуальная
  оценка по макетам; экранный ΔE снимается в MS-T-13 и MS-AT-30.
- **Многозонные пространства.** Подложка не перекрашивает сектора зон: заливка 18 %, кольцо по краю круга.
- **Пути по связям.** Линия всегда идёт по реальным связям топологии и проходит сквозь союзников по правилам, как
  путь M13→M25 через гарпию на M20.
