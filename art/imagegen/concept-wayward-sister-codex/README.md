g1 не выбрана: виден верх подставки, рукава сливаются с корпусом; возникло подозрение на градиент. g2 исправляет подставку и просветы. Фон g2 дополнительно проверен по исходным пикселям: медианы 46–47, p99 рамки 2, выраженного градиента не обнаружено. CORE неизменен; CORRECTION содержит три строки.

Каждый кандидат и финальный g2: код 0, 12 PASS, 1 WARN, 0 FAIL. Все шесть пунктов CHECKLIST g2 пройдены. Отклонения CORE: верх g2 y=2,970% вместо ≥4% (WARN view.frame_top), низ y=94,890% вместо 93%. У g1 верх y=3,936%. WARN не повод для повтора. Использовано 2/2; limit_reached пуст, поскольку незакрытых пунктов CHECKLIST нет. Внешняя художественная приёмка не выполнена.

Мелкие решения: side_view=null; режим generate с референсом мастерства; g2 выбрана за подставку и просветы, несмотря на меньшее верхнее поле. Камера оценена визуально, её параметры недоступны. Межвидовое совпадение не проверялось: вид один.

Оригиналы оставлены в папке инструмента. Изображения не обрабатывались; SHA-256 копий совпадают. Входы и исходный palette.json неизменны. Все пакетные записи — UTF-8 без BOM, записаны Python.
