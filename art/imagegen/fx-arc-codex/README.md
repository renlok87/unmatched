## Числа серпа

Положительное Y вниз, углы растут по часовой стрелке. Полный осевой радиус **88.539591 px**. Начало оси при −160° имеет X=64 px, конец при −20° — X=230.4 px. Выпуклая цветная граница проходит по `R_outer=R_frame+W_previous/2`; ширина растёт только внутрь. На полном размахе `R_outer=92.966570 px`.

`s` идёт от рукояти/хвоста (0) к ведущему концу/острию (1). Узлы **0, 0.12, 0.5, 0.78, 1**. Между соседними узлами: `t=(s-s0)/(s1-s0); W(s)=W0+(W1-W0)*(3t²−2t³)`.

До максимума ширина монотонно растёт, после него плавно уменьшается. Нет волн, выемок и нулевых концов. Начало — **4 px**. Окончания круглые, радиус половины локальной ширины. В коротком кадре 0 ранний узел равен средней ширине: это сохраняет непрерывность на 36 px без перемещения окружности и перерисовки уменьшенного кадра.

Номинальная минимальная ширина — 4 px; крайние пиксели и касания круглых окончаний не считаются самостоятельными штрихами. Обводка строится по евклидову расстоянию 4 px до аналитического контура, шаг выборки контура <0.04 px.

## Pivot и игровой масштаб для FX-32

На собственном историческом кадре 1920×1080 bbox Arthur **`(1081,638,1125,707)`**, высота **H=69 px**. Включены красный плащ, фигура, поднятый меч и круглый диск основания. Плашка, тень, гекс выделения и клетка карты исключены. Pivot на правой руке у рукояти поднятого меча — **`(1118,664)` px**, оценочная погрешность JPEG около 2 px. [Измерение](../../../scraped-data/derived/fx-arc-codex/arthur-measurement-annotated-nearest6.png), [происхождение и координаты](../../../scraped-data/derived/fx-arc-codex/crop-provenance.json).

Спрайт обращён к камере без сжатия по вертикали. Центр ячейки `(147.2,164.0)` совмещается с рукой. Правило: **осевой радиус 88.54 px → 0.5×H**, размер ячейки `256×0.5×H/88.54`.

- 1080p: H=69, идеальная ячейка **99.751 px**, растровая **100×100**, pivot `(1118,664)`.
- 720p: весь кадр уменьшен bilinear до 1280×720; H=46, идеальная ячейка **66.501 px**, растровая **67×67**, pivot `(745.333,442.667)`.

Фактический pivot после округления позиции и ячейки записан в verification. Каналы маски уменьшаются независимо bilinear, без premultiply RGB через alpha. Цвет: `(R×#F2C14E+G×#FAF8F2+B×#111317)/max(R+G+B,ε)`, opacity=A. Bilinear уменьшение эффекта используется только для этих симуляционных листов; их увеличение — nearest ×4. Обычные 48/36 px получены nearest из мастера.

## Контракт и воспроизведение

Линейные independent RGBA coverage: **R=gold, G=core, B=keyline, A=max(R,G,B)**, только 0/255, прозрачный RGB нулевой. Токены `fx.gold → turn.flash.yellow #F2C14E`, `card.glyph #FAF8F2`, `mark.keyline #111317` прочитаны из неизменённого `_tools/draw_icons_v3_snapshot.py`; исходный генератор не исполняется. RGB bleed 4 px только в straight-alpha цветном превью: в маске он противоречил бы формуле. Пустые ячейки нулевые.

Из корня проекта:

```text
python -B art/imagegen/fx-arc-codex/_tools/build_arc.py
python -B art/imagegen/fx-arc-codex/_tools/build_arc.py --verify
```

Использованы существующие Python/Pillow/NumPy/SciPy, зависимости не устанавливались. Генератор и `fix1_support.py` ограничивают записи двумя разрешёнными папками. `--verify` проверяет сохранённые файлы и обновляет отчёт/манифест без пересборки. [Манифест](manifest-sha256.json) записывается последним, покрывает пакет и derived кроме себя и `__pycache__`.

Триггер — CUE-014: BOOST способности Arthur, кадр переворота атакующей карты. Сокет `Weapon`, правая рука, кость `weapon.R` / `weapon_R` по контракту рига. Row-major; индекс `floor(t_ms×30/1000)` при `0≤t<400`, выключение в 400 мс; время масштабируется скоростью игры, повтор выключен. Reduced motion — неподвижный кадр 5 в том же временном окне. Предположен 1 спрайт, системный предел ≤64; runtime и GPU не измерялись.

Сохранён [source-hashes-before.json](source-hashes-before.json); повторно сверены все 7 входов и **1073 файла hud-icons-v3**, хэши совпали; [хэши после](source-hashes-after.json). Визуальный просмотр цветных/серых мастеров, малых и игровых листов привязан к хэшам в verification. Отдельные R/G могут распадаться на малых размерах: итоговая полоса и силуэт имеют по одной 8-связной компоненте. Радиальная длина кадра 0 по прежней оси равна 30% полного радиуса; клинок меша не измерялся. Первые версии и исходные ограничения сохранены в журнале и отчёте.

Все изображения с собственной картой/Arthur лежат только в derived. Исторический кадр не подтверждает актуальные модели героев или окружение. Коммерческие игровые ассеты не использованы.
