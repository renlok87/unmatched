# ASSET-INVISIBLE-MAN-001 — концепт 1a
Дата: 2026-10-13. Статус: **предложено**.

Создан один фронтальный дизайн коллекционной миниатюры Невидимки. Использованы только эталон мастерства Medusa и заданная палитра; изображение Medusa — единственный вход image_gen. Выполнено 2 генерации из разрешённых 2.

Выбран **design-front g2**, файл `design/invisible-man-front.png`: подставка показана с ребра, её верхняя плоскость скрыта и передний край горизонтален. Все шесть пунктов визуального CHECKLIST выполнены. Сырые g1 и g2 сохранены отдельно и не изменялись; выбранный дизайн — побайтовая копия g2.

g1 не выбран: видимая верхняя плоскость подставки нарушала пункт CHECKLIST о фронтальной ортографической проекции. Повтор использовал неизменённый CORE и одну строку CORRECTION только для этого нарушения.

Все три запуска скрипта завершились кодом 0: по 12 PASS, 1 WARN, 0 FAIL. WARN `view.frame_top` остался: g1 — 1,934%, g2 и финальный дизайн — 2,21% вместо минимум 4%. Это разрешённое предупреждение, не основание для повтора. Превышенный предел рамки явно записан в `verification.json`. После исчерпания лимита нет проваленных пунктов CHECKLIST: `limit_reached=[]`.

Малые решения: выбран g2 по геометрии подставки и ясному накладному носу; `side_view=null`, поскольку выполняется только фронтальный дизайн 1a. Белый воротник и галстук входят в белый основной цвет; отделка очков остаётся в коричневой гамме. Другие виды не создавались, согласованность между видами не проверяется.

SHA-256 обоих входов до и после совпадают. Палитра сохранена без изменений. Записи генераций содержат исходные пути инструмента, пути копий, размеры и хеши. Текстовые файлы записаны Python в UTF-8 без BOM; манифест записан последним. Git, Unreal, Tripo, SYNTX и загрузки не использовались. Собственные записи ограничены этим пакетом; оригиналы image_gen оставлены в его штатном каталоге по договору задачи. Художественная приёмка и коммит остаются за Claude.
