# Sun Wukong — концепт 1a

Дата: 2026-10-13. Ассет: ASSET-SUN-WUKONG-001. Статус: **предложено**.

Создан один фронтальный дизайн коллекционной расписанной миниатюры для дальнейшего image-to-3D моделирования. Использован только референс качества Medusa; палитра прочитана из существующего palette.json. Карточка ассета и другие изображения не использовались как входы.

Выбран **design-front / g2**: `design/sun-wukong-front.png` — побайтная копия `concepts/sun-wukong-design-front-g2.png`. Основание показано ребром, руки отделены от корпуса, посох находится в собственной правой руке, все четыре якоря и цвета палитры читаются. Обе генерации имеют размер 1086 × 1448, соотношение 3:4. Изображения не ретушировались и не перекодировались.

Использованы 2 из 2 разрешённых генераций. У g1 скрипт дал 12 PASS, 1 WARN, 0 FAIL: верх маски y3,315% (допустимый WARN view.frame_top). Визуальная проверка выявила раскрытую верхнюю поверхность подставки и неравномерный фон; поэтому g1 не выбран. CORE во второй попытке сохранён дословно, добавлены только две строки CORRECTION для ракурса и фона.

У g2 и финальной проверки: **13 PASS, 0 WARN, 0 FAIL, код 0**. Все шесть пунктов визуального CHECKLIST пройдены. Верх маски y4,075%, низ y92,472%, центр основания x49,816%. Фон ровный тёмно-серый; выборочные свободные точки имеют RGB 45–47. Слабые колебания на 1–2 уровня трактованы как шум изображения, а не выраженный градиент. Это небольшое решение проверки записано явно.

Незакрытых пунктов CHECKLIST нет; `limit_reached` пуст. Исчерпание двух попыток не потребовало дальнейших генераций. Один вид не позволяет оценить согласованность боковой и задней геометрии: они не создавались на этапе 1a. Технический PASS и визуальный чек-лист не заменяют внешнюю художественную приёмку; пакет остаётся предложением.

Оригиналы image_gen оставлены на своих местах, их абсолютные пути и SHA-256 записаны в generation-records.json. Файлы concepts/ не перезаписывались. Единственный прежний файл пакета — palette.json — сохранён без изменений. Авторские записи выполнены только внутри этого пакета; оригиналы инструмента вне пакета — прямо разрешённое заданием исключение.

Git, Unreal, Tripo, SYNTX и загрузки не использовались. Команды запускались из корня репозитория; фоновые процессы не запускались, все команды завершились. Исходные хеши, проверки каждой попытки и финальный отчёт перечислены в verification.json. manifest-sha256.json записан последним.
