# Robin Hood — дизайн-front, этап 1a

Дата: 2026-10-13. Статус: **предложено**.

Сделаны две отдельные генерации image_gen с одним изображением Medusa как эталоном мастерства. Палитра прочитана из palette.json. CORE передан дословно, у g2 добавлен только CORRECTION из двух строк. SHA-256 обоих входов не изменились.

Выбран **design-front g2**, файл design/robin-hood-front.png. У g1 была видна верхняя поверхность подставки; у g2 верх скрыт, передние края дисков горизонтальны. Лук в собственной левой руке, колчан за правым плечом, капюшон и поясная сумка видны. Размер исходного результата 1086×1448, аспект 3:4. Центр подставки x=49.954%, низ y=93.370%.

Все шесть пунктов CHECKLIST выбранного g2 выполнены. Финальный скрипт: **код 0, PASS 11 / WARN 2 / FAIL 0**. Верх лука y=3.453% вместо 4% даёт WARN view.frame_top. WARN view.single_component относится к сегментации частей единственной фигуры и её лука. WARN не были основанием для ретрая.

Что не вышло: плащ длиннее короткой накидки CORE, задние полотнища ниже колен. Круглую форму подставки в глубину нельзя подтвердить по единственному строго фронтальному виду. Ограничения записаны в verification.json. Лимит 2/2 использован; limit_reached пуст, потому что у выбранного изображения не осталось проваленных пунктов CHECKLIST. Приёмщик решает, допустимы ли остальные ограничения.

Первоначальное впечатление о градиенте фона включено в CORRECTION. Позднее чтение пикселей не подтвердило это подозрение: фоновые значения g2 около RGB 45 с небольшим шумом, p99_deviation рамки = 2. Этот замер не изменял изображения.

Небольшие решения: side_view=null для фронта, mode=generate для использования эталона мастерства, номера попыток g1 и g2. Вторая попытка выбрана за исправленный ракурс подставки и более точное положение её низа и центра.

Оригиналы image_gen оставлены на месте. Каждый результат сразу сохранён побайтно в собственном concepts/ файле. Обе генерации и рабочая копия выбранного дизайна не ретушировались, не обрезались, не изменяли размер или цвет и не перекодировались. Сравнение байтов и SHA-256 выполнено.

Технические ошибки раскрыты в verification.json: первая команда копирования не выполнилась из-за кавычек PowerShell, после неё checker был ошибочно вызван без каталога design/ и вернул 1 без отчёта. Передача Python исправлена через шестнадцатеричное представление UTF-8; кандидат успешно скопирован и проверен. g2 генерировался из-за визуального провала подставки g1. Одна слишком длинная команда финализации была отклонена до запуска; её разделили на короткие.

Отчёты всех состоявшихся проверок кандидатов находятся в checks/design-front-g1/ и checks/design-front-g2/. Финальный отчёт выбранного дизайна — design/checks-report.json. Точные промпты — prompts.md и prompts/concept-prompts.json; журнал генераций — generation-records.json. Верификация — verification.json. Манифест SHA-256 и размеров каждого файла пакета — manifest-sha256.json.
