# Jersey Devil — фронтальный дизайн 1a

Статус: **предложено**. Дата: 2026-10-13. Карточка: ASSET-JERSEY-DEVIL-001.

Создан оригинальный концепт коллекционной окрашенной миниатюры Jersey Devil. Единственный вход изображения — эталон мастерства Medusa; палитра прочитана из сохранённого `palette.json`. Хеши обоих входов совпали с заданием и остались неизменными.

Использованы две разрешённые генерации. Выбран **design-front g2**: `design/jersey-devil-front.png`, 1086×1448, RGB PNG. Он показывает подставку ребром без видимой верхней поверхности и сохраняет все признаки персонажа и палитру. Выбранный файл — побайтовая копия `concepts/jersey-devil-design-front-g2.png`.

| Генерация | Выбрана | Автопроверка | Визуальный результат |
|---|---|---|---|
| design-front g1 | Нет | Код 0; 12 PASS, 1 WARN, 0 FAIL | Видна верхняя поверхность подставки; пункт строгого фронтального ракурса не выполнен. |
| design-front g2 | Да | Код 0; 12 PASS, 1 WARN, 0 FAIL | Все шесть пунктов CHECKLIST пройдены; подставка показана ребром. |

Коррекция g2 содержит одну строку и исправляет только проваленный пункт подставки/ракурса. CORE в обоих вызовах одинаков. Сырые результаты и их отдельные отчёты сохранены без перезаписи; абсолютные исходные пути инструмента, относительные пути копий, хеши и размеры записаны в `generation-records.json`.

Финальный запуск выбранного дизайна без `--out`: **код 0**, 12 PASS, 1 WARN, 0 FAIL; отчёт `design/checks-report.json`. Визуальный осмотр выполнен по обоим изображениям. Ограничение осталось: верхний отступ g2 равен 2,901% вместо минимум 4% (разрешённый WARN `view.frame_top`); низ подставки расположен на 94,682% вместо заданных 93%. Эти отклонения раскрыты в `verification.json`. Исчерпан лимит 2/2 генераций; проваленных пунктов CHECKLIST у выбранного файла нет, поэтому `limit_reached` пуст.

Небольшие решения: после g1 использована только коррекция видимой верхней плоскости подставки; WARN не был причиной повтора. Для фронтального вида `side_view` записан как null. Предпочтён g2, хотя верхний отступ у него меньше, поскольку он исправил визуальный провал g1. Хвост g2 раздваивается между ногами; расположение хвоста и очертания перепонок изменились самим генератором, что зафиксировано в промпт-журнале.

Точные промпты: `prompts.md` и `prompts/concept-prompts.json`. Проверки, хеши входов после работы и ограничения: `verification.json`. Все файлы пакета, включая исходную палитру, перечислены в последнем записанном `manifest-sha256.json`. Вне папки пакета агент ничего не записывал; собственные оригиналы image_gen оставлены по указанным инструментом путям согласно заданию.
