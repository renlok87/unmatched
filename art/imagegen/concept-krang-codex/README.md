# ASSET-KRANG-001 — концепт 1a
Дата: 2026-10-13. Статус: **предложено**.

Создан один фронтальный дизайн Кранга для последующего image-to-3D. Использованы только референс качества Медузы и указанная палитра; единственный вход image_gen — референс качества. Оба исходных файла сохранены без изменений.

Выбран **design-front g2**, файл design/krang-front.png: у подставки прямые горизонтальные кромки, верхняя плоскость не видна. Розовый мозг с лицом и щупальцами, высокий робот, серо-фиолетовая броня и жёлтые глаза читаются. Пустые кисти отделены от корпуса.

Использованы 2 из 2 разрешённых генераций. g1 не прошла визуальный пункт strict front orthographic view: была видна узкая верхняя поверхность подставки. В g2 к CORE добавлена одна строка CORRECTION по этому пункту; CORE сохранён дословно. Сам генератор также поменял рельеф бронепластин, нагрудные детали, пояс и щупальца. На этапе дизайна выбран вариант с более точной геометрией подставки.

Финальная проверка: код 0, PASS 11, WARN 2, FAIL 0. Все шесть пунктов CHECKLIST отмечены как пройденные после визуального осмотра. WARN view.frame_top: верхний отступ 2,348% вместо 4%. WARN view.single_component: алгоритм разделил маску на компоненты; визуально дополнительных фигур нет. Предупреждения не были основанием для повторной генерации.

Отклонения от ориентиров CORE сохранены в verification.json: низ подставки 95,994% вместо целевых 93%; оценочный диаметр подставки около 0,67 высоты фигуры вместо около 0,55. Изображение не исправлялось. limit_reached пуст: не осталось проваленных пунктов CHECKLIST. Утверждение дизайна остаётся за приёмщиком.

Оба результата сразу скопированы побайтно в concepts/, оригиналы image_gen оставлены на месте. Каждый кандидат имеет отдельный отчёт; design/checks-report.json получен последним прогоном выбранной g2 без --out. Все пути записей нормализованы относительно корня репозитория, кроме original_path. Других видов на этапе 1a нет; межвидовое совпадение пока не проверяется.
