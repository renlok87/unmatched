# ASSET-SLASH-001 — дизайн фронтального концепта, этап 1a

Дата: 2026-10-13. Статус: **предложено**.

Создан фронтальный дизайн коллекционной миниатюры Slash. Единственный вход изображения — эталон качества Medusa для уровня скульптуры и матовой ручной окраски. Существующий palette.json прочитан и не изменён.

Выполнены две генерации image_gen из двух разрешённых. Каждый сырой PNG немедленно скопирован побайтно в concepts/; оригинальные копии инструмента оставлены на месте. Ретушь, обрезка, ресайз, перекраска и перекодирование не выполнялись. Размер обоих результатов — 1086 × 1448, аспект 3:4. CORE передан дословно; вторая попытка добавляет одну строку CORRECTION.

Для вида design-front выбрана **g2**: верх подставки скрыт, передний край горизонтальный, булава находится в собственной правой руке фигуры, все якоря узнаваемости видны. design/slash-front.png побайтно совпадает с concepts/slash-design-front-g2.png.

g1 прошла скрипт (13 PASS, 0 WARN, 0 FAIL), но не прошла визуальный пункт о виде подставки с ребра: видна её верхняя поверхность. Это единственная причина повтора. g2 и финальный прогон: 12 PASS, 1 WARN, 0 FAIL, код выхода 0. WARN view.single_component относится к сегментации; визуально изображена одна фигура. WARN не использован как причина повтора.

Все шесть пунктов CHECKLIST выбранной g2 пройдены. Оставшиеся отклонения CORE сохранены в verification.json:
- Подставка читается как один диск вместо двух низких дисков.
- Диаметр подставки относительно высоты фигуры без подставки приблизительно 0.72 вместо 0.55.
- Измеренный центр подставки x52.348% и низ y91.782% вместо x50% и y93%.
- Есть дополнительный приглушённый бежевый пластрон, цвет которого отсутствует в palette.json.

Мелкие решения: при выборе приоритет дан выполненному пункту о виде подставки с ребра; g1 с двумя дисками сохранена для сравнения. Новых видов и дальнейших генераций нет. Лимит использован; невыполненных пунктов CHECKLIST нет, поэтому limit_reached пуст. Отклонения CORE остаются на решение приёмщика.

Отчёты каждого кандидата находятся в checks/design-front-g1/ и checks/design-front-g2/. Финальный отчёт выбранного файла — design/checks-report.json. Хеши двух входов совпадают с заданием и не изменились. Все файлы пакета перечислены в manifest-sha256.json.

Запись команд и ручное копирование выполнялись только в этом пакете; внешние оригинальные PNG сохранены самим инструментом по разрешённому исключению. Git, Unreal, Tripo и SYNTX не запускались; загрузок не было. npx openskills не нашёл кэш пакета, поэтому навык прочитан из локального SKILL.md. Слишком длинная команда записи была отклонена Windows до запуска; повтор выполнен короткими командами с передачей текста в base64, без пайпа кириллицы.

Пакет подготовлен для проверки и коммита Claude; этапы 1b/1c и внешняя приёмка в эту задачу не входят.
