# Martian Invader — фронтальный концепт 1a

Статус: **предложено**. Дата: 2026-10-13.

Созданы две генерации одного фронтального дизайна ASSET-MARTIAN-INVADER-001. Визуальный вход только один: medusa-quality-reference.png как эталон мастерства. palette.json задаёт палитру. Карточка ассета — происхождение брифа; дополнительным входом она не использовалась.

Выбрана **design-front g2**: art/imagegen/concept-martian-invader-codex/design/martian-invader-front.png. Верх подставки скрыт, передние края горизонтальны. Все шесть пунктов CHECKLIST визуально пройдены. Это предложение для внешней приёмки.

Оба кандидата сохранены в concepts/ без перезаписи; итог — побайтовая копия g2. Исходные копии image_gen оставлены на месте, пути и хеши записаны в generation-records.json. Размер обеих генераций 1086 × 1448, аспект 3:4; размер инструменту не задавался. Ретуши, изменения размера, обрезки, перекраски и перекодирования не было.

В g1 не прошёл визуальный пункт о строгой фронтальной проекции: видна верхняя плоскость подставки. Скрипт g1 вернул 0, FAIL 0, WARN 1. Повторный вызов сделан из-за CHECKLIST, а не WARN. CORE во втором вызове сохранён дословно; добавлена одна строка CORRECTION о проекции подставки.

Финальный скрипт для g2: **код 0, PASS 11, WARN 2, FAIL 0**. WARN: view.frame_top (2,762% вместо минимум 4%) и view.single_component (маска разделяет детали). Визуально фигура одна. Все три запуска скрипта перечислены в verification.json.

Отклонения CORE: низ подставки на 95,166% вместо 93%; ширина подставки относительно высоты фигуры приблизительно 0,67 вместо 0,55; правая рука согнута заметнее, чем «слегка». Круглая форма подставки в плане не подтверждается единственным фронтальным растром. Эти ограничения занесены в verification.json. FAIL-пунктов выбранного CHECKLIST нет: limit_reached пуст, хотя обе разрешённые генерации использованы.

Малые решения: выбран g2 по выполнению проекции подставки; WARN не исправлялись. Второстепенные детали костюма, плавников и оружия самостоятельно изменились при перегенерации. Межвидового сравнения нет: создан только design-front, без side/back и контактного листа.

Хеши обоих входов до и после совпадают; palette.json сохранён. Все записи агента ограничены пакетом; внешние копии image_gen сохранены инструментом по контракту. Git, Unreal, Tripo, SYNTX и загрузки не использовались. Фоновые процессы не запускались. Ошибка Windows 206 при слишком длинной команде записи отчётов устранена разделением записи; генерации и проверки не повторялись. JSON и Markdown записаны Python в UTF-8 без BOM. manifest-sha256.json записан последним и охватывает каждый файл пакета, кроме себя.
