# Martian Invader — исправленный фронт 1a

Статус: **предложено**. Дата: 2026-10-13. Корректирующий запуск fix1, цикл приёмки r2.

Выбран **design-front g4**: `art/imagegen/concept-martian-invader-codex/design/martian-invader-front.png`. Оружие в собственной правой руке, слева для зрителя, опущено к бедру; локоть слегка согнут. Скафандр получил рёбра, швы, заклёпки и орнамент на рукавах, бёдрах, голенях и ботинках. Красные плавники, зелёная кожа, серебро и циан видны. Верх подставки скрыт, её края горизонтальны.

Использованы **2 из 2** разрешённых новых генераций: g3 и g4; всего на этапе 1a — **4 из 4**. У g3 видна узкая верхняя плоскость подставки: провален визуальный пункт проекции. Скрипт g3 дал 0, но повтор разрешён из-за CHECKLIST. В g4 исправление проекции добавлено к первой строке CORRECTION; все обязательные S/Q/P сохранены, CORE не менялся.

Финальная проверка g4: **код 0, PASS 12, WARN 1, FAIL 0**. Все шесть пунктов CHECKLIST пройдены визуально; `limit_reached` пуст. Это предложение для внешней приёмки, а не художественный pass.

Ограничения: верх купола на 2,970% вместо минимум 4% — допустимый WARN; низ подставки на 95,787% вместо 93%. Отношение ширины подставки к высоте фигуры примерно 0,574 при запросе «около 0,55». Круглая форма в плане и параметры камеры не подтверждаются одним фронтальным растром. Точные значения цвета после освещения не равны гарантированным albedo. Всё записано в verification.json.

Малые решения: g4 выбран за исправленную подставку при сохранении опущенного оружия и детализации. WARN не исправлялся. Второстепенные формы плавников и орнамента изменились при генерации. Side/back не создавались.

G1/g2, их отчёты и точные промпты сохранены; прежние итоговые документы и финальный отчёт скопированы без изменений в `history/20261013-front-r1/`. История хешей дополнена новым блоком, флаг выбора перенесён с g2 на g4. Итоговый PNG и все concepts — побайтовые копии image_gen; оригиналы инструмента оставлены на месте. Ретуши и перекодирования нет.

Оба входа неизменны. Записи ограничены пакетом; внешние оригиналы созданы самим image_gen по контракту. Git, Unreal, браузеры, другие агенты, Tripo, SYNTX и загрузки не использовались. Фоновых процессов нет. Ошибка аргументов Windows при записи метаданных устранена передачей ASCII-кода Python через stdin; генерации и проверки не повторялись. JSON и Markdown записаны Python в UTF-8 без BOM. Манифест SHA-256 записан последним.
