# Golden Bat — концепт 1a

Дата: 2026-10-13. Карточка: ASSET-GOLDEN-BAT-001. Статус: **предложено**.

Выполнен один фронтальный дизайн окрашенной коллекционной миниатюры для последующего image-to-3D. Встроенный image_gen дал две генерации, по одному виду каждая. Единственный визуальный вход — эталон качества Medusa. Палитра прочитана как JSON и не передавалась как изображение.

Для design-front выбрана **g2**: `art/imagegen/concept-golden-bat-codex/design/golden-bat-front.png`. Все сырые генерации побайтово сохранены в concepts/. Оригиналы инструмента оставлены на месте; оба пути каждой генерации записаны в generation-records.json. Изображения не ретушировались, не обрезались, не масштабировались, не перекрашивались и не пересохранялись.

g1 прошла скрипт (13 PASS, 0 WARN, 0 FAIL), но при осмотре обнаружены узкая верхняя площадка подставки и логотипоподобные эмблемы летучей мыши на застёжках и пряжке. Повтор получил неизменённый CORE и ровно две строки CORRECTION. В g2 подставка показана в профиль, эмблемы заменены абстрактным орнаментом. Все шесть пунктов CHECKLIST у g2 пройдены.

Финальная проверка: код **0**, 12 PASS, 1 WARN, 0 FAIL. Отчёт: `art/imagegen/concept-golden-bat-codex/design/checks-report.json`. Кандидаты имеют отдельные отчёты в checks/design-front-g1/ и checks/design-front-g2/.

Не выполнен ориентир CORE по верхней рамке: верхушка посоха на y=3,177% вместо ≥4%; это разрешённый WARN view.frame_top, предмет не обрезан. Подставка визуально шире ориентира «около 0,55 роста»: оценка около 0,64. Оба отклонения записаны в verification.json. Лимит 2/2 использован; limit_reached пуст, поскольку проваленных пунктов CHECKLIST у выбранного файла нет. Приёмщик решает об окончательной приёмке.

Малые решения: зелёный акцент — камни посоха; застёжки и пряжка — абстрактный декоративный орнамент; side_view=null. Тонкая светлая линия верхнего края подставки читается как фаска, не как верхняя площадка. Круглая форма дисков задана CORE; один строгий фронт не измеряет их глубину.

Входные SHA-256 до и после совпадают; palette.json сохранён без изменения. Все записи агента — внутри пакета; внешний оригинал image_gen прямо разрешён заданием. Git-команды, Unreal, Tripo, SYNTX и загрузки не выполнялись. npx openskills read не сработал из-за отсутствия кеша npm; навык прочитан напрямую из локального SKILL.md. Долгоживущие процессы не запускались.
