# Bigfoot — дизайн-front, этап 1a

Статус: **предложено**. Карточка: ASSET-BIGFOOT-001. Дата: 2026-10-13.

Созданы два самостоятельных фронтальных концепта коллекционной миниатюры. Единственный графический вход — эталон качества Медузы; палитра прочитана из palette.json. CORE передан дословно. Во втором вызове добавлены только две строки CORRECTION.

Выбрана **design-front g2**: art/imagegen/concept-bigfoot-codex/design/bigfoot-front.png. У неё подставка показана с ребра, без видимой верхней плоскости; сохранены длинные руки с зазорами, большие стопы, тяжёлые надбровья и лохматая коричневая шерсть. Оригиналы обоих вызовов и пакетные копии совпадают побайтно; изображения не редактировались и не пересохранялись.

У g1 провалился визуальный пункт о ракурсе подставки: была видна её верхняя плоскость. Первоначальное подозрение на градиент фона тоже вошло в коррекцию; измерение рамки впоследствии показало лишь p99 отклонения 2, поэтому автоматического FAIL фона не было.

Финальный check_concept_views.py: **код 0, PASS 11 / WARN 2 / FAIL 0**. Все шесть пунктов визуального CHECKLIST выбранной g2 пройдены. Верх маски на y=2,831% вместо требуемых CORE 4% — разрешённый WARN view.frame_top, явно записанный в verification.json. WARN view.single_component относится к отделению маски от фона; глазами второй фигуры или постороннего предмета нет. Две генерации использованы; limit_reached пуст, поскольку непройденных пунктов CHECKLIST выбранного вида нет.

Небольшие решения: moss green реализован малыми мшистыми акцентами на шерсти; side_view=null, потому что создан только design-front. Позу оценивал по опущенным рукам, слегка согнутым локтям и зазорам у корпуса. g2 выбрана по исправленной геометрии подставки, несмотря на дополнительный WARN сегментации.

Хеши обоих входов неизменны. Исходный palette.json сохранён. git не вызывался; Unreal, Tripo и SYNTX не открывались. Пакет готов для внешней художественной приёмки; она не входит в это задание.
