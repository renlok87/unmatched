# Ant Queen — дизайн-front, этап 1a

Статус: **предложено**.

Создан один фронтальный дизайн оригинальной коллекционной миниатюры ASSET-ANT-QUEEN-001. Использованы только перечисленные входы: Medusa как эталон качества исполнения и неизменённая palette.json. Две генерации выполнены встроенным image_gen.imagegen, по одному изображению на вызов; размер не задавался. Оба изображения имеют размер 1086 × 1448 px (3:4) и сохранены побайтно.

Выбран **design-front g2**: `design/ant-queen-front.png` — побайтовая копия `concepts/ant-queen-design-front-g2.png`. В g2 подставка показана строго ребром, без видимой верхней поверхности. Финальный скрипт завершился с кодом 0: 13 PASS, 0 WARN, 0 FAIL. Все шесть пунктов визуального CHECKLIST пройдены.

## Что не вышло

В g1 верхняя поверхность подставки была видна, а её передняя граница изгибалась: визуальный пункт строгого фронтального вида не пройден. Скрипт g1 дал 0 FAIL и допустимый WARN `view.frame_top` (верх 3,798%); WARN не был причиной повтора. Вторая генерация получила неизменённый CORE и одну строку CORRECTION только о ракурсе подставки.

В выбранном g2 остаются отклонения от дополнительных требований CORE: отношение ширины подставки к высоте фигуры приблизительно 0,74 вместо 0,55; коронообразный гребень получился крупным относительно головы. Они явно записаны в `verification.json` (`core_deviations`). Пунктов CHECKLIST с результатом failed нет, поэтому `limit_reached` пуст. Окончательное решение принимает приёмщик.

Команда первого копирования g2 завершилась синтаксической ошибкой до записи файлов. Следующая проверка по ошибке прочитала ещё установленный g1. Этот отчёт сохранён отдельно в `checks/design-front-g2/checks-report-before-copy-error.json` и записан как проверка фактического g1 в `verification.json`. После исправления команды g2 скопирован побайтно, проверен в своём каталоге, выбран и проверен ещё раз без --out.

## Небольшие решения

Шесть ног прочитаны как три пары: верхняя свободная пара выполняет роль описанных в CORE рук, четыре остальные ноги поддерживают фигуру. Дизайн симметричен и не использует оружие. Боковой вид на этапе 1a не создавался, `side_view = null`. Единственная коррекция касается проваленного визуального пункта; CORE двух вызовов одинаков. По одному фронтальному изображению невозможно независимо доказать круглую форму основания в плане.

Исходные изображения генератора оставлены на месте; абсолютные пути записаны в `generation-records.json`. SHA-256 всех входов до и после совпадают. palette.json сохранён без изменений. Промпты записаны дословно в `prompts.md` и `prompts/concept-prompts.json`; отчёты каждой фактической проверки сохранены отдельно. Самостоятельные записи выполнены только внутри этого пакета; разрешённые собственные копии image_gen вне пакета не являются дополнительными файлами проекта.
