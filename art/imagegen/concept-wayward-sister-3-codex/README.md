# Wayward Sister 3 — дизайн-front, этап 1a

Статус: **предложено**. Дата: 2026-10-13. Ассет: ASSET-WAYWARD-SISTER-3-001.

Созданы два фронтальных концепта через image_gen, по одному изображению на вызов. Единственный графический вход — эталон качества Medusa; palette.json прочитан как неграфический вход. CORE передан дословно; к g2 добавлены только три строки CORRECTION. PNG не ретушировались, не масштабировались, не обрезались, не перекрашивались и не перекодировались. Копии побайтовые, оригиналы инструмента оставлены на месте.

Выбран **design-front g2**: `design/wayward-sister-3-front.png` — побайтовая копия `concepts/wayward-sister-3-design-front-g2.png`. Причина: вместо широкополой шляпы появился остроконечный капюшон, видимая плоскость верха подставки значительно уменьшилась, передний край стал горизонтальным. Плащ с заплатами, железный котелок в обеих руках и зелёный дым сохранены. g1 сохранён вместе с отдельным отчётом.

g1 и g2 проверены каждый в своём каталоге; выбранный g2 проверен повторно без --out. Финальный код **0**: 11 PASS, 2 WARN, 0 FAIL. Предупреждения: view.frame_top (3.522% вместо минимум 4%) и view.single_component. WARN допускается заданием и не является причиной повторной генерации. Автоматический PASS не заменяет визуальный CHECKLIST.

Лимит **2/2** использован. Не закрыты два пункта CHECKLIST:

- Строгая ортография: над верхним диском всё ещё видна узкая полоска верхней плоскости.
- Запрет удерживаемых предметов и разделение рук: котелок обязателен по CORE, но одновременно запрещён буквальным «No weapon or held object»; этот пункт отмечен как failed. Зазоры фона между каждой рукой и корпусом также остаются недостаточно ясными.

В g1 дополнительно не получился pointed cowl: нарисована широкополая шляпа. g2 исправил этот якорь. Точная рамка CORE не достигнута: верх 3.522%, низ — по измерению в verification.json, вместо точных 4% и 93%. Верхний отступ имеет разрешённый WARN. Приземистость передана широким плащом; относительный рост без соседней фигуры не проверяется.

Небольшие решения: выбрать g2 по видимому улучшению; сохранить обязательный котелок и честно записать конфликт, не менять CORE; не исправлять PNG; завершить с limit_reached по инструкции, решение оставлено приёмщику.

Входные хеши совпали с заданием и после работы не изменились; palette.json сохранён побайтово. Карточка из шапки задания не открывалась и не использовалась как дополнительный вход. Git, Unreal, Tripo, SYNTX, загрузки и фоновые процессы не запускались. Записи и отчёты созданы только внутри пакета; внешние оригиналы автоматически сохранены image_gen по договору пакета.
