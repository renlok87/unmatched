# Leatherhead — концепт 1a

Статус: **предложено**. Дата: 2026-10-13. Ассет: ASSET-LEATHERHEAD-001.

Создан один фронтальный дизайн расписанной коллекционной миниатюры для image-to-3D. Использованы только эталон качества Medusa и palette.json из задания. Выполнено две генерации image_gen из разрешённых двух; обе 1086 × 1448, аспект 3:4.

Выбран **design-front g2**: `design/leatherhead-front.png` — побайтная копия `concepts/leatherhead-design-front-g2.png`. Во второй генерации верхняя плоскость подставки скрыта, передние края горизонтальны; фон ровнее. Все шесть пунктов визуального CHECKLIST пройдены. Финальный скрипт: код 0, 13 PASS, 0 WARN, 0 FAIL; отчёт `design/checks-report.json`.

В g1 скрипт также дал код 0, однако визуально были видны узкая верхняя плоскость подставки и лёгкая неоднородность фона. Повтор вызвали только эти два пункта. CORE сохранён дословно, в g2 добавлен только двухстрочный CORRECTION. Оба кандидата и их отдельные отчёты сохранены.

Отклонения CORE: подставка шире ориентировочных 0,55 высоты фигуры — оценка по маске около 0,73; низ y94,682% вместо y93%, центр x49,079% вместо x50%. Верх y4,765% соблюдает минимум 4%. Эти отклонения записаны в verification.json и не исправлялись обработкой изображения. Непройденных пунктов выбранного CHECKLIST нет; limit_reached пуст.

Малые решения: выбран g2 по подставке и фону; side_view=null, поскольку на 1a существует только фронтальный дизайн. Между независимыми генерациями различаются детали чешуи, прорехи жилета и изгиб хвоста. Согласованность с боковым и задним видами ещё не проверялась.

Изображения не ретушировались, не обрезались, не масштабировались, не перекрашивались и не перекодировались. Оригиналы image_gen оставлены на месте; оба пути и хеши указаны в generation-records.json. Хеши обоих входов до и после совпали. palette.json сохранён без изменений. Все файловые записи команд ограничены пакетом; исключение — прямо предусмотренные заданием оригиналы самого image_gen. Git не вызывался; Unreal не открывался.

Промпты: prompts.md и prompts/concept-prompts.json. Проверки кандидатов: checks/design-front-g1/checks-report.json и checks/design-front-g2/checks-report.json. Итоговые доказательства: verification.json и manifest-sha256.json.
