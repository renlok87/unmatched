Статус: **предложено**.

Созданы два независимых фронтальных варианта одной коллекционной миниатюры через image_gen.imagegen. Единственное изображение-референс — medusa-quality-reference.png, только для качества исполнения; palette.json использован как текстовая палитра. Входные хеши совпали с заданием и после работы не изменились.

Выбран **design-front g2**: design/dr-jekyll-front.png — побайтовая копия concepts/dr-jekyll-design-front-g2.png, 1086 × 1448, точное соотношение 3:4. g2 лучше выполняет фронтальную проекцию подставки: её верх не виден, края двух ярусов горизонтальны. Флакон слева у персонажа и саквояж справа, серый сюртук и кремовый платок читаются.

g1 не выбран: визуально видна верхняя поверхность круглой подставки. Коррекция g2 содержит только одну строку про этот пункт CHECKLIST; CORE сохранён дословно. Повтор не был вызван WARN.

Все три запуска check_concept_views.py завершились кодом 0: 12 PASS, 1 WARN, 0 FAIL. Последний отчёт — design/checks-report.json. Допустимый WARN view.frame_top: g1 2,486%, g2 2,970% вместо ≥4%. Низ подставки g2 находится на 95,304% вместо запрошенных 93%, центр x49,954%; изображения не правились.

Незакрытый CHECKLIST: буквальное «No weapon or held object» противоречит обязательным флакону и саквояжу в самом CORE. Оружия нет, обе руки отделены от корпуса; обязательные предметы сохранены. Это отмечено как failed, а не скрыто. Использован лимит 2/2, limit_reached передан приёмщику; дальнейшее решение за ним.

Мелкие решения: LEFT/RIGHT трактуются анатомически; при выборе приоритет получил скрытый верх подставки; потрачена только одна коррекция камеры, без замены CORE и без попытки устранить противоречие удалением identity anchors. Ортографичность оценена по изображению, технические параметры камеры недоступны.

Оба оригинала генератора оставлены на месте; каждый кандидат сохранён побайтово, без ретуши, обрезки, ресайза, перекраски или перекодирования. Все записи путей внутри пакета относительны корню репозитория; original_path абсолютный. Скрипт запускался без --palette строго по команде задания, поэтому палитра проверена глазами. Других видов на этапе 1a нет.

Изменения исполнителя ограничены этим пакетом; palette.json сохранён. Единственные разрешённые внешние записи — собственные PNG image_gen. Git, Unreal, Tripo, SYNTX и загрузки не использовались.
