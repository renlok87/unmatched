# ASSET-RAPTORS-001 — дизайн фронтального вида, этап 1a

Статус: **предложено**. Художественную приёмку выполняет принимающий агент.

Создан один фронтальный дизайн миниатюры раптора встроенным инструментом image_gen. Использованы ровно две генерации из разрешённых двух. Единственный графический вход — эталон качества Medusa; палитра прочитана как JSON и не передавалась изображением. Хэши обоих входов до и после совпадают с заданием.

Выбран **design-front g2**: `design/raptors-front.png`, побайтная копия `concepts/raptors-design-front-g2.png`. Размер выбран инструментом: 1086 × 1448, соотношение 3:4. g2 предпочтён за симметричный фронтальный вид фигуры и подставку строго с ребра, без видимой верхней плоскости. Обе ступени имеют прямые горизонтальные кромки. Кожа, полосы, светлое брюхо, жёлтые глаза, два серповидных когтя и промежутки между руками и корпусом читаются.

g1 отклонён: видна верхняя плоскость подставки, нарушен пункт CHECKLIST о фронтальной ортографической проекции. Хвост у g1 читается лучше, но ошибка камеры существенна для входа image-to-3D. Единственная коррекция g2 направлена на этот пункт; CORE сохранён дословно, эталон не заменялся.

У выбранного g2 **провален пункт CHECKLIST об идентичности**: длинный жёсткий хвост почти полностью скрыт за фигурой; виден только поднятый конец над головой. Лимит генераций 2/2 исчерпан. Этот дефект записан в `verification.json#limit_reached`; пакет передаётся принимающему агенту без объявления художественного PASS.

Автопроверки всех трёх запусков завершились кодом **0**: g1 — 12 PASS / 1 WARN / 0 FAIL; g2 и финальный прогон — 11 PASS / 2 WARN / 0 FAIL. У g2 допустимы WARN `view.frame_top` (верх 2,831 % вместо не менее 4 %) и `view.single_component` (маска выделила дополнительный компонент 1,755 %). WARN не были причиной повторной генерации. Низ выбранной подставки измерен на 94,268 % вместо заданных 93 %. Дополнительные отклонения CORE: пасть открыта шире «slightly open»; ориентировочное отношение ширины подставки к высоте полного силуэта фигуры около 0,70 вместо около 0,55. Эти ограничения также отражены в verification.json.

Оба исходных результата сохранены в concepts/ без перезаписи, обработки и перекодирования. Копии image_gen оставлены на месте; абсолютные пути к ним, SHA-256, размеры и точные промпты записаны в журнале. Отчёт каждого кандидата находится в отдельном checks/design-front-gN/, финальный — в design/checks-report.json.

Малые решения: нумерация с g1; side_view=null, поскольку этап 1a содержит только фронтальный дизайн; g2 выбран по читаемости фронтальной проекции, а не по числу WARN. Новые ракурсы не создавались. Все текстовые файлы записаны Python в UTF-8 без BOM. palette.json сохранён без изменений. Команды git не выполнялись. Изменения вручную и скриптами ограничены этим пакетом; внешние оригиналы созданы самим image_gen по договору. Файлы Unreal не открывались, процессы Unreal, Tripo и SYNTX не запускались.
