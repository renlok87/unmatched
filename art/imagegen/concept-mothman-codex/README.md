# ASSET-MOTHMAN-001 — дизайн-front, этап 1a

Статус: **предложено**.

Создан один фронтальный дизайн коллекционной миниатюры Mothman. Использован встроенный image_gen: две генерации, по одному изображению на вызов, с единственным референсом качества art/imagegen/hero-quality-v1/reference/medusa-quality-reference.png. Палитра прочитана из palette.json, сам файл сохранён без изменений. Размер обоих результатов — 1086 × 1448, аспект 3:4; размер инструменту не передавался.

Выбран **design-front g2**: art/imagegen/concept-mothman-codex/design/mothman-front.png — побайтовая копия art/imagegen/concept-mothman-codex/concepts/mothman-design-front-g2.png. У g2 скрыта верхняя поверхность подставки, сохраняются фронтальный силуэт, крылья, серо-коричневое опушение, красные глаза и свободные когтистые руки. Генерация g1 оставлена в concepts/: у неё была видна узкая верхняя поверхность подставки. Повтор выполнен с неизменённым CORE и одной строкой CORRECTION только об этом дефекте.

Решение по выбору: более точный вид подставки с ребра у g2 предпочтён полям кадра g1. Руки визуально проверены как свободная нейтральная стойка с небольшим сгибом локтей; за промежутками между руками и корпусом находятся крылья. Между разными видами согласованность не оценивалась: в задании только design-front.

Автопроверки каждого кандидата сохранены отдельно. Финальный прогон выбранного g2 без --out записал art/imagegen/concept-mothman-codex/design/checks-report.json: **exit 0, 12 PASS, 1 WARN, 0 FAIL**. WARN view.frame_top: верхняя точка на 3,315% высоты вместо не менее 4%; этот WARN разрешён заданием. У g1 было 13 PASS, 0 WARN, 0 FAIL.

Не выполнен строгий пункт CHECKLIST о плоском фоне: видимо слабое потемнение тёмно-серого фона книзу. Фигура и подставка не обрезаны, но фон не совершенно однороден. Лимит **2/2** использован; g2 сохранён для решения приёмщика, а failed-пункт внесён в verification.json / limit_reached. Дополнительно зафиксированы отклонения CORE: низ подставки на 95,373% вместо 93%; оценочная ширина подставки относительно высоты фигуры около 0,65 вместо целевых примерно 0,55. Эти отклонения не скрыты и не исправлялись обработкой изображения.

Оба сырых PNG скопированы без ретуши, ресайза, обрезки, перекраски или повторного кодирования. Их штатные оригиналы image_gen оставлены на месте; пути и SHA-256 записаны в generation-records.json. Хеши обоих входов совпали с заданием до работы и остались неизменными после неё. Точные промпты, визуальный CHECKLIST, все три запуска проверки и манифест файлов находятся в этом пакете.
