# Гарри Гудини — концепт 1a

Статус: **предложено**.

Созданы два фронтальных дизайна встроенным `image_gen` с одним эталоном мастерства Medusa. CORE сохранён дословно; g2 содержит две строки CORRECTION. Использовано 2 из 2 разрешённых генераций.

Выбран **design-front g2**, копия `design/harry-houdini-front.png`: верхняя поверхность подставки не видна, кромки горизонтальны, все четыре якоря читаются. g1 отклонён визуально из-за перспективы подставки и неоднородности фона. Оригиналы обоих результатов сохранены побайтно в `concepts/`, копии инструмента оставлены на месте. Хеши, размеры и пути — в `generation-records.json`.

Проверки кандидатов находятся в `checks/design-front-g1/` и `checks/design-front-g2/`. Финальный отчёт выбранного дизайна — `design/checks-report.json`: код 0, PASS 11, WARN 2, FAIL 0. WARN `view.frame_top`: верх 3,177% вместо минимум 4%; WARN `view.single_component`: тёмные части разделены сегментацией. WARN не вызывали ретрай. Низ маски 94,13% вместо целевых 93%; центр подставки 49,77%. Размер обоих файлов 1086×1448, аспект 3:4.

Не закрыто: фон g2 сохраняет слабую пятнистую неоднородность; строго ровная заливка не достигнута. Автопроверка рамки PASS допускает эту вариацию. Лимит исчерпан, неудавшийся пункт CHECKLIST внесён в `verification.json` → `limit_reached`; решение о приёмке остаётся за приёмщиком.

Малые решения: сторона обвитого цепью предплечья не задана — у выбранного g2 это собственное левое предплечье. Форма замка и тонкая латунная цепочка жилета оставлены в пределах палитры. Руки опущены, локти мягко согнуты, видны зазоры — нейтральная стойка миниатюры. Боковой и задний виды не создавались.

SHA-256 обоих входов совпал с заданием до работы и после неё. Текст записан Python в UTF-8 без BOM. Изображения не ретушировались, не обрезались, не масштабировались и не перекодировались. Записи агента вне пакета отсутствуют; автоматические оригиналы `image_gen` — разрешённое заданием исключение. Git-команды не выполнялись.
