# Гарри Гудини — концепт 1a, corrective fix1

Статус: **предложено**.

В fix1 перегенерирован только **design-front**: g3 и g4, две генерации из двух разрешённых. Суммарно использовано 4 из 4 для этого вида. CORE сохранён дословно. На первой генерации g3 к CORE добавлена ровно указанная пользователем CORRECTION из карточки r1. На g4 добавлены три строки исправлений по осмотру g3; WARN не был причиной повтора.

Выбран **design-front g3**, побайтная копия в `design/harry-houdini-front.png`. Его поза асимметрична: обвитая цепью рука поднята, другая опущена, обе ладони открыты и пусты, зазоры от корпуса читаются. g4 улучшил ракурс подставки, но вернул симметричную A-позу, поэтому не выбран. Полная коррекция S не достигнута и у g3: поднятая ладонь выше талии, сгиб нижнего локтя недостаточно выражен.

Все три прогона fix1 завершились кодом **0**. Финальный отчёт выбранного g3: PASS 12, WARN 1, FAIL 0. WARN `view.frame_top`: верх 2.831% вместо минимум 4%; это не причина ретрая. Низ маски 95.994% вместо целевых 93%, центр подставки 49.263%. Оба новых изображения имеют размер 1086×1448, аспект 3:4.

Не закрыто у выбранного g3: видна верхняя поверхность подставки; фон сохраняет слабую неоднородность; положение поднятой ладони и сгиб нижнего локтя не полностью соответствуют CORRECTION. Лимит исчерпан; пункты перечислены в `verification.json` → `limit_reached`. Приёмку исполнитель не запускал и коэффициент не выставлял.

g1–g2, их промпты и отдельные отчёты кандидатов сохранены. Старый блок `source-hashes-before.json` сохранён; добавлен блок fix1. Предыдущие метаданные и финальный отчёт g2 побайтно сохранены в `history/fix1-before/`. Текущие записи всех четырёх генераций находятся в `generation-records.json`; только g3 отмечен selected=true. Предыдущий выбор g2 сохранён в истории.

Малые решения: при выборе приоритет отдан устранению A-позы, ради которой назначен fix1. Цепь в g3 обвивает собственное правое предплечье, ладонь находится слева на изображении; сторона CORE не задана. Тонкие звенья цепи не служили причиной повторной генерации. Боковой и задний виды не создавались.

SHA-256 обоих входов совпал с заданием до работы и после неё. Все изображения скопированы без ретуши, масштабирования, обрезки, изменения цвета и перекодирования. Текст записан Python в UTF-8 без BOM. Записи агента вне пакета отсутствуют; автоматические оригиналы image_gen — разрешённое заданием исключение. Git-команды не выполнялись.
