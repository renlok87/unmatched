# Дракула — концепт 1a

Дата: 2026-10-13. Статус: **предложено**.

Создан один фронтальный дизайн коллекционной расписанной миниатюры. Использованы только указанные эталон качества Medusa и palette.json; изображением-входом был только эталон. CORE передан дословно, во втором вызове добавлен CORRECTION из трёх строк. Tripo, SYNTX, Unreal и git не использовались.

Выбран **design-front g2**: design/dracula-front.png — побайтная копия concepts/dracula-design-front-g2.png. g2 ближе к фронтальному виду подставки, имеет спокойную стойку и ясные якоря идентичности. Размер обеих генераций — 1086 × 1448, аспект 3:4; размер инструменту не задавался. Оригиналы инструмента оставлены на месте, оба пути и хеши записаны в generation-records.json.

Использовано **2 из 2** генераций. Все три запуска check_concept_views.py завершились кодом **0**: 12 PASS, 1 WARN, 0 FAIL. Итоговый отчёт: design/checks-report.json. Допустимый WARN view.frame_top: верх маски g2 на 3,246 % вместо 4 %. Это не основание для повторной генерации.

## Осмотр и незакрытые пункты

- g1: заметна верхняя поверхность подставки, плащ закрывает просветы у рук. Фон при осмотре показался неоднородным — замечание вошло в CORRECTION; выборки RGB по краям не подтвердили сильного перепада тона.
- g2: подставка ближе к виду ребром, но узкая верхняя поверхность всё ещё видна. Строгое требование ортографической камеры не закрыто.
- g2: руки отведены, локти согнуты, но плащ по-прежнему заполняет просветы между руками и корпусом.
- Остальные четыре пункта CHECKLIST пройдены при осмотре; фон g2 выглядит ровным, со слабым шумом.

Лимит исчерпан при двух проваленных пунктах CHECKLIST; они записаны в verification.json.limit_reached. Пакет завершён нормально для решения приёмщика; статус принятия не присваивался.

## Небольшие решения

side_view = null: этап 1a содержит только фронтальный дизайн. Золотые застёжки, цепочки и вышивка оставлены как орнамент в пределах акцентного цвета. Плащ не удалялся, пиксели не правились; оба кандидата и выбранный файл сохранены без перекодирования. Тексты записаны из Python в UTF-8 без BOM. palette.json не менялся; входные хеши подтверждены.

Записи этой задачи ограничены пакетом. Предусмотренное заданием исключение — собственные оригиналы image_gen в каталоге инструмента вне пакета. Фоновые процессы не запускались.
