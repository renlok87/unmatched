# Leonardo — концепт 1a

Дата: 2026-10-13. Карточка: ASSET-LEONARDO-001. Статус: **предложено**.

Подготовлен один фронтальный дизайн миниатюры Leonardo для image-to-3D. Выполнено две генерации image_gen с единственным изображением Medusa как эталоном исполнения и неизменённым CORE. Цвета сверены с palette.json.

Выбран **design-front g2**: `design/leonardo-front.png` — побайтная копия `concepts/leonardo-design-front-g2.png`, 1086 × 1448, точное соотношение 3:4. Подставка у g2 показана строго с ребра: передние края горизонтальны, верхняя поверхность не видна. Низ подставки: 92,956% высоты кадра; центр: 49,954% ширины. Ракурс и размещение лучше соответствуют CORE, чем у g1.

Оба кандидата и финальная копия проверены указанной командой: каждый из трёх запусков получил код 0, 13 PASS, 0 WARN, 0 FAIL. Отчёты кандидатов: `checks/design-front-g1/checks-report.json`, `checks/design-front-g2/checks-report.json`; финальный: `design/checks-report.json`. Автопроверки не оценивают оружие, эмблемы и ортографичность; эти пункты проверены глазами.

Незакрытые пункты CHECKLIST выбранного g2:

- **Запрет оружия:** обе руки держат по катане. CORE одновременно требует их в SUBJECT/IDENTITY ANCHORS и запрещает оружие в POSE. Текст сохранён дословно; корректировать оружие без противоречия одному из требований невозможно.
- **Запрет логотипов:** на синей круглой пряжке виден рельефный эмблемный знак. Буква L не читается однозначно; строгий запрет логотипов консервативно отмечен как невыполненный.

Оба пункта записаны в `verification.json#limit_reached`. Лимит 2/2 исчерпан, решение остаётся за приёмщиком. У g1 дополнительно видна узкая верхняя поверхность подставки; единственная строка CORRECTION исправляла этот пункт. У g2 ракурс исправлен, но появилась эмблемная пряжка.

Дополнительные отклонения от CORE вне шести пунктов CHECKLIST: клинки в обеих генерациях расходятся в стороны, а не скрещены; диаметр подставки g2 визуально около 0,72 высоты фигуры без подставки вместо около 0,55 (приблизительная оценка по изображению).

Небольшие решения: нумерация g1/g2, поскольку прежних поколений не было; side_view = null для фронтального вида; выбор g2 по исправлению ракурса и размещению подставки. Генератор также перенёс хвосты маски с правой на левую сторону изображения, добавил обмотки стоп и синюю ткань на поясе. Эти изменения не запрашивались в CORRECTION. Других видов нет, согласованность front/side/back не оценивалась.

Все изображения сохранены без ретуши, изменения размера, обрезки, перекраски и перекодирования. Оригиналы image_gen оставлены на месте; original_path и SHA256 записаны в generation-records.json. Входные хеши совпали с заданием до и после работы; palette.json не изменён. Записи исполнителя ограничены пакетом; внешние оригиналы созданы самим image_gen по контракту. Git, Unreal, Tripo, SYNTX и загрузки не использовались.
