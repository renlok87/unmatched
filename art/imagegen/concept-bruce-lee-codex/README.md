# Bruce Lee — фронтальный дизайн, этап 1a

Дата: 2026-10-13. Карточка: ASSET-BRUCE-LEE-001.
Статус: **предложено**.

Создан один фронтальный дизайн коллекционной расписанной миниатюры для последующего image-to-3D моделирования. Использованы только эталон качества Medusa и заданная палитра; единственный изображение-вход каждого вызова image_gen — эталон Medusa. Сделаны две генерации из разрешённых двух.

Выбран **design-front g2**: design/bruce-lee-front.png — побайтовая копия concepts/bruce-lee-design-front-g2.png. У g2 подставка показана с ребра, фон ровнее, обе кисти и просветы между руками и корпусом читаются. Все шесть пунктов визуального CHECKLIST отмечены как пройденные в verification.json.

g1 не выбран: была видна верхняя плоскость подставки, а фон имел слабую неравномерность тона. Для g2 исходный CORE сохранён дословно, добавлен CORRECTION из двух строк, исправляющий только эти пункты. Каждый кандидат хранится отдельно и имеет свой отчёт в checks/design-front-g1/ или checks/design-front-g2/.

Все три запуска check_concept_views.py завершились кодом **0**: 12 PASS, 1 WARN, 0 FAIL. Финальный отчёт выбранного дизайна — design/checks-report.json.

Ограничение рамки не выполнено полностью: верхняя точка g2 находится на 3,453% высоты вместо не менее 4%; у g1 — 3,177%. Это разрешённый WARN view.frame_top, не причина для повторной генерации. Ничего не обрезано. limit_reached пуст, поскольку у выбранного файла не осталось проваленных пунктов CHECKLIST. Фон g2 визуально плоский и нейтральный, с небольшим зерном генерации: медиана рамки RGB [47, 47, 47], p99 отклонения 2.

Малые решения: выбран более фронтальный g2; небольшая асимметрия положения пустых кистей сохранена как боевая стойка. Чёрная обувь имеет жёлтые детали в пределах основной палитры. Только один ракурс; межвидовая согласованность будет проверяться на последующем этапе 1c.

Точные промпты, порядок ссылок и различия попыток записаны в prompts.md и prompts/concept-prompts.json. generation-records.json содержит оба пути каждого PNG, размеры, SHA-256 и выбор g2. Исходные хеши записаны до генерации в source-hashes-before.json, совпадение после работы доказано в verification.json.

Изображения не ретушировались, не масштабировались, не кадрировались, не перекрашивались и не перекодировались. Оригиналы инструмента оставлены на месте. Запись в репозиторий ограничена этим пакетом; git-команд, сборок Unreal, Tripo, SYNTX и загрузок не было. Сбой чтения скилла через npx openskills (ENOTCACHED) обойдён чтением локального SKILL.md; он не повлиял на генерацию.
