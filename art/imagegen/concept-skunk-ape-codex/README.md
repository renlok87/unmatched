# Skunk Ape — дизайн-front, этап 1a

Статус: **предложено**. Дата: 2026-10-13. Карточка: ASSET-SKUNK-APE-001.

Создан один фронтальный дизайн коллекционной миниатюры: высокий сутулый обезьяноподобный персонаж с длинными руками, крупными стопами, спутанной тёмной шерстью и болотным мхом. Палитра взята из неизменённого palette.json; Medusa использована только как эталон мастерства.

Выбрана **design-front g2**: `design/skunk-ape-front.png` — побайтовая копия `concepts/skunk-ape-design-front-g2.png`, 1086×1448, аспект 3:4. У g2 скрыта верхняя поверхность подставки и ровнее фон. Локально решено предпочесть эти улучшения двум допустимым WARN; подробности маски не подменяют осмотр изображения.

Использовано **2 из 2** разрешённых генераций. g1 сохранена, но не выбрана: при осмотре заметны узкая полоска верха подставки и слабый градиент фона. g2 получена с тем же неизменённым CORE и двухстрочным CORRECTION только по этим пунктам. Рисунок мха, шерсти и мелкие пропорции между попытками изменился.

Каждый кандидат проверен в собственном каталоге checks/design-front-gN. Финальный отчёт выбранного дизайна: `design/checks-report.json`; код **0**, **11 PASS, 2 WARN, 0 FAIL**. Шесть пунктов визуального CHECKLIST выполнены.

Не выдержаны точные числа рамки: верх маски y2,486% вместо минимум y4%; низ y96,133% вместо y93%. Центр подставки x49,770%. WARN view.single_component связан с разделением маски; глазом видна одна фигура на одной подставке. Эти ограничения записаны в verification.json. limit_reached пуст: неисправленных пунктов CHECKLIST у выбранного файла нет. Фон имеет небольшую пиксельную фактуру; абсолютное равенство пикселей, математическая ортографичность камеры и точное совпадение освещённых цветов с hex по одному PNG не доказываются.

Размер не передавался инструменту. Ретушь, изменение размера, обрезка, перекраска и пересохранение изображений не выполнялись. Сырые копии, пути оригиналов, хеши и точные промпты сохранены. Все записи и копии сделаны только внутри этого пакета; штатные оригиналы image_gen оставлены на месте.

Хеши обоих входов проверены до и после работы. palette.json сохранён без изменений. Внешняя художественная приёмка и следующие стадии пайплайна остаются за запускающим агентом.
