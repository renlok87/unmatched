# Dr. Ellie Sattler — концепт 1a

Дата: 2026-10-13. Карточка: ASSET-DR-SATTLER-001. Статус: **предложено**.

Создан один фронтальный дизайн коллекционной окрашенной миниатюры. Выполнено две генерации встроенным image_gen; единственный образец изображения — medusa-quality-reference.png, только для уровня исполнения. palette.json использован как текстовая палитра. Шаги 1b/1c в этот запуск не входят.

Для вида design-front выбрана **g2**: design/dr-sattler-front.png — побайтовая копия concepts/dr-sattler-design-front-g2.png. У g2 полевая рубашка хаки, розовая внутренняя майка, походные ботинки, светлый хвост и красный фальшфейер в собственной правой руке (слева для зрителя). Верхняя плоскость подставки не видна. Все шесть пунктов визуального CHECKLIST пройдены.

g1 сохранена без изменений. Автопроверка: код 0, 12 PASS, 1 WARN, 0 FAIL. Визуально не выполнены два пункта: видна верхняя плоскость подставки, а полевая рубашка розовая вместо хаки. Второй промпт содержит дословный CORE и только две строки CORRECTION на эти ошибки.

Автопроверка g2 и финальный запуск: код 0, 12 PASS, 1 WARN, 0 FAIL. Невыполненный числовой отступ: view.frame_top — 3,591% вместо минимум 4%; у g1 — 3,936%. Задание разрешает этот WARN и запрещает повтор только из-за WARN. Обрезки нет. Лимит запуска — 2/2; непройденных пунктов визуального CHECKLIST у выбранной g2 нет, поэтому limit_reached пуст.

Небольшие решения и ограничения: розовый цвет сохранён на внутренней майке, чтобы наружная полевая рубашка соответствовала якорю хаки. g2 добавила коричневые полевые ремни и сумку, которых CORE явно не задаёт; это зафиксировано как отличие кандидата. Круглая форма дисков при виде с ребра независимо не проверяется. Поза рук асимметричная, с видимыми просветами, не T и не A. Эти детали оценивает приёмщик.

Изображения не ретушировались, не масштабировались, не обрезались, не перекрашивались и не перекодировались. Оба кандидата совпадают с оригиналами image_gen по SHA-256 и байтам; оригиналы оставлены на месте. Входы не изменились. Все записи пакета сделаны Python в UTF-8 без BOM; манифест записан последним. Git, Unreal, Tripo и SYNTX не запускались.
