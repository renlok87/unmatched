# ASSET-PIRATE-CREWMAN-001 — концепт 1a

Дата: 2026-10-13. Статус: **предложено**.

Создан фронтальный дизайн пирата для image-to-3D. Единственный графический вход — эталон качества Medusa; палитра взята из palette.json. SHA-256 входов совпал с заданием до работы и после неё.

Выбран **design-front g2**, файл design/pirate-crewman-front.png. Размер инструмента — 1086 × 1448, аспект 3:4. Изображения сохранены побайтово, без правки пикселей; оригиналы инструмента оставлены на месте. Пути и хеши — в generation-records.json.

Использовано **2 из 2** генераций. g1: код 0, 12 PASS / 1 WARN / 0 FAIL; визуально видна верхняя плоскость подставки. g2 и финальный прогон: код 0, 13 PASS / 0 WARN / 0 FAIL. Выбран g2 из-за исправленного ракурса подставки. Топор в собственной правой руке, слева для зрителя; бандана, повязка, полосатая рубашка и зазоры между руками и корпусом читаются.

Что не выполнено: латунная серьга не читается уверенно. Латунные пряжки не заменяют заданную серьгу; пункт палитры CHECKLIST отмечен failed, лимит исчерпан и записан в verification.json → limit_reached. В обеих генерациях остался дополнительный меч в ножнах, нарушающий CORE. Низ подставки g2 — y94.406% вместо y93%; верх — y4.420%, центр — x50.000%. PASS скрипта не подтверждает выполнение всех визуальных требований.

Решения: повтор вызван ракурсом, а не допустимым WARN верхнего поля. CORE сохранён дословно; одна строка CORRECTION исправляла только фронтальный ракурс. При исчерпанном лимите оставлен лучший кандидат. Нечитаемая серьга не объявлена выполненной. Межвидовая согласованность не оценивалась: на этапе 1a один вид.

Записи выполнены только внутри пакета. Git, Unreal, Tripo, SYNTX и загрузки не использовались. npx openskills read недоступен в локальном кэше; навык прочитан напрямую с диска, без установки. Приёмку и коммит выполняет Claude.
