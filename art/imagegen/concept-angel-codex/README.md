# ASSET-ANGEL-001 — виды концепта 1c

Статус: **предложено**.

Последовательно созданы front, side и back поверх разрешённых черновых ортопроекций. Одобренный design/angel-front.png передан вторым референсом каждого вызова; выбранный angel-side.png — третьим референсом back. Изображения созданы встроенным image_gen: один вызов на каждый вид, размер не задан, CORE неизменён.

Выбраны:

- **front g1** — angel-front.png: фронтальный вид, поза и меч слева для зрителя совпадают с черновиком; чёрная кожа и лицо перенесены с одобренного дизайна.
- **side g1** — angel-side.png: собственный левый профиль, лицо к левому краю; ближняя левая рука свободна, меч в дальней правой.
- **back g1** — angel-back.png: строгий вид со спины, лица нет, меч справа для зрителя; материал и детали согласованы с side.

Использовано по одной генерации из двух разрешённых для каждого вида. Отдельные проверки front/side: 12 PASS, 0 WARN, 0 FAIL; back: 11 PASS, 1 WARN, 0 FAIL. Финальный checks-report.json и sheet-angel.png: **код 0, 32 PASS, 1 WARN, 0 FAIL**. Лист и каждый исходный PNG просмотрены.

Что не удалось воспроизвести точно: численные границы рамки и абсолютный тон фона. Наибольшее отклонение рамки — ширина подставки back: 67,495% вместо 68,2% (0,705 процентного пункта); оценка её верха 88,122% вместо 87,7%. Эти измерения и остальные небольшие отклонения перечислены в verification.json. Визуальная оценка рамки пройдена; математической идентичности исходным орто не заявляется. WARN view.single_component на back относится к сегментации тёмной поверхности; это не FAIL и не повод для ретрая. Невыполненных визуальных пунктов CHECKLIST нет, limit_reached пуст.

Первый вызов сохранения front сорвался на кавычках PowerShell; последующая преждевременная проверка не нашла ещё не скопированный файл и не создала отчёт. Исправлена передача данных в Python; тот же PNG сохранён без изменения и проверен успешно. Ошибочный запуск и его текст записаны в verification.json.

Малые решения: оставлены первые кандидаты, поскольку валидные проверки и визуальный CHECKLIST пройдены; WARN не исправлялся. side_view=left у side и null у front/back. Рубашка на back закономерно закрыта плащом. Принята вариация мелкой фактуры между видами, без нового оружия и анатомии.

Все шесть входов неизменны по SHA-256. Прежние кандидаты 1a, design/, palette.json и их отчёты сохранены. История исходных хешей и генераций дополнена; прежняя verification сохранена внутри previous_runs, прежние промпты и README сохранены ниже/в своих файлах. Новые JSON и Markdown записаны Python как UTF-8 без BOM.

PNG в concepts/ созданы без перезаписи и побайтно равны собственным оригиналам image_gen; выбранные angel-*.png побайтно равны кандидатам. Оригиналы инструмента оставлены на месте и записаны в original_path. Все записи путей пакета относительно корня репозитория с прямыми слешами. Все записи этой задачи на диск — внутри пакета, кроме явно разрешённых собственных копий image_gen.

Команд git, доступа к Unreal, Tripo, SYNTX, загрузок и фоновых процессов не было. manifest-sha256.json записан последним. Художественную приёмку и коммит выполняет Claude.

# ASSET-ANGEL-001 — концепт 1a

Статус: **предложено**.

Созданы два фронтальных дизайна миниатюры Angel встроенным image_gen. Единственный визуальный вход — указанный эталон мастерства Medusa; palette.json задаёт цвета и не является изображением для генератора. Входы сохранены без изменений. CORE передан дословно; g2 содержит одну дополнительную строку CORRECTION.

Для design-front выбран **g2**: art/imagegen/concept-angel-codex/design/angel-front.png — побайтовая копия art/imagegen/concept-angel-codex/concepts/angel-design-front-g2.png. Размер 1086 × 1448, аспект 3:4. Причина выбора: подставка показана с ребра без видимой верхней плоскости. Шесть пунктов CHECKLIST выбранного изображения визуально пройдены.

g1: 13 PASS, 0 WARN, 0 FAIL, но визуально видна узкая верхняя поверхность подставки. Это единственная причина повторной генерации. g1 и его отдельный отчёт сохранены.

g2 и финальный прогон: код выхода 0, 12 PASS, 1 WARN, 0 FAIL. WARN view.single_component относится к автоматическому выделению частей тёмной фигуры и меча; визуально в кадре одна фигура. Задание разрешает WARN.

**Что не удалось:** у g2 две низкие ступени подставки не читаются; она выглядит единым диском. Это невыполненное требование CORE.PEDESTAL.two_low_stacked_discs. Две разрешённые генерации использованы; результат оставлен без ручных исправлений для решения приёмщика. limit_reached в verification.json пуст: он относится только к проваленным пунктам CHECKLIST. Невыполненное требование CORE записано отдельно в unmet_requirements с отметкой об исчерпанном лимите.

Малые решения: выбран g2 ради правильного вида подставки с ребра; side_view равен null, поскольку создан только фронт. Воротник, складки и оформление клинка изменились самим генератором, без изменения CORE; это перечислено в prompts.md. Измеренные отклонения рамки также сохранены в verification.json: низ y=92.265% вместо 93%, центр x=49.678% вместо 50%.

Первое обращение с относительным путём эталона было отклонено при разборе AbsolutePathBuf до создания изображения. Путь развёрнут в абсолютный; затем выполнены две успешные генерации. Ошибка записана в tool_errors; она не считается созданной генерацией.

Каждый PNG в concepts/ побайтно равен собственному исходнику image_gen; исходники инструмента оставлены на месте. Выбранный design/ также проверен побайтно. Изображения не ретушированы, не масштабированы, не обрезаны, не перекрашены и не перекодированы. palette.json не изменён. Все новые текстовые файлы написаны из Python в UTF-8 без BOM.

Сохранены точные промпты, записи генераций, отдельные отчёты кандидатов, финальный design/checks-report.json, входные хеши, verification.json и manifest-sha256.json. Команд git, доступа к Unreal, Tripo, SYNTX, загрузок и фоновых процессов не было. Художественную приёмку и коммит выполняет Claude.
