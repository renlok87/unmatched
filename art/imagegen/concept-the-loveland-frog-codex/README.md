# Loveland Frog — концепт 1a

Статус: **предложено**. Карточка: ASSET-THE-LOVELAND-FROG-001. Дата: 2026-10-13.

Создан один фронтальный дизайн коллекционной миниатюры через image_gen. Единственный вход изображения — указанный референс мастерства; palette.json сохранён без изменений. CORE передан дословно. Использованы две разрешённые генерации, по одному изображению в вызове.

Выбрана **design-front g2**, 1086 × 1448: design/the-loveland-frog-front.png — побайтовая копия concepts/the-loveland-frog-design-front-g2.png. Подставка g2 показана с ребра, верхняя поверхность не видна; широкий раскрытый рот и перепончатая раскрытая кисть читаются ясно. Обе руки отделены от корпуса. Собственные копии image_gen оставлены на месте; абсолютные пути и хэши записаны в generation-records.json. Ни одно изображение не ретушировалось, не масштабировалось, не обрезалось, не перекрашивалось и не перекодировалось.

g1 сохранена для сравнения. Скрипт завершился кодом 0, но визуально была видна узкая верхняя поверхность подставки и замечена слабая неоднородность фона. Повтор получил две строки CORRECTION только для этих пунктов, без изменения CORE. Фон g2 визуально ровный; p99 отклонения цвета на рамке — 2 уровня RGB.

Отчёты кандидатов: checks/design-front-g1/checks-report.json и checks/design-front-g2/checks-report.json. Финальная проверка g2 без --out: **код 0, 13 PASS, 0 WARN, 0 FAIL**; отчёт design/checks-report.json. Визуальный чек-лист записан отдельно в verification.json.

**Не выполнено:** «No weapon or held object». Фигура держит искрящуюся палочку, обязательную одновременно в SUBJECT и IDENTITY ANCHORS. Запрет в POSE и чек-листе противоречит этому требованию. CORE оставлен дословно; запрет не выполнен. Лимит 2/2 исчерпан; пункт записан в limit_reached. Решение остаётся за приёмщиком.

Другие отклонения CORE записаны в verification.json: янтарные радужки и коричневые шнуры вне заданной палитры; измеренный низ подставки g2 — y94.268% при цели y93%. Заданные основные цвета и голубой акцент присутствуют; командной окраски, цветного кольца и металлической полосы на основании нет.

Небольшие решения: выбрана g2 за более точную подставку и читаемый рот; сохранён предложенный генератором оливковый рваный плащ; отклонения задокументированы без правки изображения. Других проекций на этапе 1a нет. Статус художественной приёмки не присваивался.

Хэши обоих входов до и после совпадают; palette.json сохранён побайтово. Все ручные записи находятся в этой папке. Git, Unreal, Tripo, SYNTX и загрузки не использовались. Полные промпты — в prompts.md и prompts/concept-prompts.json; manifest-sha256.json записан последним.
