# Wiglaf — концепт 1a

Статус: **предложено**. ASSET-WIGLAF-001, 2026-10-13.

Созданы два самостоятельных фронтальных дизайна миниатюры. Единственный визуальный вход — эталон качества Medusa; палитра прочитана из palette.json. CORE передан без изменений; повтор добавляет только двухстрочный CORRECTION. Размер инструменту не задавался. Этапы 1b/1c не выполнялись.

Выбран **design-front g2**: design/wiglaf-front.png — побайтовая копия concepts/wiglaf-design-front-g2.png. Щит стал фронтальнее, верхняя плоскость подставки значительно уменьшилась; топор, кабан, конический шлем и палитра читаются. Оба кандидата сохранены без обработки, автоматические оригиналы image_gen оставлены на месте. Пути и SHA-256 записаны в generation-records.json.

Каждый кандидат и финальный выбор прошли скрипт: код 0, 12 PASS, 1 WARN, 0 FAIL. WARN view.frame_top: g1 3,177%, g2 3,660% вместо 4%; он не послужил причиной повтора. В g1 визуально нарушены проекция подставки и видимость зазоров рук.

Лимит **2/2** исчерпан. В g2 остались два failed пункта CHECKLIST: строгая проекция подставки точно ребром (узкая верхняя полоска ещё видна) и видимые зазоры у обеих рук (их закрывают плащ и щит). Код 0 скрипта не отменяет визуальные ограничения. Они записаны в verification.json / limit_reached; решение о приёмке оставлено приёмщику.

Мелкие решения: выбрать более фронтальный g2; светлый нейтральный кабан на приглушённом красном поле считать допустимым представлением красного акцента; не ретушировать изображения. Скрипт запущен ровно трижды, без --sheet. Отчёты кандидатов сохранены отдельно. npx openskills недоступен из-за отсутствующего npm-кеша; навык прочитан напрямую из локальных файлов.

Хеши двух входов совпали с заданием и проверены после работы; palette.json не изменён. Команды задачи писали только внутри пакета; автоматические оригиналы image_gen — разрешённое договором исключение. Git и Unreal не использовались. Коэффициент приёмки не оценивался.
