# Wiglaf — концепт 1c: front / right side / back

Статус: **предложено**. ASSET-WIGLAF-001, 2026-10-15. Выполнена задача `docs/game-design/visual/06-tasks/prompts/ASSET-WIGLAF-001-concept-views.codex.md` встроенным `image_gen.imagegen`, по одному виду за вызов. Изображения: 1086×1448; размер не передавался, аспект 3:4 указан только в CORE.

Выбраны **front g1** → `wiglaf-front.png`, **right side g1** → `wiglaf-side.png`, **back g2** → `wiglaf-back.png`. Front и side сохраняют ракурс, силуэт и позу соответствующего чернового орто, топор в собственной правой руке и щит слева; видимые материалы и детали перенесены с принятого design-front. Для side использован именно `ortho_right.png`: лицо смотрит вправо, хват топора открыт. В back оба раза третьим входом был выбранный готовый side.

Использовано вызовов: front **1/2**, side **1/2**, back **2/2**. Причина единственного повтора — визуальная ошибка back g1: красная наружная роспись с кабаном оказалась на внутренней поверхности щита под рукой. Back g2 исправляет её на некрашеное дерево с внутренним хватом. G1 сохранён; численная проверка сама эту ошибку не обнаружила. У выбранных видов failed пунктов CHECKLIST нет; `limit_reached=[]`.

Все четыре проверки кандидатов: **exit 0**, каждая 12 PASS / 0 WARN / 0 FAIL. Итоговая проверка выбранного набора с палитрой и листом: **exit 0, 33 PASS / 0 WARN / 0 FAIL**. `sheet-wiglaf.png` просмотрен: спереди топор слева от зрителя, сзади справа; профиль правый, лицо в back не видно, подставки и фон согласованы. Отчёты кандидатов раздельные, итог — `checks-report.json`. Проверки не повторялись ради WARN или микродеталей.

Ограничения и мелкие решения: верх side измерен на 4,8% вместо заданных орто 5,8%; проверки кадрирования и набора проходят, поэтому вид не перегенерировался и не подгонялся. Фактура плаща, волосы, складки и мелкий орнамент остаются интерпретацией генератора; попиксельное совпадение и скульптурная тождественность не доказаны. Кабан виден на лицевой стороне щита; изнутри роспись не добавлялась. Это только 2D-концепты: геометрия, топология, риг, размеры и пригодность для игры не проверялись. Приёмка остаётся за приёмщиком.

Все четыре сырых PNG сохранены в `concepts/` побайтово; три выбранных файла также побайтовые копии. Ретуши, ресайза, обрезки, перекраски и пересохранения PNG не было. Автоматические оригиналы image_gen оставлены на месте, их абсолютные пути и хеши записаны. Лист проверки — отдельная производная, он не заменяет оригиналы.

Шесть входов сверены с заданием и после работы: SHA-256 не изменились. Прежние изображения 1a, design, палитра и отчёты не изменены. Старые записи и промпты сохранены; старый объект verification целиком находится в `previous_runs`. Метаданные до 1c дополнительно сохранены побайтово в `history/1c-20261015-054952/preexisting-metadata/`, включая прежний manifest. Точные промпты — `prompts.md` и `prompts/concept-prompts.json`; происхождение и ограничения — `generation-records.json` и `verification.json`.

Все явные записи этой работы — внутри пакета; разрешённое исключение — автоматические оригиналы встроенного image_gen в CODEX_HOME. Git, внешние сервисы, Unreal и дополнительные агенты не использовались; фоновых процессов не запускалось. Ниже предыдущий README 1a сохранён без изменений.

# Wiglaf — концепт 1a

Статус: **предложено**. ASSET-WIGLAF-001, 2026-10-13.

Созданы два самостоятельных фронтальных дизайна миниатюры. Единственный визуальный вход — эталон качества Medusa; палитра прочитана из palette.json. CORE передан без изменений; повтор добавляет только двухстрочный CORRECTION. Размер инструменту не задавался. Этапы 1b/1c не выполнялись.

Выбран **design-front g2**: design/wiglaf-front.png — побайтовая копия concepts/wiglaf-design-front-g2.png. Щит стал фронтальнее, верхняя плоскость подставки значительно уменьшилась; топор, кабан, конический шлем и палитра читаются. Оба кандидата сохранены без обработки, автоматические оригиналы image_gen оставлены на месте. Пути и SHA-256 записаны в generation-records.json.

Каждый кандидат и финальный выбор прошли скрипт: код 0, 12 PASS, 1 WARN, 0 FAIL. WARN view.frame_top: g1 3,177%, g2 3,660% вместо 4%; он не послужил причиной повтора. В g1 визуально нарушены проекция подставки и видимость зазоров рук.

Лимит **2/2** исчерпан. В g2 остались два failed пункта CHECKLIST: строгая проекция подставки точно ребром (узкая верхняя полоска ещё видна) и видимые зазоры у обеих рук (их закрывают плащ и щит). Код 0 скрипта не отменяет визуальные ограничения. Они записаны в verification.json / limit_reached; решение о приёмке оставлено приёмщику.

Мелкие решения: выбрать более фронтальный g2; светлый нейтральный кабан на приглушённом красном поле считать допустимым представлением красного акцента; не ретушировать изображения. Скрипт запущен ровно трижды, без --sheet. Отчёты кандидатов сохранены отдельно. npx openskills недоступен из-за отсутствующего npm-кеша; навык прочитан напрямую из локальных файлов.

Хеши двух входов совпали с заданием и проверены после работы; palette.json не изменён. Команды задачи писали только внутри пакета; автоматические оригиналы image_gen — разрешённое договором исключение. Git и Unreal не использовались. Коэффициент приёмки не оценивался.
