# ASSET-BUFFY-001 — фронтальный концепт Buffy

Статус: **предложено**.

Создан один вариант нового дизайна миниатюры, этап 1a. Выбран **design-front g1**: это единственный кандидат, все признаки персонажа и палитра видны; оружие находится в собственной правой руке, слева для зрителя. Руки отделены от корпуса, фигура и подставка не обрезаны.

Выбранный файл: `design/buffy-front.png`; исходная генерация: `concepts/buffy-design-front-g1.png`. Это побайтно одинаковые копии результата image_gen размером 1086 × 1448. Оригинал инструмента сохранён; оба пути и SHA-256 есть в generation-records.json.

Использовано **1 из 2** разрешённых генераций. Первая команда копирования не выполнилась из-за передачи кавычек PowerShell в Python; следующая проверка получила отсутствующий каталог design. Эта ошибка входа записана в verification.json; новые генерации после неё не запускались. Копирование исправлено для сохранения уже полученного результата и оформления пакета.

Автопроверка кандидата и финальная автопроверка выбранного файла: **код 0, 12 PASS, 1 WARN, 0 FAIL**. WARN `view.frame_top`: верхняя точка на 2,555% высоты вместо минимум 4%. Низ подставки — 96,754% вместо заданных 93%; центр — x49,954%. Эти отклонения явно записаны как ограничения, изображение не нормализовалось.

Не пройден один пункт визуального CHECKLIST: **верхняя поверхность подставки видна**, передняя кромка слегка дугообразная; строго горизонтальная ортопроекция не получилась. Пакет не утверждён художественно и передаётся приёмщику с этим дефектом. Лимит генераций не исчерпан; limit_reached пуст, причина остановки — ошибка входа.

Мелкие решения: side_view = null для фронта; обе ступени считаются одной подставкой; мелкая приглушённая фурнитура куртки и украшение допускаются без дополнительного сильного цвета. Межвидовая проверка неприменима: создан один дизайн, этап 1c не выполнялся.

Оба входа сохранили исходные SHA-256. Palette.json оставлен без изменений. Все текстовые файлы записаны Python в UTF-8 без BOM; манифест записан последним. Git, Unreal, Tripo, SYNTX и загрузки не использовались.
