# ASSET-SINBAD-001 — концепт 1a

Дата: 2026-10-13. Статус: **предложено**.

Создан один фронтальный дизайн Синдбада для image-to-3D: два исходных PNG-кандидата от image_gen. Единственное изображение-референс — Медуза из задания, только как образец качества миниатюры. Палитра прочитана из palette.json и сохранена без изменения. Карточка ассета, коммерческие изображения и другие ассеты не открывались.

## Выбор

Для вида design-front выбрана **g2**: concepts/sinbad-design-front-g2.png, её побайтовая копия — design/sinbad-front.png. g2 показывает подставку ребром без видимой верхней плоскости; все шесть пунктов CHECKLIST визуально пройдены. Это предложение для последующей приёмки, а не художественное утверждение.

g1 получила код 0 скрипта (12 PASS, 1 WARN), но не прошла визуальный пункт о подставке: верхняя плоскость была видна. На g2 CORE оставлен дословно, добавлена только одна строка CORRECTION по этому пункту. g1 сохранена без перезаписи. Внешность, орнамент, клинок, ножны и складки одежды между независимыми генерациями немного изменились; референс и CORE одинаковые.

## Проверки и ограничения

Всего использовано **2 из 2** разрешённых генераций. Оба кандидатных прогона и финальный прогон выбранной g2 завершились кодом **0**: 12 PASS, 1 WARN, 0 FAIL. Отчёты кандидатов находятся в checks/design-front-g1/ и checks/design-front-g2/; окончательный — design/checks-report.json.

У g2 остаётся WARN view.frame_top: 3,522% вместо минимум 4%. Низ подставки — 94,751% вместо заданных 93%; центр — 49,678%. Аспект ровно 3:4, размер 1086×1448 выбран инструментом. Диаметр подставки визуально около 0,63 высоты фигуры вместо «about 0.55».

**Нарушение CORE:** над ножнами видна дополнительная рукоять с гардой, похожая на второе оружие. Оно не входит в отдельные шесть пунктов CHECKLIST; отмечено в verification.json#limitations как CORE.FORBIDDEN.extra_weapons. Эта деталь есть в обоих вариантах, новые генерации не разрешены. Приёмщик решает, допустим ли кандидат.

Визуальных провалов CHECKLIST у выбранной g2 нет, поэтому verification.json#limit_reached — пустой список. Это не означает полного соблюдения CORE: отклонения перечислены выше и в verification.json.

## Принятые мелкие решения

- side_view = null: выполнен только дизайн-front этапа 1a; боковой слот здесь не выбирается.
- mode = generate: входная Медуза служит референсом качества, а не объектом редактирования.
- Для имён кандидатов использованы свободные g1 и g2; до начала пакет содержал только palette.json.
- Повтор выполнен только из-за визуального провала CHECKLIST; WARN не был причиной повторной генерации.
- Результаты скопированы побайтово. Ретушь, кадрирование, перекодирование, изменение размеров и цвета не выполнялись.
- Оригиналы image_gen оставлены на месте; абсолютные пути записаны в generation-records.json. Остальные пути в записях — относительно корня репозитория.
- Выполнены только действия внутри пакета; исключение — разрешённое заданием сохранение оригиналов самим image_gen. git, Unreal, Tripo, SYNTX и загрузки не использовались.
- Фоновые процессы не запускались; команды Python завершились.

prompts.md и prompts/concept-prompts.json содержат точные промпты. source-hashes-before.json и verification.json фиксируют неизменность обоих входов. manifest-sha256.json записан последним и покрывает все остальные файлы пакета.
