# Томоэ Годзэн — дизайн фронта, этап 1a

Статус: **предложено**. Карточка: ASSET-TOMOE-GOZEN-001. Дата: 2026-10-13.

Сгенерирован один оригинальный концепт премиальной окрашенной миниатюры Томоэ Годзэн. Единственный графический вход — эталон мастерства Medusa; его дизайн не переносился. Палитра прочитана из неизменённого palette.json. CORE передан дословно, без CORRECTION, без размера в пикселях; аспект 3:4 указан только в тексте. Инструмент: image_gen.imagegen, встроенный режим generate.

Выбран **design-front g1**: `concepts/tomoe-gozen-design-front-g1.png`. Он побайтно скопирован в `design/tomoe-gozen-front.png`; это единственный кандидат. Размер оригинала — 1086 × 1448. Нагината в правой руке фигуры, слева для зрителя. Видимы красные доспехи о-ёрой, белая повязка, длинные чёрные волосы, синие шнуры и золотая отделка. Детализация литья и окраски подходит для предложенного дизайна.

Финальный скрипт проверки завершился с кодом **0**: 12 PASS, 1 WARN, 0 FAIL. Отчёт выбранного дизайна: `design/checks-report.json`. Отдельный отчёт кандидата: `checks/design-front-g1/checks-report.json`. WARN view.frame_top: верх маски находится на y=1,519% вместо не менее 4%. WARN сам по себе не основание для ретрая.

## Что не выполнено

- Визуальный пункт о строгой ортогональности подставки не выполнен: видна узкая верхняя поверхность, край слегка изогнут.
- Генератор добавил меч в ножнах на поясе; CORE запрещает дополнительное оружие.
- Низ подставки — y=95,994% вместо y93%; центр по x=49,954%. Подставка визуально шире ориентировочного отношения 0,55 высоты фигуры.
- Исходная команда сохранения метаданных не прошла из-за обработки кавычек PowerShell. Проверка была ошибочно запущена до успешного копирования и сообщила об отсутствующей папке design. Ошибка и доступный код оболочки записаны в verification.json. После исправления копирования кандидат и выбранный файл проверены успешно.

Использована **1 генерация из 2 разрешённых**. После первоначальной ошибки входа проверки дальнейшие генерации остановлены согласно заданию. Бюджет не исчерпан: `limit_reached` пуст, а незакрытый визуальный пункт и причина отсутствия ретрая явно записаны в verification.json. Это предложенный дизайн с ограничениями, решение о приёмке принимает приёмщик.

## Решения и сохранность

Фронтальный вид обозначен `design-front`, `side_view = null`; других видов нет. Выбор g1 обусловлен наличием только одного кандидата и успешной финальной автопроверкой, а не полным выполнением визуальных требований.

Оригинал image_gen оставлен на месте; его абсолютный путь, путь копии, хеш, размер и точный промпт записаны в generation-records.json и prompts/concept-prompts.json. Ни оригинал, ни копии не ретушировались, не обрезались, не масштабировались и не перекодировались. palette.json сохранён побайтно. Все созданные агентом файлы находятся в этой папке; git и unreal не использовались. Долгоживущих процессов не запускалось.

manifest-sha256.json записан последним и содержит SHA-256 и размер каждого файла пакета, кроме самого манифеста.
