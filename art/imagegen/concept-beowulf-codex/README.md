# ASSET-BEOWULF-001 — концепт 1c

Статус: **предложено**. Дата: 2026-10-14.

Созданы front, side (строгий левый профиль) и back поверх черновых ортопроекций этапа 1b. Использован встроенный image_gen в режиме edit/style-transfer: один вызов, одно изображение, один вид. Порядок — front → side → back. Для каждого вида использованы 2 из 2 разрешённых генераций; всего 6 новых изображений. Вместе с двумя сохранёнными кандидатами design-front этапа 1a в журнале 8 генераций. Параметр размера не передавался; все результаты инструмента имеют 1086×1448 и аспект 3:4. CORE каждого вида не менялся, повтор добавлял только CORRECTION.

Выбраны:
- **front g2** — восстановлен тёмный камень подставки вместо светлого g1; герой, оружие и палитра сохраняются.
- **side g1** — отделка шлема и положение оружия лучше согласованы с принятым дизайном. У g2 подставка ближе по размеру к орто, но меняются отделка шлема и видимость гарды возле торка.
- **back g2** — исправлены длинные кольчужные рукава g1, кожа между короткими рукавами и наручами снова видна. Оба back использовали именно выбранный side g1 третьим референсом.

Файлы beowulf-front.png, beowulf-side.png и beowulf-back.png — побайтные копии выбранных concepts/. Каждый кандидат имеет собственный отчёт checks/<view>-g<N>/checks-report.json; ни один concepts/ не перезаписан. Все оригиналы image_gen оставлены на своих местах. Ретушь, изменение размера, обрезка, перекраска и повторное кодирование кандидатов не выполнялись. Единственный составной лист — sheet-beowulf.png, штатный производный отчёт checker.

Все шесть отдельных проверок завершились кодом 0 (каждая 12 PASS, 0 WARN, 0 FAIL). Финальная проверка выбранного набора завершилась кодом **0: 33 PASS, 0 WARN, 0 FAIL**. Лист и каждое изображение осмотрены. Межвидовые проверки: разница низа подставок 0.138 процентного пункта высоты, центра 0.046 процентного пункта ширины; разброс роста 0.306%, медиан фона 1 RGB.

**Что не закрыто.** Автоматический PASS не доказывает точное следование орто. У каждого выбранного вида остаются проваленные пункты CHECKLIST: точное сохранение силуэта (особенно ширины/острия клинка), буквальное совпадение рамки и строго одинаковая плоская заливка фона. Фон визуально почти ровный, но контрольные RGB различаются на 1–3 уровня; медианы 42–43 вместо исходных 46. Верх выбранных видов: front 4.213%, side/back 3.936% вместо 4.0%; верх подставки ~86.1–86.2% вместо 85.9%. У side g1 ширина подставки 63.444% вместо исходных 64.275%. Эти замечания и limit_reached для всех трёх видов записаны в verification.json; лимит исчерпан, решения о приёмке здесь нет. Кольчуга по-прежнему содержит подробные кольца вместо полностью крупных плоских пятен.

Небольшие решения: side_view = left для боковых генераций, null для front/back; выбран side g1 по согласованности костюма, несмотря на более узкую подставку. Строгие требования не заменены допусками checker. При скрытой за щитом правой кисти профиль оценивается по орто и согласованности с фронтом; геометрия камеры — только визуально. Сторона меча верна: на фронте слева для зрителя, со спины справа.

Шесть исходников сверены до и после; их хэши совпадают с заданием. Содержимое palette.json, design/ и прежних candidates/checks не изменено. История 1a сохранена в старых записях журналов и в previous_runs verification.json; прежние README и prompts.md сохранены ниже/перед новой секцией. Новые записи используют пути от корня репозитория с прямыми слешами; tool-originals имеют абсолютные пути. В вызовах image_gen относительные пути разрешались через абсолютный корень репозитория.

Все управляемые записи ограничены этим пакетом. Git, Unreal, Tripo, SYNTX и скачивания не использовались. Попытка запуска npx openskills завершилась ENOTCACHED без загрузки; навык прочитан локально. Два служебных сбоя формирования python -c/записи финального отчёта устранены до соответствующих записей, они не являются ошибками checker и не требовали новых генераций. Фоновые процессы не запускались; все команды завершены.

# ASSET-BEOWULF-001 — концепт 1a

Статус: **предложено**. Дата: 2026-10-13.

Создан один фронтальный дизайн коллекционной расписанной миниатюры Беовульфа. Инструмент — встроенный image_gen, режим generate. Единственное изображение на входе — эталон качества Medusa; palette.json задаёт цвета. CORE передан без изменений. Использованы две генерации из двух разрешённых.

Для design-front выбран **g2**: design/beowulf-front.png — побайтная копия concepts/beowulf-design-front-g2.png. Оба кандидата и оригиналы инструмента сохранены, пиксели не менялись. G2 лучше показывает руки отдельно от корпуса и подставку с ребра; фон ровнее. Финальный checker: код 0, 13 PASS, 0 WARN, 0 FAIL. Все шесть пунктов CHECKLIST пройдены при визуальном осмотре.

У g1 видна верхняя плоскость подставки, мех/щит мешают просветам у рук, фон слегка неравномерен. Скрипт дал код 0 и WARN view.frame_top (верх 3,039% вместо 4%). Повтор вызван пунктами CHECKLIST, а не WARN. К CORE добавлен только CORRECTION из трёх строк.

Небольшие решения: выбрана g2 по читаемости; наклон щита допустим при фронтальном корпусе; side_view = null, поскольку этап 1a содержит только фронт. Командного цвета на подставке нет. Кольчуга детальнее крупных плоских пятен из CORE: это ограничение записано в verification.json для приёмщика. Геометрия камеры оценена визуально.

Хеши обоих исходников до и после совпадают; palette.json не изменён. Точные промпты, журнал генераций, три прогона checker и манифест сохранены. Проваленных пунктов CHECKLIST у выбранного файла нет: limit_reached = [].
