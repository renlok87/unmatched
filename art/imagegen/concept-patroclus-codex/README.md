# Патрокл — дизайн-front, этап 1a

Дата: 2026-10-13. Карточка: ASSET-PATROCLUS-001. Статус: **предложено**.

Созданы две генерации image_gen.imagegen с единственным графическим входом medusa-quality-reference.png. Палитра прочитана из неизменённого palette.json. CORE передан дословно; g2 содержит две строки CORRECTION.

Выбран **design-front g2**, файл design/patroclus-front.png: лицо фронтальное, фон ровнее, подставка ближе к ракурсу ребром, кадрирование лучше. Меч в правой руке персонажа, щит на левой, синий плащ и белый плюмаж сохранены. Оба кандидата и оригиналы инструмента сохранены, копии побайтно идентичны.

У g1 визуально отмечены поворот лица, видимая верхняя плоскость подставки и впечатление неоднородного фона. Обе проверки кандидатов и финальная проверка: код 0, PASS 12, WARN 1, FAIL 0.

**Не выполнено у g2:** полная невидимость верха подставки — остаётся узкая полоска за стопами и вдоль верхней кромки. Лимит 2/2 исчерпан; пункт записан в verification.json → limit_reached. Решение оставлено приёмщику.

WARN view.frame_top у g2: верх 3,384 % вместо минимум 4 %; допустимый WARN сам по себе не вызвал повтор. Низ подставки 93,715 % вместо 93 %, центр x49,724 % вместо x50 %. Аспект точный 3:4, 1086×1448; размер выбрал инструмент.

Малые решения: выбран g2 по фронтальности и кадрированию; side_view=null, поскольку есть только фронтальный дизайн; бронзовые узоры считаются орнаментом. Межвидовая согласованность не оценивалась. Между попытками менялись орнаменты, складки и форма деталей.

Входы проверены SHA-256 до и после. Ранее существовал только palette.json; его байты сохранены. Ретуши и перекодирования нет. Все записи агента — внутри пакета; разрешённое исключение — собственные оригиналы image_gen в штатном каталоге. Git, Unreal, Tripo, SYNTX и загрузки не использовались. manifest-sha256.json записан последним.
