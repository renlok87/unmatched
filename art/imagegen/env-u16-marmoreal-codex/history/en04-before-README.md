## Результат

Подготовлены маска настоящего поля, локальные маски четырёх фонарей и двух бра с их засветкой, два независимых варианта imagegen, скриптовая сборка и листы сравнения. **Рекомендую A как наиболее бережный кандидат для ревью.** Он удаляет четыре головы фонарей и два бра, оставляет каменные постаменты с простыми крышками и лучше сохраняет исходные формы окружения. Израсходован весь бюджет: A, B, A-R1, A-R2 — ровно четыре image-edit генерации, без SYNTX. Уточнения не приняты.

**Строгая приёмка не пройдена.** Пакет завершён как воспроизводимое предложение с честно зафиксированными ограничениями, а не как принятый ассет. Численные результаты находятся в [verification.json](verification.json).

## Решения по сборке

- Все изображения, включая вход с закрытым полем, неизменённые генерации и листы, находятся только в `scraped-data/derived/env-u16-marmoreal-codex/`. В этой папке пакета — только текст, JSON и скрипты.
- Поле — прямоугольник на плоскости доски, который в концепте виден трапецией. Маска расширена на 2% с округлением к целым пикселям внутри деревянной рамы. Координаты в `_tools/mask-spec.json` даны в реальных 1672×941 пикселях. Координаты C0 из paste-спецификации 1920×1080 переводятся множителем 1672/1920. Координаты шести фонарей из задания уже относятся к реальному изображению, повторно не масштабируются.
- Настоящая иллюстрация карты использовалась только для определения поля. Генератор получает исключительно концепт с закрытым серым полем. Никакая карта, герой или материал коммерческого цифрового издания не передаётся генератору.
- `marmoreal-lantern-mask.png` — головы, бра и связанные пятна света. Она не включает поле. Тела постаментов остаются, разрешённая правка внутри их области — удаление засветки и восстановление плоской каменной крышки.
- `marmoreal-remove-mask.png` включает также серое поле. Это необходимо для одновременного выполнения двух условий: поле #808080 и ноль отличий от исходного C0 вне маски удаления. Это исключение явно отмечено в проверке.
- Растушёвка направлена внутрь маски: расстояние до внешней границы / 6 px. Нулевой вес снаружи исключает хвосты Gaussian blur. В остальных областях финал берёт исходные байты RGB концепта. Деревянная рама, небо и остальное окружение не перерисовываются.
- Чтобы захватить дальние пятна свечения, локальная геометрическая маска дополнена процедурным поиском уменьшения тёплой хромы C0 → A в четырёх ограниченных областях. Порог, полигоны, расширение и SHA-256 A записаны в `_tools/mask-spec.json`. Этот шаг строит только маску; новые пиксели изображения не рисует.
- Исходные генерации сохранены без ретуши. Если инструмент возвращает другой размер, только копия для композита приводится к 1672×941 Lanczos; сырой файл остаётся неизменённым. Размер и SHA-256 каждой генерации указаны в `generation-records.json`.
- K1 ×0.65 — сравнение на плоскости изображения: масштаб 0.65 в центре прежнего холста. Пустой внешний край показан нейтральным тёмно-серым. Достройка краёв относится к EN-02; этот лист не заявляется как кадр Unreal или проверка его камеры.
- K2 — увеличенные кропы шести источников, а не новая сцена или рендер движка. Для каждого кропа в подписи указаны исходные координаты.
- Серые листы: sRGB → линейный RGB → Rec.709 Y (0.2126, 0.7152, 0.0722) → sRGB. Измерение L* использует ту же линейную Y и стандартную CIELAB-функцию.
- `_tools/draw_icons_v3_snapshot.py` скопирован побайтно, не исполняется и не меняется. Логика этой задачи находится в отдельном `_tools/build_plate.py`; исходный генератор и набор значков не менялись.

## Воспроизведение

Из корня проекта, без Git и без Unreal:

```powershell
$env:PYTHONDONTWRITEBYTECODE='1'
python art/imagegen/env-u16-marmoreal-codex/_tools/build_plate.py finalize --variant A
python art/imagegen/env-u16-marmoreal-codex/_tools/finish_review.py
python art/imagegen/env-u16-marmoreal-codex/_tools/verify_package.py
python art/imagegen/env-u16-marmoreal-codex/_tools/build_plate.py manifest
```

`prepare` выполняется один раз перед работой и отказывается заменять исходные хеши. `record --variant A --source <файл-инструмента>` сохраняет сырую генерацию без изменения байтов и отказывается её перезаписывать. Окончательный выбор — A.

`expand-masks` восстанавливает окончательные маски из C0 и неизменённой генерации A. `finish_review.py` восстанавливает **уже выполненную** запись визуального ревью; он не проводит новое автоматическое художественное ревью. После изменения изображения его заключения требуют повторного ручного просмотра.

Перед работой зафиксированы SHA-256 819 файлов: 10 входов и 809 файлов `hud-icons-v3/**`. Проверка происхождения входов по таблице задания — `_tools/input-provenance-check.json`. SHA-256 готового пакета и изображений — `manifest-sha256.json` (он исключает только сам себя). Временные файлы, которыми распоряжается встроенный imagegen, перечислены отдельно в `generation-records.json`; агент копирует их в разрешённую папку, не изменяя исходный файл инструмента.

### Что изменено и какие решения применены

1. **ВР-VS2-EN.1:** применяется односторонний R1, а не прежний абсолютный контраст пятна и кольца. Все R1–R3 проходят. Старые значения сохранены в `legacy_spot_ring_Lstar` с пометкой `superseded`; ради них тёмная листва не осветлялась.
2. **ВР-VS2-EN.2:** тёплый свет на ступенях, вазонах, косяках, защищённой деревянной раме и мостовой вне support сохранён ровно как в C0. Исключения R4 определены по ≥50% внешней полосы на защищённой раме или в пределах 40 px от двери; список ячеек до и после приведён полностью в verification.
3. **ВР-VS2-EN.3:** маска перестроена из полигонов полных голов четырёх фонарей и двух бра, включая тёмный металл; полигоны поставлены по C0 при 4×. Расширение 2 px и мягкий край 2,5 px получены евклидовым distance field, без крестообразной/квадратной binary dilation. Свечение вычислено точно по заданной разнице L*/b* C0 и финальной плиты, с окнами 260/130 px, smoothstep от 0,6R до R, Gaussian sigma 3 px и отсечкой значений <8/255. После blur вновь ограничен радиус каждого источника; зоны пересечения учитываются объединением радиусов. Итог ограничен remove-mask и обнулён на поле. Полные полигоны не уменьшались ради формального прохождения проверки.
4. **ВР-VS2-EN.4:** использована **одна из двух** разрешённых image-edit генераций, SYNTX 0. Правка только SW: кроп `[56,393,248,585)` 192×192 px, без единого пикселя поля, увеличен Lanczos до 1024×1024. Встроенный imagegen вернул 1254×1254; его PNG скопирован без изменения байтов. Для композита копия уменьшена Lanczos до 192×192 и вклеена только через локальный полигон с растушёвкой 8 px внутрь; каменная крышка вне полигона. Текст запроса соответствует заданию, Forbidden сохранён дословно. NW/NE/SE дополнительно не генерировались: на исходном листе доработки я увидел листву, а не крышу/навершие/крюк.

Шов исправлен ровно по предписанному алгоритму: для семи неосвобождённых ячеек с s>4 и областей по 32 px вокруг них альфа равна `min(remove/255, smoothstep(distance/32))`. В остальных местах альфа прежняя. Основа композита — C0 и неизменённый A-raw, затем SW-патч, затем поле #808080. Геометрия, формулы и координаты записаны в [_tools/mask-spec.json](_tools/mask-spec.json); весь код доработки — [_tools/rework_r3.py](_tools/rework_r3.py).
