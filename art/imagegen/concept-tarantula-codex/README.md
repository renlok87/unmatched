# ASSET-TARANTULA-001 — концепт 1a

Статус: **предложено**. Подготовлен один фронтальный дизайн новой миниатюры Тарантула; выполнены две отдельные генерации встроенным `image_gen.imagegen`. Это пакет для последующей приёмки дизайна.

## Выбранный дизайн

Для вида `design-front` выбран **g1**: `design/tarantula-front.png` — побайтная копия `concepts/tarantula-design-front-g1.png`. В нём лучше читаются восемь толстых ног с оранжевыми полосами, волосатое тело, блестящие чёрные глаза и клыки. Сохранён премиальный вид окрашенной смоляной миниатюры. Оба исходных PNG имеют размер 1086 × 1448; размер инструменту не задавался.

g1 прошёл проверку кандидата с кодом 0: 13 PASS, 0 WARN, 0 FAIL. Визуальный пункт строгой ортографии подставки не пройден: видна узкая верхняя поверхность диска, нижняя кромка слегка выгнута.

g2 получен с неизменным CORE и одной строкой CORRECTION на положение подставки. Он также прошёл автопроверку с кодом 0: 13 PASS, 0 WARN, 0 FAIL. Подставка исправилась, но восемь полосатых ног не читаются: передняя пара стала короткой и без оранжевых полос. Поэтому выбран g1 — сохранение анатомических опорных признаков важнее улучшения одного элемента подставки.

Финальная проверка выбранного g1 выполнена без `--out`: `design/checks-report.json`, код 0, 13 PASS, 0 WARN, 0 FAIL. Автопроверка не определяет число ног и геометрию камеры; визуальный чек-лист сохранён отдельно в `verification.json`.

## Что осталось невыполненным

Лимит этого запуска исчерпан: **2/2**. У выбранного g1 остаётся непройденный пункт CHECKLIST `front_orthographic`; он записан в `verification.json#limit_reached`. Дизайн передаётся приёмщику с этой пометкой.

Дополнительно CORE выполнен не во всех геометрических деталях: низ подставки измерен на y90,608 % вместо y93 %; её диаметр визуально около 0,92 высоты самого паука вместо около 0,55. Несколько концов ног находятся вне подставки либо выше её верхней границы, поэтому равномерная опора не подтверждена. Эти ограничения записаны в `verification.json#core_constraints`; отсутствие FAIL скрипта их не отменяет.

## Принятые небольшие решения

- Формулировки CORE «both feet / both arms» сохранены дословно. Для визуального пункта разделения конечностей проверялась передняя пара паучьих ног; человеческая анатомия не добавлялась.
- g2 использует только исходный референс Медузы, как требует задание. g1 не подавался в инструмент как дополнительный вход.
- Референс Медузы применялся только к качеству скульптуры, покраски и студийной подаче; паук, его палитра и поза заданы CORE.
- При недоступном `npx openskills read` из-за отсутствия npm-кэша прочитан локальный файл скилла; ничего не устанавливалось.

## Состав и сохранность

`concepts/` содержит оба неизменённых результата инструмента; `checks/design-front-g1/` и `checks/design-front-g2/` — отдельные отчёты кандидатов. `generation-records.json` фиксирует пути оригиналов, SHA-256, размер, референс, коррекцию и выбор. Точные промпты находятся в `prompts.md` и `prompts/concept-prompts.json`.

Оба входных SHA-256 до и после совпадают с заданием. Ранее существовавший `palette.json` сохранён побайтно. Все записи задания выполнены внутри пакета; автоматические оригиналы `image_gen` оставлены по их исходным путям. PNG не ретушировались, не масштабировались, не обрезались, не перекрашивались и не перекодировались. Git-команды не выполнялись. Файлы `unreal/` не открывались и не менялись. Последним записан `manifest-sha256.json`.
