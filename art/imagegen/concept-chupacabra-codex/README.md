# ASSET-CHUPACABRA-001 — концепт 1a

Статус: **предложено**.

Выполнен один фронтальный дизайн коллекционной миниатюры Чупакабры. Использован встроенный image_gen.imagegen, две генерации из двух разрешённых. Единственный графический референс — medusa-quality-reference.png, только для качества лепки и покраски; палитра взята из неизменённого palette.json.

Для вида design-front выбран **g2**: design/chupacabra-front.png — побайтовая копия concepts/chupacabra-design-front-g2.png. Размер обоих кандидатов 1086 × 1448, аспект 3:4. У g2 подставка показана ребром без видимой верхней плоскости, лицо направлено в камеру, руки отделены от торса, все якоря узнаваемости и цвета палитры видны. Все шесть пунктов визуального CHECKLIST пройдены.

g1 не выбран: при визуальном осмотре у подставки была видна узкая полоса верхней поверхности, что нарушало пункт о строгом фронтальном ракурсе. Повтор сделан с неизменённым CORE и одной строкой CORRECTION только по этому пункту. Предыдущий кандидат и его собственный отчёт сохранены.

Автопроверки g1, g2 и финального выбранного дизайна: **код 0; 12 PASS, 1 WARN, 0 FAIL** в каждом прогоне. Финальный отчёт — design/checks-report.json. Что не удалось соблюсти: верхнее поле g2 равно **2,762% вместо 4%** (g1: 1,796%). Это разрешённый WARN view.frame_top; он не был поводом для ретрая и записан в verification.json. Низ подставки g2: 93,923%; центр по x: 49,724%. Незакрытых пунктов CHECKLIST нет, limit_reached пуст.

Мелкие решения: красный акцент размещён в крупных тёмных глазах с чёрными зрачками; костяной цвет использован для когтей и клыков. Спинной гребень читается по левому краю силуэта и продолжается на хвосте. Видны боковые стенки и фаски двух низких тёмных каменных дисков. Боковой и задний виды, внешняя приёмка и дальнейшие этапы не входят в эту задачу.

Каждая генерация сохранена без изменения байтов; оригинальные файлы image_gen оставлены на месте. Хеши входов совпали до и после работы. Исходный palette.json не изменён. Все записи и отчёты лежат в этом пакете, текстовые файлы записаны из Python в UTF-8 без BOM. Команды git, Unreal, Tripo и SYNTX не запускались, загрузок не было. manifest-sha256.json перечисляет все файлы пакета кроме себя.

Точные промпты и единственная коррекция: prompts.md и prompts/concept-prompts.json. Пути оригиналов, ссылки на референс и хеши результатов: generation-records.json. Проверки каждого кандидата: checks/design-front-g1/ и checks/design-front-g2/.
