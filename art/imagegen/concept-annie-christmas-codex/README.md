# Annie Christmas — фронтальный дизайн, этап 1a

Статус: **предложено**.

Выполнены две генерации image_gen из неизменённого CORE. Единственный вход изображения — эталон мастерства Medusa; палитра прочитана из palette.json. Новых видов и этапов 1b/1c нет.

Выбран **design-front g2**: `design/annie-christmas-front.png`. Фронтальная фигура с вертикальным шестом в собственной правой руке, красным платком, длинными бусами и закатанными рукавами. Руки отделены от корпуса. Подставка показана ребром, фон ровный. Итоговый скрипт: код **0**, 13 PASS, 0 WARN, 0 FAIL; все шесть пунктов CHECKLIST пройдены визуально.

g1 сохранена в concepts, но не выбрана: видны верхняя поверхность подставки и градиент фона. Скрипт g1: код 0, 12 PASS, 1 WARN, 0 FAIL. WARN view.frame_top (2,901%) разрешён и не был причиной повтора. Вторая генерация добавляет к тому же CORE только две строки CORRECTION для камеры/подставки и фона.

Использовано **2 из 2** разрешённых генераций. limit_reached пуст: после g2 проваленных пунктов CHECKLIST нет. Отклонение от CORE: низ подставки y95,925% вместо y93%, при полном сохранении объекта в кадре. Подставка центрирована x50%, верхняя точка y4,144%. Размер выбранного файла 1086 × 1448, точный аспект 3:4. Остальные ограничения оценки записаны в verification.json.

Мелкие решения: side_view = null, поскольку это единственный front; обе попытки относятся к режиму generate. Фасон юбки и распределение бус из g2 считаются предложением дизайна. Бусы бирюзовые и коричневые; природные тона кожи и приглушённые украшения не вводят новых сильных цветов. Новая генерация могла менять складки и положение поднятого края юбки; отдельного исправления или ретуши пикселей не было.

Оригиналы image_gen оставлены на месте. Каждый concepts-файл и выбранный design-файл скопированы побайтно; хеши сверены с оригиналами. Каждый кандидат имеет отдельный checks-report, финальный отчёт находится в design. Входные хеши до и после совпадают. palette.json сохранён без изменений. Запись пакета выполнялась Python в UTF-8 без BOM.

Команды git не выполнялись. Unreal, Tripo, SYNTX, загрузки и фоновые сервисы не запускались. `npx openskills read 3d-model-pipeline` завершился ENOTCACHED без загрузки; навык прочитан напрямую из локального SKILL.md. Изображение использует только два разрешённых входа задачи, а не карточку ассета.

Все пути и SHA-256 — в generation-records.json, source-hashes-before.json и verification.json. Финальный manifest-sha256.json включает каждый файл пакета, кроме самого манифеста.
