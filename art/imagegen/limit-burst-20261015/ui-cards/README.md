Дата: 2026-10-15. Статус: **предложено**. Четыре новых оригинальных raster source candidates; **не runtime-ready**.

Потребитель уже существует: `UmPortrait::Find` → `UmCardMedia::FindPortrait` по slug героя, портреты в PANEL, ROOM, LOBBY, загрузке и GAMEOVER. В просмотренном `S08CardMedia.json` было только пять portrait-ключей: King Arthur, Merlin, Medusa, Harpies, T. Rex. Ключей ниже нет. Все четыре героя подтверждены живым `/__art-hub/data` и `hero-links.json`; снимок в `art-hub-roster-snapshot.json`.

Это пробел собственного оригинального исходника и runtime key, **не отсутствие любого изображения**: коммерческий scrape для героя может существовать. Готовые MVP портреты не заменены; сканы карт, UI, SVG-значки и общие реестры не изменены. Постановки окружения и production sheets героев не входят в пакет.

Сделано встроенным `image_gen.imagegen`: 5 генераций, из них одна адресная правка кадрирования Ахиллеса. Ни CLI/API fallback, ни SYNTX/Tripo не использованы. Каждый исходник — неизменённая побайтовая копия tool output; фактический размер 1254×1254 RGB, несмотря на advisory 1024² в промпте. Оригиналы инструмента сохранены на месте. Exact prompts, local task-card, metadata лежат в каждой папке, полный журнал — `generation-records.json`.

До каждой генерации просмотрен соответствующий project design front. Все пять результатов открыты через `view_image`; выбранные четыре дополнительно просмотрены на [общем листе](review-sheet.png). Сравнение: project design, квадратный исходник, круг 100% в 160 px, серый 160 px, круг 80 px с увеличением ×2 nearest, диагностический круг 76%. Лица, оба глаза, одежда и характерные головные уборы сохранены, текста, рамок и UI нет. У Ахиллеса лицо меньше других из-за высокого гребня, но силуэт читается. У Робина круг может скрыть край колчана, второстепенную деталь.

**Ограничение кадрирования:** требование initial prompt о голове целиком в центральном круге 76% не выполнено у всех четырёх. Рекомендован круг полного исходника `cx=0.5, cy=0.5, d=1.0`; только этот вариант оценён как пригодный source candidate. Ни точный финальный crop, ни runtime appearance не приняты. g1 Ахиллеса отклонён: гребень обрезан верхом кадра; сохранён для истории. g2 восстановил полный гребень и верхний запас.

Фон визуально navy, точное равенство каждого пикселя `#061623` не заявляется; перекраски нет. Техническая проверка и саморевью — `verification.json`, `visual-review.json`. Все 12 входных файлов сохранили SHA-256; все 5 копий совпали с оригиналами инструмента. Диагностические thumbnails сделаны отдельным скриптом `_tools/build_review.py`, выбранные source PNG он не изменяет. `manifest-sha256.json` охватывает пакет.
