# Tara — original scholarly-caster reference

Tara подтверждена у Willow свежим read-only запросом живого Hero.sidekicks и сырым owner JSON: range, health 6, movement 2. Точного concept/card или alias не найдено. Создана оригинальная взрослая спокойная заклинательница с медово-светлыми волосами, синим кардиганом, кремовой блузой, коричневой юбкой и пустыми руками. Выбран g2 с подставкой ребром; ranged-роль оставлена для будущих эффектов, без нарисованного заклинания на исходнике.

Статус: **proposed-production-reference-only**. Вызовов встроенного image_gen: 2; выбранный/сохраняемый PNG: 1086×1448. Оригинал скопирован побайтно без ретуши, обрезки и ресайза.

Самопроверка 2026-10-15: PNG открыт исполнителем. Это не независимая приёмка пайплайна.

Ограничения:

- Оба кандидата: 12 PASS / 1 WARN / 0 FAIL; WARN view.frame_top сохранён. Выбранный g2: верх 2.762%, низ 95.649% вместо целевых >=4% / 93%.
- g1 показывает верх подставки; g2 убирает явный верхний эллипс, но строгая ортография камеры математически не подтверждена. Фон визуально почти ровный; полное равенство каждого пикселя не заявлено.
- На ассет выполнено ровно два вызова: исходный и одна коррекция фактического дефекта базы; у Drusilla той же коррекцией улучшались зазоры у рук. Дополнительных генераций не требуется в этом scope.
- Два front-кандидата не являются набором 1c. Нужны отдельные intake, независимая design acceptance и следующие гейты; 3D, риг, Tripo, анимация и UE не выполнялись.
- Возраст, лицо, волосы, костюм и украшение — делегированная оригинальная интерпретация, не канонический портрет и не копия актрисы.
- g2 изменил причёску и мелкие детали кардигана, сохранив основные anchors. Ладони пустые, без книги, посоха и baked-in magic FX.

Ни моделью, ни игровым ассетом, ни принятым rig-compatible результатом пакет не объявляется. Общие реестры, карточки существующих ассетов, ledger, Unreal и git не изменялись. Источники и точный промпт записаны рядом; хэши в `manifest-sha256.json`.
