# Faith — missing Angel sidekick, front design proposal

В реальных данных Angel имеет помощницу Faith (melee, health 8, movement 2), отдельного пакета фигуры не было. Создано два фронтальных кандидата оригинальной взрослой охотницы на вампиров. Для будущей модели выбран g2: удалена лишняя набедренная кобура и значительно выпрямлена проекция подставки. Это предложенный дизайн, не утверждённый этап 1a. Существующие источники, принятые герои и пайплайн не изменялись.

Статус: **proposed-awaiting-independent-acceptance**. Вызовов встроенного image_gen: 2; выбранный/сохраняемый PNG: 1086×1448. Оригинал скопирован побайтно без ретуши, обрезки и ресайза.

Самопроверка 2026-10-15: PNG открыт исполнителем. Это не независимая приёмка пайплайна.

Ограничения:

- Строгая рамка не выдержана: верх волос g2 1.519% вместо не менее 4%; низ подставки ниже цели y93%. Оба чекера: 12 PASS / 1 WARN / 0 FAIL.
- Проекция подставки намного лучше g1, но тонкая верхняя кромка всё ещё различима; независимый приёмщик решает пригодность.
- В отправленные prompt g1/g2 ошибочно попал хвост внешней инструкции шаблона Wiglaf, в том числе checklist axe/boar shield/helmet. Фактические SUBJECT, ANCHORS и PALETTE были Faith и изображение им соответствует. Точные отправленные prompts сохранены неизменно; prompts/future-core-clean.txt — исправленный чистый CORE только для будущего использования, он не выдаётся за уже отправленный промпт.
- Источник подтверждает имя/роль/механику Faith, но не её одежду и оружие: костюм и один деревянный кол выбраны по делегированию как оригинальный дизайн. Ни актёрский портрет, ни игровой аватар не использованы.
- Поза g1 и детали одежды отличаются от g2; это два кандидата одного front, не согласованный набор видов 1c. Трата Tripo, риг, 3D и UE не выполнялись.

Ни моделью, ни игровым ассетом, ни принятым rig-compatible результатом пакет не объявляется. Общие реестры, карточки существующих ассетов, ledger, Unreal и git не изменялись. Источники и точный промпт записаны рядом; хэши в `manifest-sha256.json`.
