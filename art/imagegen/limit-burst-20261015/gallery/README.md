# Каталог текущей очереди

`index.html` — автономная HTML-галерея. Основной способ просмотра: открыть сохранённый локальный файл в обычном браузере пользователя. Установка зависимостей, сборщик, новая служба и подключение к сети не требуются. JSON встроен в HTML: локальному файлу не нужен fetch.

Пересборка из корня репозитория:

```powershell
python art/imagegen/limit-burst-20261015/gallery/build_gallery.py
```

Генератор обнаруживает `review/independent-review-index.json` и существующие каталоги `review-waveN` с числовым N ≥ 2, сортирует их по номеру и читает только замороженные индексы. Верхняя граница волн не задана: после freeze `review-wave9`, `review-wave10` и следующих достаточно повторить команду. У существующего каталога без индекса или без freeze появляется pending-запись; будущие неназначенные волны не выдумываются. SHA каждого PNG сверяется с индексом. Несовпадение или отсутствующий файл не превращаются в картинку-заглушку: запись исключается, ошибка сохраняется, код завершения 1.

Формальные карточки 1c Patroclus/Wiglaf/Sherlock Holmes/Dr. Watson читаются отдельно. Показываются реальные три вида из `accepted_object`, их SHA, оценка и ограничения. Наличие `accepted_object` само по себе не означает pass: Wiglaf остаётся возвращённым на этап 1. Ни один formal pass не расширяется до модели/рига/анимации/runtime.

`blocked_outputs` берутся из каждого замороженного индекса. Geralt и четыре отказа CP-34 показаны текстом: `images: []`, без SHA изображения, PNG-ссылки или превью. Путь реальной ошибки проверяется; её SHA сверяется с ревью, когда он указан. Одна blocked-запись на asset: более поздний замороженный индекс заменяет прежнюю запись того же asset. Заблокированная запись с фактическим выходным PNG вызывает ошибку сборки. Источники и blocked-карточки никогда не наследуют formal pass концепта.

Портреты/референсы имеют ссылки на ближайший README автора, независимое ревью и PNG. Весь кадр показан с `object-fit: contain`, без обрезки и изменения исходников. Поиск охватывает русское имя, ключ и текст ревью; фильтры — тип, статус и партия. В подробном просмотре доступны ограничения, полный SHA и все виды формального листа.

Для `file://` изображения и ссылки используют `../../../../` + repo path. HTTP-вариант URL изображений подготовлен как `/__art-hub/file?path=` с URL-encoded repo path, но сам HTML существующий ArtHub на5480 отдаёт с `Content-Type: text/plain`; его `/@fs` отклоняет запрос403. Эти настройки не менялись. Просмотр локального HTML через управляемый браузер также отклонён политикой разрешённых протоколов; обход не предпринимался. Автоматического браузерного прогона UI не было. Каталог не запускает новую службу.

Выходы: `gallery-data.json`, `index.html`, `verification.json`, `input-hashes.json`, `manifest-sha256.json`. Парсер проверяет JSON/HTML и баланс тегов, inline JSON, уникальные ID, соответствие картинок карточкам, отсутствие пустых image sources и PNG-ссылок у blocked-карточек, реальные пути/хэши и отсутствие изменений прочитанных источников. При наличии локального Node выполняется только `node --check` inline JavaScript. GUI/браузер, сеть и runtime не проверяются. Все записи генератора — только в этом gallery/.
