# Каталог текущей очереди

`index.html` — автономная HTML-галерея. Основной способ просмотра: открыть сохранённый локальный файл в обычном браузере пользователя. Установка зависимостей, сборщик, новая служба и подключение к сети не требуются. JSON встроен в HTML: локальному файлу не нужен fetch.

Пересборка из корня репозитория:

```powershell
python art/imagegen/limit-burst-20261015/gallery/build_gallery.py
```

Генератор читает только замороженные `review/independent-review-index.json`, `review-wave2` … `review-wave7`. Отсутствующие и незамороженные волны перечисляются в данных и проверке; после их freeze повторная команда включит фактические записи. SHA каждого PNG сверяется с индексом. Несовпадение или отсутствующий файл не превращаются в картинку-заглушку: запись исключается, ошибка сохраняется, код завершения 1.

Формальные карточки 1c Patroclus/Wiglaf/Sherlock Holmes/Dr. Watson читаются отдельно. Показываются реальные три вида из `accepted_object`, их SHA, оценка и ограничения. Наличие `accepted_object` само по себе не означает pass: Wiglaf остаётся возвращённым на этап 1. Ни один formal pass не расширяется до модели/рига/анимации/runtime. Geralt с фактическим `moderation_blocked` показывается только текстом без изображения.

Портреты/референсы имеют ссылки на ближайший README автора, независимое ревью и PNG. Весь кадр показан с `object-fit: contain`, без обрезки и изменения исходников. Поиск охватывает русское имя, ключ и текст ревью; фильтры — тип, статус и партия. В подробном просмотре доступны ограничения, полный SHA и все виды формального листа.

Для `file://` изображения и ссылки используют `../../../../` + repo path. HTTP-вариант URL изображений подготовлен как `/__art-hub/file?path=` с URL-encoded repo path, но сам HTML существующий ArtHub на5480 отдаёт с `Content-Type: text/plain`; его `/@fs` отклоняет запрос403. Эти настройки не менялись. Просмотр локального HTML через управляемый браузер также отклонён политикой разрешённых протоколов; обход не предпринимался. Автоматического браузерного прогона UI не было. Каталог не запускает новую службу.

Выходы: `gallery-data.json`, `index.html`, `verification.json`, `input-hashes.json`, `manifest-sha256.json`. Парсер проверяет JSON/HTML и баланс тегов, inline JSON, реальные пути/хэши и отсутствие изменений прочитанных источников. При наличии локального Node выполняется только `node --check` inline JavaScript. GUI/браузер, сеть и runtime не проверяются. Все записи генератора — только в этом gallery/.
