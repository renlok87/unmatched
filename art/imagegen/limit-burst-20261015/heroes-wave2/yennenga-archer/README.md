# Yennenga Archers — one original representative reference

У Yennenga живой Hero.sidekicks и сырой owner JSON содержат двух одинаковых Archers: range, health 2, movement 2 каждый. GameInitializationService разбирает этот список, создаёт бойцов с их именами и нормализованными attack types. Готового пакета или remap в hero-links не обнаружено. Создан один оригинальный репрезентативный лучник для будущего использования двумя равноценными фишками; не две разные фигуры. Выбран g2 с проекцией базы ребром, лук слева у персонажа, колчан справа.

Статус: **proposed-production-reference-only**. Вызовов встроенного image_gen: 2; выбранный/сохраняемый PNG: 1086×1448. Оригинал скопирован побайтно без ретуши, обрезки и ресайза.

Самопроверка 2026-10-15: PNG открыт исполнителем. Это не независимая приёмка пайплайна.

Ограничения:

- Оба кандидата: 12 PASS / 1 WARN / 0 FAIL; WARN view.frame_top сохранён. Выбранный g2: верх 3.936%, низ 94.13% вместо целевых >=4% / 93%.
- g1 показывает верх подставки; g2 убирает явный верхний эллипс, но строгая ортография камеры математически не подтверждена. Фон визуально почти ровный, полное равенство каждого пикселя не заявлено.
- Два front-кандидата не являются набором 1c. Нужны отдельные intake, независимая design acceptance и следующие гейты; 3D, риг, Tripo, анимация и UE не выполнялись.
- Один archetype для двух runtime Archers; командные кольца, нумерация или baked-in team colours не добавлены.
- Пол, одежда и декоративные полосы — оригинальное решение; историческая точность конкретной одежды или совпадение со сканом жетона не заявляются.
- Тетива тонкая: масштабирование будущей модели требует отдельного контроля; референс не доказывает её пригодность после image-to-3D.

Ни моделью, ни игровым ассетом, ни принятым rig-compatible результатом пакет не объявляется. Общие реестры, карточки существующих ассетов, ledger, Unreal и git не изменялись. Источники и точный промпт записаны рядом; хэши в `manifest-sha256.json`.
