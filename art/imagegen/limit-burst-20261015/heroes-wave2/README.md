# Helpers, wave 2 — production references, 2026-10-15

Три новых оригинальных 2D-референса для реально отсутствовавших помощников. На каждого выполнены один основной вызов и одна корректировка по наблюдаемому дефекту; всего шесть встроенных вызовов image_gen. Для будущего обсуждения выбраны g2; все g1 сохранены. Ни один пакет не объявлен принятым 1a/1c, 3D-моделью или готовым игровым ассетом.

| Пакет | Реальный потребитель | Механика из текущей БД | Выбранный файл |
|---|---|---|---|
| `charlie/` | Annie Christmas → Charlie | range, health 8, move 2 | `design/charlie-front.png` |
| `dr-malcolm/` | Dr. Sattler → Dr. Malcolm | melee, health 7, move 2 | `design/dr-malcolm-front.png` |
| `yennenga-archer/` | Yennenga → Archers ×2 | range, health 2, move 2 каждый | `design/yennenga-archer-front.png` |

Связи проверены заново прямым read-only запросом `Hero.name` и `Hero.sidekicks` к уже работавшему PostgreSQL. Обезличенный снимок без avatar URLs: `live-roster-evidence.json`. Все три связи совпадают с `scraped-data/api/heroes/<owner>.json`. `GameInitializationService` разбирает и создаёт sidekick-бойцов с этими именами и attack types. Готовых exact-concept пакетов в `art/imagegen` / `art/pipeline-candidates` и remap в `hero-links.json` на момент проверки не найдено. Спорные связи из иных fixtures не использованы.

Одежда, возраст, пол и инструменты там, где источник их не задаёт, — оригинальные решения по делегированию. Charlie показан взрослым речным помощником с одним старинным пистолетом как авторской интерпретацией ranged-роли. Malcolm — оригинальный научный советник в очках, без актёрского портрета. Один Archer представляет два равноценных runtime-помощника Yennenga; его одежда не заявлена исторической реконструкцией. Перед генерацией осмотрены существующие оригинальные owner concepts; генератору передавался только наш референс качества Medusa. Фотографии, аватары, сканы карт, коммерческие игровые кадры не использованы.

У g1 всех троих был виден верхний эллипс подставки; у Charlie дополнительно был повёрнут взгляд/голова. В g2 база визуально стала ребром, у Charlie исправлена фронтальность. Каждый из шести checker-запусков дал **12 PASS / 1 WARN / 0 FAIL**. Сохранён WARN рамки: верх g2 Charlie 2.555%, Malcolm 3.660%, Archer 3.936% при минимуме 4%. Низ выбранных кадров 95.373%, 95.994%, 94.130% вместо цели 93%. Полная ортография камеры математически не подтверждена; это самопроверка 2D-референсов.

У каждого пакета есть exact prompts, generation records, source hashes before/after, self-review, verification и manifest. Вызовы используют чистый CORE без чужих служебных инструкций; это проверяется в `verification.json`. PNG сохранены побайтно, без ретуши, ресайза, кропа и перекодирования. Один кадр 1086×1448. Все результаты остаются `proposed-production-reference-only`; формальный intake, независимая приёмка и следующие 3D-гейты ещё нужны.

Первая папка `heroes/` оставлена frozen: из неё только прочитан чистый шаблон и скопирован локальный finalize-скрипт в эту новую папку. Общие реестры, ledger, git, исходники и Unreal не менялись. Новых сервисов или долгоживущих процессов этот исполнитель не запускал. `ledger-handoff.json` — только входные данные для координатора; это не запись в общий журнал.
