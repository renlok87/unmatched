# Giles — missing Buffy helper, original reference candidate

Giles подтверждён у Buffy в живой БД и scraped owner JSON: melee, health 6, movement 3; отдельного пакета фигуры нет. Создан оригинальный фронт зрелого академического наставника: очки, твид, оливковый жилет, пустые руки. Это кандидат референса будущей фигуры; он не начинает полный 3D-пайплайн и не подменяет канонический игровой аватар.

Статус: **proposed-reference-only**. Вызовов встроенного image_gen: 1; выбранный/сохраняемый PNG: 1086×1448. Оригинал скопирован побайтно без ретуши, обрезки и ресайза.

Самопроверка 2026-10-15: PNG открыт исполнителем. Это не независимая приёмка пайплайна.

Ограничения:

- Скрипт: 12 PASS / 1 WARN / 0 FAIL; верх волос 3.522% при требовании не менее 4%.
- Верхняя поверхность подставки узкой полосой видна: точная ортопроекция не заявляется пройденной.
- Источник подтверждает имя/роль/механику, но не внешность. Очки, одежда и добавленная генератором короткая седая борода — оригинальная интерпретация; сходство с конкретным актёром не запрашивалось.
- Референс требует регистрации intake, независимой приёмки и отдельного согласованного набора видов перед любым 3D.

Ни моделью, ни игровым ассетом, ни принятым rig-compatible результатом пакет не объявляется. Общие реестры, карточки существующих ассетов, ledger, Unreal и git не изменялись. Источники и точный промпт записаны рядом; хэши в `manifest-sha256.json`.
