# Daisy — missing Jill Trent helper, original reference candidate

Daisy подтверждена у Dr. Jill Trent в живой БД и scraped owner JSON: melee, health 6, movement 2; пакета фигуры не было. Созданы два кандидата оригинальной полевой помощницы-техника в духе научного приключения 1940-х. Выбран g2: ключ отделён от бедра фоновым зазором и подставка стала ближе к проекции ребром. Силуэт в комбинезоне отличается от уже существующего дизайна Jill в лабораторном халате и платье.

Статус: **proposed-reference-only**. Вызовов встроенного image_gen: 2; выбранный/сохраняемый PNG: 1086×1448. Оригинал скопирован побайтно без ретуши, обрезки и ресайза.

Самопроверка 2026-10-15: PNG открыт исполнителем. Это не независимая приёмка пайплайна.

Ограничения:

- g1: 12 PASS / 1 WARN / 0 FAIL; верх 2.693%. g2: 11 PASS / 2 WARN / 0 FAIL; верх 3.315% и view.single_component WARN. Визуально это одна фигура; автоматическое разбиение компонент не выдано за PASS.
- Тонкая верхняя кромка подставки остаётся видимой; строгая ортопроекция ещё требует решения независимого приёмщика.
- Костюм, прическа и инструмент — оригинальная интерпретация роли по делегированию. Данные подтверждают Daisy и её механику, но не такой точный вид или ключ; скан/аватар не копировался.
- Есть только два альтернативных front-кандидата, не набор 1c. Формальный pipeline, модель, риг, Tripo и UE не запускались.

Ни моделью, ни игровым ассетом, ни принятым rig-compatible результатом пакет не объявляется. Общие реестры, карточки существующих ассетов, ledger, Unreal и git не изменялись. Источники и точный промпт записаны рядом; хэши в `manifest-sha256.json`.
