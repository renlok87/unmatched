# Wolf — exploratory quadruped production reference

В ростере и живой БД у Ancient Leshen есть два помощника Wolf; пакет фигуры отсутствует. Создан оригинальный нейтральный профиль лесного волка как 2D-источник для будущего обсуждения анатомии. Имя, количество и механика подтверждены локальными данными; цвет и скульптурный дизайн выбраны по делегированию. Сканы и аватары не использовались.

Статус: **proposed-reference-only**. Вызовов встроенного image_gen: 1; выбранный/сохраняемый PNG: 1448×1086. Оригинал скопирован побайтно без ретуши, обрезки и ресайза.

Самопроверка 2026-10-15: PNG открыт исполнителем. Это не независимая приёмка пайплайна.

Ограничения:

- Четвероногая анатомия: rig-contract/3 не принят; формальный этап 0 и следующие этапы не выполнялись.
- Это полезный одиночный профиль для будущего model brief, не комплект видов 1c и не основание тратить Tripo.
- Видна тонкая верхняя кромка подставки. Некоторые пряди гривы острые: при будущем моделировании понадобится контроль силуэта.
- Точный вид оригинального игрового жетона не воспроизводился; это самостоятельный визуальный дизайн по имени/роли из данных.

Ни моделью, ни игровым ассетом, ни принятым rig-compatible результатом пакет не объявляется. Общие реестры, карточки существующих ассетов, ledger, Unreal и git не изменялись. Источники и точный промпт записаны рядом; хэши в `manifest-sha256.json`.
