# The Porter — концепт 1a

Статус: **предложено**.

Создан один фронтальный дизайн коллекционной окрашенной миниатюры The Porter. Выбрана **design-front g2**: подставка показана строго ребром, фон ровный, обе руки отделены от корпуса, дубинка находится в собственной правой руке (слева для зрителя), корзина и головной платок хорошо читаются. Финальный файл: `design/the-porter-front.png`, 1086 × 1448, аспект 3:4.

Использовано **2 из 2** разрешённых генераций image_gen. Обе автоматические проверки кандидатов и финальная проверка выбранного дизайна завершились кодом 0: 13 PASS, 0 WARN, 0 FAIL. Визуальный чек-лист выбранной g2: 6/6.

В g1 не выполнены два визуальных требования: видна верхняя поверхность подставки, фон имеет слабый градиент. Скрипт этих нарушений не обнаружил. В g2 добавлена только двухстрочная CORRECTION к неизменному CORE; оба нарушения исправлены. Повторных генераций из-за WARN или тонких деталей не было.

Небольшие решения: корзина выступает над плечами и по бокам, чтобы оставаться узнаваемой спереди; кремовая одежда и обмотки поддерживают палитру; красный платок служит акцентом, а не цветом команды. Изображение g2 заново синтезировано по тому же эталону мастерства: изменились лицо, заплаты, свёртки и положение дубинки. Эти вариации документированы, исходные PNG не редактировались.

Ограничения: это только дизайн-front этапа 1a; согласованность с боковым и задним видами не проверялась. Нулевую перспективу можно оценить визуально, но параметры камеры из PNG не доказать. Диаметр подставки визуально около 0,67 высоты фигуры вместо ориентировочных 0,55 из CORE; два низких диска и прямые края соблюдены. Это отклонение отмечено в verification.json для приёмщика и не является отдельным пунктом заданного CHECKLIST.

Входы — только эталон качества Medusa и palette.json. Их SHA-256 до и после совпадают. Оба результата скопированы побайтно в concepts/; оригиналы image_gen оставлены на месте и указаны в generation-records.json. Существовавший palette.json сохранён без изменений. Все записи пакета выполнены Python в UTF-8 без BOM. Изменений файлов репозитория за пределами пакета нет; копии, которые сохраняет сам image_gen вне репозитория, разрешены контрактом.

README, точные промпты, журнал каждой генерации, все три отчёта проверок, verification.json и manifest-sha256.json включены в пакет.
