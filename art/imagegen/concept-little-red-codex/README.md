# Красная Шапочка — дизайн-front, этап 1a

Дата: 2026-10-13. Карточка: ASSET-LITTLE-RED-001. Статус: **предложено**.

Создан один фронтальный дизайн коллекционной расписной миниатюры. Использованы только эталон мастерства Medusa и palette.json из задания. Эталон подан как единственное изображение в каждом вызове image_gen. Карточка, коммерческие изображения и другие ассеты не открывались.

Выбрана **design-front g2**: `design/little-red-front.png` — побайтовая копия `concepts/little-red-design-front-g2.png`, 1086 × 1448, точный аспект 3:4. Израсходовано **2 из 2** разрешённых генераций.

## Выбор и неудачи

- g1: автопроверка завершилась кодом 0 (12 PASS, 1 WARN). При визуальном осмотре видна верхняя поверхность подставки; фон имеет небольшую неоднородность. Поэтому выполнен разрешённый ретрай с двумя строками CORRECTION, без изменения CORE.
- g2: верх подставки скрыт, её края горизонтальны, фон ровнее. Все шесть пунктов CHECKLIST визуально пройдены. Топор находится в собственной правой руке (слева для зрителя), корзина на левом предплечье. Детали капюшона, фартука, шнуровки и лозы читаются.
- Финальный скрипт: **код 0, 11 PASS, 2 WARN, 0 FAIL**. WARN `view.frame_top`: верх на y=3,729%, чуть выше требуемых 4%. WARN `view.single_component`: сегментация нашла дополнительную компоненту 1,89%; глазами второго предмета или фигуры нет.
- Точное размещение CORE не достигнуто: низ подставки y=94,613% вместо 93%, центр x=49,217% вместо 50%. Эти отклонения записаны в verification.json. Они не скрыты и не исправлялись ретушью.
- Неустранённых нарушений CHECKLIST у выбранного g2 нет; `limit_reached` пуст. WARN не были поводом для повторной генерации.

## Небольшие решения

Нейтральный металл топора и естественный цвет кожи считаются материалами, а не дополнительными сильными цветами палитры. Золотистая лоза — акцент; командных цветов нет. Круглая подставка показана строго с ребра: её контур выглядит как два горизонтальных профиля. Светлая тонкая линия по краю — фаска, не открытая верхняя плоскость и не металлический обод. Слабый шум фона допустим при визуально ровном тоне; идеальная попиксельная заливка не заявляется.

Обе генерации сохранены без изменений; оригиналы image_gen оставлены на месте. Пути оригиналов, копий, хеши и размеры указаны в generation-records.json. Кандидаты проверены каждый в своём checks/design-front-gN, затем выбранный дизайн проверен отдельно в design/checks-report.json.

Входные SHA-256 до и после совпали. Все управляемые записи выполнены только в этом пакете, текст — Python, UTF-8 без BOM. Внешние автоматические копии image_gen являются предусмотренным заданием исключением. Git, Unreal, Tripo, SYNTX и загрузки не использовались; npm-openskills не запустился из-за отсутствия локального кэша, навык прочитан непосредственно из .agents/skills. Пакет передаётся Claude для внешней приёмки и коммита.
