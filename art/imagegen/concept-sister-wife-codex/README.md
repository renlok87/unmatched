# ASSET-SISTER-WIFE-001 — фронтальный дизайн 1a

Дата: 2026-10-13. Статус: **предложено**.

Создан один фронтальный дизайн оригинальной коллекционной миниатюры невесты-вампира. Единственный графический вход — референс качества Medusa; палитра прочитана отдельно. Выполнены две генерации image_gen, каждая — одно изображение 1086 × 1448. CORE передан дословно. В g2 добавлена одна строка CORRECTION.

Выбрана **design-front g2**: подставка показана с ребра, без видимой верхней поверхности и с горизонтальными передними краями. Все шесть пунктов визуального чек-листа выполнены. Выбранная копия: `design/sister-wife-front.png`. Сырые g1 и g2 сохранены в `concepts/` без изменений, копии инструмента оставлены на исходных местах.

У g1 не выполнен пункт о строгом виде подставки: виден узкий верхний эллипс, передний край изогнут. Это единственное основание для повторной попытки. У g2 финальный скрипт завершился с кодом **0**: 11 PASS, 2 WARN, 0 FAIL.

Ограничения: верх маски находится на y2,210% вместо y≥4%; низ — на y97,099% вместо y93%. WARN `view.frame_top` допустим и не служил поводом для повтора. WARN `view.single_component` относится к сегментации маски; визуально есть одна фигура на одной подставке. Изображения не исправлялись. Подробности внесены в `verification.json`; `limit_reached` пуст, поскольку выбранный кандидат проходит чек-лист.

Малые решения: у выбранной генерации сохранены корона, рваная фата, красные розы и приглушённые украшения как детали образа невесты. Красный остаётся единственным сильным цветовым акцентом. Эти детали отличаются от g1; постоянство между самостоятельными вариантами 1a не заявляется. Проверка перспективы и позы визуальная; точные параметры виртуальной камеры неизвестны.

Все три запуска проверки перечислены в `verification.json`. Входные SHA-256 совпадают до и после; палитра сохранена без изменений. Новые текстовые файлы записаны Python в UTF-8 без BOM. Git-команды не выполнялись. Изменения агента ограничены этой папкой; процессы и сервисы для дальнейшей работы не оставлены.
