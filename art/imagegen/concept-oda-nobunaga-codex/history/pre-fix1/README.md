# Oda Nobunaga — концепт 1a
Дата: 2026-10-13. Статус: **предложено**.

Создан фронтальный концепт миниатюры встроенным image_gen. Генераций: 2 из 2, обе 1086 × 1448 (3:4). Единственный вход изображения — Medusa как референс качества; палитра прочитана отдельно. Виды 1c не создавались.

Выбран **design-front g2**: `design/oda-nobunaga-front.png`, побайтная копия `concepts/oda-nobunaga-design-front-g2.png`. У g2 подставка показана строго с ребра, горизонтальные кромки прямые, фон ровнее. Обе генерации и оригиналы инструмента сохранены без ретуши, масштабирования и перекодирования.

У g1 визуально не прошли пункты о подставке с ребра и ровном фоне. Повтор сделан с неизменным CORE и двумя строками CORRECTION только по этим пунктам. WARN верхнего отступа причиной повтора не был.

Все три запуска check_concept_views.py дали код 0: 12 PASS, 1 WARN, 0 FAIL. Индивидуальные отчёты — в checks/design-front-g1 и checks/design-front-g2; финальный — design/checks-report.json. Все шесть пунктов CHECKLIST выбранного g2 оценены визуально с пояснениями в verification.json.

Ограничения CORE: верх полумесяца g2 на y2,21% вместо минимум 4% (WARN view.frame_top); в ножнах на левом бедре изображена дополнительная рукоять, которая может читаться как второе оружие, запрещённое CORE. У g1 также есть дополнительная рукоять. Эти ограничения оставлены для решения приёмщика. Лимит 2 генераций использован; непрошедших пунктов CHECKLIST у выбранного g2 нет, поэтому limit_reached пуст.

Малые решения: цветочные рельефы считаются декоративным орнаментом, а не коммерческими логотипами. Промежутки между руками и торсом видны с плащом позади; через плащ фон не просматривается. Ортографичность оценена визуально: параметры камеры генератора недоступны. Точные HEX служат ориентиром, оттенки меняются от освещения.

Хеши обоих входов до и после совпадают. Команды писали только внутри пакета; внешние оригиналы image_gen — предусмотренное заданием исключение. Git, Unreal, Tripo, SYNTX и загрузки не использовались.
