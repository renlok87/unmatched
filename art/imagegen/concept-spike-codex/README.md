# ASSET-SPIKE-001 — дизайн фронтального вида, этап 1a

Дата: 2026-10-13. Статус: **предложено**.

Созданы два независимых фронтальных концепта коллекционной миниатюры Spike через встроенный image_gen. Каждая генерация использовала только референс мастерства Medusa; palette.json задавал цвета текстом CORE. Оба результата имеют размер 1086 × 1448 пикселей (3:4). Исходные PNG сохранены побайтно; ретушь, обрезка, изменение размера, перекраска и пересохранение не выполнялись.

## Выбранный вариант

Для вида design-front выбран **g2**: art/imagegen/concept-spike-codex/concepts/spike-design-front-g2.png. Его побайтовая копия для приёмщика — art/imagegen/concept-spike-codex/design/spike-front.png.

В g2 подставка показана строго ребром: верхняя плоскость скрыта, передние кромки горизонтальны. Видны все четыре якоря идентичности и пустые руки, отделённые от корпуса. Все шесть пунктов визуального CHECKLIST пройдены. Это предложение дизайна для внешней приёмки.

## Проверки и ограничения

- g1: код скрипта 0, PASS 12 / WARN 1 / FAIL 0. При визуальной проверке не пройден пункт строгого фронтального ортографического вида: видна верхняя поверхность подставки.
- g2: код скрипта 0, PASS 12 / WARN 1 / FAIL 0; визуальный CHECKLIST пройден.
- Финальная проверка выбранного g2 без --out: код 0, PASS 12 / WARN 1 / FAIL 0; отчёт art/imagegen/concept-spike-codex/design/checks-report.json.
- Не достигнут отступ сверху не менее 4%: у g1 — 1,312%, у g2 — 2,762%. Это разрешённый WARN view.frame_top. Фигура не обрезана; предупреждение не было причиной повтора.
- Потрачены 2 генерации из 2. Повтор вызван только визуальным дефектом подставки g1. У выбранного g2 нет проваленных пунктов CHECKLIST, поэтому limit_reached пуст.
- Метаданные камеры генератор не предоставляет: строгий фронтальный вид оценён визуально.
- Системный запрос списка процессов через Win32_Process отклонён правами среды. Все запущенные командные сессии завершились; постоянные службы или фоновые процессы для задачи не запускались.

## Небольшие решения

Красная рубашка раскрыта поверх чёрной футболки и под длинным кожаным плащом, чтобы оба слоя читались. Для моделирования сохранена нейтральная стойка с пустыми руками и просветами у корпуса. Во второй вызов передан неизменённый CORE и одна строка CORRECTION только о фронтальной ортографии и подставке. Дополнительные ракурсы не создавались.

Хеши обоих входов до и после совпали. palette.json сохранён без изменений. Записи команд и отчёты лежат в пакете; штатные оригиналы image_gen оставлены по путям original_path из generation-records.json. manifest-sha256.json записан последним и содержит размеры и SHA-256 всех остальных файлов пакета.
