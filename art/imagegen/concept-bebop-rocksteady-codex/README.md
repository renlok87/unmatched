# ASSET-BEBOP-ROCKSTEADY-001 — концепт 1a

Дата: 2026-10-13. Статус: **предложено**.

Создан фронтальный дизайн одной коллекционной миниатюры Бибопа для image-to-3D. SUBJECT задания определяет одну фигуру Бибопа.

**Выбран design-front g2.** Подставка показана ребром с горизонтальными кромками; верхняя плоскость не видна. Все якоря, палитра и правый хват бластера сохранены. Финальный файл: `design/bebop-rocksteady-front.png`, побайтная копия `concepts/bebop-rocksteady-design-front-g2.png`.

Использовано **2 генерации из 2**. Финальный скрипт: **код 0; PASS 13, WARN 0, FAIL 0**. Все шесть пунктов CHECKLIST пройдены по визуальному осмотру. `limit_reached` пуст.

В g1 видна верхняя плоскость подставки и эллиптическая кромка: пункт строгого фронтального ортографического вида не выполнен. Повтор вызван этим пунктом. Допустимый WARN `view.frame_top` (верх 2,417%) причиной повтора не был.

Ограничения CORE в g2: низ подставки y94,682% вместо 93%, центр x49,816% вместо 50%; подставка шире ориентира (приблизительно 0,719 роста по маске, ориентир 0,55). Верх фигуры y7,113% соблюдает минимум 4%. Эти отклонения рамки и пропорций записаны в `verification.json#limitations`; пиксели не правились.

Мелкие решения: `side_view = null`, поскольку в 1a есть только фронт; нумерация начата с g1, так как до запуска в пакете был только `palette.json`. Генератор выбрал 1086 × 1448, точно 3:4. Ортографичность оценена визуально; параметры камеры из PNG не извлекаются. Межвидовая согласованность остаётся для 1c.

Единственный визуальный вход — `art/imagegen/hero-quality-v1/reference/medusa-quality-reference.png` как эталон мастерства. Палитра прочитана из `palette.json`. Хеши обоих входов до/после равны хешам задания. PNG обоих кандидатов и выбранного дизайна побайтно равны выходам image_gen. Оригиналы оставлены по адресам `original_path` в журнале.

Перед проверкой g2 команда копирования остановилась из-за передачи кавычек в Python через PowerShell. Следующий скрипт с кодом 0 фактически проверил ещё g1. Его отчёт сохранён как checks/design-front-g2/stale-input-report.json и отдельно учтён в verification.json. Затем g2 побайтно скопирован, проверен в собственном каталоге и финальным прогоном. Ошибка устранена; дополнительных генераций не было.

Пакет содержит точные промпты, журнал генераций, все четыре отчёта прогонов скрипта, визуальный чек-лист и SHA256-манифест. JSON и Markdown записаны Python в UTF-8 без BOM. Команды выполнены из корня репозитория. Все наши записи направлены в пакет; собственные оригиналы image_gen вне пакета — явное исключение контракта. Git не вызывался; unreal/ не открывался.
